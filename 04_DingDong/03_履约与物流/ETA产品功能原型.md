## 2. 订单状态机

### 2.1 状态定义

| 状态码 | 状态名 | 说明 | ETA 行为 |
|-------|--------|------|---------|
| S0 | CREATED | 订单已创建 | 计算初始 ETA |
| S1 | ACCEPTED | 仓内已接单 | ETA 不变 |
| S2 | PICKING | 分拣中 | 根据分拣进度更新 ETA |
| S3 | PACKING | 打包中 | ETA 收敛 |
| S4 | PACKED | 已打包出库 | ETA 更新（去除仓内不确定性） |
| S5 | RIDER_ASSIGNED | 骑手已接单 | 根据骑手位置更新 ETA |
| S6 | RIDER_PICKING | 骑手取货中 | ETA 收敛 |
| S7 | DELIVERING | 骑手配送中 | 实时更新 ETA |
| S8 | DELIVERED | 已送达 | ETA 结束 |
| S9 | CANCELLED | 已取消 | ETA 终止 |
| SE | EXCEPTION | 异常 | 触发异常处理流程 |

### 2.3 状态转换规则

| 当前状态 | 触发事件 | 目标状态 | ETA 动作 | 通知用户 |
|---------|---------|---------|---------|---------|
| S0 | 仓内接单 | S1 | 保持 | 否 |
| S1 | 开始分拣 | S2 | 重新计算仓内时间 | 否 |
| S2 | 分拣完成 | S3 | 收敛仓内时间 | 否 |
| S3 | 打包完成 | S4 | 更新 ETA（去除仓内段） | 否 |
| S4 | 骑手接单 | S5 | 根据骑手 GPS 更新配送时间 | 否 |
| S5 | 骑手到仓取货 | S6 | 收敛取货时间 | 否 |
| S6 | 取货完成出发 | S7 | 更新 ETA（仅剩配送段） | 是：骑手已出发 |
| S7 | GPS 更新 | S7 | 实时更新 ETA | 否（仅变更 >3min 时通知） |
| S7 | 送达 | S8 | 结束 | 是：已送达 |
| 任意 | 用户取消 | S9 | 终止 | 是：已取消 |
| 任意 | 超时/异常 | SE | 触发异常处理 | 是：异常通知 |

## 3. 异常处理机制

### 3.1 异常分类

| 异常类型 | 触发条件 | 影响范围 | 严重等级 |
|---------|---------|---------|---------|
| 仓内超时 | 分拣时间 > 20min 或打包时间 > 8min | ETA 仓内段 | P1 |
| 运力不足 | 无可用骑手 > 5min | ETA 配送段 | P0 |
| 骑手异常 | 骑手 GPS 静止 > 10min | ETA 配送段 | P1 |
| 天气极端 | 暴雨/暴雪/极端高温 | 全链路 ETA | P1 |
| 仓内故障 | 设备故障/断电 | 全链路 ETA | P0 |
| 地址异常 | 地址无法解析/超出配送范围 | 订单 | P0 |

### 3.2 异常处理流程

```
异常检测 → 异常分类 → 影响评估 → 处理策略 → 用户通知 → 结果记录
    │           │           │           │           │           │
    ▼           ▼           ▼           ▼           ▼           ▼
 规则引擎    自动分类    ETA 重算    分级处理    推送/短信    日志+指标
```

### 3.3 异常处理策略矩阵

| 异常类型 | 处理策略 | ETA 调整 | 用户通知 | 补偿 |
|---------|---------|---------|---------|------|
| 仓内超时(轻) | 仓内主管介入 | ETA +5~10min | 推送："拣货中，稍有延迟" | 无 |
| 仓内超时(重) | 切换仓发货或取消 | ETA 重算或取消 | 推送+短信 | 5 元优惠券 |
| 运力不足(轻) | 调度中心调配骑手 | ETA +3~5min | 推送："骑手正在赶来" | 无 |
| 运力不足(重) | 众包平台发单 | ETA +10~15min | 推送+短信 | 10 元优惠券 |
| 骑手异常 | 联系骑手→换骑手 | ETA 重算 | 推送："正在为您更换骑手" | 5 元优惠券 |
| 天气极端 | 全局补偿系数 | ETA ×1.2~1.5 | 下单前提示："恶劣天气配送较慢" | 无 |
| 仓内故障 | 关仓+路由到邻近仓 | ETA 重算 | 推送+短信 | 10 元优惠券 |
| 地址异常 | 客服联系确认 | 暂停计时 | 短信+电话 | 无 |

### 3.4 ETA 变更通知规则

| 变更幅度 | 通知方式 | 通知频率 | 文案模板 |
|---------|---------|---------|---------|
| +1~3 min | 不通知 | - | - |
| +3~5 min | App 推送 | 最多 1 次 | "您的订单预计 XX:XX 送达" |
| +5~10 min | App 推送 | 最多 2 次 | "非常抱歉，订单稍有延迟，预计 XX:XX 送达" |
| +10 min 以上 | App 推送 + 短信 | 每次变更通知 | "订单延迟，预计 XX:XX 送达，可选择取消" |
| 提前送达 | 不通知 | - | - |

### 4.2 核心接口定义

| 接口 | 方法 | 请求参数 | 响应 | 调用方 |
|------|------|---------|------|-------|
| `/eta/predict` | POST | address, skus, orderTime | eta_time, confidence, segments | 商品页/确认订单页 |
| `/eta/refresh` | GET | order_id | eta_time, status, remaining_min | 等待页轮询 |
| `/eta/subscribe` | WS | order_id | eta_update_event (push) | 等待页/配送追踪 |
| `/eta/simulate` | POST | address, skus, time_range | eta_distribution | 运营后台 |
| `/eta/report` | GET | date_range, station_id | accuracy_metrics | 数据看板 |

### 4.3 ETA 预估接口详细设计

**请求 (POST /eta/predict)**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| address_id | string | 是 | 配送地址 ID |
| latitude | float | 是 | 纬度 |
| longitude | float | 是 | 经度 |
| skus | array | 是 | SKU 列表 [{sku_id, qty}] |
| order_time | datetime | 否 | 下单时间（默认当前） |
| is_rush | bool | 否 | 是否催单 |

**响应**：

| 字段 | 类型 | 说明 |
|------|------|------|
| eta_time | datetime | 预计送达时间 |
| eta_minutes | int | 预计分钟数 |
| confidence | float | 置信度 0~1 |
| segments | object | 分段预估 {warehouse, pickup, delivery} |
| is_throttled | bool | 是否被节流（仓内积压） |
| throttle_reason | string | 节流原因 |

### 4.4 数据流与消息队列

| 数据源 | 消息类型 | 目标 | 用途 |
|--------|---------|------|------|
| WMS | 仓内作业事件 | ETA 核心服务 | 更新仓内进度 |
| TMS | 骑手 GPS | ETA 核心服务 | 实时更新配送 ETA |
| OMS | 订单状态变更 | ETA 状态机 | 触发状态流转 |
| 调度中心 | 骑手分配事件 | ETA 核心服务 | 更新骑手配送预估 |
| 天气服务 | 天气变更 | 特征计算服务 | 更新天气补偿系数 |

| 用户分桶 | 0~99 | 基于 user_id hash 分桶 |
| 城市 | 全量 / 单城市 | 按城市灰度 |
| 站点 | 全量 / 单站点 | 按站点灰度 |
| 时段 | 全天 / 高峰 / 平峰 | 按时段控制 |

### 5.2 核心实验方案

| 实验编号 | 实验名称 | 假设 | 实验组 | 对照组 | 核心指标 | 观测指标 |
|---------|---------|------|-------|-------|---------|---------|
| EXP-001 | ETA 精度模型升级 | 新模型提升 ETA 准确率 | 新 ML 模型 | 现有规则模型 | ETA MAE, 准时率 | 超时投诉率, ETA 变更率 |
| EXP-002 | ETA 展示形式 | 进度条比时间点降低焦虑 | 进度条+时间点 | 仅时间点 | 用户满意度, 取消率 | 页面停留时长, 复购率 |
| EXP-003 | ETA 安全边际 | 适当放宽 ETA 降低超时率 | ETA +3min 缓冲 | 无缓冲 | 超时投诉率 | ETA MAE, 准时率 |
| EXP-004 | ETA 变更通知 | 主动通知降低客诉 | 主动推送变更 | 仅页面更新 | 客诉率, 满意度 | 推送打开率, 取消率 |
| EXP-005 | 天气补偿系数 | 天气补偿降低恶劣天气超时率 | 动态补偿 | 固定补偿 | 恶劣天气准时率 | 整体 ETA MAE |

### 5.3 实验指标体系

| 指标类型 | 指标名 | 计算方式 | 显著性阈值 | 最小样本量 |
|---------|--------|---------|-----------|-----------|
| **核心指标** | ETA MAE | mean(abs(预估-实际)) | p < 0.05 | 10,000 单/组 |
| **核心指标** | 准时率 | 实际≤预估 / 总单量 | p < 0.05 | 10,000 单/组 |

| **护栏指标** | 取消率 | 取消单 / 总单量 | 不可恶化 | 5,000 单/组 |
| **观测指标** | 用户满意度 | NPS / 评分 | 观察趋势 | 5,000 单/组 |
| **观测指标** | ETA 变更率 | 变更单 / 总单量 | 观察趋势 | 10,000 单/组 |
| **观测指标** | 复购率 | 7 日复购 | 观察趋势 | 10,000 用户/组 |
