# 蜂鸟众包履约链路

专送：供应商管理的全职骑手为主的配送形式，优质服务、速度较快，但成本高，配送时间和配送区域有限制，一般是3km以内的订单

众包：兼职骑手，依托产品进行管理，一般配送范围、配送时间没有严格的限制

分流：单子分配给谁来送

降级：运力线配送压力过大时，分给谁来配送（专送or众包）

降级根据：

营业时间、天气、压力系数（判定触发压力平衡的阈值，阈值影响因素：天气、骑手数、背单数、骑手背单能力）

运单属性：

| 属性类别 | 属性列表 |
|---|---|
| 基础属性 | 重量、体积、距离、其他等 |
| 品类属性 | 数码、餐饮、生鲜果蔬、鲜花蛋糕、文件、生活用品等 |
| 业务属性 | 外卖单、淘宝单、新零售、帮买帮送、品牌单等 |
| 策略属性 | 顺路单、合并、指派、预订单、高价任务单等 |

指派调度：抢派结合方式，主要有三种调度模式

| 模式 | 时间 | 说明 |
|---|---|---|
| 弱指派 | 1V1 90s内 | 找到最合适的骑手 |
| 扩散 | 1V多 90-150s内 | 一群不错的骑手，抢单 |
| 强指派（高价任务单） | 1V多 时长灵活配置 | 一群骑手，一人接起即可；如无人接起，这群骑手会受到处罚（如拒绝多次，降低指派指数） |

定价：基础定价+动态加价（轮询，一般是在6min无人接起时开始干预；特殊时段）+难度奖励（距离、重量、恶劣天气等）

运力分层：稳定骑手活跃骑手全职骑手兼职骑手

异常处理：

| 异常类型 | 说明 |
|---|---|
| 商家定位不准 | 商家地址与实际位置不一致 |
| 商家未营业 | 商家未在营业时间内 |
| 商家已在平台关店 | 商家已下线 |
| 商品售罄 | 商品库存不足 |
| 商家选择自配送 | 商家自行安排配送 |
| 商家出餐慢 | 商家备餐超时 |
| 用户拒收 | 用户拒绝接收订单 |
| 用户定位有误 | 用户收货地址定位异常 |
| 联系不上用户 | 无法联系用户确认信息 |

违规操作：

| 违规类型 | 考核指标 |
|---|---|
| 违规取餐 | 超时、投诉、差评 |
| 违规到店 | 超时、投诉、差评 |
| 违规送达 | 超时、投诉、差评 |
