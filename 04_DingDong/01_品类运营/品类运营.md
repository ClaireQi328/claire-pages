# 品类运营

品类运营考核方式

| 指标 | 定义/公式 |
|---|---|
| 销售额达成率 | 实际交易额/目标交易额 |
| 毛利额达成率 | 实际毛利额/目标毛利额 |
| 笔单价目标达成率 | 实际客单价/目标客单价 |
| 营销费用 | 营销投入金额 |
| 价格指数 | 售价/竞对价格 |
| 品类运营规划落地 | 重点品类规划、爆款、新品、清仓品 |
| 项目运营 | 项目推进与执行 |
| 快速反应/协作指数/用户思维 | 团队协作与响应能力评估 |
