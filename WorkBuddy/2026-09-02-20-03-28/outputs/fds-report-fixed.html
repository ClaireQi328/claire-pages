⑧Q4 看当下 · 三个 P0 模块的落地管理模型
Q4 落地三个模块：供应商管理平台（供应商全生命周期线上化）、A+B 价格卷积（变更价格自动重算）、统一工作台（跨系统任务聚合）。三个模块可在一个季度内并行推进。
P0 · Q4 首期
供应商管理平台
供应商全生命周期线上化 · 风险可控 · 资源最优
⏱ 10.08–11.15 · 交付：供应商库补齐绩效 / 标签 / 资源池 / 退出机制，五维评分 → 九宫格分层分级
流程
  • 先从品类资源池里把想引入的供应商纳入规划，按战略件 / 杠杆件 / 瓶颈件分类；
  • 供应商在门户注册、签 NDA，进入准入评审（PSA 评估 + QTR 质量目标评审）；
  • 评审通过后纳入正式供应商库，可参与定点选型；
  • 量产阶段由系统自动采集 QCDS 数据，落到绩效九宫格；
  • 按结果触发晋级、奖惩或退出，形成全生命周期闭环。
输入
  • 供应商注册资料、NDA 保密协议；
  • PSA 评估结果、QTR 质量目标；
  • 量产后的 QCDS 采集数据（EP / 物流 / SRM / SQMS / SAP）；
  • 工商、司法、舆情等第三方风险数据。
处理规则
  • 准入评分低于 80 分直接拒绝，汽车件必须通过 IATF16949；
  • 绩效按 QCD 权重打分，连续两期达标晋级、红牌即冻结；
  • 资质到期提前 90 天预警，逾期自动冻结。
输出
  • 正式供应商库与准入结论；
  • 绩效评分九宫格；
  • 晋级 / 奖惩 / 退出指令；
  • 风险预警清单。
数据源
Tako（注册 / NDA）· EP（PSA / QTR / 绩效九宫格）· EP / 物流 / SRM / SQMS / SAP（QCDS 采集）· 洞见（风险）
管理流程与要求
  • 建立「准入 → 认证 → 绩效 → 奖惩 → 退出」全生命周期闭环；
  • 周度核对 QCDS 采集质量，月度绩效评审，季度资源池复盘；
  • 异常问题 24 小时内升级、责任到人。
P0 · Q4 首期
A+B 价格卷积
变更价格自动卷积重算 · A（主体价）+B（总成价）联动确认
⏱ 10.20–11.28 · 交付：BOM 卷积引擎上线，价格台账入库，试点品类端到端跑通
流程
  • 先捕获变更源（EWO / CWO / SWO / 商务 / 物流）；
  • 再做影响评估，从量纲、价格、产能三个维度判断变更范围；
  • 判定料号路由，走「成本变更核价」还是「直接变价」；
  • 触发 A+B 总成卷积重算，同步更新变价单和价格台账；
  • 完成卷积后进入补差结算，全程留痕可追溯。
输入
变更源数据 · BOM · 价格数据 · 产能数据 · 框架协议
处理规则
  • 结构级变更走成本变更核价，价格级变更走变价；
  • A+B 总成卷积重算，量纲 × 价格 × 产能三重评估；
  • 框架协议截断判定，超限触发重谈。
输出
  • 变价单；
  • 更新后的价格台账；
  • 补差结算单；
数据源
EP（变更源 / 变价单）· CE（A+B 卷积）· SAP（台账）· SRM（补差）
管理流程与要求
  • 随时发起、与项目解耦，走「变更 → 影响 → 决策 → 重算 → 结算」闭环；
  • 台账版本留痕、全程可追溯，变更争议有据可查。
