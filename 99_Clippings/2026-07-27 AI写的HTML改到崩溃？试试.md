# AI写的HTML改到崩溃？试试这个工具吧🔧

最近经常使用各类 HTML skills来制作PPT或是文档，但也在修改细节的过程中发现许多问题🤯，例如：  1. 很难直接在原生文件上修改，代码看得头昏眼花 2. 交给AI改，多轮对话太伤精力，碰到听不懂人话的时候改错了真的很崩溃 3. 一个团队无法一起改同一份，通常需要接力导出或合并，修改费时费力  基于这些问题，我做了这个叫做HTML Editor的网站，现已开源，欢迎收藏使用👏  HTML Editor主要有三大功能： 1. 上传HTML文档后便自动解析，可以直接在页面上修改任意元素✏️ 2. 可以勾选元素留下批注，这样交给AI做后续优化时将更加精准💬 3. 支持多人协作，再也不用接力改HTML了👥  网站有中英文两个版本，上传后的文件将自动保存，用户可以在主页对历史文件进行管理。欢迎大家留下建议，我们一起迭代🔁。
