# AI 生成的 HTML 报告，这样发图不会丢

AI时代来了之后，大家用 PPT 和 figma 做汇报越来越少，用 AI生成的 HTML 文件展示的频率越来越高。很多时候，我们汇报 html 文件的图表配色、KPI 卡片、版式都很在线，本地打开一切正常 但发给老板那一刻，图片全部加载失败 满屏都是"图片无法显示"的占位图，那一刻确实有点尴尬...  其实，图片其实是"外链"形式存在的 意思是：图片单独存在另一个文件夹里 HTML，只是引用了它的路径；你转发 HTML 单文件，图片文件夹没跟着走，对方打开当然就是空的  因此，我们可以把所有图片"内联"到 HTML 里，技术名词叫 Base64 编码 通俗说：让图片成为 HTML 文件本身的一部分  这样不管发微信、邮件、网盘 对方收到的就是一个完整独立的文件 双击即开，图片完整保留  当然，我们也可以将其沉淀为一个skill，我称其为“html-image-inliner” 不需要懂代码，对话框里说一句话，"把图片内联进 HTML"，就能完成。
