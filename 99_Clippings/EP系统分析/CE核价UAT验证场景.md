## 核价任务生成

- 定点类型 RFQ 首轮发布后，系统自动生成核价任务，编号格式 `CE-YYYYMMDD-NNN`，流水号唯一递增
- 核价任务与 RFQ 为 1:1 关系
- 非定点类型 RFQ 不生成核价任务
- 生成时自动发送单步待办 + 飞书通知给 CE 核价人员

## 核价明细编辑

- 数据粒度：零件号 + 工厂 = 一行
- 5 个必填字段：材料费、制造费、管理费、出厂价、模具总费用；开发总费用非必填，默认 0
- 出厂价不可为 0
- 所有费用字段保留 3 位小数
- 自动计算：修改材料费/制造费/管理费时自动重算 `出厂价 = 三者之和`，会覆盖手动填写值
- 手动修改出厂价时以手动值为准，直到下次修改子项触发重算

## 提交核价校验

- 遍历所有必填字段，任一为空阻止提交
- 出厂价 = 0 阻止提交
- 校验失败：Toast 提示 + 未填项红色边框高亮
- 校验通过：弹出审批人选择弹窗，审批人从 Finance 角色中选择，过滤当前 CE 自己

**验证方式：任意一待核价/已核价状态数据**

## 单步待办&通知

- 审批页面：RFQ 基本信息 + 核价明细（只读）+ 备注（只读）
- 同意：状态 → `已核价`，通知 CE
- 驳回：状态 → `待核价`，通知 CE（含驳回原因）
- 审批中 + 新轮次零件更新：自动终止审批流
- 审批中 + 新轮次零件无更新：审批流继续不受影响

**验证方式：任意一待核价/已核价状态数据**

## 转派

- 所有状态均可转派（含 `已完成`）
- 转派后：CE 人员更新、RFQ 同步更新、数据权限转移、待办迁移、飞书通知新 CE
- 审批中转派：审批流按新人员展示
- RFQ 采购员变更 → 核价任务中采购工程师字段同步更新

**验证方式：任意一待核价/已核价状态数据**

## 导入导出

- 导出：Excel 格式，`已完成` 状态也可导出
- 导入：按零件号匹配更新，页面锁定不允许操作
- 导入成功：Toast 提示 + 列表刷新
- 导入失败：提示下载失败文件（`-fail.xlsx`）
- 空文件：提示「请选择文件」
- 零件号不存在于核价任务中 → 记录到失败文件，该行跳过

## **状态流转**

- 全状态链路：`待核价` → `审批中` → `已核价` → `已完成`
- 审批驳回：`审批中` → `待核价`（可重新提交）
- `已核价` 状态下 CE 可再次提交，重新走审批流
- 新轮次发布 + 零件更新：`审批中`/`已核价` → `待核价`（自动终止旧审批）
- 定点通知单生成：任意状态 → `已完成`（终态，不可编辑）

## 上一轮数据继承

- 零件-工厂在上一轮已有数据 → 默认带出
- 新轮次新增行 → 数据为空，行背景高亮标示
- 零件-工厂减少 → 列表移除对应行，不通知

## 待办与通知

- 核价任务生成 → CE 收到待核价待办
- CE 提交 → 审批人收到待审批待办
- 审批驳回 → CE 收到待核价待办（含驳回原因）
- 转派 → 新 CE 收到待核价待办，旧 CE 待办移除

## 边界异常场景

- 新轮次零件无更新：状态不变、不通知
- 新轮次零件减少：列表更新、不通知
- 提交时审批人变更：旧审批人权限移除，新审批人赋权
- 导入文件无有效数据行：提示「文件中无有效数据」
- 审批中 CE 不可再次提交（阻止重复提交）

## 操作权限矩阵

- **CE**：待核价/已核价状态下可编辑、保存、提交、导入；所有状态可查看、导出、转派
- **审批人**：仅 `审批中` 状态可同意/驳回，其余状态只读
- **采购员**：全状态只读，不可编辑
- **管理员**：全量可见，可转派
- `已完成` 状态下所有编辑操作均被禁止

## 菜单可见性

- Finance（CE）：RFQ 询报价管理 + 成本管理，不可见其他 RFQ 菜单和其他一级菜单
- 采购员：RFQ 询报价管理 + 成本管理 + 其他一级菜单，不可见其他 RFQ 二级菜单
- 管理员：全部菜单可见
- CE 老板：RFQ 询报价管理 + 成本管理，只读查看
