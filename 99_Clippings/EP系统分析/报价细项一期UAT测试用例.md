### 用例4：多零件 + 多供应商 + 多工厂场景验证

| **项** | **内容** |
|-|-|
| **SOR编号** | SOR-MP-BIW-0125 |
| **RFQ编号** | RFQ-20260318-001 |
| **零件号** | S000000030001；E000000049001 |
| **模块** | 询报价/定点 |
| **场景描述** | 多个零件、多个供应商、多个工厂，验证系统能正确处理复杂定点矩阵 |
| **前置条件** | 1. 零件P01、P02  <br/>2. 供应商S01、S02  <br/>3. 工厂F01、F02  <br/>4. 各供应商对每个零件在各工厂均有报价 |
| **测试步骤** | 1. 创建询价单，包含P01、P02，发给S01、S02，指定F01、F02  <br/>2. 所有组合均完成报价  <br/>3. 采购员定点：- P01/F01 → S01  - P01/F02 → S02  - P02/F01 → S02   - P02/F02 → S01  <br/>4. 提交审批 |
| **预期结果** | 1. 系统支持按(零件+工厂)维度独立定点供应商  <br/>2. 定点结果可正确保存并展示矩阵关系  <br/>3. 后续下单时按(零件+工厂)自动匹配正确供应商 |

|-|-|

| **RFQ编号** |  |
| **零件号** |  |
| **轮次** | 1-2 |
| **场景描述** | 二轮报价时，系统应自动带出上一轮（第一轮）供应商已提交的报价细项（如材料费、模具费等），避免重复录入，并支持修改。 |
| **前置条件** | 1. 已创建RFQ单，包含零件P-87654321，分配给供应商S01（已准入）  <br/>2. 第一轮报价已完成：供应商S01已提交报价细项（单价：10.5元，模具费：5000元，开发费：3000元）  <br/>3. 采购方发起第二轮报价（原因：价格谈判或技术调整）  <br/>4. 第二轮报价单状态为“待供应商报价” |
| **测试步骤** | 1. 供应商S01登录SRM供应商门户  <br/>2. 进入“我的报价”列表，找到RFQ-2403-01的第二轮报价任务  <br/>3. 点击“报价”进入报价页面  <br/>4. 观察页面是否自动展示第一轮已填写的报价细项（单价、模具费、开发费等）  <br/>5. 修改单价为9.8元，模具费保持不变，开发费改为2500元  <br/>6. 新增一条“软模费”细项，金额800元  <br/>7. 提交第二轮报价 |
| **预期结果** | 1. 报价页面自动带出第一轮的所有报价细项，且数值准确（单价10.5元、模具费5000元、开发费3000元）  <br/>2. 供应商可直接修改已有细项，也可新增/删除细项  <br/>3. 修改后提交成功，系统保存第二轮报价明细  <br/>4. 采购方在后台查看第二轮报价时，能看到完整细项，并与第一轮进行对比（支持版本对比功能）  <br/>5. 带出数据仅限上一轮，不会跨轮次混乱 |
