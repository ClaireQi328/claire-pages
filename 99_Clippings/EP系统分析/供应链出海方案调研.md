## 零部件出海

整车企业一旦进入 **“供应链出海（Global Supply Chain）”** 阶段，供应链系统会从“国内单一体系”演变为 **全球多区域、多法规、多组织、多物流网络** 的复杂系统。  
本质变化是：

```Plain Text
国内供应链系统
→ 全球供应链网络系统
```

其影响会渗透到 **定点（Sourcing / Nomination）、订单（Ordering）、物流、库存、结算、质量、合规等所有模块**。

下面从 **系统架构 + 业务模式 + 定点设计 + 订单设计** 四个层面完整拆解。

```Plain Text
中国供应商
 → 中国工厂
 → 中国市场
```

出海模式：

```Plain Text
中国供应商
     ↘
      海外工厂
     ↗
海外供应商
```

- 报关
