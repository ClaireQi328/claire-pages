# Tampermonkey 脚本导出指南

> 由于 Tampermonkey 使用 LevelDB 存储，需要通过浏览器界面导出

---

## 📋 导出步骤

### 方法一：通过 Tampermonkey 面板（推荐）

1. **打开 Tampermonkey 面板**
   - 点击 Chrome 工具栏的 Tampermonkey 图标
   - 选择「管理面板」或「Dashboard」

2. **进入实用工具**
   - 点击顶部「实用工具」标签
   - 找到「导出」部分

3. **导出所有脚本**
   - 点击「导出所有脚本」按钮
   - 保存生成的 `.zip` 文件到本文件夹

4. **导出单个脚本**（可选）
   - 在脚本列表中点击脚本名称
   - 点击「导出」按钮

---

## 📁 存储位置

导出的脚本文件请保存到：

```
00_Self/assets/chrome-extensions/tampermonkey-scripts/
├── 导出指南.md          ← 本文件
├── scripts-backup.zip   ← 导出的脚本压缩包
└── individual/          ← 单个脚本（可选）
```

---

## 🔧 导入到夸克浏览器

### 步骤 1：安装 Tampermonkey

1. 在夸克浏览器中打开 `chrome://extensions/`
2. 开启「开发者模式」
3. 加载已解压的 Tampermonkey 扩展：
   - 路径：`00_Self/assets/chrome-extensions/Tampermonkey_dhdgffkkebhmkfjojejmpbldmpobfkfo/`

### 步骤 2：导入脚本

1. 打开夸克浏览器的 Tampermonkey 面板
2. 进入「实用工具」→「导入」
3. 选择之前导出的 `.zip` 文件
4. 确认导入

---

## ⚠️ 注意事项

- **脚本数据不会自动同步**，需要手动导出/导入
- **部分脚本可能需要更新**以兼容新浏览器
- **建议定期备份**：每月导出一次脚本配置
