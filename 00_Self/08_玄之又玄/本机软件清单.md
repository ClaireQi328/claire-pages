## 🚀 Winget 批量安装脚本

> 以管理员 PowerShell 运行。`--accept-package-agreements --accept-source-agreements` 跳过交互确认。
> 可按需注释/删除不需要的应用。

```powershell
# ============================================================
# 本机软件批量安装脚本
# 生成日期：2026-07-22
# 运行方式：管理员 PowerShell → 右键粘贴执行
# ============================================================

$common = "--accept-package-agreements --accept-source-agreements --silent"

Write-Host "===== 🛠 开发工具 =====" -ForegroundColor Cyan
winget install Git.Git                              $common
winget install GitHub.cli                           $common
winget install GitHub.GitHubDesktop                 $common
winget install Microsoft.VisualStudioCode           $common
winget install Anysphere.Cursor                     $common
winget install NodeJS.NodeJS                        $common
winget install Python.Python.3.12                   $common

Write-Host "===== 🤖 AI 工具 =====" -ForegroundColor Cyan
winget install Anthropic.Claude                     $common
winget install OpenAI.ChatGPT                       $common
winget install Tencent.ima-copilot                  $common

Write-Host "===== 📝 办公与协作 =====" -ForegroundColor Cyan
winget install Obsidian.Obsidian                    $common
winget install WPS.WPSOffice                        $common
winget install TheDocumentFoundation.LibreOffice    $common
winget install Zotero.Zotero                        $common
winget install ByteDance.Feishu                     $common
winget install Tencent.WeChat                       $common

Write-Host "===== 🎨 设计与原型 =====" -ForegroundColor Cyan
winget install Figma.Figma                          $common
winget install Axure.AxureRP.11                     $common

Write-Host "===== 🌐 浏览器 =====" -ForegroundColor Cyan
winget install Google.Chrome                        $common
winget install Microsoft.Edge                       $common

Write-Host "===== 🔒 安全与网络 =====" -ForegroundColor Cyan
winget install ESET.EndpointSecurity                $common
winget install chen08209.FlClash                    $common

Write-Host "===== 🔧 系统工具 =====" -ForegroundColor Cyan
winget install 7zip.7zip                            $common
winget install Microsoft.PowerToys                  $common
winget install hluk.CopyQ                           $common
winget install Logitech.OptionsPlus                 $common
winget install Microsoft.OneDrive                   $common
winget install Microsoft.DotNet.DesktopRuntime.8    $common

Write-Host "===== ✅ 全部完成！=====" -ForegroundColor Green
```
