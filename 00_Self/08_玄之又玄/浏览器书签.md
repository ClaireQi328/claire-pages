# 浏览器书签导出

> 从 Chrome 导出的标准 HTML 书签文件，可导入任何浏览器（Safari、夸克、Firefox 等）

## 📥 导入方法

| 浏览器 | 操作 |
|--------|------|
| **Safari** | 文件 → 导入自 → 书签 HTML 文件 |
| **夸克** | 设置 → 书签与历史 → 导入书签 |
| **Firefox** | 书签 → 管理书签 → 导入和备份 → 从 HTML 导入 |
