# 咨询方法论详表 — 高阶打法参考

> 本文档是 analyst Skill 的参考库，包含各大咨询公司经典方法论的详细说明。

## 一、McKinsey 麦肯锡

### 1. MECE 原则（Mutually Exclusive, Collectively Exhaustive）

**来源**：Barbara Minto，麦肯锡金字塔原理创始人

**核心思想**：将问题分解为互不重叠、完全穷尽的子问题。

**应用方式**：
- 任何分析的第一步：先确保问题分解是 MECE 的
- 检验标准：每个子问题是否独立？所有子问题加起来是否覆盖全部？
- 常见维度拆分：
  - 按流程：Plan → Source → Make → Deliver → Return（SCOR）
  - 按利益相关者：客户 / 供应商 / 内部 / 监管
  - 按时间：短期（<3月）/ 中期（3-12月）/ 长期（>1年）
  - 按地域：国内 / 亚太 / 欧美

**在 nailit 中的位置**：Step 1（As-Is 分解）+ Step 4（Options 生成）

### 2. 7S 框架

**来源**：Tom Peters & Robert Waterman，麦肯锡

**七个要素**：

| 要素 | 含义 | 典型问题 |
|------|------|---------|
| **Strategy** | 战略方向 | 我们的竞争策略是什么？ |
| **Structure** | 组织结构 | 谁向谁汇报？决策权在哪？ |
| **Systems** | 流程系统 | 日常运营靠什么流程驱动？ |
| **Shared Values** | 共享价值观 | 组织的核心信念是什么？ |
| **Skills** | 核心能力 | 我们最擅长什么？缺什么能力？ |
| **Style** | 管理风格 | 领导层的行为模式？ |
| **Staff** | 人才配置 | 关键岗位有没有合适的人？ |

**使用方式**：
1. 先诊断 7 个要素的当前状态
2. 找到不一致/不匹配的要素（组织问题的根源）
3. 设计变革方案，确保 7 个要素重新对齐

**在 nailit 中的位置**：Step 1（组织 As-Is）+ Step 2（组织 To-Be）

### 3. 三层面增长（Three Horizons of Growth）

**来源**：麦肯锡，Merder & Jones

| 层面 | 时间范围 | 核心问题 | 资源配比 |
|------|---------|---------|---------|
| **H1** | 现在（0-12月） | 如何守住核心业务？ | 70% |
| **H2** | 近期（1-3年） | 如何扩大新兴业务？ | 20% |
| **H3** | 远期（3-10年） | 如何投资未来机会？ | 10% |

**使用方式**：
- 评估现有业务在三个层面的分布
- 确保 H1 的现金流支撑 H2/H3 的投资
- 避免过度集中在 H1（温水煮青蛙）

**在 nailit 中的位置**：Step 2（To-Be 的时间维度分层）

### 4. Issue Tree（问题树）

**来源**：麦肯锡 Problem Solving 流程

**使用方式**：
1. 将核心问题放在树顶
2. 第一层拆分为 2-4 个 MECE 子问题
3. 每个子问题继续拆分，直到可以被数据/行动直接回答
4. 识别"关键路径"：哪条分支对答案影响最大？

**类型**：
- **假设树**：先提出假设，再验证
- **诊断树**：从现象出发，逐层定位根因
- **计算树**：量化估算的分解路径

**在 nailit 中的位置**：Step 3（Gap 诊断的核心工具）

### 5. 金字塔原理（Pyramid Principle）

**来源**：Barbara Minto，麦肯锡

**核心规则**：
1. **结论先行**：每层只讲一个核心观点
2. **以上统下**：上层是下层的总结
3. **归类分组**：同层内容逻辑一致
4. **逻辑递进**：同组内按逻辑顺序排列

**汇报结构**：
```
核心结论
├── 论点 1
│   ├── 论据 1a
│   └── 论据 1b
├── 论点 2
│   ├── 论据 2a
│   └── 论据 2b
└── 论点 3
    ├── 论据 3a
    └── 论据 3b
```

**在 nailit 中的位置**：Step 5（Recommendation 的呈现方式）

### 6. 80/20 法则（Pareto Principle）

**来源**：Vilfredo Pareto，麦肯锡广泛应用于咨询实践

**核心思想**：80% 的结果来自 20% 的原因。

**应用**：
- 成本分析：20% 的品类贡献 80% 的成本
- 客户分析：20% 的客户贡献 80% 的收入
- 问题分析：20% 的根因导致 80% 的问题

**在 nailit 中的位置**：Step 3（找到关键杠杆）+ Step 4（聚焦高杠杆方案）

## 二、BCG 波士顿咨询

### 1. BCG 矩阵（增长-份额矩阵）

**核心思想**：用市场增长率和相对市场份额将业务分为四象限。

|  | 高增长率 | 低增长率 |
|--|---------|---------|
| **高份额** | ⭐ 明星（Star） | 🐄 现金牛（Cash Cow） |
| **低份额** | ❓ 问题儿童（Question Mark） | 🐕 瘦狗（Dog） |

**策略**：
- 明星：加大投资，保持领先
- 现金牛：收割利润，投资 H2/H3
- 问题儿童：选择性投资，赌对变明星
- 瘦狗：剥离或放弃

**在 nailit 中的位置**：Step 4（业务组合评估）

### 2. 经验曲线（Experience Curve）

**来源**：BCG，Bruce Henderson

**核心公式**：`C₁ = C₀ × (Q₁/Q₀)^(-α)`

- 每次累计产量翻倍，单位成本下降固定百分比（通常 20-30%）
- α 为学习率参数

**战略含义**：
- 先发优势：早期规模越大，成本优势越显著
- 定价策略：可以低价抢占份额，靠经验曲线拉开成本差距
- **风险**：技术变革可能重置经验曲线

**在 nailit 中的位置**：Step 4（成本杠杆分析）

### 3. 优势矩阵（Advantage Matrix）

**核心思想**：不同行业的竞争优势类型不同，策略应匹配。

| 优势类型 | 特征 | 策略 |
|---------|------|------|
| **规模经济** | 大玩家碾压 | 追求规模 |
| **专精化** | 小而美 | 差异化定位 |
| **无优势** | 同质化严重 | 成本领先或退出 |
| **锁定效应** | 客户迁移成本高 | 建立壁垒 |

**在 nailit 中的位置**：Step 1（竞争格局评估）

## 三、Bain 贝恩

### 1. 利润池分析（Profit Pool）

**来源**：Bain & Company，Gadiesh & Gilbert

**核心思想**：行业各环节的利润分布极不均匀。

**使用方式**：
1. 绘制价值链各环节的收入规模
2. 估算每个环节的利润率
3. 识别"利润厚区"和"利润薄区"
4. 选择切入利润最厚的环节

**经典发现**：
- 汽车行业：制造环节收入大但利润薄，金融和售后利润厚
- PC 行业：硬件利润趋零，软件和服务利润厚

**在 nailit 中的位置**：Step 4（选择最优切入位置）

### 2. NPS（净推荐值）

**公式**：`NPS = 推荐者% - 贬损者%`

| 分数区间 | 评价 |
|---------|------|
| > 50 | 优秀 |
| 0-50 | 良好 |
| < 0 | 需要立即行动 |

**使用方式**：
- 作为 To-Be 的客户维度目标
- 按客户细分追踪 NPS 差异
- 找到 NPS 最低的环节，集中改善

**在 nailit 中的位置**：Step 2（客户维度的成功指标）

### 3. 简化聚焦（Simplify and Focus）

**核心思想**：战略的本质是选择不做什么。

**Bain 的简化框架**：
1. 识别所有在做的事项
2. 按"对核心目标的贡献度"排序
3. 底部 30-50% 的事项 → 停止
4. 释放的资源投入 Top 20%

**在 nailit 中的位置**：Step 5（方案筛选后，明确"不做什么"）

## 四、Harvard & 经典理论

### 1. 波特五力模型（Porter's Five Forces）

**来源**：Michael Porter，哈佛商学院

| 力量 | 核心问题 | 分析维度 |
|------|---------|---------|
| **现有竞争** | 行业竞争激烈程度？ | 竞争者数量、差异化程度、退出壁垒 |
| **潜在进入** | 新玩家容易进来吗？ | 规模经济、资金需求、品牌壁垒、政策 |
| **替代品** | 有没有替代方案？ | 性能/价格比、客户转换成本 |
| **买方议价** | 客户有多强？ | 集中度、转换成本、信息透明度 |
| **供方议价** | 供应商有多强？ | 集中度、替代品、前向整合威胁 |

**在 nailit 中的位置**：Step 1（外部环境 As-Is）

### 2. 价值链分析（Value Chain）

**来源**：Michael Porter

**内部活动拆解**：

| 类别 | 活动 | 分析要点 |
|------|------|---------|
| **主要活动** | 入库物流 → 运营 → 出库物流 → 营销 → 服务 | 每个环节的成本、价值、效率 |
| **支撑活动** | 采购 / 技术开发 / 人力资源 / 基础设施 | 如何赋能主要活动 |

**使用方式**：
1. 拆解价值链每个环节
2. 识别高成本、低价值的环节
3. 对标行业最佳实践，找到优化空间

**在 nailit 中的位置**：Step 1（内部能力 As-Is）+ Step 4（优化杠杆）

### 3. 蓝海战略（Blue Ocean Strategy）

**来源**：W. Chan Kim & Renée Mauborgne，INSEAD

**核心工具：四步动作框架（ERRC）**

| 动作 | 问题 |
|------|------|
| **Eliminate**（消除） | 行业内习以为常的哪些因素可以消除？ |
| **Reduce**（减少） | 哪些因素可以低于行业标准？ |
| **Raise**（提升） | 哪些因素可以高于行业标准？ |
| **Create**（创造） | 行业从未提供的哪些因素可以创造？ |

**战略画布**：将四个动作绘制在一张图上，与竞争对手形成差异化曲线。

**在 nailit 中的位置**：Step 4（创新方案生成）

### 4. JTBD（Jobs to Be Done）

**来源**：Clayton Christensen，哈佛商学院

**核心思想**：客户不是在"买产品"，而是在"雇佣产品来完成一个任务"。

**使用方式**：
1. 识别客户要完成的"任务"（Job）
2. 分析当前的解决方案（包括非直接竞品）
3. 找到未被满足的维度（便利性 / 效果 / 成本）
4. 设计更优的解决方案

**Job Statement 模板**：
> 当 [情境] 时，我想要 [动机]，以便 [期望结果]

**在 nailit 中的位置**：Step 2（理解客户真实需求）

### 5. TOC 约束理论（Theory of Constraints）

**来源**：Eliyahu Goldratt，《目标》

**五步聚焦法**：
1. **识别**（Identify）：系统的约束在哪？
2. **利用**（Exploit）：在不增加投入的情况下，最大化利用约束
3. **从属**（Subordinate）：所有非约束环节服从约束节奏
4. **提升**（Elevate）：如果利用还不够，投资扩大约束产能
5. **重复**（Repeat）：约束解决后，找到下一个约束

**缓冲管理**：
- 约束前设缓冲（Buffer）
- 用 DBR（Drum-Buffer-Rope）控制节奏
- 监控 Buffer 消耗预警

**在 nailit 中的位置**：Step 3（瓶颈诊断 + 优先级排序）

### 6. VRIO 分析

**来源**：Jay Barney，资源基础观（RBV）

| 维度 | 问题 |
|------|------|
| **Value**（价值） | 这个资源能否抓住机会或抵御威胁？ |
| **Rareness**（稀缺） | 竞争对手是否也拥有？ |
| **Imitability**（难模仿） | 模仿的成本/难度如何？ |
| **Organization**（组织） | 我们的组织能否有效利用这个资源？ |

**判断结果**：
- V✗ → 竞争劣势
- V✓ R✗ → 竞争均势
- V✓ R✓ I✗ → 暂时竞争优势
- V✓ R✓ I✓ O✓ → 持续竞争优势

**在 nailit 中的位置**：Step 1（内部能力评估）

### 7. PESTLE 分析

| 维度 | 关注点 |
|------|--------|
| **P**olitical（政治） | 政策、法规、贸易壁垒 |
| **E**conomic（经济） | 经济周期、利率、汇率 |
| **S**ocial（社会） | 人口趋势、消费习惯 |
| **T**echnological（技术） | 技术成熟度、颠覆性技术 |
| **L**egal（法律） | 合规要求、知识产权 |
| **E**nvironmental（环境） | 可持续性、碳排放 |

**在 nailit 中的位置**：Step 1（宏观环境扫描）

### 8. Kano 模型

**来源**：狩野纪昭（Noriaki Kano）

| 类型 | 特征 | 投资策略 |
|------|------|---------|
| **基本型**（Must-be） | 没有会不满，有了不惊喜 | 必须满足，不值得过度投资 |
| **期望型**（One-dimensional） | 越多越满意 | 线性投入，对标竞品 |
| **兴奋型**（Attractive） | 没有不不满，有了很惊喜 | 差异化来源，但要找对 |
| **无差异型** | 有没有都无所谓 | 不投资 |
| **反向型** | 有了反而不满 | 避免 |

**在 nailit 中的位置**：Step 2（需求分层）+ Step 4（投资优先级）

## 五、供应链专项方法论

### 1. SCOR 模型（Supply Chain Operations Reference）

**五大流程**：

| 流程 | 英文 | 核心活动 |
|------|------|---------|
| **Plan** | 计划 | 需求/供应规划、S&OP |
| **Source** | 采购 | 寻源、下单、收货、付款 |
| **Make** | 制造 | 生产、测试、包装 |
| **Deliver** | 交付 | 订单管理、运输、安装 |
| **Return** | 退货 | 退货处理、翻新、报废 |

**绩效维度**：可靠性 / 响应性 / 敏捷性 / 成本 / 资产管理

**在 nailit 中的位置**：贯穿 Step 1-3（供应链全景诊断）

### 2. DDMRP（Demand-Driven MRP）

**核心思想**：用实际需求拉动补货，而非预测推动。

**三个核心机制**：
1. **战略解耦点**：在关键位置设置缓冲库存
2. **动态缓冲调整**：根据实际消耗自动调整缓冲大小
3. **需求驱动执行**：只在缓冲低于阈值时触发补货

**适用场景**：需求波动大、供应链长、牛鞭效应严重

**在 nailit 中的位置**：Step 4（库存优化方案）

### 3. S&OP（Sales & Operations Planning）

**五步流程**：

| 步骤 | 活动 | 输出 |
|------|------|------|
| 1. 数据准备 | 历史数据、趋势分析 | 基线数据包 |
| 2. 需求规划 | 需求预测、需求感知 | 需求计划 |
| 3. 供应规划 | 产能评估、约束分析 | 供应计划 |
| 4. 预会议 | 差异分析、方案准备 | 建议方案 |
| 5. 执行会议 | 高层决策、资源分配 | 最终计划 |

**在 nailit 中的位置**：Step 4（供需平衡方案）

### 4. 七步战略采购（Kearney）

| 步骤 | 活动 |
|------|------|
| 1. 分析品类 | 供应市场分析、品类定位 |
| 2. 制定策略 | 采购策略、供应商策略 |
| 3. 评估供应商 | 能力评估、财务健康、风险 |
| 4. 选择供应商 | RFQ/RFP、技术评审、商务谈判 |
| 5. 谈判 | 价格、条款、服务水平 |
| 6. 整合 | 供应商接入、流程对接 |
| 7. 持续改进 | 绩效监控、成本优化、创新合作 |

**在 nailit 中的位置**：Step 4（采购决策变量）

## 六、其他经典框架

### Ansoff 矩阵（安索夫矩阵）

|  | 现有产品 | 新产品 |
|--|---------|--------|
| **现有市场** | 市场渗透 | 产品开发 |
| **新市场** | 市场开发 | 多元化 |

### GE-麦肯锡矩阵

|  | 高吸引力 | 中吸引力 | 低吸引力 |
|--|---------|---------|---------|
| **强竞争力** | 投资增长 | 选择性投资 | 保护地位 |
| **中竞争力** | 选择性投资 | 选择性投资 | 收割/退出 |
| **弱竞争力** | 选择性投资 | 收割/退出 | 收割/退出 |

### 利益相关者分析（Stakeholder Analysis）

**四象限**：

|  | 高影响力 | 低影响力 |
|--|---------|---------|
| **高利益** | 密切合作 | 保持满意 |
| **低利益** | 保持知情 | 最少投入 |

### 决策矩阵（Weighted Scoring）

**步骤**：
1. 列出候选方案
2. 确定评估维度和权重
3. 每个维度打分（1-5）
4. 加权求和，排序
5. 敏感性分析：调整权重看排序是否稳定

## 七、框架组合拳

> 以下是在 nailit 各 Step 中嵌入辅助框架的推荐组合

```
MECE → 拆解问题结构

├── 五力模型 → 行业竞争
├── 价值链 → 内部活动
├── VRIO → 资源能力
└── 7S → 组织诊断
```

### Step 2（To-Be）的工具包

```
目标设定
├── 北极星指标 → 核心度量

├── JTBD → 客户真实需求
├── NPS → 客户满意度目标

```

### Step 3（Gap）的工具包

```
差距诊断
├── Issue Tree → 逻辑拆解

├── 5 Whys → 根因追问
└── 80/20 → 关键少数识别
```

```
方案生成
├── 利润池 → 切入位置
```

```
决策输出
```
