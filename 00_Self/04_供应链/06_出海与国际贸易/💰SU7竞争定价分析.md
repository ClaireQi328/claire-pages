## 术语速查

| 缩写 | 英文全称 | 中文 | 含义 |
|------|---------|------|------|
| **CBU** | Completely Built Up | 整车出口/进口 | 整车组装好直接运输销售 |
| **CKD** | Completely Knocked Down | 全散件出口 | 完全拆散为零件级，运到当地工厂组装 |
| **SKD** | Semi Knocked Down | 半散件出口 | 部分总成已预装，到当地做简单拼装 |

## 八、关税盈亏平衡分析

### 8.1 盈亏平衡模型框架

**关键变量**：
- 固定成本（建厂/认证/研发分摊）
- 变动成本（生产/物流/关税）
- 单车售价
- 销量规模

### 8.2 欧盟市场盈亏平衡计算（SU7 Max）

**CBU 模式（整车进口）**：

```
到岸成本 = FOB × (1 + 关税率) + 运费 + 保险 + 合规
         = $38,000 × (1 + 40.8%) + $2,500 + $2,000
         = $58,004

盈亏平衡售价 = 到岸成本 × (1 + 经销商利润 12%) × (1 + 毛利率 10%)
              = $58,004 × 1.12 × 1.10
              = $71,461
              ≈ €66,000

❌ 结论：高于 BMW i4 (€51,370)，市场不可接受
```

**CKD 模式（匈牙利组装）**：

```
散件加权关税 = 2.5%（电池2.7% + 电机2.7% + 车身3% + 底盘2.75% 平均）

到岸成本 = FOB × (1 + 2.5%) + 运费 + 保险 + 合规 + 组装成本
         = $38,000 × 1.025 + $2,500 + $2,000 + $3,000
         = $47,450

盈亏平衡售价 = $47,450 × 1.12 × 1.10
              = $58,368
              ≈ €54,000

🟡 结论：接近 Tesla Model 3 (€42,990)，需进一步优化
```

**CKD + 供应链本地化（40% 本地化率）**：

```
通过本地采购（座椅/轮胎/玻璃/线束等）降低关税基数

优化后到岸成本 = $42,000（估算）

盈亏平衡售价 = $42,000 × 1.12 × 1.10
              = $51,744
              ≈ €48,000

🟢 结论：有竞争力，可与 Tesla/BYD 竞争
```

### 8.3 盈亏平衡敏感性分析

|------|---------|-----------------|--------|
| **关税率** | ±5% | ±€3,300 | 🔴 高 |
| **FOB 价格** | ±$2,000 | ±€2,400 | 🔴 高 |
| **本地化率** | ±10% | ±€2,700 | 🔴 高 |

| **物流成本** | ±$500 | ±€600 | 🟢 低 |

### 8.4 盈亏平衡条件汇总

**欧盟市场盈亏平衡的 3 个必要条件**：

| 条件 | 要求 | 当前状态 | 差距 |
|------|------|----------|------|
| ① **关税率 ≤ 25%** | CKD 模式 + 匈牙利组装 | CBU 40.8% | 🔴 需建厂 |
| ② **本地化率 ≥ 40%** | 获得"匈牙利制造"原产地证 | 0% | 🔴 需供应链重构 |
| ③ **年销量 ≥ 8,000 台** | 摊薄固定成本 | 0（未进入） | 🔴 需市场开拓 |

**盈亏平衡销量计算**：

```
固定成本（CKD 匈牙利工厂）：
  - 工厂建设：€8,000 万（分 5 年摊销 = €1,600 万/年）
  - 认证费用：€2,000 万（分 3 年摊销 = €667 万/年）
  - 研发分摊：€3,000 万/年
  - 管理费用：€2,000 万/年
  ─────────────────────────
  合计：€8,267 万/年

单车毛利（目标 10%）：
  - 售价：€54,000
  - 变动成本：€47,450
  - 毛利：€6,550

盈亏平衡销量 = €8,267 万 / €6,550 = 12,621 台/年
             ≈ 1,052 台/月
```
