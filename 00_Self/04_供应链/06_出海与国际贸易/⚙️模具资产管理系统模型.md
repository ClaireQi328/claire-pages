## 💡 核心发现

> [!tip]- 一句话总结
> - **模具不只是"资产"**：它是生产系统的核心瓶颈资源，坏了整条线停产
> - **管理的核心矛盾**：模具在哪里 × 谁在用 × 还能用多久 × 花了多少钱
> - **系统设计关键**：实时冲次采集 + 预测性维护 = 把"坏了再修"变成"快坏了提前修"
> - **厂外模具是盲区**：放在供应商那里的模具，数据断层最大、风险最高

### 1.2 模具 vs 普通设备的管理差异

| 维度 | 普通设备（如机器人） | 模具（如冲压模） |
|------|---------------------|-------------------|
| **寿命度量** | 运行小时数 | **冲次/件数**（核心差异） |
| **磨损特征** | 渐进式，可预测 | 冲次累积→突然失效（磨损曲线非线性） |
| **维护模式** | 定期保养（按时间） | **按冲次保养** + 定期检查 |
| **存放管理** | 固定在产线 | **频繁换模**，需要库位管理 |
| **产权归属** | 通常 OEM 自有 | **多种模式**（OEM/供应商/共有） |
| **成本结构** | 采购+维护 | 采购+维护+分摊（向供应商收取） |
| **管理跨度** | 厂内 | **厂内+厂外**（供应商处模具） |
| **瓶颈影响** | 有备用方案 | **无替代**，模具坏了整线停产 |

### 3.2 状态定义

| 状态 | 英文 | 触发条件 | 允许操作 | 阻塞生产？ |
|------|------|----------|----------|------------|
| **采购中** | Purchasing | 合同签订 | 跟踪进度 | - |
| **待验收** | Pending Acceptance | 到货 | 验收检查 | - |
| **在库** | In Stock | 验收通过 | 领用、盘点 | 否 |
| **在用** | In Use | 上线生产 | 生产记录、冲次采集 | 否 |
| **保养中** | In Maintenance | 到达保养冲次/时间 | 保养作业 | ⚠️ 是 |
| **维修中** | Under Repair | 故障/异常 | 维修作业 | 🔴 是 |
| **待报废** | Pending Scrapping | 寿命耗尽/判定报废 | 审批 | 🔴 是 |
| **已报废** | Scrapped | 报废审批通过 | 资产处置 | - |
| **验收异常** | Acceptance Exception | 验收不合格 | 退修/退货 | - |

### 3.3 关键状态转移规则

| 转移 | 触发条件 | 审批要求 | 系统动作 |
|------|----------|----------|----------|
| 在用 → 保养中 | `current_strokes >= next_maint_stroke` 或到达保养日期 | 自动触发 | 生成保养工单，通知维护团队 |
| 在用 → 维修中 | 操作员报修 / IoT 异常告警 | 班组长确认 | 生成维修工单，通知供应商（如需） |
| 保养中 → 在用 | 保养完成 + 质检通过 | 质检员确认 | 更新 `next_maint_stroke`，恢复生产 |
| 在用 → 待报废 | `life_pct >= 95%` 或 经济性评估不合格 | 技术+财务+管理层审批 | 冻结模具，发起报废流程 |

#### **模块 5：成本管理**

| 功能 | 说明 |
|------|------|
| **原值管理** | 采购成本、运费、安装费归集 |
| **折旧计算** | 按产量法/直线法自动计算折旧 |
| **维修成本** | 维修工单费用归集、备件消耗 |
| **分摊管理** | 向供应商收取分摊费（OEM 垫付模式） |
| **单冲次成本** | (原值残值 + 累计维修) / 累计冲次 |
| **TCO 分析** | 模具全生命周期总拥有成本 |

**成本结构分解**：

```
单冲次成本 = (采购原值 - 残值 + 累计维修费) / 累计冲次

示例：
采购原值：$2,500,000
残值（5%）：$125,000
累计维修费：$45,000
累计冲次：125,000

单冲次成本 = ($2,500,000 - $125,000 + $45,000) / 125,000
           = $2,420,000 / 125,000
           = $19.36/冲次

单车模具成本 = 单冲次成本 × 单车冲次数
            = $19.36 × 1（假设 1 冲次 = 1 件）
            = $19.36/车
```

#### **模块 7：预测性维护**

| 功能 | 说明 |
|------|------|
| **数据采集** | 冲次、压力曲线、温度、振动、产品质量 |
| **特征工程** | 提取磨损特征（毛刺高度、间隙值、表面粗糙度） |
| **模型训练** | 基于历史数据训练剩余寿命预测模型 |
| **实时预测** | 输入当前数据 → 输出 RUL（剩余有用寿命） |
| **自动排程** | 基于 RUL 自动调整保养计划 |

**预测性维护模型**：

```
输入特征：
  X1: 累计冲次
  X2: 近 1000 次合格率趋势
  X3: 毛刺高度（传感器）
  X4: 冲压力曲线偏差
  X5: 模具温度
  X6: 上次保养后冲次

输出：
  RUL（Remaining Useful Life）= 剩余可用冲次
  置信区间 = ±N 冲次

判定规则：
  IF RUL < 5,000 → 红色告警，建议立即保养
  IF RUL < 20,000 → 黄色预警，安排保养计划
  IF RUL > 50,000 → 绿色正常

模型算法建议：
  - 数据量少：物理模型 + 专家规则
  - 数据量中：随机森林 / XGBoost
  - 数据量大：LSTM 时序预测
```

| **BR-05** | 维修审批 | 维修费用 > ¥100,000 → 需采购+财务双审批 | P1 |
| **BR-06** | 报废审批 | 报废需 技术部+财务部+管理层 三级审批 | P0 |

| **BR-09** | 成本归集 | 维修成本自动归集到对应模具台账，月结时同步 ERP | P1 |
| **BR-10** | 盘点差异 | 盘点差异 > 0 → 冻结模具，48 小时内查明原因 | P0 |
