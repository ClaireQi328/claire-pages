# 产能管理 × APS：有限产能排程

> 💡 产能管理和 APS 的分工一句话说清：**产能管理告诉 APS "你有多少资源可用"，APS 告诉产能管理 "我把这些资源怎么用了"。**

---

## 一、产能管理和 APS 的分工

| 维度 | 产能管理 | APS |
|------|---------|-----|
| **角色** | 资源管理者 | 排程执行者 |
| **输入** | 设备能力、人员、模具数据 | 工单、BOM、工艺路线 |
| **输出** | 可用产能、产能约束 | 排程计划、甘特图 |
| **粒度** | 日/周（战术层） | 小时/分钟（执行层） |
| **关注点** | "够不够？给谁？" | "什么时候做？先做哪个？" |
| **时间跨度** | 全跨度（战略+战术+执行） | 短期（1-4 周） |

**类比**：产能管理是"餐厅老板"（决定几张桌、几个厨师、接多少客），APS 是"排位系统"（决定哪个客人坐哪桌、什么时候上菜）。

---

## 二、产能管理向 APS 提供的约束

APS 排程必须遵守产能管理定义的约束规则：

```
产能约束 = f(设备, 人力, 模具, 物料, 时间)
```

### 2.1 设备约束

```
设备可用时间 = 日历时间 − 计划停机 − 非计划停机
设备产能 = 可用时间 × 设备速率 × OEE

并行约束：同一设备同时只能做 1 个工单
顺序约束：某些工序必须在特定设备上按顺序执行
```

**示例**：

| 设备 | 设计速率 | OEE | 可用时间 | 日产能 |
|------|---------|-----|---------|--------|
| 冲压机 A | 1200 件/h | 85% | 7.5h | 7,650 件 |
| 焊接机器人 B | 60 JPH | 90% | 7.5h | 405 件 |
| 涂装线 C | 60 JPH | 88% | 7.5h | 396 件 |
| 总装线 D | 60 JPH | 92% | 7.5h | 414 件 |

### 2.2 人力约束

```
人力产能 = 人数 × 工时 × 效率系数

技能矩阵约束：
- A 工序需要高级技工（持证上岗）
- B 工序普通工人即可
- C 工序需要双人协作

班次约束：
- 单班：8:00-17:00 → 7.5h 有效工时
- 双班：8:00-01:00 → 15h 有效工时
- 三班：24h 连续 → 22.5h 有效工时（扣除交接班）
```

### 2.3 模具约束

```
模具数量 × 模具寿命 × 换模时间

示例：
- 某冲压模具只有 2 套
- 每套模具寿命 10000 次（已用 8000 次）
- 换模时间 30 分钟
- 产品 A 和 B 共用同一套模具

→ 模具约束：日产能受限于 2 套模具的产出 + 换模损失
→ 寿命约束：剩余 2000 次，需要提前采购新模具
→ 共享约束：A 和 B 不能同时生产，需要排换模顺序
```

### 2.4 物料约束

```
物料可用量 / BOM 用量 = 物料约束产能

示例：
- 产品 X 需要芯片 Y（BOM 用量：2 件/台）
- 芯片 Y 库存：5000 件
- → 物料约束产能 = 5000 / 2 = 2500 台

供应商产能约束（来自 SRM）：
- 芯片 Y 供应商月产能 5 万件
- → 月物料约束产能 = 50000 / 2 = 25000 台

齐套约束：
- 产品 X 需要 A、B、C 三种物料
- A 有 1000 件，B 有 800 件，C 有 1200 件
- → 齐套约束产能 = min(1000, 800, 1200) = 800 台
```

## 三、APS 反馈给产能管理的数据

| 数据 | 内容 | 产能管理的用途 |
|------|------|--------------|
| 排程甘特图 | 每台设备/每个时间槽的排程 | 产能可视 |
| 资源利用率 | 排程后的设备/人力利用率 | 瓶颈识别 |
| 排程冲突 | 资源争用、超负荷 | 产能预警 |
| 工单完成预测 | 每个工单的预计完成时间 | 交期承诺 |
| 换线计划 | 产品切换时间和顺序 | 产能损失计算 |

## 四、What-if 场景模拟

这是产能管理与 APS 协同最强大的能力——**在不实际执行的情况下，模拟"如果发生X会怎样"**。

### 4.1 场景 1：紧急插单

```
输入：新订单（产品 Y，500 件，要求 3 天内交货）

模拟步骤：
1. 产能管理查询当前产能负荷（各产线利用率）
2. 将新订单传给 APS，要求"紧急排程"
3. APS 返回：
   ├── 方案 A：插入产线 B，延迟订单 #123 和 [[125（各]] 2 天）
   ├── 方案 B：插入产线 C（需加班），不影响其他订单，成本 +2 万
   └── 方案 C：外协生产，成本 +5 万，不影响任何订单
4. 产能管理评估：
   ├── 订单 #123 是战略客户 → 方案 A 不可接受
   ├── 加班成本 2 万 vs 订单利润 10 万 → 方案 B 划算
   └── 决策：选择方案 B
```

### 4.2 场景 2：设备故障

```
输入：产线 A 主焊机故障，预计修复 8 小时

模拟步骤：
1. 产能管理更新产线 A 可用产能（-8 小时）
2. APS 重新排程：
   ├── 受影响工单 12 个
   ├── 其中 3 个可以转产线 B（有替代设备）
   ├── 其中 9 个只能等待修复
   └── 总体延迟：3 个订单延迟 1 天
3. 产能管理决策：
   ├── 3 个转产线 B → 执行
   ├── 9 个等待 → 通知客户延迟
   └── 同时触发设备维修工单
```

### 4.3 场景 3：加班 vs 外包决策

```
场景：本月产能缺口 2000 工时

┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 方案      │ 产能增量  │ 成本      │ 质量风险  │ 灵活性    │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│ 周末加班  │ +1500h   │ 人工 1.5x │ 中（疲劳）│ 高       │
│ 夜班加班  │ +800h    │ 人工 2x   │ 高       │ 高       │
│ 外协加工  │ 不限     │ 成本 +30% │ 中       │ 中       │
│ 临时工    │ +1000h   │ 培训+工资 │ 高       │ 低       │
└──────────┴──────────┴──────────┴──────────┴──────────┘

决策逻辑：
├── 缺口 2000h，周末加班可覆盖 1500h → 覆盖 75%
├── 剩余 500h 用外协 → 总成本可控
├── 质量风险：周末加班中等，外协中等 → 可接受
└── 决策：周末加班 + 外协 500h
```

### 4.4 场景 4：换线优化

```
场景：本周需要生产 5 种产品，换线时间各不同

换线矩阵（分钟）：
        → 产品A  → 产品B  → 产品C  → 产品D  → 产品E
产品A      -      30      45      20      35
产品B     30       -      15      40      25
产品C     45      15       -      30      20
产品D     20      40      30       -      10
产品E     35      25      20      10       -

最优换线顺序（APS 求解）：
D → E → C → B → A
总换线时间：10 + 20 + 15 + 30 = 75 分钟

vs 最差顺序：
A → C → E → D → B
总换线时间：45 + 20 + 10 + 40 = 115 分钟

节省：40 分钟（35%）
```
