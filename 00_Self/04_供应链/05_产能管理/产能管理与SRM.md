# 产能管理 × SRM：供应商产能协同

> 💡 产能管理不能止步于"自己的工厂"。对制造业而言，**供应商产能 = 你的产能上限之一**。2021 年全球汽车行业因缺芯减产约 1000 万辆，本质上就是**供应链产能管理失败**。

---

## 一、为什么要管供应商产能？

一个真实场景：

> 芯片缺货时，你自己的产线空转——不是因为你没产能，而是因为供应商没产能。

供应商产能管理的核心矛盾：

| 你的视角 | 供应商的视角 |
|---------|------------|
| 我需要你保产能 | 我需要你保订单量 |
| 你的产能是我的产能上限 | 你的订单量是我的收入来源 |
| 我希望你预留产能给我 | 我希望产能不被锁定、灵活分配 |

**解决之道**：通过 LTA（长期协议）+ 产能可视 + 配额机制，在"锁定"和"灵活"之间找到平衡。

---

## 二、四类交互场景

| 场景 | 数据流向 | 内容 | 触发条件 | 频率 |
|------|---------|------|---------|------|
| **产能可视** | SRM → 产能管理 | 供应商周/月产能报告、产能利用率 | 定期 | 周/月 |
| **产能预留** | 产能管理 → SRM | 预留产能请求（LTA 框架） | 新项目定点 | 事件触发 |
| **产能预警** | SRM → 产能管理 | 供应商产能不足/超负荷/断供风险 | 异常事件 | 实时 |
| **产能分配** | 产能管理 → SRM | 供应商配额调整建议 | 供需变化 | 周度 |

## 三、场景详解

### 3.1 场景 A：供应商产能可视

**目标**：知道每个关键供应商"还能接多少活"。

```
数据采集方式：
├── 方式 1：供应商主动填报（SRM 门户）
│   └── 供应商每月填报产能声明（Capacity Declaration）
│       字段：零件号、月产能、已承诺量、剩余可用量
│
├── 方式 2：EDI 830 自动推送
│   └── OEM 发送 830（Planning Schedule）给供应商
│       供应商回复产能确认
│
└── 方式 3：API 实时对接（高成熟度）
    └── 供应商 MES/ERP API → OEM 产能管理平台
        实时获取供应商设备状态和排产进度
```

**产能可视看板示例**：

```
┌─────────────────────────────────────────────────┐
│  供应商产能可视看板                                │
│                                                   │
│  供应商 A（芯片）  ████████████░░  80%  🟡       │
│  供应商 B（电容）  ██████████████  95%  🔴       │
│  供应商 C（PCB）   ██████░░░░░░░░  50%  🟢       │
│  供应商 D（连接器）████████░░░░░░  65%  🟢       │
│                                                   │
│  ⚠️ 预警：供应商 B 产能利用率 95%，建议启动备选   │
└─────────────────────────────────────────────────┘
```

### 3.2 场景 B：产能预留与 LTA 管理

**场景**：新车型定点时，需要为关键零件预留供应商产能。

```
流程：
1. 产能管理计算新车型的零件需求量（按月/年）
   例：某连接器，年产 50 万件
       ↓
2. 查询 SRM 中该零件的供应商产能
   供应商 A：月产能 8 万件（年 96 万）→ 可承接
   供应商 B：月产能 3 万件（年 36 万）→ 可承接部分
       ↓
3. 生成产能预留方案
   供应商 A：预留 60%（30 万件/年）
   供应商 B：预留 55%（20 万件/年）
       ↓
4. 推送到 SRM，触发 LTA 签订
   LTA 条款：产能预留 + 价格联动 + 最低采购承诺
```

**LTA 中的产能条款设计**：

| 条款 | 内容 | 目的 |
|------|------|------|
| **产能预留量** | 供应商每月为 OEM 预留 X 件产能 | 保障供应 |
| **最小采购承诺** | OEM 每年至少采购 Y 件 | 保障供应商收入 |
| **弹性区间** | 预留量 ±15% 浮动 | 应对需求波动 |
| **价格联动** | 产能预留量越大，单价越低 | 激励长期合作 |
| **违约条款** | 供应商未保产能 → 赔偿；OEM 未保量 → 补偿 | 双向约束 |

### 3.3 场景 C：供应商产能预警与应急

**预警等级**：

| 等级 | 触发条件 | 响应动作 |
|------|---------|---------|
| 🟢 正常 | 利用率 <80% | 常规监控 |
| 🟡 关注 | 利用率 80-90% | 增加安全库存、确认交期 |
| 🟠 预警 | 利用率 >90% | 启动备选供应商、调整配额 |
| 🔴 紧急 | 供应商通知断供 | 全力调动备选、调整排程 |

**应急响应流程**：

```
供应商产能不足时：
1. SRM 发出预警 → 产能管理接收
2. 评估影响范围：
   - 受影响零件清单
   - 受影响产品/客户
   - 预计缺口量和持续时间
3. 生成应急方案：
   ├── 方案 A：启用备选供应商（AB 点切换）
   ├── 方案 B：调整配额（减少 A 增加 B）
   ├── 方案 C：调整排程（延迟非紧急订单）
   └── 方案 D：客户沟通（协商交期）
4. 推送方案到相关系统（SRM/APS/SCM）
```

### 3.4 场景 D：产能分配与配额调整

**配额调整的触发条件**：

| 触发条件 | 调整方向 | 依据 |
|---------|---------|------|
| 供应商 A 产能紧张（>90%） | 减少 A 配额，增加 B | 产能利用率数据 |
| 供应商 B 质量下降（PPM 上升） | 减少 B 配额，增加 A | 质量绩效数据 |
| 新供应商 C 通过验证 | 逐步增加 C 配额 | 供应商评估结果 |
| 需求下降 20% | 按比例减少所有供应商 | 需求预测数据 |

## 四、SRM 提供给产能管理的数据清单

| 数据字段 | 来源 | 频率 | 用途 |
|---------|------|------|------|
| 供应商产能声明（Capacity Declaration） | SRM 门户/EDI | 月度 | 中期产能规划 |
| 确认交期（Confirmed Delivery Date） | SRM 订单确认 | 实时 | 订单承诺 |
| 产能利用率 | SRM/供应商填报 | 周度 | 产能瓶颈预警 |
| 历史准时交付率（OTD） | SRM 绩效模块 | 月度 | 产能可靠性评估 |
| 质量合格率（PPM） | SRM 质量模块 | 月度 | 有效产能修正 |
| 产能扩展计划 | SRM 战略模块 | 季度 | 长期产能规划 |

---

## 五、产能管理输出给 SRM 的决策

| 输出 | 内容 | SRM 的动作 |
|------|------|-----------|
| 配额调整建议 | "供应商 A 配额从 60% 调到 40%" | 执行配额变更、通知供应商 |
| 产能预留请求 | "为新项目预留月产能 5 万件" | 发起 LTA 谈判 |
| 供应商切换建议 | "启用备选供应商 B" | 发起供应商导入流程 |
| 产能协调通知 | "下月需求增加 20%，请确认产能" | 向供应商发送产能确认请求 |

## 六、供应商产能协同成熟度模型

| 等级 | 特征 | 数据方式 | 典型企业 |
|------|------|---------|---------|
| **Level 1：被动响应** | 供应商不交货才发现问题 | 电话/邮件 | 中小制造 |
| **Level 2：定期报告** | 供应商每月填报产能 | SRM 门户 | 多数制造企业 |
| **Level 3：EDI 协同** | 产能数据自动交换 | EDI 830/862 | 汽车行业 |
| **Level 4：实时可视** | 供应商产能实时可见 | API 对接 | 领先企业 |
| **Level 5：联合规划** | 供应商参与 S&OP | 联合产能规划 | 丰田/苹果 |
