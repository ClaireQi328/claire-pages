# 定义、边界与三层模型

> 💡 产能管理是"产能的全生命周期管理"，APS 和 RCCP 只是它的执行工具。产能管理 = 产能的**"数据中台" + "决策中枢"**。

---

## 一、先厘清一个常见误解

很多人把"产能管理"等同于"APS 排程"或"MPS 产能校验"——这是错的。

| 概念 | 回答的问题 | 时间跨度 | 谁在用 |
|------|-----------|---------|--------|
| **MPS 产能校验（RCCP）** | "这个月的 MPS 能不能排下去？" | 周-月 | 计划员 |
| **APS 排程** | "这周三产线 A 先做哪个单？" | 小时-天 | 车间计划员 |
| **产能管理** | "整体能做多少？瓶颈在哪？给谁做？未来够不够？" | 全跨度 | 供应链总监+VP |

**关键区分**：APS 是"排程引擎"，产能管理是"产能大脑"。APS 告诉你"这周三产线 A 排了 500 件"，产能管理告诉你"产线 A 本月还剩 30% 产能，建议分配给客户 X"。

## 二、产能的三种定义

这是理解产能管理的基石——三种产能逐级递减，每一级都有对应的管理动作：

```
设计产能（Design Capacity）
│   理论最大值，设备铭牌产能
│   = 日历时间 × 设计速率
│   例：某冲压线设计产能 1200 件/天
│
├── 扣除：计划停机（维护、换班、节假日）
│   例：每天 8 小时工作制 → 可用 7.5 小时（扣除交接班/休息）
│
有效产能（Effective Capacity）
│   可持续运营的最大产能
│   = 有效工作时间 × 实际速率
│   通常 = 设计产能 × 70-85%
│   例：1200 × 0.8 = 960 件/天
│
├── 扣除：非计划停机（故障、缺料、质量、换线）
│   例：设备故障 30 分钟 + 换线 20 分钟 + 不良品 2%
│
实际产能（Actual Capacity）
    真实产出
    = 有效产能 × OEE
    通常 = 设计产能 × 55-75%
    例：960 × 0.85 = 816 件/天
```

**关键指标公式**：

| 指标 | 公式 | 健康值 | 含义 |
|------|------|--------|------|
| **产能利用率** | 实际产出 / 设计产能 | 75-85% | 设计产能用了多少 |
| **效率** | 实际产出 / 有效产能 | >90% | 有效产能用了多少 |
| **OEE** | 可用率 × 表现性 × 良品率 | ≥85% | 设备综合效率 |

**为什么利用率不是越高越好？**

> 💡 利用率 >90% = 没有 buffer = 任何异常（设备故障、紧急插单、供应商延迟）都会导致交期违约。
>
> **汽车行业经验法则：留 15-20% buffer 给波动和 NPI 爬坡。** 半导体行业因为资本密度极高，利用率目标 >90%，靠极高的良率和计划精度来弥补。

## 三、产能管理的三层模型

每一层解决不同问题、面向不同角色、使用不同数据：

```
┌─────────────────────────────────────────────────────────────┐
│                    战略层（Strategic）                        │
│         1-5 年  ·  工厂布局 · 产线投资 · 外包策略             │
│         决策者：VP / CSCO / COO                              │
│         输入：业务战略、市场预测、资本预算                      │
│         输出：产能蓝图、投资计划、供应商产能协议               │
├─────────────────────────────────────────────────────────────┤
│                    战术层（Tactical）                         │
│         1-6 月  ·  产能分配 · 工厂平衡 · 粗能力计划            │
│         决策者：供应链总监 / 计划经理                          │
│         输入：S&OP 决议、需求预测、现有产能                    │
│         输出：产能分配方案、RCCP 报告、ATP/CTP               │
├─────────────────────────────────────────────────────────────┤
│                    执行层（Operational）                      │
│         日/班次  ·  排程约束 · OEE 监控 · 异常响应             │
│         决策者：车间主任 / 工厂厂长                            │
│         输入：MPS 工单、设备状态、实时数据                     │
│         输出：排程约束、产能预警、实际产出                     │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 战略层（Strategic）—— "未来需要多少产能？"

| 维度 | 内容 |
|------|------|
| **时间跨度** | 1-5 年 |
| **决策者** | VP / CSCO / COO |
| **核心问题** | 要不要建新工厂？要不要扩产线？自制还是外包？ |
| **输入** | 业务战略、市场预测、资本预算、技术路线图 |
| **输出** | 产能蓝图、投资计划、产能合作协议（LTA） |
| **关键工具** | SCP / IBP、Excel 财务模型、行业对标 |

**典型决策场景**：

```
场景：小米汽车 2027 年产能规划
├── 输入：2027 年销量目标 50 万辆
├── 现有产能：北京工厂 15 万辆 + 武汉工厂 15 万辆 = 30 万辆
├── 缺口：20 万辆
├── 方案评估：
│   ├── A. 北京二期扩建 → +10 万辆，投资 30 亿，18 个月
│   ├── B. 武汉工厂双班 → +5 万辆，投资 5 亿，6 个月
│   ├── C. 代工（海马/北汽） → +10 万辆，管理成本高
│   └── D. 海外工厂（泰国） → +10 万辆，投资 50 亿，24 个月
└── 决策：B + A 组合（短期双班 + 中期扩建）
```

### 3.2 战术层（Tactical）—— "产能怎么分配？"

| 维度 | 内容 |
|------|------|
| **时间跨度** | 1-6 月 |
| **决策者** | 供应链总监 / 计划经理 |
| **核心问题** | 产能给哪个产品？给哪个客户？哪个工厂做什么？ |
| **输入** | S&OP 决议、需求预测、现有产能、客户优先级 |
| **输出** | 产能分配方案、RCCP 报告、ATP/CTP |
| **关键工具** | APS（粗能力计划）、SCP 产能模块 |

**核心机制——产能分配规则引擎**：

```
需求总量 vs 可用产能
│
├── 产能充足 → 按需求分配，无需取舍
│
└── 产能不足 → 启动优先级分配
    │
    ├── 规则 1：战略客户优先（VIP 客户保障产能）
    ├── 规则 2：高毛利产品优先（利润导向）
    ├── 规则 3：交付紧急度（已确认订单 > 预测订单）
    ├── 规则 4：最小批量约束（不能低于 MOQ）
    └── 规则 5：公平性约束（单客户占比不超 40%）
```

**ATP/CTP 是这一层的核心输出**：

| 概念 | 计算方式 | 使用场景 |
|------|---------|---------|
| **ATP（可承诺量）** | 现有库存 + 计划产出 − 已确认订单 | 销售问"还能卖多少？" |
| **CTP（可承诺交期）** | 考虑产能约束后的最早交货日期 | 销售问"什么时候能交？" |
| **MTP（可制造性承诺）** | 考虑工艺约束后的可行性 | 工程问"这个配置能不能做？" |

### 3.3 执行层（Operational）—— "现在产能情况怎样？"

| 维度 | 内容 |
|------|------|
| **时间跨度** | 实时 / 日 / 班次 |
| **决策者** | 车间主任 / 工厂厂长 |
| **核心问题** | 设备停了怎么办？插单怎么排？瓶颈怎么调？ |
| **输入** | 设备状态（IoT）、工单进度（MES）、异常事件 |
| **输出** | 排程调整、产能预警、实际产出报告 |
| **关键工具** | APS（详细排程）、MES（执行监控）、IoT（数据采集） |

**实时监控核心指标**：

| 指标 | 定义 | 预警阈值 |
|------|------|---------|
| **设备 OEE** | 可用率 × 表现性 × 良品率 | <80% 黄色，<70% 红色 |
| **产线节拍** | 实际产出节拍 vs 设计节拍 | 偏差 >5% 预警 |
| **在制品（WIP）** | 线上在制品数量 | 超过 buffer 上限预警 |
| **停线时间** | 累计非计划停线时间 | >30 分钟/班次预警 |
| **换线时间** | 上一产品末件到下一产品首件 | >目标时间预警 |

## 四、产能管理 vs 相关系统的边界

| 功能 | 产能管理 | APS | MES | SCP |
|------|:-------:|:---:|:---:|:---:|
| 产能主数据维护 | ✅ 管 | ❌ 用 | ❌ | ❌ |
| 产能规划（投资决策） | ✅ 管 | ❌ | ❌ | ✅ 协同 |
| 产能分配（客户/产品） | ✅ 管 | ❌ | ❌ | ❌ |
| ATP/CTP 计算 | ✅ 管 | ❌ | ❌ | ✅ 用 |
| 有限产能排程 | ❌ 提供约束 | ✅ 管 | ❌ | ❌ |
| 实时设备监控 | ❌ 用数据 | ❌ | ✅ 管 | ❌ |
| OEE 采集与分析 | ❌ 用数据 | ❌ | ✅ 管 | ❌ |
| 需求预测 | ❌ 用 | ❌ | ❌ | ✅ 管 |
| 产能预警与决策 | ✅ 管 | ❌ | ❌ | ❌ |

**一句话总结**：

> 产能管理 = 产能的**"数据中台" + "决策中枢"**。它不排程（APS 的事），不采集数据（MES/IoT 的事），不做需求预测（SCP 的事）。它做的是：**整合所有产能数据，做出产能层面的规划和分配决策，输出给各系统执行。**

---

## 五、产能管理的关键能力

| 能力 | 描述 | 价值 |
|------|------|------|
| **产能全景视图** | 从企业到设备的多级产能可视 | 一眼看清瓶颈在哪 |
| **ATP/CTP 引擎** | 实时计算可承诺量和交期 | 销售接单有底气 |
| **What-if 模拟** | 插单/故障/加班的场景模拟 | 决策有依据 |
| **产能预警** | 利用率超阈值自动告警 | 不事后救火 |
| **产能分配规则** | 可配置的优先级分配引擎 | 分配公平透明 |
| **多工厂平衡** | 跨工厂产能负荷均衡 | 避免有的闲有的忙 |
