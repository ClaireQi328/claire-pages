# 系统架构总设计

> 💡 前 7 个文件分别研究了产能管理的定义、与各系统的交互、行业实践。本文件把它们整合成一个**可落地的系统架构**——功能模块、数据模型、集成接口、实施路径。

---

## 一、功能模块全景

```
产能管理系统（Capacity Management System）
│
├── 📊 产能模型管理
│   ├── 多级产能模型（企业→工厂→产线→工序→设备）
│   ├── 产能约束定义（设备/人力/模具/物料/时间）
│   ├── 产能参数维护（OEE 目标、速率、换线时间）
│   └── 产能日历（班次、维护计划、节假日）
│
├── 📈 产能规划（Strategic）
│   ├── 中长期产能需求预测（与 SCP 联动）
│   ├── 产能缺口分析（按时间/工厂/产品）
│   ├── 投资方案评估（扩产/外包/新建 + ROI 分析）
│   └── 产能蓝图管理（3-5 年产能路线图）
│
├── 🔄 产能分配（Tactical）
│   ├── 客户/产品优先级管理
│   ├── 工厂间产能平衡
│   ├── ATP/CTP 计算引擎
│   ├── 产能分配规则引擎（可配置优先级规则）
│   └── 产能预留管理（LTA 对接）
│
├── 📡 产能监控（Operational）
│   ├── 实时 OEE 监控（设备→产线→工厂→企业）
│   ├── 产能利用率看板
│   ├── 瓶颈预警与告警（多级告警）
│   ├── 异常事件管理（故障/缺料/质量）
│   └── WIP 监控与产线节拍
│
├── 🔗 协同接口
│   ├── SRM 接口：供应商产能可视/预留/预警
│   ├── SCM 接口：ATP/CTP 输出、供需缺口
│   ├── APS 接口：产能约束下发、排程结果回收
│   ├── SCP 接口：产能规划输入/输出
│   ├── MES 接口：实时产出、OEE、工单进度
│   ├── ERP 接口：订单、BOM、库存
│   └── 数据直连接口：IoT/EDI/API 网关
│
└── 🤖 智能决策
    ├── What-if 场景模拟（插单/故障/加班/外包）
    ├── 产能预测（AI/ML 基于历史数据预测产能趋势）
    ├── 自动产能分配推荐（基于规则引擎 + 优化算法）
    └── 异常根因分析（关联分析、故障树）
```

## 二、数据模型

### 2.1 核心实体关系

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   工厂(Plant)│ 1:N │ 产线(Line)   │ 1:N │ 工序(Process)│
│ - 工厂ID     │────→│ - 产线ID     │────→│ - 工序ID     │
│ - 工厂名称   │     │ - 产线名称   │     │ - 工序名称   │
│ - 地理位置   │     │ - 设计JPH    │     │ - 瓶颈标识   │
│ - 产能上限   │     │ - OEE 目标   │     │ - 标准工时   │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │ 1:N
                                           ┌──────▼───────┐
                                           │设备(Equipment)│
                                           │ - 设备ID      │
                                           │ - 设备类型    │
                                           │ - 速率/小时   │
                                           │ - 当前 OEE    │
                                           │ - 运行状态    │
                                           │ - 维护计划    │
                                           └──────────────┘

┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 产品(Product)│ 1:N │ 工艺路线     │ 1:N │ 产能需求     │
│ - 产品ID     │────→│ (Routing)    │────→│ (CapReq)     │
│ - 产品名称   │     │ - 工序顺序   │     │ - 产品+工序  │
│ - 产品族     │     │ - 标准工时   │     │ - 单件工时   │
│ - 优先级     │     │ - 设备要求   │     │ - 批量       │
└──────────────┘     └──────────────┘     └──────────────┘

┌──────────────┐     ┌──────────────┐
│ 产能日历     │ N:1 │ 产能快照     │
│ (Calendar)   │────→│ (Snapshot)   │
│ - 日期       │     │ - 时间点     │
│ - 班次       │     │ - 可用产能   │
│ - 可用小时   │     │ - 已占用     │
│ - 维护计划   │     │ - 可用余额   │
└──────────────┘     └──────────────┘
```

### 2.2 关键数据表

| 表名 | 核心字段 | 说明 |
|------|---------|------|
| **capacity_model** | plant_id, line_id, process_id, equipment_id | 多级产能树 |
| **capacity_calendar** | date, shift, available_hours, maintenance | 产能日历 |
| **capacity_snapshot** | timestamp, available, occupied, balance | 产能快照 |
| **product_routing** | product_id, process_seq, standard_time | 工艺路线 |
| **capacity_allocation** | product_id, customer_id, allocated_qty, period | 产能分配 |
| **supplier_capacity** | supplier_id, part_no, capacity, committed | 供应商产能 |

## 三、系统集成接口

### 3.1 接口清单

| 接口 | 方向 | 协议 | 频率 | 数据 |
|------|------|------|------|------|
| **→ SRM** | 双向 | API / EDI | 实时/日 | 产能声明、配额、预警 |
| **→ SCM** | 产能管理→SCM | API / 消息 | 实时 | ATP、CTP、产能缺口 |
| **→ APS** | 双向 | API / 消息 | 小时 | 产能约束、排程结果 |
| **→ SCP** | 双向 | API | 周/月 | 产能规划、需求预测 |
| **→ MES** | MES→产能管理 | API / IoT | 分钟 | 产出、OEE、工单进度 |
| **→ ERP** | 双向 | API / RFC | 实时 | 订单、BOM、库存 |
| **→ IoT** | IoT→产能管理 | MQTT / OPC UA | 秒 | 设备状态、传感器数据 |
| **→ EDI** | 双向 | EDI 830/862/856 | 日 | 供应商产能、ASN |

## 四、技术选型参考

| 层级 | 技术选项 | 推荐场景 |

## 五、实施路径

### 5.1 分阶段实施

| 阶段 | 时间 | 目标 | 关键交付 | 前置条件 |
|------|------|------|---------|---------|
| **Phase 1：基础** | 3-6 月 | 产能数据标准化 | 产能主数据、多级产能模型、MES 对接 | MES 上线、主数据治理 |
| **Phase 2：可视** | 6-9 月 | 产能实时可视 | 产能看板、OEE 监控、瓶颈预警 | IoT 基础设施 |
| **Phase 3：协同** | 9-12 月 | 系统互联 | SRM/APS/SCP 接口、ATP/CTP | 各系统 API 就绪 |
| **Phase 4：智能** | 12-18 月 | 数据驱动决策 | AI 预测、自动分配、What-if | 足够的历史数据 |

### 5.2 各阶段详细交付

**Phase 1：基础（3-6 月）**

| 交付 | 内容 | 负责方 |
|------|------|--------|
| 产能主数据模型 | 工厂/产线/工序/设备层级 | 业务+IT |
| 产能参数定义 | OEE 目标、速率、换线时间 | 生产部门 |
| 产能日历 | 班次、维护计划、节假日 | 生产部门 |
| MES 数据对接 | 产出、OEE、工单进度 | IT |

**Phase 2：可视（6-9 月）**

| 交付 | 内容 | 负责方 |
|------|------|--------|
| 产能看板 | 多级产能可视（设备→企业） | IT+BI |
| OEE 监控 | 实时 OEE 计算和展示 | IT+IoT |
| 瓶颈预警 | 利用率超阈值自动告警 | IT |
| 异常事件管理 | 故障/缺料/质量事件跟踪 | 生产+IT |

**Phase 3：协同（9-12 月）**

| 交付 | 内容 | 负责方 |
|------|------|--------|
| SRM 接口 | 供应商产能可视/预警 | IT+采购 |
| APS 接口 | 产能约束下发、排程结果回收 | IT+计划 |
| SCP 接口 | 产能规划输入/输出 | IT+计划 |
| ATP/CTP 引擎 | 可承诺量/交期计算 | IT+销售 |

**Phase 4：智能（12-18 月）**

| 交付 | 内容 | 负责方 |
|------|------|--------|
| What-if 模拟 | 插单/故障/加班场景模拟 | IT+计划 |
| AI 产能预测 | 基于历史数据预测产能趋势 | IT+数据 |
| 自动分配推荐 | 规则引擎 + 优化算法 | IT+计划 |
| 异常根因分析 | 关联分析、故障树 | IT+生产 |

## 六、成功关键因素

| 因素 | 说明 | 常见失败原因 |
|------|------|------------|
| **数据质量** | 产能主数据准确是基础 | 设备参数不更新、OEE 数据造假 |
| **系统集成** | 与 SRM/APS/SCP 的接口要实时 | 接口不实时、数据不一致 |
| **组织协同** | 生产+采购+计划共同参与 | 各自为政、数据不共享 |
| **持续运营** | 模型参数持续优化 | 上线后不维护、参数三年没调 |
| **高层支持** | VP 级推动跨部门协作 | 只有 IT 在推，业务不配合 |
| **分步实施** | 先基础后智能，不贪大求全 | 一步到位，项目失控 |

## 七、投资估算

| 阶段 | 投资范围 | 说明 |
|------|---------|------|
| **Phase 1** | 200-500 万 | 主数据治理 + MES 对接 |
| **Phase 2** | 300-800 万 | 看板 + IoT 基础设施 |
| **Phase 3** | 500-1000 万 | 系统集成 + ATP/CTP |
| **Phase 4** | 300-600 万 | AI/ML + What-if |
| **合计** | 1300-2900 万 | 18 个月，含软件+实施+运维 |

> 💡 投资规模取决于企业现有 IT 基础。已有 MES/IoT 的企业，Phase 1-2 投资可降低 50%。
