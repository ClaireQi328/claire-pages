# 产能管理 × SCM：供需平衡与订单承诺

> 💡 SCM 的核心任务是"把正确的产品在正确的时间送到正确的地点"。但如果你不知道"能做多少"，就无法回答"什么时候能交"。**产能管理是 SCM 的"底气"。**

---

## 一、为什么产能管理是 SCM 的底气？

一个每天都在发生的场景：

> 销售接了一个大单，承诺 4 周交货。结果生产说"排满了，至少 8 周"。**根因就是产能管理没有给 SCM 提供可靠的 ATP/CTP。**

产能管理与 SCM 的关系：

```
SCM 问：客户要 1000 件，能交吗？
  │
  ├─ 产能管理答：ATP = 800 件（还有 200 缺口）
  │
  ├─ 方案 1：先交 800，剩余 200 下批补
  ├─ 方案 2：加班生产，1000 件全交
  ├─ 方案 3：外协 200 件
  └─ 方案 4：拒绝多出的 200 件
```

---

## 二、四类交互场景

| 场景 | 数据流向 | 内容 | 价值 |
|------|---------|------|------|
| **ATP 计算** | 产能管理 → SCM | 可承诺量（Available-to-Promise） | 销售接单决策 |
| **CTP 计算** | 产能管理 → SCM | 可承诺交期（Capable-to-Promise） | 客户交期回复 |
| **供需缺口** | SCM → 产能管理 | 需求 vs 产能差异 | 触发产能调整 |
| **订单优先级** | SCM → 产能管理 | 客户/产品优先级排序 | 产能分配依据 |

---

## 三、ATP/CTP 计算引擎详解

### 3.1 ATP（可承诺量）计算

**ATP 的本质**：在已有的计划中，还有多少"空余"可以承诺给新订单？

```
计算公式（按时间桶）：
ATP(t) = 期初库存(t) + 计划产出(t) − 已确认订单(t) − 安全库存

逐期滚动示例：
┌──────────┬────────┬────────┬────────┬────────┐
│ 时间桶    │ 第1周   │ 第2周   │ 第3周   │ 第4周   │
├──────────┼────────┼────────┼────────┼────────┤
│ 期初库存  │ 100    │ 50     │ 80     │ 30     │
│ 计划产出  │ 200    │ 200    │ 200    │ 200    │
│ 已确认订单│ 250    │ 170    │ 250    │ 100    │
│ 安全库存  │ 50     │ 50     │ 50     │ 50     │
│ ─────────│────────│────────│────────│────────│
│ ATP      │ 0      │ 30     │ -20    │ 80     │
│ 状态     │ 🔴     │ 🟢     │ 🔴     │ 🟢     │
└──────────┴────────┴────────┴────────┴────────┘

第 3 周 ATP 为负 → 产能不足 → 需要调整排程或拒绝新订单
```

**ATP 的两种计算模式**：

| 模式 | 逻辑 | 适用场景 |
|------|------|---------|
| **离散 ATP** | 每个时间桶独立计算 | 标准产品、库存生产（MTS） |
| **累积 ATP** | 累计计算，前期负数可被后期正数抵消 | 定制产品、订单生产（MTO） |

### 3.2 CTP（可承诺交期）计算

**CTP 的本质**：如果接了这个新单，最早什么时候能交？

```
计算逻辑：
1. 获取新订单需求（产品、数量、期望交期）
2. 查询产能管理的可用产能（按产线/工序/时间）
3. 按工艺路线，逐工序计算：
   - 该工序是否有可用产能？
   - 如果有 → 分配产能，记录完成时间
   - 如果没有 → 推迟到下一个可用时间槽
4. 最后一个工序的完成时间 = 可承诺交期

示例：
新订单：产品 X，1000 件，客户期望 7 月 25 日

工艺路线：冲压(2天) → 焊装(3天) → 涂装(2天) → 总装(2天)

产能查询：
- 冲压：7/15 有空闲 → 7/17 完成
- 焊装：7/17-7/20 满，7/21 有空闲 → 7/24 完成
- 涂装：7/24-7/25 满，7/27 有空闲 → 7/29 完成
- 总装：7/29-7/31 有空闲 → 7/31 完成

CTP 结果：最早交期 7/31（vs 客户期望 7/25，延迟 6 天）

决策选项：
├── 接受延迟 → 告知客户新交期
├── 加班赶工 → 涂装加班可提前 2 天 → 7/29
├── 外协涂装 → 可满足 7/25 → 但成本增加 15%
└── 拒绝订单 → 产能确实不足
```

### 3.3 ATP vs CTP vs MTP 对比

| 概念 | 全称 | 考虑因素 | 精度 | 适用场景 |
|------|------|---------|------|---------|
| **ATP** | Available-to-Promise | 库存 + 计划产出 − 已确认订单 | 低 | 快速回复"还有多少可卖" |
| **CTP** | Capable-to-Promise | ATP + 产能约束 + 工艺路线 | 中 | 精确回复"什么时候能交" |
| **MTP** | Manufacturable-to-Promise | CTP + 工艺可行性 + 特殊资源 | 高 | 回复"这个配置能不能做" |

## 四、供需平衡看板

### 4.1 核心指标

| 维度 | 指标 | 计算方式 | 健康值 | 预警阈值 |
|------|------|---------|--------|---------|
| **产能利用率** | 实际产出 / 有效产能 | 按工厂/产线 | 75-85% | >90% 或 <60% |
| **订单满足率** | 按时交付订单 / 总订单 | 按月统计 | >95% | <90% |
| **产能缺口** | 需求产能 − 可用产能 | 按周/月预测 | 0 | >10% |
| **瓶颈工序数** | 利用率 >90% 的工序 | 实时统计 | 0 | ≥1 |
| **ATP 覆盖率** | ATP 为正的时间桶占比 | 按周滚动 | >80% | <60% |

### 4.2 供需平衡矩阵

```
              需求低          需求高
           ┌──────────────┬──────────────┐
  产能高   │  产能过剩     │  基本平衡     │
           │  → 优化效率   │  → 持续监控   │
           │  → 承接代工   │              │
           ├──────────────┼──────────────┤
  产能低   │  严重过剩     │  产能不足     │
           │  → 关停产线   │  → 加班/外包  │
           │  → 人员优化   │  → 扩产规划   │
           └──────────────┴──────────────┘
```

## 五、产能管理输出给 SCM 的决策支持

| 输出 | 内容 | SCM 的动作 |
|------|------|-----------|
| ATP 报告 | "本月还可接单 5000 件" | 销售接单参考 |
| CTP 报告 | "这个单最早 7/31 交" | 客户交期回复 |
| 供需缺口预警 | "下月产能缺口 15%" | 触发 S&OP 会议 |
| 优先级排序 | "客户 A 优先级高于客户 B" | 订单排程调整 |
| 多工厂分配建议 | "产品 X 建议在工厂 B 生产" | 工厂间产能平衡 |

## 六、SCM 反馈给产能管理的数据

| 数据 | 内容 | 产能管理的用途 |
|------|------|--------------|
| 需求预测 | 未来 12 月按产品/客户的需求量 | 产能规划输入 |
| 订单优先级 | 客户分级、产品利润排序 | 产能分配规则 |
| 库存水位 | 成品/半成品库存 | ATP 计算输入 |
| 物流约束 | 运输时间、仓储能力 | CTP 计算修正 |
