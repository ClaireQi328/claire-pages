## 一、什么是月结

**月结（Monthly Settlement）** 是供应链中最普遍的结算模式：月末汇总当月所有采购交易，统一生成结算单，按约定账期付款。

### 月结 vs 其他结算模式

| 模式 | 结算频率 | 适用场景 | 优缺点 |
|------|----------|----------|--------|
| 月结 | 每月一次 | 大宗物料、框架协议 | 效率高，但差异堆积 |
| 周结 | 每周一次 | 高频交易、电商供应商 | 差异少，但操作量大 |
| 季结 | 每季一次 | 长周期定制件 | 减少操作，但资金压力大 |
| 预付+尾款 | 分两次 | 定制模具、设备 | 供应商风险低，采购方资金占用 |
| 即时结算 | 每笔 | MRO、小额采购 | 无对账压力，但付款成本高 |

## 二、月结全流程

```
┌──────────────────────────────────────────────────────────────┐
│                      月结全流程（T+30天为周期）                   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  D1~D25        D25~D28        D28~D30        T+1~T+5        │
│  业务发生期      对账窗口        结算单生成       付款执行        │
│                                                              │
│  ·采购订单      ·供应商提交     ·差异确认        ·付款申请       │
│  ·收货入库       对账明细      ·结算单审批      ·付款审批       │
│  ·发票接收      ·系统自动      ·生成应付凭证    ·银企直连       │
│                比对                                   付款      │
└──────────────────────────────────────────────────────────────┘
```

### 2.1 收货截止与开票截止

| 概念 | 定义 | 作用 |
|------|------|------|
| 收货截止日 | 当月最后可收货日期（如25日） | 确保收货数据完整后再对账 |
| 开票截止日 | 供应商最晚开票日期（如28日） | 确保发票数据完整后再结算 |
| 结算周期 | 收货截止日 → 开票截止日 → 结算日 | 控制对账窗口期 |

> [!warning] 截止日管理
> 收货截止日后入库的物资，会计入下月结算。如果供应商在25日23:59发货但26日凌晨才入库，这笔交易就会跨月，导致供应商对账差异。

### 2.2 结算单生成逻辑

```
结算单 = Σ（入库单 × 协议价格） - Σ（退货单 × 协议价格） ± 价格调整

其中：
- 入库单：已确认收货的采购入库记录
- 协议价格：框架协议或采购订单约定的价格
- 退货单：当月发生的退货记录
- 价格调整：补差、扣款、返利等
```

### 2.3 差异处理

| 差异类型 | 产生原因 | 处理方式 |
|----------|----------|----------|
| 数量差异 | 收货数量 ≠ 发票数量 | 以实际收货为准，要求供应商补开/冲红 |
| 价格差异 | 发票价格 ≠ 协议价格 | 核实协议，按协议价结算 |
| 时间差异 | 跨月收货/开票 | 计入正确月份结算 |
| 税率差异 | 发票税率 ≠ 合同约定税率 | 退回重开 |

## 三、账期管理

### 3.1 账期计算规则

```
付款日 = 结算确认日 + 账期天数

例：
- 结算确认日：2026年7月30日
- 账期：Net 30
- 付款日：2026年8月29日
```

### 3.2 账期分级管理

| 级别 | 账期 | 适用对象 | 管理要求 |
|------|------|----------|----------|
| S级 | Net 15 | 战略供应商（独家供应） | 优先付款，保障供应 |
| A级 | Net 30 | 核心供应商 | 标准流程 |
| B级 | Net 45-60 | 一般供应商 | 正常排期 |
| C级 | Net 90 | 非关键供应商 | 可协商延长 |

### 3.3 账期优化策略

1. **提前付款折扣**：与供应商协商 2/10 Net 30（10天内付款享2%折扣），年化折扣收益约 36%
2. **动态折扣**：根据供应商资金需求灵活调整折扣率
3. **供应链金融**：通过银行保理，供应商提前收款，采购方按原账期付款

## 四、结算系统架构

### 4.1 功能模块

```
结算管理系统
├── 对账管理
│   ├── 自动对账引擎（按供应商/物料/订单维度）
│   ├── 差异标记与跟踪
│   └── 供应商自助对账门户
├── 结算单管理
│   ├── 结算单自动生成
│   ├── 结算单审批流程
│   └── 结算单变更/作废
├── 账期管理
│   ├── 账期规则配置
│   ├── 付款日历
│   └── 到期预警
├── 差异处理
│   ├── 差异分类（数量/价格/时间/税务）
│   ├── 差异审批
│   └── 差异报表
└── 结算看板
    ├── 月度结算进度
    ├── 差异分布分析
    ├── 付款计划预测
    └── 供应商满意度指标
```

### 4.2 与周边系统对接

| 对接系统 | 接口方向 | 数据内容 |
|----------|----------|----------|
| ERP/WMS | 入 ← | 入库单、退货单 |
| SRM | 双向 | 采购订单、框架协议、供应商信息 |
| 发票系统 | 入 ← | 发票数据、认证结果 |
| 资金系统 | 出 → | 付款指令、付款结果 |
| 税务系统 | 双向 | 进项税认证、纳税申报 |

## 六、常见坑与经验

| 坑 | 描述 | 解法 |
|----|------|------|
| "假收货" | 系统收货但实物未到，导致提前结算 | 收货确认需实物+系统双签 |
| 价格滞后 | 框架协议调价后系统未同步 | 价格变更需自动触发结算单更新 |
| 跨月退货 | 退货发生在下月，但影响上月结算 | 退货需关联原结算单，支持跨月冲销 |
| 多币种结算 | 跨境采购的汇率波动 | 以约定汇率（月初/月末/实时）锁定 |
