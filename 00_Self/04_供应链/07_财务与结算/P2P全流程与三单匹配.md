# 结算、对账、付款、发票流程及系统

> 💡 **10年+视角**：P2P（Procure-to-Pay）是采购的"最后一公里"。很多企业采购做得不错，但结算环节一团糟——三单匹配靠人工、发票积压、供应商投诉付款慢。**供应商愿意给你好价格、好交期，很大程度取决于你付款及不及时。**

---

## 一、P2P 全流程

```
采购申请(PR) → 采购订单(PO) → 收货入库(GR) → 发票接收(INV) → 三单匹配 → 付款审批 → 付款执行
                                                                    │
                                                              PO = GR = INV ?
                                                              差异处理
```

---

## 二、三单匹配（Three-Way Match）

### 2.1 匹配逻辑

```
PO（采购订单）：数量 100，单价 10 元 = 1,000 元
GR（收货记录）：实际收货 98 件
INV（供应商发票）：发票金额 1,000 元（按 100 件开）

匹配结果：
  数量差异：PO 100 vs GR 98 → 差异 2 件
  金额差异：INV 1,000 vs GR 980 → 差异 20 元
  → 触发差异处理流程
```

### 2.2 匹配规则

| 匹配类型 | 匹配内容 | 容差设置 | 处理方式 |
|---------|---------|---------|---------|
| **严格匹配** | PO=GR=INV 完全一致 | 0% | 差异必须解决 |
| **2单匹配** | PO=INV（不看GR） | ±5% | 适合服务类采购 |
| **3单匹配** | PO=GR=INV | ±2% | 最严格，适合物料 |
| **自动过账** | 差异在容差内自动通过 | 按规则 | 减少人工处理 |

## 三、发票管理

### 3.1 发票类型

| 类型 | 说明 | 系统处理 |
|------|------|---------|
| **增值税专用发票** | 可抵扣进项税 | OCR识别→自动校验→认证抵扣 |
| **增值税普通发票** | 不可抵扣 | OCR识别→自动入账 |
| **电子发票** | 全电发票 | API对接→自动接收 |
| **形式发票（Proforma）** | 预付款/信用证 | 手工处理 |

### 3.2 发票自动化

```
传统流程：
  供应商寄纸质发票 → 财务收到 → 手工录入 → 三单匹配 → 审批 → 付款
  周期：15-30 天

自动化流程：
  供应商电子发票 → OCR/EDI 自动接收 → 系统自动三单匹配 → 自动审批(规则) → 自动付款
  周期：1-3 天
```

## 四、供应商对账

### 4.1 对账流程

```
月度对账：
  1. 系统导出当月 GR 汇总
  2. 供应商提供发货/开票汇总
  3. 逐笔核对差异
  4. 确认应付金额
  5. 生成付款计划
```

### 4.2 常见对账差异

| 差异类型 | 根因 | 处理方式 |
|---------|------|---------|
| **数量差异** | 收货数量与发货不一致 | 核对签收单 |
| **价格差异** | 合同价格与发票不一致 | 核对合同 |
| **时间差异** | GR 在月底、INV 在月初 | 跨期调整 |
| **退货未冲红** | 退货后未开红字发票 | 催促供应商 |

## 五、付款管理

### 5.1 付款方式

| 方式 | 适用 | 优缺点 |
|------|------|--------|
| **电汇(T/T)** | 最常用 | 灵活但手续费高 |
| **银行承兑汇票** | 大额、有信用 | 供应商可贴现 |
| **商业承兑汇票** | 核心企业 | 信用依赖企业 |
| **信用证(L/C)** | 跨境采购 | 安全但流程复杂 |
| **供应链金融** | 中小供应商 | 核心企业信用背书 |

### 5.2 付款条件的供应链价值

```
付款条件不只是"财务的事"，是采购谈判的核心筹码：

  付款周期短（Net 30）→ 供应商更愿意给好价格、优先供货
  付款周期长（Net 90）→ 短期现金流好，但供应商关系差

  提前付款折扣（2/10 Net 30）：
    10天内付款打 2% 折扣，否则 30 天内全额付
    年化折扣率 = 2% × (365/20) = 36.5%
    → 非常划算！
```

## 六、供应链金融

### 6.1 核心模式

| 模式 | 原理 | 代表 |
|------|------|------|
| **反向保理** | 核心企业信用背书，供应商提前收款 | 蚂蚁供应链金融 |
| **应收账款融资** | 供应商以应收账款质押融资 | 银行供应链金融产品 |
| **存货融资** | 以库存质押融资 | 大宗商品融资 |
| **订单融资** | 以确认订单融资 | 跨境电商融资 |

### 6.2 反向保理示例

```
传统模式：
  供应商发货 → 等 90 天 → 收到货款
  → 供应商现金流紧张 → 可能影响交付

反向保理：
  供应商发货 → 银行基于核心企业信用立即付款（扣 2% 手续费）
  → 90 天后核心企业向银行付款
  → 供应商立即收到 98% 货款
  → 核心企业享受 90 天账期
  → 三赢！
```

## 七、系统选型

| 系统 | 功能 | 代表厂商 |
|------|------|---------|
