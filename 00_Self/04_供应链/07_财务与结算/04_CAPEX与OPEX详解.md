## 一、核心定义

### CAPEX（Capital Expenditure，资本性支出）

> 用于获取或升级长期资产的支出，受益期超过一个会计年度。

**典型场景**：
- 购买生产设备（冲压机、焊接机器人、涂装线）
- 建设厂房、仓库
- IT 系统建设（ERP、MES、WMS）
- 模具开发
- 工厂自动化改造

### OPEX（Operating Expenditure，运营性支出）

> 日常经营活动产生的支出，当期消耗、当期费用化。

**典型场景**：
- 原材料采购
- 物流运输费
- 仓储租金
- 人工工资
- 水电费、维修费

---

## 二、CAPEX vs OPEX 对比

| 维度 | CAPEX | OPEX |
|------|-------|------|
| **定义** | 资本性支出 | 运营性支出 |
| **受益期** | > 1年 | ≤ 1年 |
| **会计处理** | 资本化 → 折旧/摊销 | 费用化 → 当期损益 |
| **利润影响** | 分多年影响（折旧） | 全额影响当期利润 |
| **税务影响** | 折旧逐年抵税 | 当年全额抵税 |
| **预算审批** | 投资委员会审批 | 部门预算内审批 |
| **决策指标** | IRR、NPV、Payback | 预算执行率、ROI |
| **资产负债表** | 资产增加 | 无资产变动 |
| **现金流** | 投资活动现金流 | 经营活动现金流 |

## 三、会计处理详解

### 3.1 CAPEX 会计处理

```
购置阶段：
借：固定资产（原值）          500万
  贷：银行存款/应付账款         500万

每月折旧（直线法，10年）：
借：制造费用-折旧              4.17万
  贷：累计折旧                 4.17万

10年后处置（残值50万）：
借：固定资产清理               50万
借：累计折旧                  450万
  贷：固定资产                 500万
```

### 3.2 OPEX 会计处理

```
采购原材料：
借：原材料/存货               100万
  贷：应付账款                100万

领用投入生产：
借：生产成本                  100万
  贷：原材料                  100万

当期费用化（如维修费）：
借：管理费用-维修费             5万
  贷：银行存款                  5万
```

### 3.3 折旧方法对比

| 方法 | 公式 | 特点 | 适用场景 |
|------|------|------|----------|
| 直线法 | (原值-残值)/使用年限 | 每年均匀 | 通用 |
| 双倍余额递减法 | 2/使用年限 × 净值 | 前多后少 | 技术更新快的设备 |
| 年数总和法 | (原值-残值)×尚可使用年限/年限总和 | 递减 | 有明确产能下降曲线 |
| 产量法 | (原值-残值)/总产量 × 当期产量 | 按使用量 | 矿山、重型设备 |

## 四、税务影响分析

### 4.1 CAPEX 税务优势

| 政策 | 说明 | 效果 |
|------|------|------|
| 折旧抵税 | 折旧费用税前扣除，减少应纳税所得额 | 500万设备10年折旧，每年抵税约12.5万（25%税率） |
| 加速折旧 | 国家鼓励的设备可缩短折旧年限或加速折旧 | 前期多抵税，递延纳税 |
| 一次性扣除 | 单价500万以下设备可一次性税前扣除（2024政策） | 当年全额抵税，极大改善现金流 |
| 研发加计扣除 | 研发设备投入可加计100%扣除 | 实际税率降至约12.5% |

### 4.2 OPEX 税务优势

- **当期全额扣除**：不需要分年摊销，当年就能减少应税所得
- **无资本化门槛**：不需要区分是否满足资本化条件
- **灵活调整**：可根据经营情况调整支出规模

### 4.3 CAPEX vs OPEX 税务选择

```
场景：工厂需要一套自动化检测系统，价值300万

方案A（CAPEX）：
- 当年抵税：300万/10年 × 25% = 7.5万
- 10年累计抵税：75万

方案B（OPEX - 租赁/服务化）：
- 当年抵税：300万 × 25% = 75万（假设全部费用化）
- 但总支出可能更高（含租赁利润）

结论：短期看 OPEX 税务效率高，长期看 CAPEX 总成本低
```

## 五、投资决策框架

### 5.1 CAPEX 投资评估指标

| 指标 | 公式 | 决策标准 |
|------|------|----------|
| **IRR**（内部收益率） | NPV=0时的折现率 | IRR > WACC（加权资本成本） |
| **NPV**（净现值） | Σ(现金流/(1+r)^t) | NPV > 0 |
| **Payback**（回收期） | 累计现金流=0的年份 | < 行业基准（通常3-5年） |
| **ROI**（投资回报率） | 净利润/投资额 | > 15% |

### 5.2 汽车工厂 CAPEX 决策案例

```
场景：投资一条新的焊接产线

投资总额：2000万
- 设备采购：1200万（焊接机器人、夹具、检测设备）
- 厂房改造：300万
- 安装调试：200万
- 培训及其他：300万

预期收益：
- 年产能提升：5万台
- 单台成本降低：800元
- 年节约成本：4000万
- IRR：28%
- Payback：3.2年

决策：IRR(28%) > WACC(10%)，NPV > 0，建议投资
```

### 5.3 CAPEX 审批流程

```
需求部门 → 工程部 → 财务部（IRR/NPV分析）→ 投资委员会 → CEO/董事会

审批要点：
├── 金额 < 100万：部门总监审批
├── 100万 ~ 500万：VP审批 + 财务评审
├── 500万 ~ 2000万：投资委员会审批
└── > 2000万：董事会审批
```

## 六、行业对标（汽车制造）

### 6.1 CAPEX 占比

| 企业类型 | CAPEX/营收 | 典型值 |
|----------|-----------|--------|
| 传统车企 | 8%-12% | 丰田约10%、大众约12% |
| 新能源车企 | 15%-25% | 特斯拉约18%、蔚来约22% |
| 零部件企业 | 5%-8% | 博世约6%、宁德时代约15% |

### 6.2 CAPEX 构成（典型汽车工厂）

```
总 CAPEX 100%:
├── 生产设备     45%  （冲压/焊接/涂装/总装线）
├── 厂房/土建    20%
├── IT系统       10%  （ERP/MES/WMS/QMS）
├── 模具         15%
└── 其他         10%  （环保/安全/培训）
```

## 八、CAPEX/OPEX 转化的灰色地带

有些支出可以资本化也可以费用化，选择不同会影响当期利润：

| 支出 | 可 CAPEX | 可 OPEX | 判断标准 |
|------|----------|---------|----------|
| 设备大修 | 延长使用寿命 → 资本化 | 日常维修 → 费用化 | 是否延长资产寿命或提升性能 |
| 软件许可 | 定制开发 → 资本化 | 标准SaaS → 费用化 | 是否有控制权 |
| 培训费 | 设备操作培训 → 可资本化 | 一般培训 → 费用化 | 是否与资产直接相关 |
| 工装夹具 | 使用寿命>1年 → 资本化 | 短期使用 → 费用化 | 使用寿命判断 |

> [!warning] 审计关注点
> 企业有动机将 OPEX 转为 CAPEX 以美化当期利润（费用资本化）。审计师会重点关注资本化政策的一致性和合理性。
