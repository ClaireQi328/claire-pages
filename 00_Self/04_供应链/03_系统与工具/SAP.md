# SAP 供应链生态

> 💡 **10年+视角**：SAP 是全球 ERP 市场的绝对霸主（市占率 ~25%），尤其在制造业和大型企业。不管你用不用 SAP，你都得理解它的逻辑——因为你上下游的客户和供应商大概率在用。**SAP 不只是一个系统，它代表了一套管理思想和流程标准。**

---

## 一、SAP 产品全景

```
SAP 产品家族
├── 核心 ERP
│   ├── SAP S/4HANA ── 新一代 ERP（内存数据库、实时计算）
│   └── SAP ECC ── 老一代 ERP（2027 年停止维护）
│
├── 供应链管理
│   ├── SAP IBP ── 集成业务计划（S&OP/需求/供应/库存）
│   ├── SAP Ariba ── 采购与供应商管理
│   ├── SAP TM ── 运输管理
│   ├── SAP EWM ── 仓库管理
│   └── SAP Digital Manufacturing ── 制造执行
│
├── 人力资源
│   └── SAP SuccessFactors ── HR 管理
│
├── 客户关系
│   └── SAP CX ── 客户体验
│
└── 技术平台
    ├── SAP BTP ── 业务技术平台
    └── SAP Fiori ── 用户体验
```

## 二、SAP S/4HANA 核心模块

### 2.1 供应链相关模块

| 模块 | 英文 | 功能 | 核心事务码 |
|------|------|------|-----------|
| **PP** | Production Planning | 生产计划、MRP、工单 | MD01/MD02, CO01 |
| **MM** | Materials Management | 采购、库存、物料主数据 | ME21N, MIGO |
| **SD** | Sales & Distribution | 销售订单、定价、发货 | VA01, VL01N |
| **WM/EWM** | Warehouse Management | 仓库管理 | LT01, /SCWM |
| **QM** | Quality Management | 质量管理 | QA01, QE01 |
| **FI/CO** | Finance/Controlling | 财务、成本控制 | FB60, KO88 |

### 2.2 SAP MRP 的运行逻辑

```
MD01/MD02 (MRP Run)
  1. 读取 MPS/独立需求
  2. 展开 BOM（CS01 维护的 BOM）
  3. 扣减库存（MM 查库存）
  4. 扣减在途（已下达的 PO/工单）
  5. 计算净需求
  6. 按批量规则生成计划订单
  7. 按 LT 偏移计算开工日期
  8. 输出：计划订单建议 / 采购申请建议

MRP 异常消息类型：
  - 例外消息 01：过去的需求（需要紧急处理）
  - 例外消息 02：交期不足
  - 例外消息 03：数量不足
  - 例外消息 04：提前期不足
  - 例外消息 05：超出安全库存
```

## 三、SAP IBP（集成业务计划）

### 3.1 IBP 的五大模块

| 模块 | 功能 | 对应传统流程 |
|------|------|------------|
| **IBP for Demand** | AI 驱动的需求预测 | 需求计划 |
| **IBP for Supply** | 供需平衡与优化 | S&OP |
| **IBP for Inventory** | 多级库存优化 | 库存计划 |
| **IBP for Response** | 快速响应计划 | ATP/CTP |
| **IBP for Control Tower** | 供应链可视化 | 控制塔 |

### 3.2 IBP vs 传统 Excel 计划

| 维度 | Excel | SAP IBP |
|------|-------|---------|
| 数据量 | 10万行卡顿 | 百万行流畅 |
| 协同 | 邮件发来发去 | 在线协同平台 |
| 版本管理 | V1/V2/Final/Final2 | 系统版本管理 |
| AI 预测 | 无 | 内置 ML 引擎 |
| 场景模拟 | 手动改公式 | 一键 What-if |

## 四、SAP Ariba（采购管理）

### 4.1 核心功能

| 功能 | 说明 |
|------|------|
| **寻源** | 在线招标、反向竞拍、供应商发现 |
| **供应商管理** | 供应商准入、绩效评估、风险监控 |
| **合同管理** | 合同创建、审批、执行、续签 |
| **采购协同** | PO 协同、ASN、电子发票 |
| **支出分析** | Spend 分析、品类洞察 |

### 4.2 Ariba Network

```
Ariba Network 是全球最大的 B2B 商业网络：
  - 连接 500 万+ 供应商
  - 年交易额 3.5 万亿美元+
  - 买家可以发现新供应商
  - 供应商可以找到新客户
  - 电子化 PO → ASN → 发票 → 付款
```

## 五、SAP 实施的"血泪教训"

### 5.1 常见失败原因

| # | 原因 | 教训 |
|:-:|------|------|
| 1 | **蓝图阶段没想清楚** | 先梳理流程，再上系统 |
| 2 | **过度定制开发** | 能标准就标准，定制成本是标准的 5-10 倍 |
| 3 | **数据治理缺失** | 主数据不准，系统跑出来的都是垃圾 |
| 4 | **变革管理不足** | 用户不接受新系统，回到 Excel |
| 5 | **测试不充分** | UAT 走过场，上线后到处 Bug |
| 6 | **上线后缺乏运维** | 没有 Basis/ABAP 团队，系统慢慢退化 |

### 5.2 实施成本参考

| 企业规模 | 实施周期 | 预算范围 | 模块范围 |
|---------|:------:|---------|---------|
| 中型企业（10-50亿） | 12-18月 | 500-2000万 | PP+MM+SD+FI |
| 大型企业（50-200亿） | 18-30月 | 2000-8000万 | 全模块 |
| 超大型（>200亿） | 24-48月 | 1-5亿 | 全球多站点 |

## 六、S/4HANA 迁移

### 6.1 ECC → S/4HANA 迁移方式

| 方式 | 说明 | 适用 |
|------|------|------|
| **Greenfield** | 全新实施 | 定制多、想重新设计流程 |
| **Brownfield** | 系统转换（保留数据和配置） | 想快速迁移 |
| **Bluefield** | 选择性迁移（两者的混合） | 平衡速度和优化 |

### 6.2 迁移时间线

```
SAP ECC → 2027 年底停止标准维护
SAP S/4HANA → SAP 的未来

迁移建议：
  - 现在还在 ECC 的企业 → 必须在 2027 前迁移
  - 新上 SAP 的企业 → 直接上 S/4HANA
  - 迁移成本 ≈ 新实施的 50-80%
```
