# 物流、仓储流程及系统

> 💡 **10年+视角**：仓储和物流是供应链的"最后一公里"。客户感知到的不是你的计划有多准、采购有多强，而是**货到得快不快、包装好不好、退货方不方便**。京东用十年投入数千亿建物流网络，本质上是在投资客户体验。

---

## 一、仓储管理

### 1.1 仓库类型

| 类型 | 功能 | 代表 |
|------|------|------|
| **原材料仓** | 存放生产用原材料 | 制造厂内仓 |
| **成品仓（DC）** | 成品存储与分拨 | 京东亚洲一号 |
| **区域仓（RDC）** | 区域分拨中心 | 菜鸟区域仓 |
| **前置仓（FDC）** | 城市级极速配送 | 叮咚买菜、盒马 |
| **保税仓** | 跨境电商保税存储 | 跨境电商保税区 |
| **退货仓** | 逆向物流处理 | 品牌退货中心 |

### 1.2 入库→在库→出库全流程

```
入库：
  收货预约(ASN) → 卸货 → 来料检验(IQC) → 上架(WMS分配库位) → 系统做账(GR)

在库：
  库存盘点(循环/年度) → 库位优化 → 批次管理 → 效期管理(FEFO)

出库：
  订单接收 → 波次生成 → 拣货(路径优化) → 复核 → 包装 → 称重 → 发运 → 系统做账(GI)
```

### 1.3 拣货策略对比

| 策略 | 原理 | 适用场景 | 效率 |
|------|------|---------|:---:|
| **摘果法** | 按订单逐个拣 | 订单少、SKU多 | ⭐⭐ |
| **播种法** | 批量拣→按订单分播 | 订单多、SKU少 | ⭐⭐⭐⭐ |
| **波次拣货** | 多订单合并为一波 | 高频场景 | ⭐⭐⭐⭐⭐ |
| **货到人(GTP)** | AGV/立体库把货架送到人 | 高密度仓 | ⭐⭐⭐⭐⭐ |

**京东亚洲一号的实际效果**：
```
传统仓：拣货员走动 ~15km/天，效率 80件/人/小时
亚洲一号（货到人）：
  - AGV搬货架到工位，拣货员不动
  - 系统指示灯指引拣货位
  - 效率 300-400件/人/小时（提升 3-5 倍）
  - 错误率从 0.3% 降到 0.01%
```

## 二、WMS（仓库管理系统）

### 2.1 核心功能

| 模块 | 功能 |
|------|------|
| **入库管理** | 收货、检验、上架（智能库位分配） |
| **库内管理** | 移位、盘点、补货、批次追溯 |
| **出库管理** | 波次策略、拣货路径优化、复核 |
| **策略引擎** | ABC分区、FIFO/FEFO、上架规则 |
| **集成接口** | ERP/TMS/MES 对接 |

### 2.2 WMS 厂商选型

| 厂商 | 特点 | 适用 |
|------|------|------|
| **Blue Yonder** | 全球领先，功能全面 | 大型零售/快消 |
| **Manhattan Associates** | 高度可配置 | 3PL/零售 |
| **SAP EWM** | 与SAP ERP深度集成 | SAP生态 |
| **唯智信息** | 中国本土领先 | 国内制造/零售 |
| **旷视(河图)** | AI+机器人调度 | 智能仓储 |

## 三、运输管理

### 3.1 运输模式

| 模式 | 时效 | 成本 | 适用 |
|------|------|:---:|------|
| 公路整车(FTL) | 1-3天 | ⭐⭐⭐ | 大批量固定路线 |
| 公路零担(LTL) | 2-5天 | ⭐⭐ | 中小批量 |
| 铁路 | 3-7天 | ⭐ | 大批量长距离 |
| 航空 | 当日-次日 | ⭐⭐⭐⭐⭐ | 高价值/紧急 |
| 水运 | 7-30天 | ⭐ | 大宗跨洋 |

### 3.2 运输成本优化五大杠杆

| 杠杆 | 方法 | 节省幅度 |
|------|------|:------:|
| 路线优化 | TMS路径规划算法 | 10-15% |
| 装载优化 | 提高车辆利用率 | 5-10% |
| 承运商整合 | 减少数量，提高议价 | 8-12% |
| 模式转换 | 公路→铁路/水运 | 20-40% |
| 共同配送 | 多客户拼车 | 15-25% |

### 3.3 TMS（运输管理系统）

| 功能 | 说明 |
|------|------|
| 订单管理 | 运输订单创建、合并 |
| 路线规划 | 最优路线、多点配送优化 |
| 在途跟踪 | GPS实时追踪、ETA预测 |
| 运费结算 | 自动对账、账单审核 |
| 数据分析 | 成本分析、KPI看板 |

## 四、物流网络设计

### 4.1 核心权衡

```
仓库多 → 配送快、运费低 → 但仓储成本高、总库存多
仓库少 → 仓储成本低、库存集中 → 但配送慢、运费高

最优解 = 仓储成本 + 运输成本 的总和最小化
```

### 4.2 京东 vs 菜鸟的网络哲学

| 维度 | 京东物流 | 菜鸟网络 |
|------|---------|---------|
| **模式** | 自营（全链路控制） | 平台（连接合作伙伴） |
| **仓库** | 自建 1,500+ 仓 | 整合社会化仓储 |
| **配送** | 自有配送员 | 三通一达+顺丰 |
| **优势** | 时效确定、体验一致 | 轻资产、覆盖广 |
| **劣势** | 重资产、成本高 | 体验不可控 |
| **时效** | 211限时达 | 次日-3日达 |

## 五、KPI 体系

| KPI | 定义 | 标杆值 |
|-----|------|:------:|
| 库存准确率 | 盘点一致率 | ≥ 99.5% |
| 拣货准确率 | 正确订单/总订单 | ≥ 99.9% |
| 拣货效率 | 件/人/小时 | 80-400 |
| 出库及时率 | 按时出库率 | ≥ 98% |
| OTIF | 准时足量交付 | ≥ 95% |
| 运输成本率 | 运输成本/销售额 | 3-8% |
| 仓库利用率 | 已用面积/总面积 | 80-90% |
