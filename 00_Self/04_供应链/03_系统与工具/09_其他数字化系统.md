# 其他数字化系统

> 💡 **10年+视角**：供应链数字化不只是 ERP/MES/WMS 这些"大系统"。真正让日常效率提升的，往往是 BI 看板、低代码表单、IoT 传感器、RPA 机器人这些"轻量级"工具。**大系统建骨架，小工具填血肉。**

## 二、BI / 数据分析平台

### 2.1 供应链 BI 的典型场景

| 场景 | 看板内容 | 价值 |
|------|---------|------|
| **供应链健康度** | OTIF、库存周转、缺货率 | 一屏掌握全局 |
| **需求预测准确率** | MAPE、Bias、按SKU/品类 | 识别预测问题 |
| **采购支出分析** | 按品类/供应商/时间 | 寻源优化依据 |
| **库存老化分析** | 库龄分布、呆滞预警 | 及时处理呆滞 |
| **供应商绩效** | QCDS评分、趋势 | 供应商管理依据 |

### 2.2 BI 工具选型

| 工具 | 特点 | 适用 |
|------|------|------|
| **Power BI** | 微软生态、性价比高 | 中小企业、Excel 用户 |
| **Tableau** | 可视化最强 | 数据分析团队 |
| **帆软(FineBI/FineReport)** | 中国本土领先 | 国内企业 |
| **Metabase** | 开源、轻量 | 技术团队 |
| **Grafana** | 实时监控强 | IoT/运维场景 |

## 四、IoT（物联网）在供应链中的应用

### 4.1 应用场景

| 场景 | 技术 | 价值 |
|------|------|------|
| **冷链监控** | 温湿度传感器+GPS | 全程温控可追溯 |
| **设备监控** | 振动/温度/电流传感器 | 预测性维护 |
| **库存监控** | RFID/重量传感器 | 实时库存可视 |
| **在途追踪** | GPS+蜂窝网络 | 运输可视化 |
| **能耗监控** | 电表/气表传感器 | 能源管理 |

### 4.2 冷链监控案例

```
疫苗冷链全程监控：
  出厂 → 冷藏车(温控) → 冷库(温控) → 冷藏车(温控) → 医院冰箱

每个环节：
  - 温度传感器每 5 分钟采集一次
  - 数据上传云端
  - 超温自动报警（短信+APP+邮件）
  - 到达后自动生成温控报告
  - 温度异常的批次自动隔离

价值：合规（GDP要求）、减少损失、可追溯
```

## 六、数字孪生（Digital Twin）

### 6.1 供应链中的数字孪生

| 层级 | 应用 | 案例 |
|------|------|------|
| **设备级** | 单台设备虚拟模型 | 预测性维护 |
| **产线级** | 整条产线仿真 | 产能优化、换型模拟 |
| **工厂级** | 整个工厂虚拟镜像 | 西门子安贝格工厂 |
| **供应链级** | 全链路仿真 | 网络优化、场景模拟 |

### 6.2 供应链数字孪生的价值

```
What-if 场景模拟：
  Q: 如果越南工厂停工 2 周，对交付有什么影响？
  A: 数字孪生模拟 → 识别受影响订单 → 自动生成应急方案

  Q: 如果把区域仓从上海搬到武汉，物流成本怎么变？
  A: 数字孪生模拟 → 对比两个方案的总成本 → 数据驱动决策
```
