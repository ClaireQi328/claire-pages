# 计划流程及系统

> 💡 **10年+视角**：计划系统是供应链的"大脑"。但很多企业的"大脑"是瘫痪的——ERP 里的 MRP 参数三年没调、APS 上了但计划员还在用 Excel 手动排、S&OP 会议开了但没人看数据。**系统是工具，流程和人才是根本。**

---

## 一、计划体系全景

```
时间跨度：  1-3年         6-18月        1-6月        1-4周        日/班次
           ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐    ┌────────┐
战略规划    │  IBP   │ →  │ S&OP  │ →  │  MPS  │ →  │  MRP  │ →  │  APS  │
           │集成业务 │    │产销协同│    │主生产 │    │物料需求│    │高级排程│
           │计划    │    │计划   │    │计划   │    │计划   │    │       │
           └────────┘    └────────┘    └────────┘    └────────┘    └────────┘
决策者：    VP/CSCO       供应链总监     计划经理      物料计划员     车间计划员
系统：      IBP/SCP      S&OP 平台     ERP-PP       ERP-MRP      APS/MES
```

## 二、S&OP（销售与运营计划）

### 2.1 五步流程

| 步骤 | 时间 | 内容 | 输出 |
|------|------|------|------|
| 1. 数据准备 | 第 1 周 | 汇总需求/供应/财务数据 | 数据包 |
| 2. 需求评审 | 第 2 周前半 | 销售+市场确认需求预测 | 共识需求 |
| 3. 供应评审 | 第 2 周后半 | 生产+采购评估产能约束 | 供应能力 |
| 4. Pre-S&OP | 第 3 周 | 识别供需缺口，制定方案 | 平衡方案 |
| 5. S&OP 会议 | 第 4 周 | 高层决策，批准计划 | S&OP 决议 |

### 2.2 S&OP 的关键成功因素

| 因素 | 做法 | 常见失败原因 |
|------|------|------------|
| **数据驱动** | 用数据说话，不用"感觉" | 数据不准，会议变成吵架 |
| **跨部门参与** | 销售+生产+采购+财务都到场 | 只有计划部门在开 |
| **高层支持** | VP 亲自参加 S&OP 会议 | 高层不重视，决议无人拍板 |
| **闭环跟踪** | 上月决议执行情况回顾 | 决议不跟踪，开了白开 |

## 三、MPS（主生产计划）

### 3.1 MPS 的核心逻辑

```
输入：S&OP 产品族计划 + 客户订单 + 成品库存
     ↓
分解：产品族 → 具体 SKU
     ↓
校验：粗能力平衡（RCCP）
     ↓
输出：SKU 级周度生产计划 + ATP/CTP 报告
```

### 3.2 ATP / CTP

| 概念 | 定义 | 用途 |
|------|------|------|
| **ATP（可承诺量）** | 现有库存 + 计划产出 − 已确认订单 | 回复客户"还有多少可卖" |
| **CTP（可承诺交期）** | 考虑产能约束后的最早可交货日期 | 回复客户"什么时候能交" |

## 五、APS（高级计划与排程）

### 5.1 APS vs ERP-PP 的区别

| 维度 | ERP-PP | APS |
|------|--------|-----|
| **产能模型** | 无限产能 | 有限产能 |
| **排程精度** | 日/周级 | 工序/小时级 |
| **优化算法** | 规则驱动 | 约束求解、启发式算法 |
| **可视化** | 表格 | 甘特图 |
| **What-if** | 不支持 | 支持场景模拟 |
| **响应速度** | 慢（批量运行） | 快（实时重排） |

### 5.2 APS 的三大核心算法

| 算法 | 原理 | 适用 |
|------|------|------|
| **有限产能排程（FCS）** | 按产能约束排产 | 单一瓶颈场景 |
| **约束规划（CP）** | 数学约束求解 | 复杂约束场景 |
| **遗传算法（GA）** | 进化优化 | 多目标优化场景 |

### 5.3 APS 厂商选型

| 厂商 | 特点 | 适用 |
|------|------|------|
| **SAP IBP** | 与 SAP ERP 深度集成 | SAP 生态企业 |
| **Kinaxis** | 并发计划、快速响应 | 多品种、高复杂度 |
| **o9 Solutions** | AI 驱动、云原生 | 数字化转型企业 |
| **Blue Yonder** | 零售/快消强 | 零售、快消行业 |
| **Asprova** | 日系精益排程 | 汽车、电子制造 |
| **Flexsche** | 日系，柔性排程 | 多品种小批量 |

## 六、IBP（集成业务计划）

> IBP 是 S&OP 的进化版，将财务视角深度融入计划流程。

| 模块 | 功能 |
|------|------|
| **需求计划** | AI 驱动的需求预测 |
| **供应计划** | 供需平衡与场景模拟 |
| **库存计划** | 多级库存优化 |
| **财务集成** | 计划结果自动转财务预算 |
| **协同平台** | 跨部门协同工作流 |

## 七、计划系统选型决策树

```
企业规模 + 行业 + 复杂度 → 选择合适的方案

小企业（<1亿营收）：
  └── ERP 标准功能 + Excel 补充

中型企业（1-50亿）：
  └── ERP-PP/MM + 独立 APS（如 Asprova）

大型企业（>50亿）：
  └── ERP + IBP（SAP IBP / Kinaxis / o9）

快消/零售：
  └── Blue Yonder / o9 Solutions

汽车/制造：
  └── SAP IBP + Asprova / Flexsche
```
