# 生产制造系统

> 💡 **10年+视角**：MES 是工厂的"神经系统"——ERP 管"做什么"，MES 管"怎么做"。很多企业上了 ERP 就觉得够了，但车间里的数据是黑箱。**没有 MES，你就不知道产线为什么停、良率为什么低、工单为什么延迟。**

---

## 一、制造系统全景

```
管理层：  ERP（SAP/Oracle）── 计划、采购、财务
    │
执行层：  MES ── 生产执行、报工、质量、追溯
    │
控制层：  SCADA/PLC ── 设备控制、数据采集
    │
设备层：  机器人、CNC、AGV、传感器
```

---

## 二、MES（制造执行系统）

### 2.1 MES 的定位

```
ERP 说：生产 1000 件产品 A，下周三交货
MES 说：产线 1 目前在做第 320 件，良率 98.5%，预计延迟 2 小时
```

### 2.2 核心功能

| 模块 | 功能 | 价值 |
|------|------|------|
| **工单管理** | 接收ERP工单→分解为工序工单→下发到设备 | 计划到执行的桥梁 |
| **排程调度** | 工序级排程、设备分配、优先级管理 | 有限产能优化 |
| **数据采集** | 设备状态、产量、工时、能耗实时采集 | 消除车间黑箱 |
| **质量管理** | 首检/巡检/终检、SPC统计过程控制 | 质量问题实时拦截 |
| **追溯管理** | 正向追溯（原料→成品）、反向追溯（成品→原料） | 召回/质量问题定位 |
| **设备管理** | 设备OEE、预防性维护、故障报警 | 提升设备利用率 |
| **物料管理** | 线边仓管理、物料拉动、齐套检查 | 减少等料停线 |

### 2.3 MES 与 ERP 的分工

| 维度 | ERP | MES |
|------|-----|-----|
| **管理对象** | 订单、物料、财务 | 工序、设备、质量 |
| **时间粒度** | 日/周 | 分钟/秒 |
| **数据来源** | 人工录入+系统集成 | 设备自动采集 |
| **核心输出** | 计划、凭证 | 实时报工、追溯 |
| **典型系统** | SAP、Oracle | 西门子、达索、用友 |

## 三、PLM（产品生命周期管理）

### 3.1 PLM 的覆盖范围

```
概念设计 → 详细设计 → 工艺规划 → 试产 → 量产 → 退市
  └──────────── PLM 全程管理 ────────────────┘
```

### 3.2 核心功能

| 功能 | 说明 | 价值 |
|------|------|------|
| **BOM 管理** | 设计BOM→制造BOM→服务BOM | BOM 一致性 |
| **变更管理（ECN）** | 工程变更发起→评审→执行→验证 | 变更可控可追溯 |
| **文档管理** | 图纸、规格书、工艺文件 | 版本控制、权限管理 |
| **项目管理** | 新品开发项目进度管理 | NPI 按时交付 |
| **合规管理** | 环保/安全/认证要求 | 法规合规 |

### 3.3 PLM 厂商

| 厂商 | 特点 | 行业 |
|------|------|------|
| **Siemens Teamcenter** | 功能最全面 | 汽车、航空 |
| **Dassault ENOVIA** | 3D 设计集成 | 航空、汽车 |
| **PTC Windchill** | IoT 集成 | 工业设备 |
| **SAP PLM** | ERP 集成 | 离散制造 |
| **用友/金蝶** | 中国本土 | 中小制造 |

## 四、SCADA / PLC / DCS

| 系统 | 定义 | 功能 | 层级 |
|------|------|------|------|
| **PLC** | 可编程逻辑控制器 | 单台设备控制 | 设备层 |
| **SCADA** | 数据采集与监控 | 多设备监控+报警 | 控制层 |
| **DCS** | 分散控制系统 | 连续过程控制 | 控制层 |

**SCADA 的核心价值**：
```
实时数据采集 → 设备状态监控 → 异常报警 → 远程控制
    ↓
数据上传到 MES → 用于 OEE 计算、质量分析、追溯
```

## 五、QMS（质量管理系统）

### 5.1 质量管理全流程

```
来料检验(IQC) → 过程检验(IPQC) → 出货检验(OQC) → 售后质量
     │                │                │
   AQL抽检         SPC控制          按标准抽检
   不合格处理       首检/巡检        COA报告
```

### 5.2 核心质量工具

| 工具 | 用途 | 场景 |
|------|------|------|
| **SPC** | 统计过程控制 | 监控过程稳定性 |
| **FMEA** | 失效模式分析 | 新品/工艺风险评估 |
| **8D** | 8步问题解决法 | 客户投诉处理 |
| **5 Why** | 根因分析 | 质量问题追溯 |
| **控制图** | 过程能力监控 | Cpk/Ppk 计算 |
