# 医药供应链

> 💡 **10年+视角**：医药供应链的核心不是"效率"，而是**合规+可追溯+保供**。一个批次的药品如果追溯链断裂，整个批次必须销毁。这种严苛的合规要求，让医药供应链的管理难度远高于其他行业。

---

## 一、行业供应链特征

| 维度 | 医药行业特点 |
|------|------------|
| **监管要求** | GMP/GSP/GDP，全程合规 |
| **追溯要求** | 批次追溯、序列号管理、一物一码 |
| **LT** | 原料药 8-16 周，成品生产 2-4 周 |
| **保质期** | 药品 2-5 年，疫苗 6-18 月（冷链） |
| **库存策略** | 安全库存高（缺药 = 人命） |
| **分销模式** | 工厂→全国总代→省级代理→医院/药店 |
| **价格机制** | 集采定价、医保谈判 |

---

## 二、核心挑战

| 挑战 | 根因 | 应对 |
|------|------|------|
| **合规成本高** | GMP/GSP 验证、追溯系统 | 数字化追溯平台 |
| **冷链管理** | 疫苗/生物制品 2-8°C | 全程冷链监控（IoT） |
| **缺药风险** | 原料药集中度高（中国/印度） | 多源采购、战略储备 |
| **集采冲击** | 价格降幅 50-90% | 成本重构、规模效应 |
| **需求不确定性** | 疫情/季节性疾病 | 应急储备机制 |

---

## 三、行业供应链模型

### 3.1 传统医药供应链

```
原料药（API）→ 制剂生产 → 流通企业 → 医院/药店 → 患者
    │              │           │
  中国/印度      GMP 合规    GSP 合规
```

### 3.2 两票制后的变化

```
两票制前：药厂 → 总代 → 省代 → 市代 → 医院（多票）
两票制后：药厂 → 流通企业 → 医院（最多两票）

影响：
- 流通企业集中度提升（国药、上药、华润）
- 药厂直面终端的能力变重要
- 供应链可视化需求增加
```

---

## 四、行业标杆

| 企业 | 标杆能力 | 核心方法 |
|------|---------|---------|
| **辉瑞** | 全球供应链管理 | 冷链物流、全球产能协调 |
| **国药控股** | 中国医药流通龙头 | 全国物流网络、数字追溯 |
| **迈瑞医疗** | 医疗器械供应链 | 平台化设计、柔性制造 |
| **药明康德** | CRO/CDMO 供应链 | 快速响应客户需求、合规管理 |

---

## 五、关键指标

| KPI | 定义 | 行业标准 |
|-----|------|---------|
| **OTIF** | 按时按量交付率 | ≥ 98% |
| **追溯完整性** | 批次追溯链完整率 | 100%（法规要求） |
| **冷链合规率** | 全程温控达标率 | ≥ 99.5% |
| **库存周转天数** | 成品库存周转 | 30-60 天 |
| **缺货率** | SKU 缺货比例 | ≤ 1%（关键药品 0%） |
| **召回响应时间** | 从发现问题到完成召回 | ≤ 48 小时 |
