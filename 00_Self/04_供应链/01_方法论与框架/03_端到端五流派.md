5 大流派

供应链 E2E（端到端）流程到底如何划分？——主要有 5 大主流流派

行业里有不同的拆分方法，本质看你从“业务流程 / 系统流程 / 价值链 / 需求侧”哪个角度出发。

我帮你整理成 5 大主流分类法 + 20+ 细分模块。

📌 流派 1：S2P + P2P（最常见，采购体系视角）

这是字节、美团、华为、字节经管体系最常用的拆法。

S2P（Source-to-Pay，寻源到支付）

S：Source（寻源）

采购需求管理RFQ/RFP 招标供应商评估、选择成本分析

P：Procure（采购）

合同管理（CLM）采购订单 PO交货计划

R：Receive（收货）

验收入库（GR）差异处理

I：Invoice（发票）

三单匹配（PO-GR-INV）异常发票处理

P：Pay（支付）

付款申请对公支付凭证与账务

适合强调“采购合规、供应商管理、成本控制”。

📌 流派 2：SCOR 模型（全球最标准，供应链教科书级）

Supply-Chain Operations Reference Model，供应链管理协会（ASCM）定义的全球标准。

SCOR 有 六大核心流程模块：

Plan（计划）需求预测产能规划库存策略S&OP（销售与运营计划）Source（采购）寻源原料采购供应商协同Make（制造）生产调度加工、组装质量管理Deliver（交付）销售订单仓储配送出库交付Return（退货）逆向物流客户退货供应商退货Enable（支撑）数据治理主数据合规与风控技术系统

适合制造业、3C、汽车、零售行业。

📌 流派 3：D2C / D2P / D2S（从“需求驱动”拆）

在强调“需求驱动供应链”的企业最常用，如快消、电商、互联网零售。

1）D2C：Demand to Customer（从需求到客户）

需求预测补货仓配客户交付

2）D2P：Demand to Production（从需求到生产）

MRP生产计划WIP 管理产能分配

3）D2S：Demand to Supply（从需求到供应商）

供应商协同拉动式补货VMI（供应商管理库存）

适合强调灵活库存、预测、履约体验的公司（如京东、拼多多，抖音电商也用这种逻辑）。

📌 流派 4：企业价值链视角（Porter’s Value Chain）

更多用于战略分析，不适合做系统，但面试非常加分。

价值链拆为：

Inbound Logistics（入库物流）Operations（生产制造）Outbound Logistics（出库配送）Marketing & Sales（销售）Service（售后）

支撑环节（Support Activities）包括：

采购技术开发人力基础设施（Finance、Legal、IT）

适合你回答“为什么供应链是企业核心价值链”。

📌 流派 5：互联网大厂“经营视角”拆法（财务 + 经营）

这是字节、阿里、腾讯都在用的体系，更偏经营管理，和你要转 PM 更贴合。

E2E 拆分为：

① 预算 → 需求 → 采购 → 使用 → 核销 → 凭证 → 大盘分析

模块化如下：

预算管理（Budget）预算编制预算冻结预算占用与执行需求管理（PR）需求拆分类目策略需求审批寻源与供应商管理（Sourcing & SRM）供应商准入策略寻源成本优化采购（PO）下单合同关联付款条件收货与验收（GR）入库次品处理发票（Invoice）三单匹配审核支付（Payment）付款审批银行执行凭证与账务（GL）财务对账自动凭证经营大盘（Ops Dashboard）供应链效率费用监控成本分析

一、供应链端到端全流程结构

需求管理（Demand Management）

目标：确定“要什么、要多少、何时要”

核心活动：

市场预测 / 销量预测（Forecast）客户订单管理（Order Intake）需求整合（Demand Consolidation）需求计划（Demand Planning）S&OP / IBP 供需平衡

输出：

 👉 需求计划、销售预测、订单池

产品与供应策略（Product & Supply Strategy）

目标：确定“如何供、谁来供”

核心活动：

产品BOM / 结构规划Make or Buy 决策供应网络设计（Network Design）供应策略（单源 / 多源 / 安全库存）供应风险评估

输出：

 👉 供应方案、BOM、供应策略

采购与供应商管理（Source / Procurement）

目标：以最优成本获得稳定供给

核心活动：

寻源 / 招标 / 竞价价格管理 / 成本分析合同管理供应商准入 & 绩效管理采购订单（PO）执行

输出：

 👉 PO、价格、合同、供应商池

生产与制造执行（Make / Production）

目标：把物料变成产品

核心活动：

主生产计划（MPS）物料需求计划（MRP）生产排程（Scheduling）制造执行（MES）质量控制（QMS）

输出：

 👉 半成品 / 成品库存

库存与仓储管理（Inventory & Warehousing）

目标：保证供给同时降低库存成本

核心活动：

安全库存策略库存优化（DOH / Turnover）收发存管理（WMS）库存盘点 / 差异管理

输出：

 👉 可用库存、库存健康度

物流与交付（Logistics & Fulfillment）

目标：把产品送到正确地点

核心活动：

运输管理（TMS）配送计划跨境 / 报关交付跟踪（OTIF）逆向物流（退货 / 维修）

输出：

 👉 客户收货、交付完成

订单到现金（Order-to-Cash, O2C）

目标：完成业务闭环与现金回收

核心活动：

销售订单执行开票应收账款（AR）回款 / 对账

输出：

 👉 现金流

采购到付款（Procure-to-Pay, P2P）

目标：完成采购财务闭环

核心活动：

收货确认（GR）发票匹配（3-way match）应付账款（AP）付款

输出：

 👉 供应商付款

数据与供应链优化（Data & Optimization）

目标：持续提升效率与成本结构

核心活动：

KPI监控（OTIF / Inventory / Cost）供应链可视化（Control Tower）风险预警（缺料 / 延迟）AI预测 / 优化网络与库存优化

输出：

 👉 优化决策、持续改进
