# 物料管理入门

> 💡 **10年+视角**：物料管理（Materials Management）是供应链中最"接地气"的环节。它不是高大上的战略问题，而是每天都在发生的"收、发、存、盘、补"。但正是这些琐碎的日常，决定了生产线会不会停工、客户能不能按时收到货。

---

## 一、什么是物料管理

### 1.1 定义

物料管理是对企业所需**原材料、在制品（WIP）、成品**从采购到消耗全生命周期的管理，核心目标是：

> **在正确的时间，把正确的物料，以正确的数量，送到正确的地点。**

### 1.2 在供应链中的位置

```
采购寻源 ──→ 【物料管理】──→ 生产制造
                 │
                 ├── 采购执行（PO → 收货 → 入库）
                 ├── 库存管理（存储 → 盘点 → 出库）
                 ├── 物料计划（MRP → 补货 → 齐套）
                 └── 物料控制（呆滞 → 损耗 → 替代）
```

## 二、物料分类体系

### 2.1 ABC 分类（价值维度）

> 📖 经典的帕累托法则在物料管理中的应用

| 分类 | 占比（SKU 数） | 占比（金额） | 管理策略 |
|:---:|:---:|:---:|------|
| **A 类** | ~20% | ~80% | 重点管理：精确计划、高频盘点、紧密跟催 |
| **B 类** | ~30% | ~15% | 常规管理：定期计划、月度盘点 |
| **C 类** | ~50% | ~5% | 简化管理：批量采购、季度盘点 |

### 2.2 XYZ 分类（需求波动维度）

| 分类 | 需求特征 | 预测难度 | 计划策略 |
|:---:|---------|:-------:|---------|
| **X 类** | 需求稳定、可预测 | 低 | 统计预测准确，适合自动化 |
| **Y 类** | 有趋势/季节性 | 中 | 需要模型+人工调整 |
| **Z 类** | 需求间歇、不规则 | 高 | 难以预测，靠安全库存兜底 |

### 2.3 ABC-XYZ 组合矩阵

```
        X（稳定）    Y（波动）    Z（间歇）
A（高值）  AX：精益管理   AY：重点关注   AZ：最高优先级
B（中值）  BX：标准管理   BY：定期审视   BZ：安全库存策略
C（低值）  CX：批量管理   CY：简化管理   CZ：按需采购或淘汰
```

> 🎯 **实战建议**：大多数企业的物料管理"一刀切"——要么全用 MRP，要么全用 Min-Max。ABC-XYZ 矩阵告诉你：**不同象限需要不同的管理策略**。A 类物料每周看一次，C 类一个月看一次就够了。

## 三、核心管理流程

### 3.1 物料主数据管理

物料主数据是所有计划和执行的**基石**。数据不准，一切白搭。

| 核心字段 | 作用 | 常见问题 |
|---------|------|---------|
| 物料编码 | 唯一标识 | 一物多码、编码不规范 |
| 描述 | 识别物料 | 描述不清、命名混乱 |
| 计量单位 | 收发存基础 | 单位换算错误 |
| 提前期（LT） | MRP 计算 | 参数过时 |
| 损耗率 | 需求放大 | 未考虑工艺损耗 |
| 安全库存 | 补货触发 | 参数多年未调 |
| BOM 用量 | 需求展开 | 工程变更未同步 |

> ⚠️ **10年教训**：物料主数据准确率低于 95% 时，不要上任何高级计划系统。先花 2-3 个月治理数据，比花 6 个月调系统有效 10 倍。

### 3.2 收货与入库

```
供应商送货 → 来料检验（IQC）→ 合格入库 → 系统做账（GR）
     │              │
     │         不合格 → 退货/让步接收/挑选使用
     │
     └── ASN（预到货通知）→ 提前准备仓位和人员
```

| 步骤 | 关键动作 | 系统操作 |
|------|---------|---------|
| 收货 | 核对 PO、数量、包装 | GR（Goods Receipt） |
| 检验 | IQC 按 AQL 抽检 | 质检结果录入 |
| 入库 | 上架至指定仓位 | 库位分配（WMS） |
| 做账 | 更新系统库存 | 自动生成凭证 |

### 3.3 发料与出库

| 发料方式 | 适用场景 | 特点 |
|---------|---------|------|
| **推式发料（Push）** | 按计划发料 | 计划驱动，可能多发/少发 |
| **拉式发料（Pull/Kanban）** | 按消耗补货 | 消耗驱动，更精准 |
| **倒冲（Backflush）** | 生产完工自动扣料 | 减少领料环节，但需要库存准确 |
| **齐套发料（Kitting）** | 按工单配套发料 | 确保物料齐套，减少产线等待 |

### 3.4 库存盘点

| 盘点方式 | 频率 | 范围 | 适用 |
|---------|------|------|------|
| **年度盘点** | 年度 | 全部 | 法规要求，停产盘点 |
| **循环盘点（Cycle Count）** | 持续 | 部分 | 日常管理，不停产 |
| **抽样盘点** | 按需 | 随机 | 快速验证库存准确性 |

**循环盘点的 ABC 频率**：

| 物料分类 | 盘点频率 | 目标准确率 |
|:---:|:---:|:---:|
| A 类 | 每周/每月 | ≥ 99.5% |
| B 类 | 每月/每季 | ≥ 99.0% |
| C 类 | 每季/每半年 | ≥ 98.0% |

## 四、库存管理核心指标

| 指标 | 公式 | 目标值 | 意义 |
|------|------|:------:|------|
| **库存周转率** | 年销售成本 / 平均库存 | 行业差异大 | 越高越好（但不是越高越好） |
| **库存周转天数** | 365 / 周转率 | 制造业 30-60 天 | 越短越好 |
| **库存准确率** | 盘点一致数 / 盘点总数 | ≥ 99% | 计划可信度的基础 |
| **呆滞库存比例** | 超 180 天未动 / 总库存 | ≤ 3% | 资金占用的黑洞 |
| **缺货率** | 缺货 SKU 数 / 总 SKU 数 | ≤ 2% | 客户满意度的底线 |
| **库存天数（DOS）** | 当前库存 / 日均消耗 | 目标范围内 | 直观的库存水位指标 |

## 五、安全库存策略

### 5.1 安全库存的三种公式

| 场景 | 公式 | 适用 |
|------|------|------|
| **需求不确定、LT 确定** | SS = Z × σd × √LT | 最常用 |
| **需求确定、LT 不确定** | SS = Z × σLT × d̄ | 供应波动场景 |
| **双重不确定** | SS = Z × √(LT × σd² + d̄² × σLT²) | 复杂场景 |

**服务水平 Z 值对照**：

| 服务水平 | Z 值 | 适用 |
|:---:|:---:|------|
| 90% | 1.28 | C 类低值物料 |
| 95% | 1.65 | B 类标准物料 |
| 97.7% | 2.00 | 重要物料 |
| 99% | 2.33 | A 类关键物料 |
| 99.9% | 3.09 | 战略瓶颈物料 |

### 5.2 补货策略选择

| 策略 | 原理 | 适用 | 典型参数 |
|------|------|------|---------|
| **ROP + EOQ** | 库存降到 ROP 时补 EOQ 量 | 独立需求件 | ROP = d̄×LT + SS |
| **Min-Max** | 低于 Min 补到 Max | 维护备件 | Min = SS + 安全余量 |
| **Periodic Review** | 固定周期检查补货 | C 类物料 | 周期 = 1 周/1 月 |
| **Kanban** | 消耗驱动的拉式补货 | 高频消耗件 | 看板卡数量 |

## 六、常见问题与对策

| 问题 | 根因 | 对策 |
|------|------|------|
| 账实不符 | 流程不规范、系统未及时更新 | Cycle Count + 倒冲发料 |
| 呆滞库存多 | 新品替代未清理旧料 | 生命周期管理 + 呆滞预警 |
| 产线等料 | 物料齐套率低 | 齐套检查 + A 类物料优先跟催 |
| 库存高但缺货 | 安全库存参数不合理 | ABC-XYZ 分类 + 重新设定 SS |
| 仓库空间不够 | 呆滞占位 + 补货过早 | 清理呆滞 + 优化 LT 参数 |
