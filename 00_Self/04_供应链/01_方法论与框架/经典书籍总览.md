## 三、核心理论速查

### 3.1 Fisher 产品-供应链匹配矩阵

> 📖 出处：Marshall Fisher, *Harvard Business Review*, 1997

| | **效率型供应链** | **响应型供应链** |
|---|---|---|
| **功能型产品** | ✅ **最佳匹配** | ❌ 成本过高 |
| **创新型产品** | ❌ 缺货/过时 | ✅ **最佳匹配** |

**实战洞察**：
- 功能型产品（牙膏、螺丝钉）→ 追求低成本、高周转、精益运营
- 创新型产品（智能手机、时装）→ 追求快速响应、柔性产能、缩短 LT
- **最常见的错误**：用效率型供应链做创新产品，结果要么大量呆滞，要么严重缺货

### 3.2 Chopra 六大供应链驱动

> 📖 出处：Chopra & Meindl, *Supply Chain Management*

```
                    ┌─────────────┐
                    │  信息 Information │
                    │  (最核心驱动)    │
                    └──────┬──────┘
           ┌───────────────┼───────────────┐
    ┌──────┴──────┐  ┌────┴─────┐  ┌──────┴──────┐
    │ 设施 Facilities│  │ 库存 Inventory │  │ 运输 Transportation │
    └─────────────┘  └──────────┘  └─────────────┘
           ┌───────────────┴───────────────┐
    ┌──────┴──────┐                  ┌──────┴──────┐
    │ 采购 Sourcing │                  │ 定价 Pricing  │
    └─────────────┘                  └─────────────┘
```

| 驱动 | 杠杆点 | 典型决策 |
|------|--------|---------|
| 设施 | 工厂/仓库选址、产能 | 集中式 vs 分散式 |
| 库存 | 安全库存、周转率、策略 | 持有成本 vs 缺货成本 |
| 运输 | 模式选择、路线优化 | 速度 vs 成本 |
| 信息 | 可视化、预测、共享 | 信息延迟 → 牛鞭效应 |
| 采购 | 自制/外购、供应商选择 | 战略采购 vs 竞争采购 |
| 定价 | 动态定价、促销策略 | 需求调节工具 |

### 3.3 Goldratt 约束理论（TOC）

> 📖 出处：Eliyahu Goldratt, *The Goal*, 1984

**五步聚焦法（Five Focusing Steps）**：

```
1. 识别（Identify）    → 找到系统的瓶颈（Constraint）
2. 挖尽（Exploit）     → 最大化瓶颈产出（不加投资）
3. 迁就（Subordinate） → 所有非瓶颈服从瓶颈节奏
4. 松绑（Elevate）     → 投资提升瓶颈产能
5. 回头（Repeat）      → 防止惰性成为新瓶颈
```

**鼓-缓冲-绳（DBR）**：
| 组件 | 含义 | 供应链类比 |
|------|------|----------|
| 🥁 鼓（Drum） | 瓶颈的节奏 | 产线最大产能节拍 |
| 🛡️ 缓冲（Buffer） | 瓶颈前的安全时间/库存 | 关键工序前的 WIP 缓冲 |
| 🪢 绳（Rope） | 物料释放信号 | 拉动式投料机制 |

**实战洞察**：
- 80% 的"产能不足"其实是瓶颈管理问题，不是真缺产能
- 非瓶颈工序的"高效运转"反而制造过多 WIP 和库存
- 车间里的忙碌 ≠ 产出，这是制造业最大的认知陷阱

### 3.4 Sheffi 五大韧性支柱

> 📖 出处：Yossi Sheffi, *The Resilient Enterprise*, 2005

| 支柱 | 核心能力 | 实践手段 |
|------|---------|---------|
| **可视性** | 看到 Tier 2/3 供应商 | 供应链映射、多层供应商可视化 |
| **风险意识文化** | 每个决策都考虑风险 | 风险评估融入日常流程 |
| **稳健设计** | 产品/流程本身抗扰 | 模块化设计、通用零部件 |
| **敏捷性** | 快速重新配置 | 柔性产能、双源采购、库存冗余 |
| **协同** | 跨供应链合作 | 信息共享、VMI、CPFR |

**冗余 vs 柔性**：

| 维度 | 冗余（Redundancy） | 柔性（Flexibility） |
|------|-------------------|-------------------|
| 手段 | 多余库存、备选产能、备用供应商 | 快速换型、模块化、跨线生产 |
| 成本 | 高（持续投入） | 中（前期投入，长期低） |
| 时效 | 快（立即可用） | 中（需要切换时间） |
| 推荐 | 关键物料、战略瓶颈 | 通用件、快速消费品 |

### 3.5 刘宝红三道防线

> 📖 出处：刘宝红,《供应链的三道防线》

```
第一道防线：需求预测 ──→ 减少不确定性（解决"看不准"）
    │  方法：统计预测 + AI + S&OP 协同
    │  目标：预测准确率 ≥ 80%
    ↓
第二道防线：库存计划 ──→ 吸收不确定性（解决"备不准"）
    │  方法：安全库存 + ABC/XYZ + VMI
    │  目标：服务水平 ≥ 95%，周转天数可控
    ↓
第三道防线：供应链执行 → 应对不确定性（解决"应变慢"）
    │  方法：柔性产能 + 缩短LT + 控制塔
    │  目标：紧急订单响应 ≤ 48h
    ↓
    整体韧性 = f(预测准度, 库存策略, 响应速度)
```

**10年经验总结**：
- 大多数企业把 80% 精力放在第一道防线（提升预测准确率），但预测改善的边际收益递减
- **真正的高手**把更多精力放在第二、三道防线——因为预测永远会有误差，关键是怎么应对
- 前端防杂（简化 SKU）、中间治乱（标准化流程）、后端减重（精简供应商）是更底层的逻辑

### 3.6 DDMRP 缓冲管理

> 📖 出处：Carol Ptak & Chad Smith, *Demand Driven MRP*, 2011

**与传统 MRP 的根本区别**：

| 维度 | 传统 MRP | DDMRP |
|------|---------|-------|
| 驱动方式 | 预测驱动（Push） | 消耗驱动（Pull） |
| 计划方式 | 批量重排（MRP Run） | 持续缓冲补货 |
| 系统波动 | 高（牛鞭效应） | 低（缓冲吸收） |
| 库存策略 | 按需计算 | 缓冲色带管理 |
| 适用场景 | 需求稳定、LT 短 | 需求波动大、LT 长 |

**缓冲色带模型**：

```
🟢 绿色区 ── 超量警告（库存过高）
🟡 黄色区 ── 正常补货区（LT 库存）
🔴 红色区 ── 安全库存（紧急信号）
────────── 0（零点）
```

**净流量方程**：`补货信号 = 期末库存 + 在途 − 已确认需求`

当库存位置降至黄色区域以下 → 触发补货订单，数量 = 黄色 + 红色总量

### 5.2 10年老鸟的忠告

> 🎯 **理论是地图，实践是地形**。
>
> 读 Fisher 框架时你会觉得"功能型产品配效率型供应链"理所当然。但当你真正在企业里推动变革时，你会发现最大的挑战不是"选错供应链类型"，而是组织内部的利益博弈、历史惯性和数据质量。
>
> 这些书给你的不是"答案"，而是"提问的方式"。能问出正确的问题，比找到正确的答案更重要。
