# 供应链风险管理

> 💡 **10年+视角**：2020年之前，供应链风险管理是"锦上添花"；2020年之后，它是"生死攸关"。新冠、芯片缺货、苏伊士运河堵塞、地缘政治——每3-5年就来一次"黑天鹅"。风险管理不是消除风险，而是**在风险发生时，你的供应链还能转**。

---

## 一、风险分类体系

### 1.1 按来源分类

```
供应链风险
├── 运营风险（Operational）
│   ├── 供应商质量/交付风险
│   ├── 生产中断风险
│   ├── 物流延误风险
│   └── IT 系统故障
│
├── 需求风险（Demand）
│   ├── 需求预测偏差
│   ├── 客户订单取消
│   ├── 市场突变
│   └── 竞争对手动作
│
├── 供应风险（Supply）
│   ├── 供应商倒闭/断供
│   ├── 原材料价格波动
│   ├── 产能不足
│   └── 质量不达标
│
├── 环境风险（Environmental）
│   ├── 自然灾害（地震、洪水、疫情）
│   ├── 政策法规变化
│   ├── 地缘政治（关税、制裁）
│   └── ESG 合规风险
│
└── 网络风险（Cyber）
    ├── 数据泄露
    ├── 勒索软件攻击
    └── 供应链 IT 系统入侵
```

### 1.2 按影响程度分类

| 类别 | 影响 | 概率 | 示例 |
|------|------|------|------|
| **高频低影响** | 小 | 高 | 个别供应商延迟 1-2 天 |
| **中频中影响** | 中 | 中 | 季节性需求波动、汇率变动 |
| **低频高影响** | 大 | 低 | 芯片缺货、工厂火灾、疫情 |
| **极端事件** | 巨大 | 极低 | 地震、战争、苏伊士堵塞 |

## 二、风险评估矩阵

### 2.1 概率-影响矩阵

```
影响程度
  高 │  ③中风险   ④高风险    ⑤极高风险
     │  （关注）   （缓解）    （立即行动）
  中 │  ②低风险   ③中风险    ④高风险
     │  （监控）   （关注）    （缓解）
  低 │  ①极低     ②低风险    ③中风险
     │  （接受）   （监控）    （关注）
     └──────────────────────────────→
        低         中         高
              发生概率
```

### 2.2 风险量化公式

```
风险暴露值（Risk Exposure）= 概率 × 影响金额

示例：
  某关键芯片供应商断供概率：5%/年
  断供导致的损失：5,000 万元/月 × 3 个月 = 1.5 亿元
  风险暴露值 = 5% × 1.5 亿 = 750 万元/年

  → 值得投入 ≤ 750 万/年来降低这个风险
```

## 三、韧性框架（Resilience Framework）

> 📖 出处：Yossi Sheffi, *The Resilient Enterprise*, 2005

### 3.1 韧性 vs 鲁棒性

| 维度 | 鲁棒性（Robustness） | 韧性（Resilience） |
|------|---------------------|-------------------|
| 定义 | 抵抗冲击、不受影响 | 受冲击后快速恢复 |
| 手段 | 冗余、厚壁垒 | 柔性、快速响应 |
| 成本 | 高（持续投入） | 中（能力投资） |
| 适用 | 可预见的常规风险 | 不可预见的极端事件 |

### 3.2 五大韧性支柱

| 支柱 | 核心能力 | 建设手段 |
|------|---------|---------|
| **1. 可视性** | 看到 Tier 2/3 供应商 | 供应链映射、多层可视化平台 |
| **2. 风险意识文化** | 全员风险思维 | 风险评估融入采购/计划决策 |
| **3. 稳健设计** | 产品/流程本身抗扰 | 模块化、通用件、平台化 |
| **4. 敏捷性** | 快速重新配置 | 柔性产能、双源采购、切换能力 |
| **5. 协同** | 跨链合作 | 信息共享、联合库存、CPFR |

### 3.3 韧性成熟度模型

```
Level 1：被动响应 ── 风险发生了才处理（救火模式）
Level 2：风险识别 ── 开始识别关键风险，有清单但无行动
Level 3：主动缓解 ── 针对关键风险制定缓解措施
Level 4：系统管理 ── 风险管理融入日常流程和决策
Level 5：韧性文化 ── 全员风险意识，组织自适应
```

## 四、风险缓解策略

### 4.1 策略矩阵

| 策略 | 适用风险 | 成本 | 效果 | 示例 |
|------|---------|:---:|:---:|------|
| **双源/多源采购** | 供应集中风险 | 中 | 高 | 关键芯片双供应商 |
| **安全库存** | 需求/供应波动 | 中 | 中 | 战略物料备 4-8 周库存 |
| **柔性产能** | 需求波动 | 中 | 高 | 可切换产线、代工厂 |
| **供应网络多元化** | 地缘风险 | 高 | 高 | 中国+越南+印度布局 |
| **近岸外包（Nearshoring）** | 物流/地缘风险 | 高 | 中 | 墨西哥替代中国出口美国 |
| **垂直整合** | 供应瓶颈 | 极高 | 极高 | 宁德时代自研锂矿 |
| **保险** | 极端事件 | 低 | 低 | 业务中断险 |
| **数字化预警** | 各类风险 | 中 | 高 | 供应链控制塔 |

### 4.2 双源采购的权衡

```
单源采购：
  ✅ 规模效应、管理简单、关系深
  ❌ 断供风险高、议价能力弱

双源采购：
  ✅ 风险分散、议价竞争、保供
  ❌ 规模分散、管理复杂、质量一致性

最佳实践：
  - A 类关键物料：双源（70:30 或 60:40）
  - B 类重要物料：单源 + 备选供应商（qualified but not active）
  - C 类标准物料：单源即可（供应充足）
```

## 五、重大供应链风险事件复盘

### 5.1 新冠疫情（2020-2022）

| 阶段 | 冲击 | 供应链应对 |
|------|------|----------|
| 第一阶段 | 中国工厂停工 | 安全库存消耗、海外替代 |
| 第二阶段 | 全球物流中断 | 空运替代海运、本地化采购 |
| 第三阶段 | 需求结构剧变 | 快速调整产品组合、柔性产能 |
| 第四阶段 | 恢复但不均衡 | 供应网络多元化、增加安全库存 |

**教训**：提前做好的企业有三个共同点——供应链可视化、多源布局、柔性产能。

### 5.2 全球芯片缺货（2021-2023）

| 根因 | 影响 |
|------|------|
| 疫情导致消费电子需求暴增 | 芯片产能被消费电子挤占 |
| 车企在疫情初期砍单 | 恢复后排不上队 |
| double booking（重复下单） | 需求信号失真，产能规划错误 |
| 台积电等代工产能集中 | 供应端无弹性 |

**教训**：芯片是"战略物资"，需要长期协议（LTA）+ 安全库存 + 双源设计。

### 5.3 苏伊士运河堵塞（2021年3月）

| 维度 | 数据 |
|------|------|
| 持续时间 | 6 天 |
| 受影响船舶 | ~400 艘 |
| 全球贸易影响 | 每天约 96 亿美元 |
| 恢复时间 | 数周才消化积压 |

**教训**：关键物流节点的风险评估和应急预案是必要的。

## 六、风险管理流程

### 6.1 四步循环

```
1. 识别（Identify）
   └── 供应链映射、风险清单、场景分析

2. 评估（Assess）
   └── 概率-影响矩阵、风险暴露值计算

3. 缓解（Mitigate）
   └── 制定应对策略、投资韧性能力

4. 监控（Monitor）
   └── 风险指标看板、预警机制、定期评审
```

### 6.2 供应链风险仪表盘

| 监控维度 | 指标 | 预警阈值 |
|---------|------|---------|
| 供应集中度 | 单一供应商占比 | > 50% 预警 |
| 地理集中度 | 单一国家/地区占比 | > 60% 预警 |
| 库存缓冲 | 关键物料 DOS | < 2 周预警 |
| 供应商健康 | 财务/交期/质量评分 | 低于阈值预警 |
| 物流风险 | 在途货物延迟率 | > 10% 预警 |
| 需求风险 | 预测偏差率 | > 25% 预警 |
