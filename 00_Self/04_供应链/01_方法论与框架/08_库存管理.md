# 库存管理理论

> 💡 **10年+视角**：库存管理的核心不是"越少越好"，而是**在正确的地方放正确的量**。库存是供应链的"血液"——太少会休克，太多会肥胖。高手管的是"库存分布"，不是"库存总量"。

---

## 一、库存的本质

### 1.1 库存的六大功能

| 功能 | 说明 | 示例 |
|------|------|------|
| **缓冲不确定性** | 应对需求/供应波动 | 安全库存 |
| **解耦供需** | 让上下游独立运作 | 成品库存 |
| **规模经济** | 批量采购/生产降低成本 | 原材料库存 |
| **季节性储备** | 平滑淡旺季差异 | 空调、羽绒服 |
| **在途库存** | 物流过程中的物料 | 在途货物 |
| **投机性库存** | 低价囤货 | 原材料涨价前囤货 |

### 1.2 库存是"结果"不是"原因"

```
库存高 ≠ 管理差
库存高 = 需求预测不准 + 供应不稳定 + 产品复杂度高 + 流程效率低

→ 要治本（改善预测、缩短 LT、简化 SKU），不要只治标（砍库存目标）
```

## 二、经典库存模型

### 2.1 经济订货量（EOQ）

> 📖 出处：Ford Whitman Harris, 1913

```
EOQ = √(2 × D × S / H)

D = 年需求量（件/年）
S = 单次订购成本（元/次）
H = 单位持有成本（元/件/年）

示例：某零件年需求 50,000 件，订购成本 150 元/次，持有成本 2 元/件/年
  EOQ = √(2 × 50,000 × 150 / 2) = √(7,500,000) ≈ 2,739 件
```

**EOQ 的假设与局限**：

| 假设 | 现实 | 影响 |
|------|------|------|
| 需求均匀 | 需求有波动 | EOQ 偏大 |
| LT 固定 | LT 有波动 | 需要安全库存补充 |
| 单价不变 | 有阶梯折扣 | 需要考虑价格折扣模型 |
| 无缺货 | 允许缺货需加入缺货成本 | 基本 EOQ 不适用 |

### 2.2 报童模型（Newsvendor Model）

> 📖 最经典的单期库存决策模型，适用于生命周期短、需求不确定的产品

```
最优订货量 Q* 满足：P(需求 ≤ Q*) = Cu / (Cu + Co)

Cu = 单位缺货成本（underage cost）= 售价 - 成本
Co = 单位过剩成本（overage cost）= 成本 - 残值

示例：
  售价 100 元，成本 60 元，残值 20 元
  Cu = 100 - 60 = 40
  Co = 60 - 20 = 40
  临界比率 = 40 / (40 + 40) = 0.5
  → 订货量 = 需求分布的中位数

如果 Cu > Co（缺货损失更大）→ 临界比率 > 0.5 → 多订
如果 Co > Cu（过剩损失更大）→ 临界比率 < 0.5 → 少订
```

**报童模型的行业应用**：

| 行业 | 应用场景 | Cu vs Co |
|------|---------|----------|
| 时装 | 季节性服装采购 | Co > Cu（过季打折）→ 保守订货 |
| 航空 | 机票超售 | Cu > Co（空座浪费）→ 适度超售 |
| 生鲜 | 每日蔬菜采购 | Co > Cu（过期报废）→ 保守订货 |
| 电子产品 | 新品首发 | Cu > Co（缺货损失口碑）→ 积极备货 |

### 2.3 (s, Q) 连续检查策略

```
当库存 ≤ s（再订货点）时，订购 Q（固定批量）单位

参数计算：
  s = d̄ × LT + SS
  Q = EOQ 或固定批量

  d̄ = 平均日需求
  LT = 提前期（天）
  SS = 安全库存
```

### 2.4 (R, S) 定期检查策略

```
每隔 R 天检查一次库存，补充至目标水平 S

参数计算：
  S = d̄ × (R + LT) + SS

适用场景：C 类物料、供应商要求定期下单
```

## 三、安全库存理论

### 3.1 安全库存的三种场景

| 场景 | 公式 | 说明 |
|------|------|------|
| 需求不确定，LT 确定 | SS = Z × σd × √LT | 最常用 |
| 需求确定，LT 不确定 | SS = Z × σLT × d̄ | 供应不稳定场景 |
| 双重不确定 | SS = Z × √(LT × σd² + d̄² × σLT²) | 复杂场景 |

### 3.2 服务水平与安全系数

| 服务水平 | Z 值 | 含义 |
|:---:|:---:|------|
| 85% | 1.04 | 每 100 次有 15 次缺货 |
| 90% | 1.28 | 每 100 次有 10 次缺货 |
| 95% | 1.65 | 每 100 次有 5 次缺货 |
| 97.5% | 1.96 | 每 100 次有 2.5 次缺货 |
| 99% | 2.33 | 每 100 次有 1 次缺货 |
| 99.5% | 2.58 | 每 200 次有 1 次缺货 |

### 3.3 安全库存的边际效应

```
服务水平 ↑ 90% → 95%   SS 增加 ~30%
服务水平 ↑ 95% → 99%   SS 增加 ~41%
服务水平 ↑ 99% → 99.5%  SS 增加 ~11%
服务水平 ↑ 99.5% → 99.9% SS 增加 ~20%

→ 从 99% 提升到 99.9%，安全库存几乎翻倍
→ 库存投资的边际收益递减，选择合适的服务水平至关重要
```

## 四、多级库存管理

### 4.1 多级库存的挑战

```
        工厂仓（DC）
       ╱          ╲
  区域仓A        区域仓B
  ╱    ╲         ╱    ╲
门店1  门店2   门店3  门店4

问题：
- 各节点独立设定安全库存 → 总库存冗余
- 节点间需求不均衡 → 一边缺货、一边积压
- 信息不透明 → 无法做全局优化
```

### 4.2 多级库存优化策略

| 策略 | 原理 | 效果 |
|------|------|------|
| **风险池（Risk Pooling）** | 合并库存，共享不确定性 | 库存降低 10-30% |
| **中心化库存** | DC 持有大部分库存，门店少量 | 总库存降低 20-40% |
| **横向转运（Lateral Transshipment）** | 门店间互相调拨 | 缺货率降低 30-50% |
| **多级补货（Echelon Replenishment）** | 考虑全链库存做决策 | 全局最优 |

### 4.3 风险池的数学原理

```
独立需求门店：4 个门店各自需求 ~ N(100, 30²)
  每个门店 SS(95%) = 1.65 × 30 = 49.5
  总 SS = 4 × 49.5 = 198

合并到中心仓：总需求 ~ N(400, 60²) [标准差不是 120，因为相关系数 < 1]
  SS(95%) = 1.65 × 60 = 99

→ 库存降低 50%！这就是风险池的力量
```

## 五、协同库存管理

### 5.1 VMI（供应商管理库存）

| 维度 | 说明 |
|------|------|
| **定义** | 供应商根据客户的消耗数据，自主决定补货时机和数量 |
| **所有权** | 通常在消耗前归供应商所有 |
| **信息流** | 客户共享 POS/消耗数据 |
| **效果** | 库存降低 20-30%，缺货率降低 30-50% |
| **代表** | 宝洁-沃尔玛、戴尔-供应商 |

### 5.2 CPFR（协同计划预测补货）

| 步骤 | 内容 |
|------|------|
| 1. 协同战略 | 双方建立合作框架和目标 |
| 2. 协同计划 | 共同制定业务计划 |
| 3. 协同预测 | 双方共同制定需求预测 |
| 4. 协同补货 | 基于共识预测生成补货计划 |

## 六、呆滞库存管理

### 6.1 呆滞的根因

| 根因 | 占比 | 对策 |
|------|:---:|------|
| 产品迭代未清理旧料 | 35% | 产品生命周期管理 |
| 预测过高导致过量采购 | 25% | 改善预测准确率 |
| 工程变更未及时通知 | 20% | ECN 流程数字化 |
| MOQ 约束导致过量 | 10% | 协商 MOQ 或转售 |
| 质量问题积压 | 10% | 加强来料检验 |

### 6.2 呆滞预警机制

```
库龄分级管理：
  0-90 天    正常（绿色）
  91-180 天  关注（黄色）→ 促销/调拨
  181-365 天 预警（橙色）→ 折价/退供应商
  >365 天    呆滞（红色）→ 报废/捐赠

月度呆滞评审：财务+供应链+产品三方联合评审
```

## 七、库存管理 KPI 体系

| KPI | 公式 | 目标 | 层级 |
|-----|------|------|------|
| 库存周转率 | 年销售成本 / 平均库存 | 行业差异大 | 战略 |
| 库存周转天数 | 365 / 周转率 | 制造业 30-60 天 | 战术 |
| 库存准确率 | 盘点一致数 / 总数 | ≥ 99% | 运营 |
| 呆滞库存比例 | 呆滞金额 / 总库存 | ≤ 3% | 运营 |
| 缺货率 | 缺货 SKU / 总 SKU | ≤ 2% | 运营 |
| 安全库存覆盖率 | 库存 > SS 的 SKU 比例 | ≥ 95% | 运营 |
| 库存天数（DOS） | 当前库存 / 日均消耗 | 目标范围内 | 监控 |
