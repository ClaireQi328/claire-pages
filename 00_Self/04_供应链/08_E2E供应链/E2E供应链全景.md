### 3.2 关键上下游接口

| 上游阶段 | 下游阶段 | 传递数据/单据 | 交互频率 |
|---------|---------|-------------|---------|
| 需求管理 → 供应网络设计 | 需求预测、产品组合、区域分布 | 周/月度 | |
| 供应网络设计 → 寻源定点 | 产能缺口、选址建议、成本目标 | 季度/年度 | |
| 寻源定点 → 计划与排程 | 供应商产能、交付周期、价格协议 | 持续同步 | |
| 计划与排程 → 采购执行 | 采购申请(PR)、需求日期、批量 | 日/周度 | |
| 采购执行 → 生产制造 | 收货确认、质量检验结果、入库通知 | 实时 | |
| 生产制造 → 仓储配送 | 生产完工、成品下线、质量放行 | 实时 | |
| 仓储配送 → 交付与售后 | 发运计划、物流跟踪、签收状态 | 实时 | |
| 交付与售后 → 需求管理 | 客户反馈、退货数据、需求偏差 | 周度 | |
| 全阶段 → 供应链控制塔 | 异常事件、KPI指标、风险信号 | 实时 | |

## 五、跨阶段关键单据流转

### 5.1 核心单据链路

```
┌─────────────────────────────────────────────────────────────────────────────────────────────┐
│                                                                                             │
│  ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────────┐   ┌─────────┐   ┌─────────┐   │
│  │  PR  │──▶│  PO  │──▶│ ASN  │──▶│ GRN  │──▶│  Invoice │──▶│ Payment │──▶│  Closing │   │
│  │采购申请│   │采购订单│   │发货通知│   │收货单 │   │  发票    │   │  付款   │   │  结算   │   │
│  └──────┘   └──────┘   └──────┘   └──────┘   └──────────┘   └─────────┘   └─────────┘   │
│                                                                                             │
│  触发方:    计划/PR审批   供应商确认   供应商发货   仓库收货      财务对账      财务付款       │
│  对应阶段:  4.计划排程    5.采购执行    5.采购执行   5.采购执行    5.采购执行    5.采购执行     │

│                                                                                             │
└─────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 单据详细说明

| 单据 | 英文全称 | 发起方 | 接收方 | 关键字段 | 状态流转 |
|------|---------|-------|-------|---------|---------|
| PR | Purchase Requisition | 业务部门/计划系统 | 采购部门 | 物料编码、数量、需求日期、成本中心 | 草稿→审批中→已批准→已转PO |
| PO | Purchase Order | 采购部门 | 供应商 | 供应商、价格、交期、付款条件 | 创建→已发送→已确认→收货中→已完成 |
| ASN | Advanced Shipping Notice | 供应商 | 采购方/仓库 | 预计到达时间、发货数量、运输方式 | 已创建→运输中→已到达 |
| GRN | Goods Receipt Note | 仓库 | 采购/财务 | 实收数量、质量状态、库位 | 待收货→检验中→已入库→已上架 |
| Invoice | 发票 | 供应商/采购方 | 财务 | PO号、金额、税额、付款条件 | 已创建→三单匹配→已审核→待付款 |
| Payment | 付款凭证 | 财务 | 供应商 | 发票号、付款金额、付款方式 | 待审批→已审批→已付款→已到账 |

### 5.3 三单匹配规则

```
┌─────────────────────────────────────────────────┐
│              三单匹配 (3-Way Match)               │
├─────────────────────────────────────────────────┤
│                                                  │
│    PO (采购订单)                                  │
│      ↓ 数量/价格                                  │
│    GRN (收货单)  ──── 匹配 ────  Invoice (发票)   │
│                                                  │
│  允许容差:                                        │
│    - 数量差异: ±2% 或 ±5件 (取较小值)              │
│    - 金额差异: ±1% 或 ±50元 (取较小值)             │
│    - 超出容差: 触发人工审批流程                     │
│                                                  │
└─────────────────────────────────────────────────┘
```

## 六、行业差异

| 维度 | 汽车行业 | 电商行业 | 消费电子 | 医药行业 |
|------|---------|---------|---------|---------|
| **供应链特征** | 推拉结合，JIT/JIS交付 | 纯拉动，快速周转 | 推拉结合，产品生命周期短 | 合规驱动，冷链要求高 |
| **核心挑战** | 多层级供应商管理、产线同步 | 峰值应对(双11)、退换货率高 | 新品导入快、物料长尾多 | 批次追溯、有效期管理 |
| **计划模式** | S&OP + JIS排序 | 需求感知 + 补货触发 | NPI驱动 + S&OP | MRP + 批次计划 |
| **寻源特点** | 平台化寻源、联合开发 | 成本导向、快速切换 | 技术寻源、长周期定点 | 合规寻源、审计要求 |
| **库存策略** | VMI + 安全库存 | 中心仓 + 前置仓 | 区域仓 + 预售 | 合规库存 + 退货管理 |
| **物流模式** | 循环取料(Milk Run) | 快递为主，次日达 | 多式联运 | 冷链+专业物流 |
| **质量要求** | IATF 16949，PPAP | 抽检为主 | IPC/AQL | GMP，CSV |
| **控制塔重点** | 产线停线预警 | 履约率、时效 | 库存周转、新品上市 | 合规追溯、温度监控 |
| **代表企业** | 丰田、大众、蔚来 | 京东、亚马逊、SHEIN | 苹果、小米、三星 | 辉瑞、恒瑞、药明康德 |
