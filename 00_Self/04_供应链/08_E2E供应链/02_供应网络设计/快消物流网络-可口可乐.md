# 快消物流网络深度研究：可口可乐全链路模拟

> 💡 **研究目标**：快消物流的核心挑战是**密度**——如何用最低成本把货送到全国 600 万个终端网点（超市/便利店/餐饮）。可口可乐是全球分销网络最复杂的企业之一。

---

## 一、行业画像与物流特征

### 1.1 可口可乐中国供应链

```
供应链拓扑：

浓缩液工厂（上海/美国进口）
    ↓
全国 45 家灌装厂（太古/中粮两大装瓶集团）
    ├─ 区域灌装：就地生产，覆盖 300km 半径
    └─ 产能：每厂日产 50-200 万箱
    ↓
区域配送中心（RDC）：全国 200+
    ├─ 太古 RDC：80 个
    └─ 中粮 RDC：120 个
    ↓
经销商/批发商：全国 5,000+
    ↓
终端网点：全国 600 万+
    ├─ 现代渠道（KA）：沃尔玛/大润发/永辉 — 20%
    ├─ 传统渠道：夫妻店/小卖部 — 50%
    └─ 餐饮渠道：餐厅/酒店/食堂 — 30%
```

### 1.2 快消物流特殊约束

| 约束维度 | 具体要求 | 对网络设计的影响 |
|---------|---------|----------------|
| **重量大价值低** | 1 箱可乐 12kg，价值 ¥20 | 运费占比极高，就近生产 |
| **季节峰值** | 夏季（6-8月）销量是冬季 3 倍 | 需要弹性产能+临时仓储 |
| **保质期** | 12 个月（较长） | 库存压力相对小 |
| **空瓶回收** | 玻璃瓶需回收复用 | 逆向物流成本高 |
| **终端密集** | 600 万+网点，日配送 | 需要极密配送网络 |
| **陈列要求** | 冰柜投放、堆头陈列 | 需要设备物流 |

| 参数 | 值 |
|------|-----|

| SKU 数量 | 200+（含口味/包装/规格） |

## 二、物流网络拓扑设计

### 2.1 多级网络：灌装厂→终端

```
三级配送网络：

Level 1: 灌装厂（CDC）
  └─ 覆盖半径：300km
  └─ 功能：生产+存储+分拨
  └─ 日产能：50-200 万箱

Level 2: 区域配送中心（RDC）
  └─ 覆盖半径：50-100km
  └─ 功能：分拣+配送
  └─ 库存：3-5 天销量

Level 3: 经销商仓库 / 直配终端
  └─ 覆盖半径：10-30km
  └─ 功能：最后一公里配送
  └─ 配送频率：每日/隔日
```

### 2.2 灌装厂选址方法

**重心法计算**（以华东区域为例）：

| 需求城市 | 坐标(X,Y) | 日需求(万箱) | 加权X | 加权Y |
|---------|-----------|-------------|-------|-------|
| 上海 | (121.5, 31.2) | 200 | 24,300 | 6,240 |
| 南京 | (118.8, 32.1) | 80 | 9,504 | 2,568 |
| 杭州 | (120.2, 30.3) | 100 | 12,020 | 3,030 |
| 苏州 | (120.6, 31.3) | 60 | 7,236 | 1,878 |
| 合肥 | (117.3, 31.8) | 40 | 4,692 | 1,272 |
| **合计** | - | **480** | **57,752** | **14,988** |

```
X* = 57752 / 480 = 120.3°E
Y* = 14988 / 480 = 31.2°N
```

**重心 (120.3°E, 31.2°N)** → 上海/苏州交界 → 实际选择：**昆山灌装厂**

> 💡 可口可乐的灌装厂布局核心原则：**每个灌装厂覆盖 300km 半径**，因为饮料的"重量价值比"极高（运费占货值 15-25%），必须就近生产。

## 三、库存部署策略

### 3.1 库存水位计算

**安全库存公式**：

$$
SS = Z_{\alpha} \times \sigma_d \times \sqrt{LT}
$$

**以可口可乐 330ml 罐装为例**：

```
参数：
  日均销量（全国）= 150亿箱 / 365 = 4,110万箱
  单厂日均 = 4,110万 / 45 = 91万箱
  日需求标准差 σ_d = 30万箱（季节波动大）
  补货 LT = 1 天（灌装厂→RDC，同城市）
  服务水平 = 95% → Z_α = 1.65

安全库存（单厂）：
  SS = 1.65 × 30万 × √1 = 49.5万箱 ≈ 50万箱

再订购点：
  ROP = 91万 × 1 + 50万 = 141万箱
```

### 3.2 季节性库存策略

| 季节 | 日均需求系数 | 库存策略 | 产能策略 |
|------|-----------|---------|---------|
| 春季（3-5月） | 0.8 | 正常库存 | 正常生产 |
| 夏季（6-8月） | **2.5-3.0** | +150% 库存 | 三班倒+临时工 |
| 秋季（9-11月） | 1.2 | 正常库存 | 正常生产 |
| 冬季（12-2月） | 0.5 | 低库存+设备维护 | 单班+检修 |

## 四、运输优化

### 4.1 运输成本结构

| 运输段 | 模式 | 年运量(亿箱) | 单价(¥/箱) | 年成本(¥亿) |
|-------|------|------------|-----------|-----------|
| 灌装厂→RDC | 整车 | 150 | 0.3 | 45.0 |
| RDC→经销商 | 整车/零担 | 150 | 0.5 | 75.0 |
| 经销商→终端 | 金杯/三轮 | 150 | 1.5 | 225.0 |
| 空瓶回收 | 逆向物流 | 80 | 0.4 | 32.0 |
| **合计** | - | - | **2.7** | **377.0** |

> 单箱物流成本 **¥2.7**，占单箱售价（¥12）的 **22.5%**。快消物流费率是所有行业中最高的。

### 4.2 末端配送 VRP 优化

**配送路线优化**（以某城市 RDC 为例）：

```
VRP 参数：
  配送中心：1 个（城市 RDC）
  终端网点：5,000 个（城区 30km 半径）
  车辆：50 台（4.2m 厢式货车，载重 3 吨）
  日配送单量：2,000 单

优化目标：min 总行驶距离
约束：
  - 每车每日最多 25 个网点
  - 每车每日最大行驶 150km
  - 优先配送餐饮渠道（上午 10:00 前）

优化结果：
  平均每车每日：22 个网点，120km
  配送效率：88 箱/km（优化前 65 箱/km）
  年节省运输成本：¥120 万/RDC × 200 RDC = ¥2.4 亿
```

## 五、订单履约全流程

```
快消配送全流程（经销商订单）：

阶段          操作              耗时        并行
────────────────────────────────────────────────
① 订单采集    终端下单(App/电话)  T-1天       业务员
② 订单汇总    经销商汇总→RDC     T日 06:00   系统
③ 波次拣选    RDC 按路线分拣     T日 07:00   拣货员
④ 装车发运    按路线装车出发     T日 08:00   司机
⑤ 末端配送    逐网点配送         T日 08-17h  司机
⑥ 签收确认    终端验收签字       配送中       业务员
⑦ 空瓶回收    回收空瓶/冰柜检查  配送中       司机
────────────────────────────────────────────────
总时效        T-1 下单 → T日送达  24-36 小时
```
