# 汽车物流网络深度研究：小米 SU7 全链路模拟

> 💡 **研究目标**：汽车物流与 3C 最大的差异是**双物流体系**——零部件入厂（百万级 SKU、JIT/JIS）和整车出厂（超大件、专用运输）。本文用小米 SU7 完整走通两条链路。

---

## 一、行业画像与物流特征

### 1.1 小米 SU7 供应链全景

```
零部件入厂物流（上游→工厂）：

Tier 1 供应商（300+家）
├─ 电池：宁德时代（福建宁德）/ 比亚迪弗迪（深圳）
├─ 电驱：汇川技术（苏州）/ 联合电子（上海）
├─ 底盘：博世（苏州）/ 采埃孚（上海）
├─ 车身：凌云股份（河北）/ 华域汽车（上海）
├─ 内饰：延锋（上海）/ 安道拓（长春）
├─ 电子：德赛西威（惠州）/ 华阳集团（惠州）
└─ 轮胎：米其林（沈阳）/ 普利司通（天津）
    ↓
  Milk-Run 循环取货 / 直送
    ↓
  小米汽车工厂（北京亦庄）
    ↓

整车出厂物流（工厂→车主）：

  小米汽车工厂（北京亦庄）
    ↓
  整车仓储（工厂 PDI 中心）
    ↓
  板车运输 / 铁路运输
    ↓
  全国 45 个交付中心
    ↓
  车主提车 / 送车上门
```

### 1.2 汽车物流特殊约束

| 约束维度 | 具体要求 | 对网络设计的影响 |
|---------|---------|----------------|
| **超大件** | 整车 4.8m×1.9m×1.5m，2.2 吨 | 专用板车，每车装 6-8 台 |
| **JIT/JIS** | 零部件 2-4 小时送达产线 | 需要近场仓 + 循环取货 |
| **多级供应商** | Tier1→Tier2→Tier3，3 级以上 | 入厂物流网络复杂 |
| **长周期** | 订单到交付 4-8 周 | 需要成品车库存前置 |
| **高单车价值** | SU7 均价 ¥25 万 | 运输需全险，库存资金压力大 |
| **售后备件** | 3 万+ SKU 备件 | 需要独立备件网络 |

| 参数 | 值 | 来源/假设 |
|------|-----|----------|

| 实际年产量（2026E） | 18 万辆 | 产能利用率 90% |
| 车型 | SU7 标准版/Pro/Max | 3 款主车型 |

| 交付中心数量 | 45 个 | 覆盖全国主要城市 |

## 二、物流网络拓扑设计

### 2.1 入厂物流网络：零部件→工厂

**入厂物流的三种模式**：

| 模式 | 适用场景 | 距离 | 频率 | 示例 |
|------|---------|------|------|------|
| **直送（Direct）** | 大件/重件/专用件 | >500km | 按需 | 电池包（宁德时代→北京，1,800km） |
| **Milk-Run** | 中小件/通用件 | <500km | 每日2-4次 | 苏州供应商群→北京，1,100km |
| **排序供货（JIS）** | 内饰/座椅/仪表板 | <200km | 每2小时 | 延锋（廊坊→北京亦庄，60km） |

**Milk-Run 路径设计**（华东线为例）：

```
华东 Milk-Run 路线（每日 2 班，17:00/05:00 出发）：

起点：北京亦庄工厂空车出发
  ↓ 320km（3.5h）
苏州站：取汇川电驱控制器 + 博世底盘件
  ↓ 100km（1.2h）
上海站：取采埃孚变速箱壳体 + 延锋内饰件
  ↓ 80km（1h）
昆山站：取华域车灯 + 其他小件
  ↓ 1,100km（12h 夜间运输）
终点：次日 07:00 到达北京工厂

单程取货量：15 托 × 500kg = 7.5 吨
车辆：9.6m 厢式货车，载重 10 吨
```

### 2.3 重心法计算交付中心选址

**需求点加权重心**：

| 区域 | 城市 | 坐标(X,Y) | 年需求(万辆) | 加权X | 加权Y |
|------|------|-----------|-------------|-------|-------|
| 华北 | 北京 | (116.4, 39.9) | 3.6 | 419.0 | 143.6 |
| 华东 | 上海 | (121.5, 31.2) | 4.5 | 546.8 | 140.4 |
| 华南 | 广州 | (113.3, 23.1) | 2.7 | 305.9 | 62.4 |
| 华中 | 武汉 | (114.3, 30.6) | 1.8 | 205.7 | 55.1 |
| 西南 | 成都 | (104.1, 30.6) | 1.8 | 187.4 | 55.1 |
| 东北 | 沈阳 | (123.4, 41.8) | 1.0 | 123.4 | 41.8 |
| 西北 | 西安 | (108.9, 34.3) | 1.0 | 108.9 | 34.3 |
| 其他 | - | - | 1.6 | - | - |
| **合计** | - | - | **18.0** | **1897.1** | **532.7** |

```
X* = 1897.1 / 16.4 = 115.7°E
Y* = 532.7 / 16.4 = 32.5°N
```

**重心 (115.7°E, 32.5°N)** → 安徽合肥附近

> 实际选择：考虑到工厂在北京，**华北交付群直接从工厂发车**，华东/华南各设区域集散中心（上海嘉定、广州南沙），再分拨到各交付中心。

## 五、订单履约全流程

### 5.1 整车订单到交付全流程

```
小米 SU7 订单履约全流程：

阶段              操作                    耗时        状态
────────────────────────────────────────────────────────
① 线上下单        App/官网选配下单         即时        订单确认
② 订单匹配        匹配现车或排产           0-14天      排产中
③ 生产排程        MES 排产到产线           7天         生产中
④ 零部件齐套      WMS 配送到线边           同步        生产中
⑤ 总装下线        整车下线+质检            同步        待发运
⑥ PDI 检测        全车检测+充电            1天         待发运
⑦ 发运            板车/铁路发出            0.5-4天     运输中
⑧ 到达交付中心    入库+二次PDI             0.5天       待交付
⑨ 交付通知        通知客户提车             即时        已到店
⑩ 客户提车        验车+上牌+交车           0.5天       已交付
────────────────────────────────────────────────────────
总周期            订单→提车               14-28天
```
