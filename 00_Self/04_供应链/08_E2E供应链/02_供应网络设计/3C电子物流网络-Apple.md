## 二、物流网络拓扑设计

### 2.1 方法论：重心法 + MILP 两阶段优化

**第一阶段：重心法确定候选区域**

重心法（Center of Gravity Method）通过需求加权计算最优仓库位置：

$$
X^* = \frac{\sum_{i=1}^{n} d_i \times x_i}{\sum_{i=1}^{n} d_i}, \quad Y^* = \frac{\sum_{i=1}^{n} d_i \times y_i}{\sum_{i=1}^{n} d_i}
$$

其中：
- $(x_i, y_i)$ = 需求点 i 的地理坐标
- $d_i$ = 需求点 i 的年需求量（万台）
- $(X^*, Y^*)$ = 重心坐标（最优仓库位置）

**第二阶段：MILP 精确优化**

在重心法候选区域内，用混合整数线性规划确定最终选址和分配：

$$
\min \sum_{j \in J} f_j \cdot y_j + \sum_{i \in I} \sum_{j \in J} c_{ij} \cdot x_{ij}
$$

约束条件：
- 每个需求点只由一个仓库服务：$\sum_j x_{ij} = 1, \forall i$
- 只有选中的仓库才能服务：$x_{ij} \leq y_j, \forall i,j$
- 仓库容量限制：$\sum_i d_i \cdot x_{ij} \leq Q_j \cdot y_j, \forall j$

## 三、库存部署策略

### 3.1 方法论：ABC 分类 + 安全库存

**Step 1：ABC 分类**

按年销售额对 SKU 进行帕累托分类：

$$
A 类：累计占比 0-80\% \quad B 类：80-95\% \quad C 类：95-100\%
$$

**Step 2：安全库存计算**

$$
SS = Z_{\alpha} \times \sigma_d \times \sqrt{LT}
$$

其中：
- $Z_{\alpha}$ = 服务水平对应的标准正态分位数（95% → 1.65，99% → 2.33）
- $\sigma_d$ = 日需求标准差
- $LT$ = 补货提前期（天）

**Step 3：库存分配策略**

| ABC 类别 | 服务水平 | 库存位置 | 补货频率 |
|---------|---------|---------|---------|
| A 类（Top 3 SKU） | 99% | CDC + 所有 RDC | 每日 |
| B 类（中间 5 SKU） | 95% | CDC + 主要 RDC | 每周 |
| C 类（长尾 4 SKU） | 90% | 仅 CDC | 按需 |

### 3.3 安全库存计算示例

**以 SKU-01（iPhone 16 Pro Max 256G）为例**：

```
参数：
  年销量 = 800 万台
  日均销量 = 800万 / 365 = 21,918 台
  日需求标准差 σ_d = 15,000 台（基于新品发布期波动）
  补货提前期 LT = 3 天（郑州CDC→上海RDC）
  服务水平 = 99% → Z_α = 2.33

安全库存：
  SS = Z_α × σ_d × √LT
     = 2.33 × 15,000 × √3
     = 2.33 × 15,000 × 1.732
     = 60,540 台

再订购点（ROP）：
  ROP = d × LT + SS
      = 21,918 × 3 + 60,540
      = 65,754 + 60,540
      = 126,294 台

上海 RDC 分配（覆盖华东 24% 需求）：
  SS_上海 = 60,540 × 24% = 14,530 台
  ROP_上海 = 126,294 × 24% = 30,311 台
```

## 四、运输优化

### 4.1 方法论：运输方式选择 + VRP

**运输方式选择模型**：

$$
\text{选择} = \arg\min_{m \in \{空运, 公路, 铁路\}} (c_m \times w + t_m \times h)
$$

其中：
- $c_m$ = 方式 m 的单位运输成本（¥/kg）
- $w$ = 货物重量
- $t_m$ = 方式 m 的运输时间（天）
- $h$ = 时间价值系数（高价值商品 h 大）

**VRP 车辆路径优化**（末端配送）：

$$
\min \sum_{k=1}^{K} \sum_{(i,j) \in A} c_{ij} \cdot x_{ijk}
$$

约束：每辆车从配送中心出发，服务若干客户后返回，总载重不超过车辆容量。

### 5.1 方法论：离散事件模拟 + Little's Law

**Little's Law**（利特尔法则）：

$$
L = \lambda \times W
$$

- $L$ = 系统中平均在制品数量
- $\lambda$ = 到达率（订单/小时）
- $W$ = 平均停留时间（小时）

## 六、成本模型

### 6.1 方法论：ABC 成本法（Activity-Based Costing）

ABC 成本法将物流成本分配到具体活动：

$$
\text{单均成本} = \sum_{a \in \text{Activities}} \text{动因量}_a \times \text{动因率}_a
$$

### 6.2 成本分解明细

| 成本大类 | 成本子项 | 年成本(¥亿) | 单均(¥/台) | 占比 | 动因 |
|---------|---------|-----------|-----------|------|------|
| **仓储成本** | | **2.10** | **4.20** | **13.5%** | |
| | 仓库租金 | 0.90 | 1.80 | | 面积 × 单价 |
| | 人工成本 | 0.72 | 1.44 | | 人数 × 月薪 |
| | 设备折旧(AGV等) | 0.30 | 0.60 | | 设备投资/5年 |
| | 水电物业 | 0.18 | 0.36 | | 面积 × 单价 |
| **运输成本** | | **7.83** | **15.66** | **50.4%** | |
| | 干线运输 | 3.20 | 6.40 | | 吨公里 × 单价 |
| | 末端配送 | 4.25 | 8.50 | | 单量 × 单价 |
| | 逆向物流 | 0.38 | 0.76 | | 退货量 × 单价 |
| **库存持有成本** | | **4.62** | **9.24** | **29.7%** | |
| | 资金占用成本 | 3.30 | 6.60 | | 库存价值 × 5% |
| | 贬值损失 | 0.82 | 1.64 | | 过季库存 × 贬值率 |

## 八、优化方案与 What-if 分析

### 8.1 场景分析

| 场景 | 变量 | 变化幅度 | 影响（年成本变化） | 影响（时效变化） | 建议 |
|------|------|---------|-----------------|----------------|------|
| **S1：新增成都RDC** | 网络节点 | +1个RDC | +¥0.8亿仓储 -¥0.3亿运输 | 西南时效-0.5天 | 待西南需求>800万台再建 |
| **S2：需求增长50%** | 需求量 | +2500万台 | +¥4.2亿总成本 | 需扩容仓+车 | 预建二期仓 |
| **S3：运输成本+20%** | 运输单价 | +20% | +¥1.57亿 | 不变 | 增加铁路比例 |
| **S4：取消RDC，仅CDC** | 网络节点 | -3个RDC | -¥0.9亿仓储 +¥0.6亿运输 | +1.3天 | 不建议（时效恶化） |
| **S5：空运→铁路** | 运输方式 | 空运转铁路 | -¥0.35亿 | 新品期+1天 | 可部分替代 |

### 8.2 敏感性分析

| 变量 | -20% | -10% | 基准 | +10% | +20% |
|------|------|------|------|------|------|
| 需求量 | -¥3.1亿 | -¥1.6亿 | ¥15.55亿 | +¥1.6亿 | +¥3.1亿 |
| 运输单价 | -¥1.6亿 | -¥0.8亿 | ¥15.55亿 | +¥0.8亿 | +¥1.6亿 |
| 仓库租金 | -¥0.18亿 | -¥0.09亿 | ¥15.55亿 | +¥0.09亿 | +¥0.18亿 |
| 库存周转天数 | -¥0.9亿 | -¥0.5亿 | ¥15.55亿 | +¥0.5亿 | +¥0.9亿 |

> 💡 **关键洞察**：**需求量**和**运输单价**是成本最敏感的两个变量。需求量波动 10% 会导致年成本变化 ¥1.6 亿。建议建立弹性运力合同，旺季上浮 30%、淡季下调 20%。
