## 一、间接采购 vs 直接采购

| 维度 | 直接采购（Direct Procurement） | 间接采购（Indirect Procurement） |
|------|-------------------------------|--------------------------------|
| **定义** | 用于产品生产制造的原材料、零部件 | 用于企业日常运营的非生产性物资与服务 |
| **典型品类** | 原材料、包装材料、生产辅料 | 办公用品、IT设备、MRO、市场物料、差旅 |
| **供应商关系** | 长期战略合作，深度绑定 | 短中长期混合，供应商池较大 |
| **采购量级** | 大批量、高货值、批量交付 | 小批量、低货值、零散交付 |
| **采购频率** | 按生产计划周期性采购 | 随时发生，高频碎片化 |
| **审批复杂度** | 技术+质量+采购多部门联合评审 | 金额驱动的层级审批，流程相对简单 |
| **系统支撑** | ERP/SRM 深度集成 | 采购商城 + 审批流 + 轻量ERP对接 |
| **价值影响** | 直接影响产品BOM成本与交付 | 占总采购额5-15%，但管理成本占30-40% |
| **降本空间** | 集中招标、框架协议、VMI | 品类集中、目录化采购、电子竞价 |

> **关键洞察**：间接采购虽然单笔金额小，但品类繁杂、供应商众多、交易频次高，
> 传统手工模式下管理成本远超物料价值本身。采购商城的核心价值在于**降低交易成本**和**提升合规率**。

**传统间接采购痛点**：

- 员工不知道向谁采购，自行联系供应商，绕过采购流程
- 采购申请通过邮件/纸质流转，审批周期长达3-7天
- 供应商分散，同类商品多家供应，无法形成规模议价
- 无预算控制，各部门支出失控，财务月底才发现超支
- 发票手工核对，三单匹配效率低，差错率高

**采购商城带来的改变**：

- 员工自助下单，采购周期从3-7天缩短至2-4小时
- 目录化采购率从30%提升至85%以上
- 品类集中后年度节约5-15%
- 预算实时控制，超支率降低60%
- 自动三单匹配，财务对账效率提升80%

## 三、子流程详解

### 3.1 商品目录管理（Catalog Management）

**功能作用**：管理供应商商品信息，构建企业内部商品目录，确保员工只能浏览和采购已审批上架的商品。

**流程说明**：
1. 供应商通过供应商门户上传商品信息（SKU、名称、规格、图片、价格、库存）
2. 采购团队审核商品信息的完整性与合规性
3. 确定内部销售价格（加价率/折扣率规则）
4. 商品分类与标签化，挂载到对应品类树
5. 设置采购限制（限购数量、适用部门、特殊审批条件）
6. 商品上架，发布到采购商城前端

**系统输入**：供应商商品数据、价格清单、库存状态、商品图片与描述

**系统输出**：可浏览的企业内部商品目录、价格目录、品类树结构

**可交付物**：
- 商品主数据（SKU、名称、规格、单位、品类编码）
- 价格目录（含内部售价、市场参考价、历史采购价）
- 供应商门户（商品维护界面、批量导入模板）

---

### 3.2 自助选购（Self-Service Shopping）

**功能作用**：员工像逛淘宝/京东一样选购办公用品、MRO、IT设备等非生产性物资，降低采购门槛。

**流程说明**：
1. **搜索发现**：员工通过关键词、品类导航、推荐位搜索目标商品
2. **浏览详情**：查看商品规格、图片、价格、库存状态、供应商评分
3. **智能比价**：同品类多供应商商品横向对比（价格、交期、评分）
4. **加入购物车**：选择数量，添加到购物车，系统实时计算预算占用
5. **凑单优化**：系统提示满减活动、合并发货建议、凑单推荐
6. **确认提交**：核对商品清单、收货地址、期望到货日期
7. **生成申请**：提交采购申请单（Purchase Requisition, PR），触发审批流

**系统输入**：员工采购需求、预算余额、企业商品目录

**系统输出**：采购申请单（PR）、预算预占记录

**可交付物**：
- 购物车（含商品快照、价格锁定、库存校验）
- 订单草稿（PR Preliminary）
- 预算预占凭证

---

### 3.3 审批工作流（Approval Workflow）

**功能作用**：按金额、品类、部门、成本中心自动路由审批链，确保合规采购。

**流程说明**：
1. PR提交后，系统根据预设规则自动匹配审批层级
2. 审批人收到待办通知（邮件/企业微信/钉钉/飞书）
3. 审批人查看采购详情、历史价格、预算余量、供应商信息
4. 审批人做出决策：批准 / 驳回 / 转审 / 要求补充信息
5. 全部审批完成后，PR状态变更为"已批准"，触发PO生成

**审批规则矩阵**：

| 金额区间（RMB） | 审批层级 | 审批人 |
|----------------|---------|--------|
| < 2,000 | 一级 | 直接主管（Direct Manager） |
| 2,000 - 10,000 | 二级 | 部门经理（Department Manager） |
| 10,000 - 50,000 | 三级 | 采购经理（Procurement Manager）+ 财务审核 |
| 50,000 - 200,000 | 四级 | VP + 采购总监（Procurement Director） |
| > 200,000 | 五级 | CEO + CFO 联合审批 |

> **特殊审批**：IT设备（> 5,000）需IT部门技术审核；涉及安全/环保品类需EHS审核。

**可交付物**：
- 审批记录（谁在什么时间做了什么决定）
- 电子签名与审批意见
- 审批时效统计报表

---

### 3.4 预算管控（Budget Control）

**功能作用**：实时控制各部门、各项目的采购预算，防止超支和预算外采购。

**流程说明**：
1. **购物车阶段**：加入商品时实时显示当前预算余额，超预算商品标红预警
2. **提交审批时**：系统自动冻结（pre-allocate）对应预算额度
3. **审批通过时**：预算从预占转为正式占用
4. **PO生成时**：预算确认扣减，不可逆
5. **月末/季末**：生成预算执行报告，推送至各部门负责人

**预算规则**：
```
部门年度预算 → 季度分配 → 月度可用额度
   ↓              ↓            ↓
  总额控制      弹性调整     滚动可用
```

- 预算超支 80% 时触发黄色预警
- 预算超支 95% 时触发红色预警，采购申请自动冻结
- 预算追加需走专项审批流程
- 跨部门/跨项目预算调拨需双方部门负责人+财务审批

**可交付物**：
- 预算看板（实时余额、执行率、趋势图）
- 超支预警通知
- 预算执行月报/季报

---

### 3.5 订单管理（Order Management）

**功能作用**：审批通过后自动生成采购订单（Purchase Order, PO），发送给供应商执行。

**流程说明**：
1. PR审批完成后，系统根据商品供应商信息自动生成PO
2. PO通过EDI/API/供应商门户推送给对应供应商
3. 供应商确认PO、承诺交期，系统更新订单状态
4. 供应商发货后推送物流信息，员工可在商城追踪物流状态

**订单状态机**：
```
待确认 → 已确认 → 已发货 → 运输中 → 已送达 → 已签收 → 已完成
                          ↘ 部分签收 → 待尾货 → 已完成
                ↘ 供应商拒绝 → 重新分配供应商
         ↘ 超时未确认 → 自动催单 / 取消
```

**可交付物**：
- 采购订单（PO，含电子签章）
- 发货通知与物流追踪
- 收货确认单（Goods Receipt Note, GRN）

---

### 3.6 供应商管理（Supplier Management）

**功能作用**：管理入驻商城的供应商全生命周期，确保供应商质量与服务水平。

**准入规则**：
- 资质审核：营业执照、行业资质、ISO认证
- 保证金：根据品类缴纳5,000 - 50,000元保证金
- 服务协议：签署平台服务协议、退换货政策、SLA承诺
- 商品审核：首批商品上架前的样品/资质审查
- 系统对接：完成API/EDI技术对接或使用供应商门户

**绩效考核（Quarterly Scorecard）**：

| 考核维度 | 权重 | 指标 | 达标线 |
|---------|------|------|-------|
| 准时交付率 | 30% | 按承诺交期发货的比例 | >= 95% |
| 质量合格率 | 25% | 收货检验合格比例 | >= 98% |
| 响应速度 | 20% | PO确认时效、客诉响应时效 | <= 24h |
| 价格竞争力 | 15% | 同品类价格排名 | Top 30% |
| 服务满意度 | 10% | 员工评价平均分 | >= 4.0/5.0 |

- 连续2个季度不达标：黄牌警告，限制新品上架
- 连续3个季度不达标：红牌清退，冻结账户，清算保证金

**可交付物**：
- 供应商档案（基本信息、资质、合同、历史绩效）
- 季度绩效报告
- 供应商黑名单/白名单

---

### 3.7 发票与付款（Invoice & Payment）

**功能作用**：发票自动识别、三单匹配（PO-GRN-Invoice）自动对账，减少人工核对。

**流程说明**：
1. 供应商开具电子发票或扫描上传纸质发票
2. 系统通过OCR识别发票关键信息（金额、税号、商品明细）
3. 系统自动匹配对应的PO和GRN，验证三单一致性
4. 匹配成功：自动生成付款申请，推送至财务审核
5. 匹配失败：标记异常，人工介入处理（价格差异/数量差异/税率差异）
6. 财务审核通过后，按付款账期执行付款（月结30天/60天/90天）

**付款条件矩阵**：

| 供应商等级 | 付款账期 | 付款方式 | 现金折扣 |
|-----------|---------|---------|---------|
| 战略供应商 | 月结60天 | 银行转账 | 2/10 net 60 |
| 核心供应商 | 月结45天 | 银行转账 | 1/10 net 45 |
| 一般供应商 | 月结30天 | 银行转账 | - |
| 新供应商 | 预付/货到付款 | 现金/转账 | - |

**可交付物**：
- 三单匹配对账报告
- 异常发票处理记录
- 付款指令与执行记录

---

### 3.8 数据分析（Spend Analytics）

**功能作用**：采购支出全维度可视化分析，支持品类优化、供应商整合、合规审计。

**分析维度**：
- **按部门**：各部门采购支出排名、预算执行率、人均采购额
- **按品类**：各品类支出占比、价格趋势、集中度分析（HHI指数）
- **按供应商**：供应商份额分布、绩效关联分析、集中采购潜力
- **按时间**：月度/季度/年度支出趋势、季节性波动、同比环比
- **按合规**：目录外采购率、审批违规率、紧急采购占比

**核心报表**：
1. **支出总览仪表盘**（Spend Dashboard）：实时支出、预算余量、关键指标
2. **品类分析报告**（Category Analysis）：品类支出结构、节约机会
3. **供应商绩效报告**（Supplier Scorecard）：综合评分、改善建议
4. **合规审计报告**（Compliance Report）：违规明细、整改跟踪
5. **节约分析报告**（Savings Report）：价格节约、流程节约、需求优化

**可交付物**：
- 支出分析仪表盘
- 品类优化建议报告
- 供应商整合方案
- 合规审计报告

## 五、系统架构

| 模块 | 功能 | 集成系统 | 技术要点 |
|------|------|---------|---------|
| **采购商城前端** | 商品浏览、搜索、购物车、下单 | 移动端APP / PC Web / 企业微信小程序 | 响应式设计，支持移动端审批 |
| **商品中心** | 商品主数据管理、品类树、价格引擎 | PIM系统、供应商ERP | 支持SPU/SKU两级管理，实时价格同步 |
| **订单中心** | PR/PO全生命周期管理 | ERP（SAP/Oracle）、WMS | 状态机驱动，支持部分交付 |
| **审批中心** | 可配置审批流引擎 | OA系统、企业微信/飞书/钉钉 | 支持串行/并行/会签/或签 |
| **预算中心** | 预算编制、分配、控制、分析 | 财务系统（FMS）、预算管理系统 | 实时预算校验，毫秒级响应 |
| **供应商门户** | 供应商自助管理商品、订单、发票 | 供应商内部系统、EDI | 多租户架构，权限隔离 |
| **财务结算** | 三单匹配、付款管理、税务合规 | ERP财务模块、银行系统 | 支持多种付款方式与账期 |
| **数据分析** | 支出分析、合规报表、预测 | BI工具（Power BI/Tableau）、数据仓库 | 实时+T+1混合计算 |

## 六、实施路线图（Implementation Roadmap）

间接采购商城的建设通常分三期推进：

### 第一期：基础商城上线（MVP, 3-4个月）

- 核心品类上线（办公用品、IT外设、MRO标准件）
- 基础审批流配置（金额驱动的3级审批）
- 供应商门户1.0（商品维护、订单确认）
- 移动端H5适配
- 预算基础管控（部门维度月度预算）

### 第二期：体验优化与扩展（3-4个月）

- 扩展品类（市场物料、差旅服务、福劳保）
- 智能推荐与比价功能
- 审批流引擎升级（支持会签、或签、条件分支）
- 三单匹配自动化
- 供应商绩效考核体系
- BI数据分析仪表盘

### 第三期：深度集成与智能化（3-4个月）

- 与ERP深度集成（实时库存、财务凭证自动生成）
- AI智能推荐（基于历史采购数据推荐商品与供应商）
- 电子签章与合同管理
- 跨BU多组织采购协同
- 供应商协同平台（VMI、自动补货）
- RPA辅助对账与付款

## 七、规则边界

| 规则类型 | 具体规则 | 触发条件 | 处理方式 |
|---------|---------|---------|---------|
| **审批阈值** | 金额>=50,000需采购经理审批 | PR提交时 | 自动路由至对应审批链 |
| **预算冻结** | 提交PR时预占预算额度 | PR提交时 | 预算余额实时扣减预占 |
| **预算超限** | 超出部门月度预算95% | 加入购物车/提交PR | 阻断采购，需预算追加审批 |
| **目录合规** | 非目录商品禁止自助采购 | 搜索/加购时 | 提示走专项采购流程 |
| **供应商资质** | 资质过期商品自动下架 | 每日定时检查 | 商品标记"暂停销售" |
| **价格保护** | 价格变更需提前7天通知 | 供应商调价时 | 旧价格有效期内可正常下单 |
| **限购规则** | IT设备每人每年限1台笔记本 | 加购时校验 | 超限需IT部门特批 |
| **紧急采购** | 紧急PR可跳过一级审批 | 标记"紧急"提交时 | 仍需部门经理及以上审批 |
| **退货时效** | 收货后7天内可申请退货 | 收货确认后 | 供应商确认退货，触发退款 |
| **付款账期** | 按供应商等级执行不同账期 | 发票三单匹配通过后 | 财务按账期排程付款 |

## 九、KPI 体系

| 指标 | 公式 | 目标值 | 统计周期 |
|------|------|-------|---------|
| **订单周期时间** | PR提交 → PO发送的平均时长 | <= 2小时（常规） / <= 30分钟（紧急） | 月度 |
| **审批时效** | PR提交 → 最终审批完成的平均时长 | <= 4小时（一级） / <= 24小时（三级） | 月度 |
| **目录采购率** | 目录内采购金额 / 总间接采购金额 | >= 85% | 月度 |
| **预算执行率** | 实际采购支出 / 预算总额 | 85% - 95%（避免不足与超支） | 季度 |
| **成本节约率** | (基准价-实际价) / 基准价 x 采购量 | >= 5% 年度节约 | 年度 |
| **供应商准时交付率** | 准时交付订单数 / 总订单数 | >= 95% | 月度 |
| **质量合格率** | 合格收货数量 / 总收货数量 | >= 98% | 月度 |
| **三单匹配成功率** | 自动匹配成功发票数 / 总发票数 | >= 90% | 月度 |
| **员工满意度** | 采购商城NPS评分 | >= 4.0 / 5.0 | 半年度 |
| **合规采购率** | 合规采购交易数 / 总交易数 | >= 95% | 月度 |
| **紧急采购占比** | 紧急PR数量 / 总PR数量 | <= 10% | 月度 |
| **供应商集中度** | Top 5供应商采购额 / 总采购额 | 持续优化（HHI < 0.25） | 季度 |

## 十、与直接采购的协同

间接采购并非孤立运作，与直接采购及整条E2E供应链存在多处协同节点：

```
                    ┌──────────────────────────────────────┐
                    │         企业采购支出总盘子              │
                    │   (Total Procurement Spend)          │
                    └──────────┬───────────────────────────┘
                               │
              ┌────────────────┼────────────────┐
              ▼                                  ▼
     ┌────────────────┐                ┌────────────────┐
     │   直接采购      │                │   间接采购      │
     │ (生产性物料)    │                │ (非生产性物资)  │
     └───────┬────────┘                └───────┬────────┘
             │                                  │
             │    ┌─────────────────────┐       │
             ├───▶│   共享供应商池       │◀──────┤
             │    │ (如：IT设备供应商)   │       │
             │    └─────────────────────┘       │
             │                                  │
             │    ┌─────────────────────┐       │
             ├───▶│   共享财务结算      │◀──────┤
             │    │ (ERP财务模块)       │       │
             │    └─────────────────────┘       │
             │                                  │
             │    ┌─────────────────────┐       │
             └───▶│   共享预算体系      │◀──────┘
                  │ (企业总预算管控)     │
                  └─────────────────────┘
```

**协同要点**：
1. **供应商协同**：部分供应商同时服务于直接采购（如MRO物料）和间接采购（办公用品），统一供应商管理降低管理成本
2. **财务协同**：间接采购订单与直接采购订单共享ERP财务模块，统一付款与记账
3. **预算协同**：间接采购预算纳入企业全面预算管理体系，与直接采购预算统一编制、分级管控
4. **数据协同**：间接采购支出数据纳入企业采购大数据平台，支撑全局品类分析与战略采购决策
5. **流程协同**：紧急生产物料可通过间接采购商城快速下单（如实验室试剂、维修工具），缩短响应时间
