# 冲压工艺

> 💡 冲压是汽车制造的第一道工序，将钢板/铝板成型为车身覆盖件和结构件。精度、节拍和模具管理是核心。

---

## 一、工艺概述

### 1.1 冲压在整车制造中的位置

```
原材料（钢板/铝板）
      ↓
   冲压成型 ──→ 覆盖件（车门外板、翼子板、引擎盖）
      ↓         结构件（纵梁、横梁、加强板）
   焊接拼装
```

### 1.2 核心参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 冲压件占车身重量 | 60-70% | 其余为铸件、塑料件 |
| 单车冲压件数 | 300-500 件 | 覆盖件+结构件 |
| 生产节拍 | 3-5 SPM（次/分钟） | 高速冲压线 |
| 尺寸精度 | ±0.5mm | 外覆盖件要求更高 |
| 模具寿命 | 50-100 万次 | 需定期维护 |
| 材料利用率 | 55-65% | 优化排样可提升至 70% |

---

## 二、工序流程

### 2.1 典型冲压工序

| 工序 | 说明 | 关键参数 |
|------|------|---------|
| **落料** | 从板材切割毛坯 | 排样优化影响材料利用率 |
| **拉延** | 主要成型工序，将平板变成立体形状 | 压边力、拉延筋、润滑 |
| **修边** | 切除多余材料 | 精度 ±0.3mm |
| **整形** | 修正形状偏差 | 回弹补偿 |
| **冲孔** | 加工安装孔、工艺孔 | 孔位精度 ±0.2mm |
| **翻边** | 边缘折弯成型 | 翻边角度、高度 |

### 2.2 典型零件工艺路线

**车门外板（4 工序）**：
```
落料 → 拉延 → 修边+冲孔 → 翻边+整形
```

**纵梁（5 工序）**：
```
落料 → 拉延 → 修边 → 冲孔 → 整形+翻边
```

## 三、关键设备

### 3.1 冲压设备类型

| 设备类型 | 吨位 | 节拍 | 特点 | 应用 |
|---------|------|------|------|------|
| **机械压力机** | 800-5,000T | 6-8 SPM | 成本低、维护简单 | 中低端车型 |
| **伺服压力机** | 800-5,000T | 3-6 SPM | 可编程曲线、节能30% | 高端车型主流 |
| **液压机** | 1,000-10,000T | 1-3 SPM | 深拉延、复杂件 | 大型覆盖件 |
| **多工位压力机** | 2,000-6,000T | 10-25 SPM | 集成多工序、效率最高 | 高产量产线 |
| **级进模冲压** | 200-1,000T | 15-30 SPM | 小件连续冲压 | 小型结构件 |

### 3.2 伺服压力机 vs 传统机械压力机

| 维度 | 机械压力机 | 伺服压力机 |
|------|----------|-----------|
| 滑块运动 | 固定正弦曲线 | 可编程任意曲线 |
| 能耗 | 基准 | 节能 20-30% |
| 噪音 | 较高 | 降低 10-15dB |
| 模具寿命 | 基准 | 延长 20-30% |
| 成本 | 基准 | 高 30-50% |
| 柔性 | 低 | 高（一机多用） |
| 趋势 | 逐步淘汰 | 主流方向 |

## 四、模具管理

### 4.1 模具开发流程

```
产品数据 → 工艺分析 → 模具设计 → 模具制造 → 调试验证 → 量产使用
  (0月)     (1月)      (2-3月)    (4-6月)     (7-8月)     (9月+)
```

| 阶段 | 周期 | 关键活动 |
|------|------|---------|
| 工艺分析 | 2-4 周 | CAE 仿真（AutoForm）、回弹分析 |
| 模具设计 | 4-8 周 | 3D 设计、结构强度校核 |
| 模具制造 | 12-20 周 | CNC 加工、热处理、研配 |
| 调试验证 | 4-8 周 | 出件检查、尺寸匹配、PPAP |

### 4.2 模具关键指标

| 指标 | 要求 | 说明 |
|------|------|------|
| 型面精度 | ±0.05mm | CNC 加工保证 |
| 冲次寿命 | 50-100 万次 | 需定期刃磨 |
| 模具材料 | Cr12MoV / SKD11 | 硬度 HRC 58-62 |
| 模具成本 | 300-2,000 万/套 | 大型覆盖件模具最贵 |

### 4.3 模具管理挑战

| 挑战 | 影响 | 应对 |
|------|------|------|
| 模具磨损 | 件精度下降 | 定期维护、刃磨、补焊 |
| 多车型共线 | 换模时间长 | 快速换模系统（SMED） |
| 模具投资大 | 新车型成本高 | 平台化、模具共享 |
| 回弹控制 | 铝合金件回弹大 | CAE 补偿、试模修正 |

## 五、新材料与趋势

### 5.1 轻量化材料应用

| 材料 | 密度（g/cm³） | 应用部位 | 冲压特点 |
|------|--------------|---------|---------|
| 普通钢板 | 7.85 | 结构件 | 传统工艺 |
| 高强钢（AHSS） | 7.85 | A/B柱、门槛 | 回弹大、模具磨损快 |
| 超高强钢（UHSS） | 7.85 | 防撞梁、座椅骨架 | 热成型为主 |
| 铝合金 | 2.7 | 引擎盖、车门、翼子板 | 回弹大、表面要求高 |
| 碳纤维 | 1.6 | 高端车型覆盖件 | 非冲压工艺（RTM） |

### 5.2 一体化压铸（Mega Casting）

| 维度 | 传统冲压焊接 | 一体化压铸 |
|------|------------|-----------|
| 零件数 | 70-100 件 | 1-2 件 |
| 工序 | 冲压→焊接→涂胶 | 一次压铸成型 |
| 重量 | 基准 | 减重 10-20% |
| 投资 | 分散 | 压铸机 6,000-12,000T |
| 代表 | 传统车企 | Tesla（后地板）、小鹏 |
| 维修性 | 可局部更换 | 整体更换、成本高 |

## 六、产能与效率

### 6.1 冲压线产能计算

```
产能 = 节拍(SPM) × 60 × 工作时间(h) × 设备利用率(OEE)

示例：5 SPM × 60 × 8h × 85% = 2,040 件/班
      一条线 2 班 = 4,080 件/天
      年产能（250天）= 102 万件/年
```

### 6.2 效率提升方向

| 方向 | 措施 | 效果 |
|------|------|------|
| 减少换模时间 | SMED 快速换模 | 换模 10min→3min |
| 提高材料利用率 | 优化排样、套裁 | 利用率 +5-10% |
| 预测性维护 | 振动监测、AI 预测 | 停机减少 30% |
| 数字化 | MES + 数字孪生 | OEE 提升 5-10% |
