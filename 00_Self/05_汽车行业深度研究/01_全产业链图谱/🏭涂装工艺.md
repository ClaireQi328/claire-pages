# 涂装工艺

> 💡 涂装是汽车制造中投资最大、环保要求最严、自动化率最高的工序。它决定了车身的防腐性能和外观品质。

---

## 一、工艺概述

### 1.1 涂装的功能

| 功能 | 说明 |
|------|------|
| **防腐** | 保护车身钢板 10-15 年不锈蚀 |
| **外观** | 颜色、光泽、平整度决定视觉品质 |
| **标识** | 品牌色、个性化颜色 |
| **功能** | 隔音、隔热、抗石击 |

### 1.2 核心参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 涂装线投资 | 10-20 亿元 | 占整车工厂投资 30-35% |
| 涂层总厚度 | 100-150μm | 5-7 层 |
| 色彩种类 | 10-30 种/工厂 | 越多柔性化要求越高 |
| 生产节拍 | 60 JPH | 与焊装/总装匹配 |
| 能耗占比 | 60-70% | 工厂总能耗的最大部分 |
| VOC 排放 | 法规严格限制 | 水性漆是趋势 |
| 自动化率 | 95%+ | 机器人喷涂为主 |

---

## 二、工艺流程

### 2.1 全流程

```
白车身进入
    ↓
┌─────────────────────────────────────────────────┐
│ 1. 前处理（Pre-treatment）                       │
│    脱脂 → 水洗 → 表调 → 磷化/硅烷 → 水洗        │
│    目的：清洁+化学转化膜                          │
├─────────────────────────────────────────────────┤
│ 2. 电泳（Electrodeposition / ED）                │
│    阴极电泳（CED）→ 超滤水洗 → 烘干              │
│    目的：内腔防腐（最关键的防腐层）                │
│    膜厚：18-25μm                                 │
├─────────────────────────────────────────────────┤
│ 3. 密封胶+PVC 底涂                               │
│    车底 PVC 防石击涂层 + 焊缝密封胶               │
│    目的：隔音、防石击、防水                        │
├─────────────────────────────────────────────────┤
│ 4. 中涂（Primer Surfacer）— 部分工艺已取消        │
│    中涂喷涂 → 烘干                               │
│    目的：填充、遮盖、过渡层                        │
│    膜厚：30-40μm                                 │
├─────────────────────────────────────────────────┤
│ 5. 面漆（Basecoat）                              │
│    色漆喷涂 → 闪干                               │
│    目的：颜色+效果（金属漆、珠光漆）                │
│    膜厚：12-20μm                                 │
├─────────────────────────────────────────────────┤
│ 6. 清漆（Clearcoat）                             │
│    清漆喷涂 → 烘干                               │
│    目的：保护+光泽+耐候                            │
│    膜厚：35-50μm                                 │
├─────────────────────────────────────────────────┤
│ 7. 检查+修饰                                     │
│    外观检查 → 抛光修饰 → 合格下线                  │
└─────────────────────────────────────────────────┘
    ↓
涂装完成车身 → 总装
```

### 2.2 各工序详解

| 工序 | 时间 | 温度 | 关键控制点 |
|------|------|------|-----------|
| 前处理 | 15-20 min | 常温-60°C | 脱脂效果、磷化膜质量 |
| 电泳 | 3-5 min | 28-32°C | 电压、时间、膜厚均匀性 |
| 密封/PVC | 10-15 min | 常温 | 胶条连续性、厚度 |
| 中涂 | 5-8 min | 140-160°C | 膜厚、外观 |
| 面漆 | 3-5 min | 常温-80°C | 颜色一致性、膜厚 |
| 清漆 | 3-5 min | 140-160°C | 光泽度、硬度 |

## 三、关键设备

### 3.1 涂装核心设备

| 设备 | 功能 | 主要供应商 | 投资占比 |
|------|------|-----------|---------|
| 前处理设备 | 化学处理 | Dürr、大气 | 8-10% |
| 电泳槽 | 阴极电泳 | PPG、巴斯夫 | 10-15% |
| 喷涂机器人 | 静电喷涂 | ABB、杜尔、发那科 | 20-25% |
| 烘干炉 | 涂层固化 | Dürr、Eisenmann | 15-20% |
| 空调系统 | 温湿度控制 | 大气、杜尔 | 10-12% |
| 废气处理 | VOC 处理 | Dürr、CECO | 8-10% |

### 3.2 喷涂技术对比

| 技术 | 原理 | 上漆率 | 特点 |
|------|------|--------|------|
| 空气喷涂 | 压缩空气雾化 | 30-40% | 成本低、浪费大 |
| 静电旋杯 | 高速旋杯+静电吸附 | 85-95% | 主流、高效 |
| 静电喷枪 | 静电吸附 | 60-75% | 补喷用 |
| IPP（集成工艺） | 内喷+外喷一体 | 90%+ | 最新趋势 |

## 四、环保法规与应对

### 4.1 VOC 排放法规

| 地区 | 法规 | VOC 限值 | 趋势 |
|------|------|---------|------|
| 中国 | GB 24409-2020 | 35g/m²（乘用车） | 2025 年加严 |
| 欧盟 | IPPC 指令 | 45g/m² | 持续加严 |
| 美国 | EPA NESHAP | 1.44kg/L（涂料） | 最严格 |

### 4.2 水性漆 vs 溶剂型漆

| 维度 | 溶剂型漆 | 水性漆 |
|------|---------|--------|
| VOC 含量 | 60-70% | 10-15% |
| 干燥方式 | 自然/烘干 | 强制闪干+烘干 |
| 设备要求 | 标准 | 需防锈改造 |
| 成本 | 基准 | 高 15-25% |
| 外观 | 好 | 略差（在改善） |
| 趋势 | 逐步淘汰 | 主流方向 |

### 4.3 环保技术趋势

| 技术 | 说明 | 成熟度 |
|------|------|--------|
| **水性漆** | 降低 VOC 80%+ | 已成熟 |
| **免中涂工艺** | 取消中涂工序，减少一次烘干 | 已成熟 |
| **干式喷房** | 石灰粉替代水幕处理漆雾 | 推广中 |
| **废气 RTO 处理** | 蓄热式热氧化处理 VOC | 已成熟 |
| **UV 固化涂料** | 紫外光固化，节能 | 研发中 |
| **粉末清漆** | 零 VOC | 试产中 |

## 五、涂装线投资分析

### 5.1 投资构成

| 项目 | 占比 | 金额（亿元） | 说明 |
|------|------|-------------|------|
| 土建 | 20-25% | 2-5 | 涂装车间最复杂 |
| 设备 | 50-60% | 5-12 | 核心投资 |
| 安装 | 10-15% | 1-3 | - |
| 其他 | 5-10% | 0.5-2 | 设计、调试 |
| **合计** | 100% | **10-20** | 30JPH 规模 |

### 5.2 运营成本构成

| 成本项 | 占比 | 优化方向 |
|--------|------|---------|
| 能源（天然气+电） | 35-40% | 热回收、LED、变频 |
| 材料（涂料+辅料） | 25-30% | 提高上漆率 |
| 人工 | 10-15% | 提高自动化 |
| 环保处理 | 10-15% | 干式喷房、RTO |
| 维护 | 5-10% | 预防性维护 |

## 六、行业趋势

### 6.1 技术趋势

| 趋势 | 说明 | 影响 |
|------|------|------|
| 免中涂工艺 | B1B2 工艺取消中涂 | 投资降 15%、能耗降 20% |
| 水性漆全面推广 | VOC 排放大幅降低 | 设备改造成本 |
| 个性化颜色 | 小批量多色柔性化 | 换色效率要求高 |
| 数字化涂装 | 膜厚在线监测、AI 调参 | 质量一致性提升 |
| 干式喷房 | 无废水排放 | 节水 90%+ |

### 6.2 新能源对涂装的影响

| 变化 | 说明 |
|------|------|
| 电池包涂装 | 新增电池包防腐涂装工序 |
| 铝合金车身 | 铝件前处理工艺不同 |
| 一体化压铸 | 压铸件涂装工艺需重新开发 |
| 轻量化 | 新材料的涂装适配性 |
