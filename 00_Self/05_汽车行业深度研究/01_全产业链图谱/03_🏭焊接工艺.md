# 焊接工艺

> 💡 焊接（焊装）是将冲压件拼装为白车身的核心工序。一辆车有 4,000-6,000 个焊点，自动化率 95%+，是精度和效率的极致体现。

---

## 一、工艺概述

### 1.1 焊装在整车制造中的位置

```
冲压件（车身板件）
      ↓
   焊装拼装 ──→ 白车身（Body-in-White, BIW）
      ↓         4,000-6,000 个焊点
   涂装
```

### 1.2 核心参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 白车身焊点数 | 4,000-6,000 个 | 轿车 4,000+，SUV 5,000+ |
| 焊接机器人 | 300-500 台/工厂 | 60 JPH 产能 |
| 焊装线投资 | 5-10 亿元 | 占整车工厂 20-25% |
| 生产节拍 | 60 JPH | 即 1 台/分钟 |
| 白车身精度 | ±1.5mm（关键尺寸） | 整车匹配的关键 |
| 自动化率 | 95%+ | 仅少量补焊人工 |
| 工位数 | 80-150 个 | 视车型复杂度 |

## 二、焊接技术

### 2.1 主要焊接方法

| 方法 | 原理 | 占比 | 应用部位 | 特点 |
|------|------|------|---------|------|
| **电阻点焊** | 电流通过产生热量 | 80-85% | 车身主体连接 | 最主流、成本低 |
| **弧焊（MIG/MAG）** | 电弧熔化焊丝 | 8-10% | 厚板、结构件 | 强度高 |
| **激光焊** | 高能量密度激光 | 3-5% | 车顶、侧围 | 美观、强度高 |
| **FDS（流钻螺钉）** | 螺钉自钻自攻 | 2-3% | 钢铝混合车身 | 连接异种材料 |
| **SPR（自冲铆接）** | 铆钉穿透连接 | 1-2% | 铝合金车身 | 无热输入 |
| **涂胶（结构胶）** | 环氧树脂胶 | 辅助 | 配合焊接 | 提高刚性、密封 |

### 2.2 电阻点焊详解

**原理**：
```
电极压力 → 通电 → 电阻热 → 熔核形成 → 断电保压 → 焊点完成

参数：
- 电流：8,000-15,000A
- 时间：0.1-0.3s
- 压力：3-5kN
- 熔核直径：5-8mm
```

**点焊质量控制**：

| 控制维度 | 方法 | 说明 |
|---------|------|------|
| 焊接电流 | 恒流控制 | 实时监测+反馈 |
| 电极磨损 | 自动修磨 | 每 200-500 点修磨一次 |
| 焊点检测 | 超声波检测 | 在线/离线抽检 |
| 焊点强度 | 剪切试验 | 破坏性检测 |

### 2.3 激光焊 vs 点焊

| 维度 | 电阻点焊 | 激光焊 |
|------|---------|--------|
| 速度 | 3-5s/点 | 1-3m/min |
| 变形 | 较大 | 极小 |
| 外观 | 有焊点痕迹 | 连续焊缝、美观 |
| 强度 | 良好 | 优秀 |
| 成本 | 低 | 高 3-5 倍 |
| 适用 | 车身主体 | 车顶、侧围外观件 |

## 三、白车身（BIW）

### 3.1 白车身结构

```
白车身（BIW）组成：

├── 下车身（Underbody）
│   ├── 前地板
│   ├── 后地板
│   └── 门槛/纵梁
├── 上车身（Body side）
│   ├── 左侧围
│   ├── 右侧围
│   └── 车顶
├── 前部（Front body）
│   ├── 前围板
│   ├── 前纵梁
│   └── 翼子板安装点
└── 后部（Rear body）
    ├── 后围板
    └── 行李箱盖安装点
```

### 3.2 白车身精度要求

| 部位 | 精度要求 | 影响 |
|------|---------|------|
| 门洞尺寸 | ±1.5mm | 车门装配间隙 |
| 窗框尺寸 | ±1.0mm | 玻璃密封 |
| 发动机舱 | ±1.5mm | 动力总成装配 |
| 底盘安装点 | ±1.0mm | 四轮定位 |
| 外观面 | ±0.5mm | 间隙面差 |

## 四、焊装线布局

### 4.1 典型焊装线结构

```
主焊线（Main Line）
├── 底板拼装工位（UB Line）
├── 侧围拼装工位（Side Panel Line）
├── 车顶拼装工位（Roof Line）
├── 调整工位（Re-station）
└── 检测工位（Quality Gate）

分总成线（Sub Line）
├── 前地板总成
├── 后地板总成
├── 前围板总成
├── 左/右侧围总成
└── 车门总成
```

### 4.2 柔性化焊装线

| 维度 | 刚性线 | 柔性线 |
|------|--------|--------|
| 车型数量 | 1-2 种 | 4-8 种 |
| 切换方式 | 人工换夹具 | 自动切换/机器人 |
| 投资 | 基准 | 高 30-50% |
| 效率 | 高 | 略低（切换时间） |
| 趋势 | 淘汰中 | 主流 |

**柔性化关键技术**：
- **可切换夹具**：伺服驱动，不同车型不同程序
- **Open Gate**：独立工位，可并行生产
- **AGV 搬运**：柔性输送，不依赖固定轨道

## 五、质量控制

### 5.1 焊装质量检测体系

| 层级 | 方法 | 频率 | 说明 |
|------|------|------|------|
| 在线监测 | 焊接参数监控 | 每个焊点 | 电流/电压/时间 |
| 在线检测 | 激光视觉检测 | 关键尺寸 | 实时反馈 |
| 抽检 | 超声波焊点检测 | 1-5% | 焊点质量 |
| 三坐标测量 | CMM | 每班 1-2 台 | 整车尺寸精度 |
| 破坏性检测 | 凿检/撕裂 | 每班 | 焊点强度验证 |

### 5.2 常见焊接缺陷

| 缺陷 | 原因 | 影响 | 应对 |
|------|------|------|------|
| 虚焊 | 电流不足、电极磨损 | 强度不足 | 参数监控、定期修磨 |
| 飞溅 | 电流过大、表面脏污 | 外观+强度 | 清洁、参数优化 |
| 烧穿 | 板材太薄、电流过大 | 密封性 | 参数调整 |
| 变形 | 热输入不均 | 尺寸偏差 | 工艺优化、夹具补偿 |

## 六、行业趋势

### 6.1 技术趋势

| 趋势 | 说明 | 影响 |
|------|------|------|
| **激光焊扩大应用** | 车顶、侧围激光钎焊 | 外观品质提升 |
| **钢铝混合车身** | 铝合金+高强钢混合 | 新连接技术需求 |
| **一体化压铸冲击** | 减少焊点数量 | 焊装线简化 |
| **数字孪生** | 虚拟调试、在线监控 | 效率提升 |
| **协作机器人** | 人机协作补焊 | 柔性化 |

### 6.2 新能源对焊装的影响

| 变化 | 说明 |
|------|------|
| 电池包焊接 | 新增电池包壳体焊接工序 |
| 电机壳体焊接 | 铝合金壳体搅拌摩擦焊 |
| 一体压铸集成 | 后地板/前地板压铸，减少焊接 |
| 轻量化连接 | 铝点焊、SPR、FDS 需求增加 |
