# 总装工艺

> 💡 总装是汽车制造的最后一道工序，也是最复杂、自动化率最低的环节。2 万+ 零部件在这里集成，决定了最终产品的质量和交付效率。

---

## 一、工艺概述

### 1.1 总装在整车制造中的位置

```
涂装完成车身
      ↓
   总装集成 ──→ 整车下线
      ↓         2万+ 零部件
   检测/路试 → 入库/发运
```

### 1.2 核心参数

| 参数 | 典型值 | 说明 |
|------|--------|------|
| 总装零部件数 | 20,000-30,000 件 | 单车装配 |
| 总装线工位 | 150-250 个 | 60 JPH 产能 |
| 生产节拍 | 60 JPH | 1 台/分钟 |
| 工人数量 | 800-1,500 人 | 工厂最大用工环节 |
| 自动化率 | 60-70% | 四大工艺中最低 |
| 总装线长度 | 2-4 km | 主线+分装线 |
| 总装投资 | 8-15 亿元 | 占整车工厂 25-30% |

## 二、工艺流程

### 2.1 总装全流程

```
涂装车身进入
    ↓
┌─────────────────────────────────────────────────┐
│ 1. 内饰装配（Trim Line）                         │
│    仪表板 → 地毯 → 线束 → 顶棚 → A/B/C柱饰板     │
│    → 座椅 → 安全带 → 门板内饰                     │
├─────────────────────────────────────────────────┤
│ 2. 底盘合装（Chassis Marriage）                   │
│    前副车架+发动机+变速箱 → 后副车架+悬挂          │
│    → 排气系统 → 燃油系统                          │
│    ★ 底盘与车身合装（关键工位）                    │
├─────────────────────────────────────────────────┤
│ 3. 外饰装配（Final Line）                        │
│    前后保险杠 → 车灯 → 车门调整 → 挡风玻璃         │
│    → 轮胎 → 装饰条 → 充电口盖                     │
├─────────────────────────────────────────────────┤
│ 4. 液体加注（Fluid Fill）                        │
│    冷却液 → 制动液 → 空调冷媒 → 洗涤液            │
│    → 燃油/充电                                    │
├─────────────────────────────────────────────────┤
│ 5. 检测与测试（Quality Gate）                     │
│    四轮定位 → 灯光检测 → 淋雨试验 → 路试          │
│    → 外观检查 → 电器功能检测                      │
└─────────────────────────────────────────────────┘
    ↓
整车下线 → 入库 → 发运
```

### 2.2 各工序详解

| 工序 | 工位数 | 工时（分钟） | 关键点 |
|------|--------|------------|--------|
| 内饰装配 | 60-80 | 40-60 | 线束布线最复杂 |
| 底盘合装 | 20-30 | 15-20 | 精度要求最高 |
| 外饰装配 | 40-60 | 30-40 | 间隙面差控制 |
| 液体加注 | 10-15 | 8-12 | 定量精确 |
| 检测测试 | 20-30 | 15-25 | 零缺陷出货 |

## 三、关键工序详解

### 3.1 底盘合装（Marriage）

**概念**：将底盘总成（含动力总成、悬挂、副车架）与车身合装，是总装最关键、精度要求最高的工序。

```
          车身（从涂装来）
              ↓
    ┌─────────────────────┐
    │    Marriage 工位      │
    │                       │
    │  车身  ←  ─  →  底盘  │
    │      ↑ 合装 ↑        │
    │    螺栓拧紧           │
    └─────────────────────┘
              ↓
    合装完成的整车
```

| 维度 | 要求 |
|------|------|
| 定位精度 | ±1.0mm |
| 拧紧扭矩 | 精度 ±3%（安全件） |
| 合装方式 | 举升式/滑撬式/AGV |
| 节拍 | 60-90s |

### 3.2 线束装配

线束是总装最复杂的零部件之一——单根线束长 3-5km，重 30-60kg。

| 维度 | 说明 |
|------|------|
| 线束长度 | 3,000-5,000m/车 |
| 连接器数 | 200-400 个 |
| 装配工时 | 占总装工时 15-20% |
| 主要供应商 | 安波福、矢崎、住友、莱尼 |
| 趋势 | 域控架构减少线束量 |

### 3.3 拧紧控制

| 等级 | 扭矩精度 | 应用 | 拧紧工具 |
|------|---------|------|---------|
| A 级（安全件） | ±3% | 底盘螺栓、座椅安装 | 伺服电动拧紧枪 |
| B 级（重要件） | ±5% | 发动机悬置、排气 | 伺服电动拧紧枪 |
| C 级（一般件） | ±10% | 内饰件、护板 | 气动扳手 |

**拧紧数据管理**：每个安全件的扭矩值实时上传 MES，实现 100% 可追溯。

## 四、柔性化与多车型共线

### 4.1 柔性化策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **JIS 配送** | 按顺序配送零件 | 内饰件（颜色、配置） |
| **RFID 识别** | 车身携带配置信息 | 自动切换工具参数 |
| **可变工装** | 伺服工装自动调整 | 多车型合装 |
| **AGV 搬运** | 柔性输送 | 替代传统输送线 |
| **模块化分装** | 预装模块化供货 | 座椅、仪表板 |

### 4.2 JIT/JIS 配送

```
供应商（JIS 排序）
      ↓
  排序零件送达总装线旁
      ↓
  按车辆序列取件装配
      ↓
  与车身配置一一匹配

示例：
- 座椅：按车辆颜色/配置排序送达
- 仪表板：按屏幕尺寸/风格排序送达
- 轮胎：按尺寸/品牌排序送达
```

## 五、检测与质量

### 5.1 整车检测体系

| 检测项 | 方法 | 标准 |
|--------|------|------|
| 四轮定位 | 光学检测 | 前束角、外倾角、主销后倾角 |
| 灯光检测 | 光强/角度 | 法规要求 |
| 淋雨试验 | 模拟暴雨 | 无渗漏 |
| 路试（Roller Test） | 室内转鼓 | 异响、制动、加速 |
| 外观检查 | 人工+AI | 间隙面差、漆面 |
| 电器功能 | 自动检测 | 全部电器功能 100% |
| 尾气排放 | 废气分析 | 法规限值 |

### 5.2 间隙面差标准

| 部位 | 间隙（mm） | 面差（mm） | 说明 |
|------|-----------|-----------|------|
| 车门-车身 | 3.5±1.0 | 0±0.5 | 最关注区域 |
| 引擎盖-翼子板 | 3.5±1.0 | 0±0.5 | 外观件 |
| 尾箱盖-车身 | 3.5±1.0 | 0±0.5 | 外观件 |
| 保险杠-车身 | 3.0±1.5 | 0±1.0 | 非金属件 |

## 六、行业趋势

### 6.1 技术趋势

| 趋势 | 说明 | 影响 |
|------|------|------|
| **模块化供货** | 座椅/仪表板/门板模块化 | 总装工序减少 |
| **AGV 智能物流** | 无人配送车 | 减少线边库存 |
| **数字孪生** | 虚拟调试、实时监控 | 效率提升 |
| **协作机器人** | 人机协作 | 自动化率提升 |
| **AI 视觉检测** | 外观质量 AI 判定 | 检测效率+一致性 |
| **数字工作指导** | AR/电子作业指导书 | 培训效率、质量 |

### 6.2 新能源对总装的影响

| 变化 | 说明 |
|------|------|
| 电池包装配 | 新增高压电池包安装+线束连接 |
| 电机/电控 | 取代发动机/变速箱，装配简化 |
| 充电系统 | 充电口、充电模块装配 |
| 热管理系统 | 电池热管理+空调集成 |
| 高压安全 | 绝缘检测、高压安全规程 |
| 无排气系统 | 简化底盘装配 |

### 6.3 总装效率提升空间

| 方向 | 当前水平 | 目标 | 措施 |
|------|---------|------|------|
| 自动化率 | 60-70% | 80%+ | 协作机器人、AI |
| 一次合格率 | 95-98% | 99%+ | 防错系统、AI 检测 |
| 混线车型数 | 4-6 种 | 8-10 种 | 柔性工装、AGV |
| 单车工时 | 20-30h | 15-20h | 模块化、工艺优化 |
