# 供应链架构与多级协同

> 💡 汽车供应链是分层金字塔结构：OEM → Tier1 → Tier2 → Tier3。理解这个结构，是理解汽车行业的基础。

---

## 一、供应链分层架构

### 1.1 Tier 分层定义

| 层级 | 定义 | 与 OEM 关系 | 典型企业 |
|------|------|-----------|---------|
| **OEM** | 整车制造商 | 直接面向用户 | 丰田、比亚迪、小米 |
| **Tier 1** | 系统/模块供应商 | 直接供货 OEM | 博世、大陆、宁德时代 |
| **Tier 2** | 零部件/子系统供应商 | 供货 Tier1 | 联合电子、均胜电子 |
| **Tier 3** | 原材料/基础件供应商 | 供货 Tier2 | 宝钢、赣锋锂业 |

### 1.2 典型 BOM 结构（以电动车为例）

```
整车（~2万+ 零件）
├── 车身系统（15%）
│   ├── 车身结构件 → Tier1: 麦格纳
│   ├── 车身覆盖件 → Tier1: 本特勒
│   └── 密封条 → Tier1: 库博标准
├── 底盘系统（15%）
│   ├── 悬挂系统 → Tier1: 采埃孚
│   ├── 制动系统 → Tier1: 博世
│   └── 转向系统 → Tier1: 蒂森克虏伯
├── 动力电池系统（35-40%）★ 电动车最大成本
│   ├── 电池包 → Tier1: 宁德时代、比亚迪
│   │   ├── 电芯 → Tier2: 宁德时代、中创新航
│   │   │   ├── 正极材料 → Tier3: 当升科技
│   │   │   ├── 负极材料 → Tier3: 贝特瑞
│   │   │   ├── 电解液 → Tier3: 天赐材料
│   │   │   └── 隔膜 → Tier3: 恩捷股份
│   │   ├── BMS → Tier2: 均胜电子
│   │   └── 电池包壳体 → Tier2: 敏实集团
│   └── 电驱系统 → Tier1: 汇川技术
├── 电子电气架构（15%）
│   ├── 域控制器 → Tier1: 华为、德赛西威
│   ├── 智驾芯片 → Tier2: 英伟达、地平线
│   └── 线束 → Tier1: 安波福、矢崎
├── 内外饰（12%）
│   ├── 仪表板 → Tier1: 延锋
│   ├── 座椅 → Tier1: 安道拓、李尔
│   └── 车灯 → Tier1: 海拉、华域视觉
└── 其他（8%）
    ├── 轮胎 → Tier1: 米其林、普利司通
    └── 玻璃 → Tier1: 福耀玻璃
```

## 二、供应链协同模式

### 2.1 JIT（Just-in-Time）

| 维度 | 说明 |
|------|------|
| **定义** | 在需要的时间，送达需要的量 |
| **目标** | 消除库存浪费 |
| **适用** | 标准件、用量稳定的零件 |
| **要求** | 供应商距离近（<4h）、质量稳定、LT 短 |
| **库存** | 线边 2-4 小时用量 |

### 2.2 JIS（Just-in-Sequence）

| 维度 | 说明 |
|------|------|
| **定义** | 按装配顺序送达 |
| **目标** | 实现混流生产零等待 |
| **适用** | 内饰件（颜色、配置相关） |
| **要求** | 供应商实时获取生产序列 |
| **典型件** | 座椅、仪表板、车门内饰板 |

### 2.3 Milk Run（循环取货）

| 维度 | 说明 |
|------|------|
| **定义** | 物流车按固定路线依次取货 |
| **优势** | 降低运输成本、提高装载率 |
| **路线** | 一般 3-5 家供应商一条路线 |
| **频率** | 每天 2-4 次 |

### 2.4 VMI（供应商管理库存）

| 维度 | 说明 |
|------|------|
| **定义** | 供应商在 OEM 仓库管理库存 |
| **所有权** | 供应商所有，OEM 使用后结算 |
| **适用** | 通用件、标准件 |
| **优势** | OEM 降低库存资金占用 |

## 三、供应商管理

### 3.1 供应商选择流程

```
潜在供应商识别 → 资质审核 → 样品验证 → PPAP → 小批量验证 → 量产
    (1月)         (2月)      (3-6月)   (2-3月)   (3-6月)     (持续)
```

### 3.2 PPAP（生产件批准程序）

| 等级 | 提交内容 | 适用 |
|------|---------|------|
| 等级 1 | 保证书 | 非关键件 |
| 等级 2 | 保证书+样品+有限数据 | 一般件 |
| 等级 3 | 保证书+样品+完整数据（默认） | 大多数零件 |
| 等级 4 | 保证书+样品+完整数据+现场审核 | 安全件 |
| 等级 5 | 保证书+样品+完整数据+现场审核+工艺审核 | 最高要求 |

### 3.3 供应商绩效管理

| 指标 | 权重 | 说明 |
|------|------|------|
| 质量（PPM） | 30-40% | 百万件不良率，目标 <50 PPM |
| 交付（OTD） | 25-30% | 准时交付率，目标 >98% |
| 成本（年降） | 20-25% | 年度降价目标 3-5% |
| 技术（NPI） | 10-15% | 新项目响应速度 |

### 3.4 供应商分级

| 等级 | 标准 | 策略 |
|------|------|------|
| **战略供应商** | 技术领先、份额高 | 联合开发、长期协议 |
| **核心供应商** | 质量稳定、交付可靠 | 优先定点、份额保障 |
| **一般供应商** | 基本满足要求 | 竞争定价、有限份额 |
| **淘汰供应商** | 绩效不达标 | 整改/淘汰 |

## 四、供应链数字化协同

### 4.1 协同平台

| 平台类型 | 功能 | 代表 |
|---------|------|------|
| SRM（供应商关系管理） | 采购流程管理 | SAP Ariba、用友 |
| 供应链可视化 | 订单跟踪、库存可视 | o9 Solutions、蓝幸 |
| EDI（电子数据交换） | 订单/发票自动化 | 标准 EDI 协议 |
| 协同计划 | 需求预测共享 | Kinaxis、Blue Yonder |

### 4.2 数据共享层级

```
Level 1: 订单/发票（EDI）
Level 2: 库存/产能可视
Level 3: 需求预测共享
Level 4: 联合 S&OP
Level 5: 实时数据协同（IoT）
```

## 五、新能源对供应链的冲击

### 5.1 供应链结构变化

| 维度 | 燃油车时代 | 电动车时代 |
|------|----------|-----------|
| **核心供应商** | 发动机/变速箱 Tier1 | 电池/芯片供应商 |
| **BOM 最大项** | 动力总成 25-30% | 电池 35-40% |
| **供应商数量** | 300-500 家 | 200-300 家（简化） |
| **垂直整合** | 低（外包为主） | 高（比亚迪全产业链） |
| **新进入者** | 少 | 华为、小米、百度 |

### 5.2 供应链重心迁移

```
燃油车供应链重心              电动车供应链重心
──────────────────────────────────────────
发动机 Tier1（博世、电装）  →  电池 Tier1（宁德时代、LG）
变速箱 Tier1（采埃孚）      →  电机/电控（汇川、精进）
ECU 芯片（恩智浦）          →  智驾芯片（英伟达、地平线）
排气系统（佛吉亚）          →  热管理系统（三花、银轮）
```
