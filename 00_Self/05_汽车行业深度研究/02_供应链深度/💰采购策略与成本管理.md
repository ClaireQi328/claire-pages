# 采购策略与成本管理

> 💡 采购是汽车供应链管理的核心杠杆——BOM 成本占整车成本 60-75%，采购降本 1% = 净利润增加 5-10%。

---

## 一、采购组织与流程

### 1.1 采购组织架构

```
采购委员会（VP 级）
├── 直接采购（生产材料）
│   ├── 动力总成采购
│   ├── 底盘采购
│   ├── 车身采购
│   ├── 电子电器采购
│   └── 内外饰采购
├── 间接采购（非生产材料）
│   ├── 设备采购
│   ├── IT 采购
│   └── 服务采购
├── 供应商质量管理（SQE）
├── 采购战略
└── 成本工程
```

### 1.2 寻源定点流程

```
产品定义 → 供应商识别 → RFQ → 商务谈判 → 技术评审 → 定点 → PPAP → 量产
(0月)      (1月)        (2月)  (3月)      (4月)      (5月)  (6-9月)  (10月+)

关键节点：
• RFQ（询价）：至少 3 家报价
• 商务谈判：价格、年降、付款条件
• 技术评审：质量、产能、技术能力
• 定点：签订开发合同
• PPAP：样品批准
• 量产：SOP 开始供货
```

## 二、采购策略

### 2.1 平台化采购

| 维度 | 传统采购 | 平台化采购 |
|------|---------|-----------|
| 零件通用率 | 30-40% | 70-80% |
| 供应商数 | 500+ | 200-300 |
| 采购规模 | 分散 | 集中 |
| 成本 | 高 | 降低 10-20% |
| 开发周期 | 长 | 缩短 30% |

**平台化策略**：
- **零件通用化**：同平台多车型共用零件
- **供应商整合**：同一零件供应商从 5-6 家减至 2-3 家
- **集中采购**：跨平台、跨车型集中采购量
- **标准化**：规格标准化，减少定制

### 2.2 竞争策略

| 策略 | 说明 | 适用 |
|------|------|------|
| **双源策略** | 同一零件 2 家供应商 | 关键件、量大件 |
| **三源策略** | 同一零件 3 家供应商 | 非关键、标准件 |
| **独家供货** | 仅 1 家供应商 | 技术垄断、模具绑定 |
| **战略合作** | 深度绑定、联合开发 | 核心技术件 |

### 2.3 年度降价（年降）

| 维度 | 说明 |
|------|------|
| 年降幅度 | 3-5%/年（行业惯例） |
| 降本来源 | 规模效应、工艺优化、材料替代 |
| 谈判节奏 | 年度商务谈判 |
| 压力传导 | OEM→Tier1→Tier2→Tier3 |

## 三、成本管理

### 3.1 成本结构分析（Cost Breakdown）

| 成本项 | 占比 | 优化方向 |
|--------|------|---------|
| 原材料 | 50-60% | 材料替代、减少浪费 |
| 人工 | 15-20% | 自动化、工艺优化 |
| 制造费用 | 10-15% | 设备效率、能耗 |
| 管理费用 | 5-10% | 规模效应 |
| 利润 | 5-10% | 谈判、竞争 |

### 3.2 VA/VE（价值分析/价值工程）

| 维度 | 说明 |
|------|------|
| **VA（Value Analysis）** | 对现有产品分析，找出不增值部分 |
| **VE（Value Engineering）** | 在新产品开发阶段优化设计 |
| **目标** | 在不降低功能的前提下降低成本 |
| **典型降本** | 5-15%（单次 VA/VE 项目） |

**VA/VE 常用方法**：

| 方法 | 说明 | 示例 |
|------|------|------|
| 材料替代 | 用更便宜的材料替代 | 铝替代钢、塑料替代金属 |
| 工艺优化 | 更高效的制造工艺 | 一体化压铸替代冲压焊接 |
| 设计简化 | 减少零件数、简化结构 | 集成化设计 |
| 规格优化 | 过设计识别与修正 | 降规格不降功能 |
| 功能合并 | 多功能集成 | 集成式域控制器 |

### 3.3 成本基准（Benchmarking）

| 维度 | 方法 | 说明 |
|------|------|------|
| 竞品拆解 | 购买竞品拆解分析 BOM | 知己知彼 |
| Should Cost | 建立理论成本模型 | 采购谈判基准 |
| 供应商报价分析 | 成本分解+市场对标 | 识别异常报价 |
| 行业数据库 | IHS、S&P 成本数据 | 市场基准 |

### 3.4 整车 BOM 成本结构（电动车）

| 系统 | 成本占比 | 金额（万元） | 变化趋势 |
|------|---------|-------------|---------|
| 动力电池 | 35-40% | 4-6 | ↓ 快速下降 |
| 电驱动系统 | 8-10% | 1-1.5 | ↓ 缓慢下降 |
| 车身 | 10-12% | 1.2-1.5 | → 稳定 |
| 底盘 | 10-12% | 1.2-1.5 | → 稳定 |
| 电子电器 | 12-15% | 1.5-2 | ↑ 智能化增加 |
| 内外饰 | 10-12% | 1.2-1.5 | → 稳定 |
| 其他 | 5-8% | 0.5-1 | → 稳定 |
| **合计** | 100% | **12-15** | ↓ 整体下降 |

## 四、国产替代

### 4.1 国产替代驱动因素

| 因素 | 说明 |
|------|------|
| 成本优势 | 国产件通常便宜 20-40% |
| 供应安全 | 减少对海外供应商依赖 |
| 技术追赶 | 中国 Tier1 技术差距缩小 |
| 政策支持 | 自主可控政策推动 |
| 本地化响应 | 中国 OEM 速度更快 |

### 4.2 国产替代进程

| 零部件  | 2020 国产化率 | 2024 国产化率 | 2028E | 代表企业      |
| ---- | --------- | --------- | ----- | --------- |
| 动力电池 | 60%       | 95%       | 98%   | 宁德时代、比亚迪  |
| 线束   | 40%       | 60%       | 75%   | 沪光、卡倍亿    |
| 制动系统 | 30%       | 50%       | 70%   | 伯特利、拿森    |
| 转向系统 | 20%       | 40%       | 60%   | 蒂森克虏伯（国内） |
| 智驾芯片 | 5%        | 20%       | 40%   | 地平线、黑芝麻   |
| 激光雷达 | 0%        | 80%       | 90%   | 禾赛、速腾     |
| 座椅   | 50%       | 65%       | 80%   | 华域、继峰     |
| 热管理  | 40%       | 70%       | 85%   | 三花、银轮     |

### 4.3 国产替代的挑战

| 挑战 | 说明 | 应对 |
|------|------|------|
| 技术差距 | 高端芯片、精密部件仍有差距 | 研发投入+人才引进 |
| 认证周期 | 汽车级认证 2-3 年 | 提前布局 |
| 品牌信任 | OEM 对新供应商谨慎 | 从非关键件切入 |
| 专利壁垒 | 海外供应商专利保护 | 自主创新+专利布局 |

## 五、采购数字化

### 5.1 数字化采购工具

| 工具          | 功能        | 代表           |
| ----------- | --------- | ------------ |
| SRM         | 供应商管理、协同  | SAP Ariba、用友 |

| 应用 | 降本效果 | 实施难度 |
|------|---------|---------|

| 供应商协同 | 1-2% | 中 |
| AI 价格预测 | 1-2% | 高 |
