### 3.5 反向竞拍（Reverse Auction）详解

**什么是反向竞拍**：
- 买方发布采购需求，多个供应商在线竞价
- 价格由高到低，供应商为获得订单主动降价
- 最终选择价格最低（或综合评分最高）的供应商

**适用场景**：

| 场景 | 适用度 | 说明 |
|------|--------|------|
| 标准化商品 | ★★★★★ | 规格明确、质量差异小 |
| 竞争充分 | ★★★★★ | 供应商数量 ≥3 家 |
| 采购量大 | ★★★★☆ | 规模效应明显 |
| 定制化商品 | ★★☆☆☆ | 技术差异大、价格不是唯一因素 |
| 战略供应商 | ★☆☆☆☆ | 长期合作、关系重要 |

**反向竞拍效果**：

| 品类 | 平均降本幅度 | 说明 |
|------|------------|------|
| 办公用品 | 15-25% | 标准化高 |
| MRO | 10-20% | 竞争充分 |
| 包装材料 | 8-15% | 规格标准 |
| 电子元器件 | 5-10% | 技术门槛高 |
| 钢材/铝材 | 3-8% | 价格透明 |

## 四、Should Cost（成本建模）

### 4.1 Should Cost 解决什么问题？

| 问题 | 现状 | Should Cost 解决方案 |
|------|------|---------------------|
| **价格黑箱** | 不知道供应商成本结构 | 拆解成本、透明化 |
| **谈判被动** | 只能压价，不知道底线 | 知道理论成本、主动谈判 |
| **设计浪费** | 过设计导致成本虚高 | 识别优化机会 |
| **对标困难** | 不知道行业成本水平 | 建立成本基准 |

### 4.2 Should Cost 是什么？

**定义**：Should Cost（应该成本）是指基于材料、工艺、人工、管理等因素，计算出的零部件"理论成本"。

**核心逻辑**：
```
Should Cost = 材料成本 + 加工成本 + 人工成本 + 管理费用 + 合理利润

其中：
  材料成本 = 材料单价 × 用量
  加工成本 = 设备折旧 + 能耗 + 辅料
  人工成本 = 工时 × 人工费率
  管理费用 = 制造费用 × 分摊比例
  合理利润 = 行业平均利润率（5-10%）
```

### 4.3 Should Cost 如何做？

**建模步骤**：

| 步骤 | 任务 | 工具/方法 |
|------|------|---------|
| **1. 零件分析** | 识别材料、工艺、结构 | CAD 拆解、3D 模型 |
| **2. 材料成本** | 查询材料单价、计算用量 | 材料数据库（LME、上海有色） |
| **3. 加工成本** | 分析工艺路线、设备参数 | 工艺数据库、设备参数 |
| **4. 人工成本** | 估算工时、查询费率 | 地区工资数据库 |
| **5. 管理费用** | 分摊比例、间接成本 | 行业基准（15-25%） |
| **6. 利润** | 行业平均利润率 | 行业报告（5-10%） |
| **7. 验证** | 对比供应商报价、修正模型 | 历史数据、竞品拆解 |

**建模示例（汽车座椅骨架）**：

| 成本项 | Should Cost | 实际报价 | 差异 | 优化方向 |
|--------|------------|---------|------|---------|
| 材料（钢材） | ¥85 | ¥95 | +12% | 材料替代、减少废料 |
| 冲压加工 | ¥40 | ¥50 | +25% | 工艺优化、自动化 |
| 焊接 | ¥30 | ¥35 | +17% | 机器人焊接 |
| 表面处理 | ¥15 | ¥18 | +20% | 工艺改进 |
| 管理费 | ¥25 | ¥30 | +20% | 规模效应 |
| 利润（8%） | ¥16 | ¥22 | +38% | 谈判、竞争 |
| **合计** | **¥211** | **¥250** | **+18%** | **谈判空间 ¥39** |

| **场景模拟** | What-if 分析、应急预案 | 决策支持 |
| **控制塔** | 端到端可视、预警 | 协同效率提升 |

**Demo 场景**：

```
o9 供应链控制塔 Demo：
```

## 六、AI 采购

### 6.1 AI 采购解决什么问题？

| 问题 | 现状 | AI 采购解决方案 |
|------|------|----------------|
| **寻源效率低** | 人工筛选供应商、耗时耗力 | 智能推荐供应商 |
| **价格预测难** | 不知道市场价格走势 | AI 价格预测 |
| **合同风险** | 合同条款人工审核慢 | NLP 合同审查 |
| **支出分析** | 不知道钱花在哪里 | 智能支出分类 |

### 6.2 AI 采购核心功能

| 功能 | AI 技术 | 价值 | 成熟度 |
|------|---------|------|--------|
| **智能寻源** | 推荐算法、知识图谱 | 快速找到优质供应商 | ★★★★☆ |
| **价格预测** | 时序预测、因果推断 | 采购时机优化 | ★★★★☆ |
| **合同审查** | NLP、实体识别 | 合规性检查、风险识别 | ★★★☆☆ |
| **支出分类** | 分类算法、聚类分析 | 支出可见性、节省机会 | ★★★★☆ |
| **需求预测** | 时序预测、多因素融合 | 采购计划优化 | ★★★★★ |

### 6.3 AI 采购应用场景

**场景一：智能寻源**

| 输入 | AI 处理 | 输出 | 价值 |
|------|---------|------|------|
| 采购需求（规格、数量、交期） | 匹配供应商能力、历史绩效、风险评分 | Top N 推荐供应商 | 寻源效率提升 50% |

**场景二：价格预测**

| 输入 | AI 处理 | 输出 | 价值 |
|------|---------|------|------|
| 历史价格、市场数据、产能、库存 | 时序预测模型 | 未来 3-6 月价格走势 | 采购时机优化，降本 2-5% |

**场景三：合同审查**

| 输入 | AI 处理 | 输出 | 价值 |
|------|---------|------|------|
| 合同文本 | NLP 实体识别、条款比对 | 风险条款标注、合规建议 | 审查效率提升 80% |

**场景四：支出分析**

| 输入 | AI 处理 | 输出 | 价值 |
|------|---------|------|------|
| 采购订单、发票 | 自动分类、异常检测 | 支出分布、节省机会 | 发现 5-10% 节省机会 |

## 七、技术选型与实施建议

### 7.1 选型决策矩阵

| 需求 | 推荐工具 | 理由 |
|------|---------|------|
| 供应商管理混乱 | SRM | 基础数据治理、流程规范 |
| 采购成本高 | 电子招标 + Should Cost | 竞争性采购 + 成本透明 |
| 库存积压/缺货 | 供应链可视 | 全链路可视、风险预警 |
| 寻源效率低 | AI 采购 | 智能推荐、效率提升 |
| 全面数字化转型 | SRM + 电子招标 + 控制塔 | 体系化建设 |

### 7.2 实施路径建议

```
采购数字化实施路径：

Phase 1（0-6个月）：基础建设
  ✓ SRM 上线（供应商主数据、档案管理）
  ✓ 电子招标试点（标准化品类）

Phase 2（6-12个月）：效率提升
  ✓ 电子招标全面推广
  ✓ Should Cost 建模（关键品类）
  ✓ 基础供应链可视（订单/库存）

Phase 3（12-18个月）：智能升级
  ✓ AI 采购试点（智能寻源、价格预测）
  ✓ 供应链控制塔上线
  ✓ Should Cost 扩展（更多品类）

Phase 4（18-24个月）：生态扩展
  ✓ 供应商门户（Ariba Network）
  ✓ AI 采购全面应用
  ✓ 全链路智能化
```
