# 原材料供应链：汽车用关键材料全解析

> 💡 **核心洞察**：原材料是汽车供应链的"地基"——钢材、铝、锂、钴等材料的价格波动和供应稳定性，直接影响整车 BOM 成本和产能。掌握原材料供应链，是采购和成本管理的基本功。

---

## 一、汽车用主要原材料

### 1.1 传统材料

| 材料 | 单车用量 | 成本占比 | 主要来源 | 趋势 |
|------|---------|---------|---------|------|
| **钢材** | 800-1,200 kg | 8-10% | 宝钢、鞍钢、浦项 | 高强钢替代 |
| **铝合金** | 150-200 kg | 5-8% | 中铝、诺贝丽斯 | 轻量化增加 |
| **塑料** | 150-200 kg | 3-5% | 巴斯夫、SABIC | 再生塑料 |
| **橡胶** | 40-60 kg | 2-3% | 米其林、普利司通 | 轮胎为主 |
| **玻璃** | 30-50 kg | 1-2% | 福耀玻璃 | HUD 玻璃 |

### 1.2 新能源关键材料

| 材料 | 单车用量 | 成本占比 | 主要来源 | 趋势 |
|------|---------|---------|---------|------|
| **锂** | 8-12 kg（碳酸锂当量） | 5-15% | 赣锋、天齐、Albemarle | 价格波动大 |
| **钴** | 5-15 kg（三元电池） | 1-3% | 嘉能可、洛阳钼业 | 低钴化趋势 |
| **镍** | 30-50 kg（三元电池） | 2-5% | 青山、金川 | 高镍化 |
| **铜** | 25-40 kg | 1-2% | 紫金矿业、江铜 | 电动化增加用量 |
| **稀土** | 2-5 kg（电机） | 0.5-1% | 北方稀土 | 无稀土电机研发 |

## 二、关键原材料供需格局

### 2.1 锂

| 维度 | 说明 |
|------|------|
| **价格趋势** | 2022年峰值 60万/吨 → 2024年跌至 8-10万/吨 → 2025年震荡 |
| **供给格局** | 澳洲（锂辉石）+ 南美盐湖 + 中国（锂云母）三足鼎立 |
| **需求驱动** | 全球 EV 渗透率提升 + 储能需求 |
| **中国龙头** | 赣锋锂业、天齐锂业、盐湖股份 |
| **风险** | 价格剧烈波动影响电池成本 |

**锂产业链**：

```
锂矿开采 → 锂精矿 → 碳酸锂/氢氧化锂 → 正极材料 → 电池
   │           │            │              │         │
  澳洲/南美   中国加工     赣锋/天齐      宁德/比亚迪  整车
```

### 2.2 铝

| 维度 | 说明 |
|------|------|
| **趋势** | 轻量化驱动单车用铝量增加（150→200→250kg） |
| **应用** | 引擎盖、车门、副车架、电池壳体 |
| **铝合金板供应商** | 诺贝丽斯、中铝、南山铝业 |
| **成本** | 比钢材贵 2-3 倍，减重 30-40% |

**铝合金应用趋势**：

| 部件 | 传统方案 | 铝合金方案 | 减重效果 | 成本增加 |
|------|---------|-----------|---------|---------|
| 引擎盖 | 钢板 | 铝板 | 40-50% | +50% |
| 车门 | 钢板 | 铝板 | 30-40% | +40% |
| 副车架 | 钢制 | 铸铝 | 30-40% | +60% |
| 电池壳体 | 钢制 | 铝型材 | 40-50% | +30% |

### 2.3 钢材

| 维度 | 说明 |
|------|------|
| **应用** | 车身结构、底盘、悬架 |
| **趋势** | 高强钢（AHSS）替代普通钢，减重 10-20% |
| **供应商** | 宝钢、鞍钢、浦项、蒂森克虏伯 |
| **成本** | 基准材料，价格相对稳定 |

**高强钢等级**：

| 等级 | 抗拉强度 | 应用 | 供应商 |
|------|---------|------|--------|
| 普通钢 | <400 MPa | 非结构件 | 国内钢厂 |
| 高强钢 | 400-800 MPa | 车身结构 | 宝钢、浦项 |
| 超高强钢 | 800-1500 MPa | A/B柱、门槛 | 宝钢、蒂森 |
| 热成型钢 | 1500+ MPa | 安全结构 | 浦项、宝钢 |

### 2.4 铜

| 维度 | 说明 |
|------|------|
| **应用** | 线束、电机、电池连接件 |
| **单车用量** | 传统车 20kg → 电动车 40-60kg |
| **增长驱动** | 电动化（高压线束、电机绕组） |
| **供应商** | 紫金矿业、江铜、自由港 |

### 2.5 稀土

| 维度 | 说明 |
|------|------|
| **应用** | 永磁电机（钕铁硼磁铁） |
| **关键元素** | 钕、镨、镝、铽 |
| **中国占比** | 全球 60%+ 产量、90%+ 加工 |
| **供应商** | 北方稀土、中国南方稀土 |
| **风险** | 地缘政治风险，出口管制 |

**无稀土电机趋势**：

| 技术 | 优势 | 劣势 | 进展 |
|------|------|------|------|
| **励磁电机** | 无需稀土 | 效率略低 | 特斯拉 Model 3 部分采用 |
| **开关磁阻电机** | 成本低 | 噪音大 | 研究阶段 |
| **铁氧体电机** | 成本低 | 性能差 | 小功率应用 |

## 三、原材料价格对 BOM 的影响

### 3.1 价格敏感性分析

| 原材料 | 价格波动 10% | 对单车 BOM 影响 | 敏感度 |
|--------|------------|---------------|--------|
| 锂（碳酸锂） | ±10% | ±¥2,000-4,000 | ★★★★★ |
| 钢材 | ±10% | ±¥300-500 | ★★★☆☆ |
| 铝 | ±10% | ±¥500-800 | ★★★★☆ |
| 铜 | ±10% | ±¥100-200 | ★★★☆☆ |
| 镍 | ±10% | ±¥300-600 | ★★★★☆ |

### 3.2 原材料价格波动管理策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **长协锁价** | 与供应商签订长期固定价格合同 | 价格稳定、供应充足 |
| **期货套保** | 在期货市场锁定未来采购价格 | 大宗商品（钢、铝、铜） |
| **价格联动** | 合同价格与原材料价格指数挂钩 | 价格波动大、量大 |
| **替代材料** | 研发替代材料降低对单一材料依赖 | 技术可行时 |
| **集中采购** | 跨平台、跨车型集中采购量 | 规模效应 |

## 四、原材料供应风险管理

### 4.1 风险矩阵

| 风险类型 | 具体风险 | 概率 | 影响 | 应对策略 |
|---------|---------|------|------|---------|
| **价格暴涨** | 锂价 2022年涨 5 倍 | 高 | 高 | 长协锁价、期货套保 |
| **供应中断** | 澳洲锂矿罢工 | 中 | 中 | 多源采购、安全库存 |
| **地缘政治** | 中国稀土出口管制 | 中 | 高 | 海外布局、替代材料 |
| **质量风险** | 原材料质量不稳定 | 低 | 中 | 供应商审核、来料检验 |

### 4.2 供应安全策略

| 材料 | 供应风险 | 中国对策 |
|------|---------|---------|
| **锂** | 中（澳洲依赖） | 海外矿权投资（赣锋/天齐） |
| **钴** | 高（刚果金依赖） | 洛阳钼业海外布局 |
| **镍** | 中（印尼依赖） | 青山集团印尼建厂 |
| **稀土** | 低（中国主导） | 战略储备、出口管控 |
| **铜** | 中（智利依赖） | 紫金矿业海外布局 |

## 五、轻量化趋势与材料创新

### 5.1 轻量化技术路线

```
轻量化技术路线：

材料轻量化 → 结构轻量化 → 工艺轻量化
    │              │              │
 铝合金/碳纤维   拓扑优化      一体化压铸
 高强钢/塑料    中空结构      激光焊接
```

### 5.2 一体化压铸革命

| 维度 | 传统工艺 | 一体化压铸 |
|------|---------|-----------|
| **零件数** | 70-100 个 | 1-2 个 |
| **工序** | 冲压+焊接 | 压铸一次成型 |
| **重量** | 基准 | 减重 10-20% |
| **成本** | 基准 | 降低 20-30%（量产后） |
| **代表** | 传统车身 | 特斯拉 Model Y 后底板 |

**一体化压铸供应链**：

| 环节 | 代表企业 | 说明 |
|------|---------|------|
| **压铸机** | 力劲（6000T+）、海天 | 超大吨位压铸机 |
| **免热处理材料** | 美国铝业、立中集团 | 无需热处理的铝合金 |
| **压铸件** | 文灿股份、广东鸿图 | 特斯拉供应商 |
| **模具** | 广州型腔、宁波臻至 | 大型压铸模具 |

## 六、线束

### 6.1 线束概况

| 维度 | 说明 |
|------|------|
| 单车重量 | 30-60 kg |
| 单车长度 | 3,000-5,000 m |
| 单车成本 | ¥3,000-8,000（电动车更高） |
| 功能 | 电力传输+信号传输 |

### 6.2 线束供应商格局

| 供应商 | 国家 | 营收（亿美元） | 客户 |
|--------|------|--------------|------|
| 安波福（Aptiv） | 爱尔兰 | 120 | 通用、大众 |
| 矢崎（Yazaki） | 日本 | 110 | 丰田、本田 |
| 住友电气 | 日本 | 80 | 丰田、日产 |
| 莱尼（Leoni） | 德国 | 50 | 宝马、大众 |
