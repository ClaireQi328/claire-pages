# 🏭 汽车工业深度研究

> [!summary] 从投资视角到供应链实战的四阶段递进研究
> - **定位**：8 年汽车行业供应链经验（延锋→蔚来→小米）的系统性沉淀
> - **四阶段递进**：投资商业视角 → 全产业链图谱 → 供应链深度 → 出海与全球化
> - **核心价值**：不只是行业报告汇编，而是「从业者视角」的深度理解——每个环节我都在现场经历过
> - **服务目标**：投资分析 + 小米出海决策参考 + 个人知识体系构建

> [!tip] 汽车行业的核心认知
> 1. **汽车供应链 = 最复杂的制造业供应链**——BOM 万级、Tier 分层、JIT/JIS 节拍、全球寻源，没有之一
> 2. **新能源转型不是「换动力」，是「重构供应链」**——电池取代发动机，芯片权重飙升，软件定义汽车改变了 Tier1 的权力结构
> 3. **中国车企出海 = 供应链出海**——不只是卖车，是在海外建采购·物流·售后体系
> 4. **汽车行业的方法论可以迁移到其他制造业**——但反过来不行（其他行业的复杂度不够）
