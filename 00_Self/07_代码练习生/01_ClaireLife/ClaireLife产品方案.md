# Loopie 产品方案设计文档

> 原名：Clife → 新名：**Loopie**（读作"露比"）
> Loop = 循环，暗合「饮食→运动→思考」的每日闭环；-ie 后缀轻快可爱

---

## 一、产品定位

**一句话定义：** 以 AI 拍照识别为核心的轻量生活记录 App。先让用户爱上「拍照记饮食」，再自然延伸到运动和灵感。

**Slogan：** 「每一天，都值得被记住」

**目标用户：** 25-35 岁都市女性，喜欢可爱治愈风格，关注健康但不想被说教

**品牌调性：** 轻松、治愈、不严肃 —— 像一个陪你好好生活的朋友，不是教练

---

## 二、三大模块设计

### 🍱 饮食记录 —「BiteLog」

> MVP 核心模块，优先打磨

#### 用户流程（4步完成一次记录）

```
📸 拍照 → 🔍 AI识别(1-3秒) → ✏️ 确认/修正 → ✅ 保存
```

**Step 1 — 拍照：**
- 默认打开相机，取景框内显示引导框「对准食物」
- 支持连拍（聚餐场景，最多9张）
- 支持从相册导入

**Step 2 — AI识别（自动触发）：**
- 识别食物品类（中餐八大菜系 + 家常菜 + 日料韩料西餐）
- 估算分量（小/中/大份）
- 输出：卡路里总量 + 蛋白质/脂肪/碳水（克数+占比）+ 饮食评分(1-10)

**Step 3 — 确认修正：**
- 滑动即保存（默认操作，追求快）
- 可修改名称、调整分量滑块
- 选择用餐场景 + 心情 emoji（😋满足 😊刚好 😐一般 😣撑了）
- 预览手账贴纸效果

**Step 4 — 保存：**
- 食物照片 + 手账涂鸦贴纸 + 营养数据整合为一张精美卡片
- 插入时间线

#### 手账涂鸦贴纸系统 🎨

> MVP 首选风格，温暖治愈，像在日记本上手绘的小插图

**设计理念：** 不幼稚、不低龄，走「日系手账」审美路线——适合 25+ 用户的可爱是「有质感的可爱」。

**贴纸类型（MVP 20+ 款）：**

| 类别 | 示例贴纸 | 触发规则 |
|------|----------|----------|
| 🍚 主食类 | 一碗米饭冒着热气、面包片长出小脚、面条卷成爱心 | 识别到米饭/面包/面食时自动匹配 |
| 🥬 蔬果类 | 西兰花变成小树、番茄切面笑脸、牛油果戴帽子 | 识别到对应品类自动匹配 |
| 🍗 蛋白类 | 鸡蛋裂开小鸡探头、鱼身上有波浪纹、豆腐小方块眨眼 | 识别到肉类/蛋类/豆制品自动匹配 |
| 🍰 甜点类 | 蛋糕上一颗草莓在发光、冰淇淋球叠罗汉、饼干咬痕变月牙 | 识别到甜点/零食自动匹配 |
| ☕ 饮品类 | 咖啡杯蒸汽画成猫、奶茶珍珠在杯底开会、水杯有彩虹折射 | 识别到饮品自动匹配 |
| 🎯 通用类 | 小叉子和小勺子牵手、便当盒开盖有光、围裙系成蝴蝶结 | 所有记录均可叠加 |

**贴纸交互细节：**
- 生成后双指缩放 + 拖拽调整位置
- 可叠加多个贴纸（最多3个）
- 每周自动生成「本周食贴」合集卡片（类似相册拼贴）
- 长按贴纸可收藏到「贴纸本」，跨餐复用

**手账涂鸦风格参数：**
- 线条：细笔触，轻微不规则（模拟手绘）
- 色彩：莫兰迪色系，低饱和度
- 纹理：纸张纹理叠加（米白底）

### 🏃 运动记录 —「MoveTrace」

> V1.0 重点模块

#### 运动类型

```
🏃 有氧：跑步/骑行/游泳/跳绳/徒步
🏋️ 力量：器械/自由重量/自重/功能性
🧘 柔韧：瑜伽/普拉提/拉伸
⚽ 球类：篮球/足球/羽毛球/网球
🎯 其他：自定义 + 日常活动
```

#### 截图识别（V1.0）

支持 Keep / Apple Fitness / 华为运动健康 / 小米 / Strava / Nike Run Club 等 App 截图 → OCR 提取运动数据 → 结构化存储

#### 运动感受（双维度记录）

```
身体感受：💪充满力量 😤挑战极限 😌轻松愉悦 😫筋疲力尽
心情评分：⭐⭐⭐⭐⭐
一句话感受（语音/文字）
```

---

### 💡 灵感记录 —「ThinkLog」

> V1.0 模块，保持极简

**四种输入方式：**
- 📝 文字：极简输入框，无标题，#标签
- 🎤 语音：一键录音，实时转文字，保留原始音频
- 📸 图片：拍照/截图，OCR提取文字
- 🔗 分享：系统Share Extension，自动抓取网页摘要

## 三、统一时间线设计

三种记录混排在一条时间线中，按天分隔，纵向无限滚动：

```
┌──────────────────────────────────┐
│         6月24日 星期三            │
│  ┌─ 07:15 ─────────────────────┐ │
│  │ 🏃 晨跑5.2km · 342kcal      │ │
│  └──────────────────────────────┘ │
│  ┌─ 08:00 ─────────────────────┐ │
│  │ 🥣 早餐 · 486kcal [贴纸]    │ │
│  └──────────────────────────────┘ │
│  ┌─ 10:23 ─────────────────────┐ │
│  │ 💡 "产品设计不是设计功能..." │ │
│  └──────────────────────────────┘ │
│  ┌─ 12:30 ─────────────────────┐ │
│  │ 🍱 午餐 · 628kcal [贴纸]    │ │
│  └──────────────────────────────┘ │
│  ┌─ 21:45 ─────────────────────┐ │
│  │ 🌙 今日小记（AI自动汇总）    │ │
│  └──────────────────────────────┘ │
│  ─────── 6月23日 ─────────────── │
│  ...                              │
└──────────────────────────────────┘
```

**时间线特性：**
- 三种卡片颜色区分模块（橙色饮食/绿色运动/紫色灵感）
- 筛选：全部/饮食/运动/灵感
- 搜索：全文搜索 + 标签 + 日期跳转
- 密度控制：相近时间同类记录自动折叠

## 四、周期性盘点与提醒

### 回顾体系

| 层级 | 频率 | 内容 |
|------|------|------|
| 🎲 随机回顾 | 每日 | Widget 轮换历史记录 / 「3个月前今天」推送 |
| 📊 周回顾 | 每周日 | AI 周报：饮食总结 + 运动统计 + 交叉洞察 |
| 📅 月回顾 | 每月1日 | 月度报告长图 / 关键词云 / 「高光时刻」 |
| 🎆 年回顾 | 年终 | Spotify 风格年度报告 |

### 温和提醒

```
📌 记录提醒
  ├── 12:00 午餐提醒 / 18:30 晚餐提醒
  ├── 18:00 运动提醒（可自定义）
  └── 21:00 灵感提醒

📌 智能调节
  ├── 连续7天记录 → 降低提醒频率
  ├── 连续3天未记录 → 温馨提醒不指责
  └── 深夜使用 → "夜深了，明天再记也不迟~"
```

## 五、产品路线图

### MVP（0-3个月）— 验证「拍照记录」核心假设

**目标：** 用户是否愿意每天拍照记录饮食？手账贴纸是否能驱动留存？

| 模块 | MVP 范围 |
|------|----------|
| 🍱 BiteLog | **全部精力投入** — 拍照→AI识别→营养数据→手账贴纸(20+款)→饮食卡片→时间线 |
| 🏃 MoveTrace | 仅手动输入：运动类型 + 时长 + 感受（不含截图识别） |
| 💡 ThinkLog | 仅文字输入 + 标签 |
| 📋 时间线 | 三模块混合时间线、按天分隔、模块筛选 |
| 📊 回顾 | 简单文字周报 |
| 👤 账号 | 手机号注册 + 云端同步 |

**不做：** 截图识别、语音输入、AI交叉洞察、Widget、社交

**技术选型：**
- 食物识别 API：百度 AI 视觉 / 阿里云视觉智能
- 营养数据库：USDA 开源 + 自建中餐数据库
- 贴纸渲染：客户端 Canvas/Skia 引擎实时合成
- 时间线：本地 SQLite + Firebase/LeanCloud 云端同步

---

### V1.0（3-8个月）— 完善三模块体验

| 模块 | 新增 |
|------|------|
| 🍱 BiteLog | 连拍模式、分量滑块、贴纸收藏本、每周食贴合集 |

| 🔗 统一 | AI交叉洞察、每日综合评分、标签贯通 |
| 📊 回顾 | AI周报/月报、月度关键词云、高光时刻 |
| 🎨 其他 | Widget小组件、Apple Health同步、数据导出 |

- 🤝 轻社交：匿名分享到社区、挑战活动

## 六、设计决策备忘

**为什么叫 Loopie？**
- Loop = 每日循环（吃→动→想），也是「闭环」——记录让生活形成完整叙事
- -ie 后缀天然可爱、亲切、好记
- 6字母，全球 App Store 无重名风险
- 发音「露比」在中文语境下也自然

**为什么 MVP 只做拍照识别？**
- 这是用户打开 App 的第一动作，也是最核心的价值感知点
- 手账贴纸的「可爱+分享」是留存和传播的钩子
- 运动和灵感如果同时做，资源分散，三个都做不好
- 先让用户爱上记录饮食，再自然延伸到运动和思考

**为什么选手账涂鸦风格？**
- 「可爱但不幼稚」——符合 25+ 用户审美
- 手账文化有成熟的用户心智（日记本、Bullet Journal）
- 和「记录生活」的品牌调性天然契合
- 视觉差异大，截图分享时辨识度高

**隐私原则：**
- 本地优先存储，云端同步可选
- 饮食照片端侧 AI 识别（不上传服务器）
- 灵感记录端到端加密
- 用户数据永不出售
