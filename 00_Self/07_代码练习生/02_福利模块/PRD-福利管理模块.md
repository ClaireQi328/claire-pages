## 1. 需求背景

### 1.1 业务背景

企业人力资源部门需要对年度各类员工福利进行统一管理。当前福利发放依赖线下 Excel 记录，存在以下痛点：

- 福利信息分散，无法统一检索和追溯
- 发放状态混乱，缺乏标准化流转机制
- 停用操作无记录，历史数据难追溯
- 同一年度可能出现重复福利项，造成 Excel 数据冗余

### 1.2 产品目标

构建一个 Web 端福利管理功能模块，实现：

- **集中管理**：福利记录的增删改查（停用）
- **状态流转**：标准化"待发放 → 已发放 / 停用"的生命周期
- **权限控制**：基于状态的操作权限隔离
- **数据一致**：同年不允许同名福利，金额精确到分

### 1.3 角色定义

| 角色 | 权限范围 |
|------|----------|
| HR管理员 | 全部操作：新增、编辑、停用、查询 |

### 2.1 功能总览

| 编号 | 功能 | 优先级 | 描述 |
|------|------|--------|------|
| F-01 | 福利列表展示 | P0 | 分页展示所有福利记录 |

## 4. 功能详细设计

### 4.1 列表页

#### 4.1.1 列表字段

| 序号 | 字段名 | 数据类型 | 排序 | 说明 |
|------|--------|----------|------|------|
| 1 | 序号 | Integer | 自增 | 列表行号，从1起递增 |
| 2 | 年度 | String | 降序 | 如"2026"，下拉枚举近4年 |
| 3 | 福利名称 | String | — | 最长30字，同年不可重名 |
| 4 | 金额（元） | Decimal(10,2) | — | 单位元，精确到分，>0 |
| 5 | 发放月份 | String | — | 1月-12月 / 生日当月 |
| 6 | 更新时间 | DateTime | 降序 | 格式 YYYY-MM-DD HH:mm:ss |
| 7 | 状态 | Enum | — | 待发放 / 已发放 / 停用 |
| 8 | 操作 | — | — | 编辑 / 停用（权限控制） |

#### 4.1.2 分页规则

- 默认每页显示 **10 条**（原型为 8 条演示数据）
- 显示当前页码、总条数、总页数
- 支持上一页/下一页/跳页

### 4.2 筛选功能 (F-02)

#### 4.2.1 筛选字段

| 字段 | 控件类型 | 匹配方式 | 说明 |
|------|----------|----------|------|
| 年度 | 下拉单选 | 精确匹配 | 枚举：2026/2025/2024/2023；默认"全部年度" |
| 福利名称 | 文本输入 | 模糊匹配（包含） | 可选置空 |
| 发放月份 | 下拉单选 | 精确匹配 | 枚举：1月～12月；默认"全部月份" |
| 状态 | 下拉单选 | 精确匹配 | 枚举：待发放/已发放/停用；默认"全部状态" |

#### 4.2.2 交互规则

1. 筛选面板默认**收起**，点击「筛选」按钮展开/收起
2. 多条件取 **AND** 关系（同时满足所有条件）
3. 点击「查询」执行筛选
4. 点击「重置」清空所有条件并恢复完整列表
5. 筛选后分页重置到第1页

### 4.3 新增功能 (F-03)

#### 4.3.1 触发方式

点击列表页「新增福利」按钮，弹出模态弹窗。

#### 4.3.2 弹窗字段

| 字段 | 控件 | 必填 | 校验规则 | 默认值 |
|------|------|------|----------|--------|
| 年度 | 下拉单选 | ✅ | 枚举近4年 | 当前年 |
| 福利名称 | 文本输入 | ✅ | 最长30字，同年不可重名 | — |
| 金额（元） | 数字输入 | ✅ | 精确到分，必须 >0 | — |
| 发放月份 | 下拉单选 | ✅ | 1-12月 / 生日当月 | — |
| 备注 | 多行文本 | ❌ | 最长200字 | — |

#### 4.3.3 业务规则

| 规则编号 | 规则内容 |
|----------|----------|
| R-01 | 新增后状态自动设为**待发放**，前端不暴露状态选择 |
| R-02 | 同年已有同名福利 → 后端返回错误，前端提示"该年度已存在同名福利" |
| R-03 | 新增成功 → 记录插入列表顶部，Toast 提示 |
| R-04 | 更新时间取服务端当前时间 |
| R-05 | 金额存储为 Decimal(10,2)，前端展示千分位格式 `¥ 1,000.00` |

#### 4.3.4 校验与反馈

- **前端校验**：缺必填项 → 对应字段红框抖动 + Toast "请输入XXX"
- **后端校验**：重名 → 返回错误码 + 消息；金额超范围 → 错误提示
- **成功反馈**：Toast 绿色 "新增成功"

### 4.4 编辑功能 (F-04)

#### 4.4.1 触发条件

- 仅 **待发放** 状态记录可编辑
- 已发放/停用状态 →「编辑」文字置灰，cursor: not-allowed，不可点击

#### 4.4.2 弹窗字段

| 字段 | 控件 | 可编辑 | 说明 |
|------|------|--------|------|
| 年度 | 下拉单选 | ✅ | 规则同新增 |
| 福利名称 | 文本输入 | ✅ | 规则同新增 |
| 金额（元） | 数字输入 | ✅ | 规则同新增 |
| 发放月份 | 下拉单选 | ✅ | 规则同新增 |
| 状态 | 只读文本 | ❌ | 显示当前状态，不可修改 |
| 备注 | 多行文本 | ✅ | 选填 |

#### 4.4.3 业务规则

| 规则编号 | 规则内容 |
|----------|----------|
| R-06 | 仅"待发放"可进入编辑弹窗 |
| R-07 | 编辑弹窗中状态字段**只读展示** |
| R-08 | 接口层必须再次校验 status === 'pending' |
| R-09 | 保存后更新时间自动刷新 |
| R-10 | 同年重名校验规则同新增 |

### 4.5 停用功能 (F-05)

#### 4.5.1 触发条件

- 仅 **待发放** 状态可停用
- 已发放/停用状态 →「停用」文字置灰，不可点击

#### 4.5.2 交互流程

```
点击「停用」→ 弹出确认弹窗 → 显示福利名称
                              → "停用后不可恢复"警告
                              → 红色「确认停用」按钮
                              → 「取消」按钮
          → 确认 → 状态变更为"停用"，Toast提示
          → 取消 → 弹窗关闭，无变化
```

#### 4.5.3 业务规则

| 规则编号 | 规则内容 |
|----------|----------|
| R-11 | 停用后状态变更为"停用"，不可逆 |
| R-12 | 已发放的记录不允许停用 |
| R-13 | 停用后记录保留在列表中，所有操作按钮置灰 |
| R-14 | 停用不涉及物理删除 |

## 5. 状态流转

### 5.1 状态枚举

| 状态值 | 中文 | 颜色 | 图标色 | 说明 |
|--------|------|------|--------|------|
| `pending` | 待发放 | 蓝色 [[3B82F6]] | [[EFF6FF]] 底 | 初始状态，可编辑可停用 |
| `issued` | 已发放 | 绿色 [[10B981]] | [[ECFDF5]] 底 | 发放完成，只读 |
| `disabled` | 停用 | 灰色 [[9CA3AF]] | [[F3F4F6]] 底 | 已停用，只读，不可恢复 |

### 5.2 状态流转图

```
                  ┌──────────────────┐
                  │     待发放        │
                  │   (pending)       │
                  └───┬──────────┬────┘
                      │          │
             系统发放  │          │  手动停用
                      ▼          ▼
              ┌──────────┐  ┌──────────┐
              │  已发放   │  │   停用   │
              │ (issued)  │  │(disabled)│
              └──────────┘  └┬─────────┘
                  │           │
              只读/终态       │ 只读/终态
                              │ 不可逆
                  ✘────不许────┘
```

### 5.3 操作权限矩阵

| 状态 \ 操作 | 编辑 | 停用 | 说明 |
|-------------|------|------|------|
| 待发放 | ✅ 可用 | ✅ 可用 | 蓝色按钮，可正常点击 |
| 已发放 | ⛔ 禁用 | ⛔ 禁用 | 置灰 `span`，不可点击 |
| 停用 | ⛔ 禁用 | ⛔ 禁用 | 置灰 `span`，不可点击 |

### 5.4 前端权限判断伪代码

```javascript
const canOperate = record.status === 'pending';

// 编辑按钮
const editBtn = canOperate
  ? <button onClick={openEdit}>编辑</button>
  : <span class="disabled" title="仅待发放可编辑">编辑</span>;

// 停用按钮
const disableBtn = canOperate
  ? <button onClick={openDisable}>停用</button>
  : <span class="disabled" title="仅待发放可停用">停用</span>;
```
