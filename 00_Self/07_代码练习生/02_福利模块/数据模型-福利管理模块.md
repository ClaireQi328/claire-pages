## 2. 表结构定义

### 2.1 welfare (福利表)

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | — | 主键ID |
| `year` | VARCHAR(4) | NOT NULL | — | 年度，如"2026" |
| `name` | VARCHAR(30) | NOT NULL | — | 福利名称 |
| `amount` | DECIMAL(10,2) | NOT NULL | — | 金额（元），精确到分，>0 |
| `disburse_month` | VARCHAR(20) | NOT NULL | — | 发放月份：1-12月 / 生日当月 |
| `status` | TINYINT | NOT NULL | 0 | 状态：0=待发放, 1=已发放, 2=停用 |
| `remark` | VARCHAR(200) | NULL | NULL | 备注信息 |
| `created_at` | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引设计：**

| 索引名 | 类型 | 字段 | 说明 |
|--------|------|------|------|
| `uk_year_name` | UNIQUE | `year`, `name` | 同年同名唯一约束 |
| `idx_year` | INDEX | `year` | 年度筛选 |
| `idx_status` | INDEX | `status` | 状态筛选 |
| `idx_disburse_month` | INDEX | `disburse_month` | 月份筛选 |
| `idx_created_at` | INDEX | `created_at` | 默认排序 |

## 3. 状态枚举

| 状态值 (status) | 中文名 | 颜色 | 说明 |
|-----------------|--------|------|------|
| `0` (pending) | 待发放 | 蓝色 [[3B82F6]] | 初始状态，可编辑可停用 |
| `1` (issued) | 已发放 | 绿色 [[10B981]] | 发放完成，只读终态 |
| `2` (disabled) | 停用 | 灰色 [[9CA3AF]] | 已停用，只读，不可恢复 |

## 4. 状态流转规则

```
           ┌──────────────────┐
           │     待发放        │
           │   (status=0)     │
           └───┬──────────┬───┘
               │          │
      系统发放  │          │  手动停用
               ▼          ▼
       ┌──────────┐  ┌──────────┐
       │  已发放   │  │   停用   │
       │(status=1) │  │(status=2)│
       └──────────┘  └──────────┘
           只读/终态      只读/终态
                      (不可逆)
```

**流转约束：**

| 当前状态 | 目标状态 | 触发方式 | 是否允许 |
|----------|----------|----------|----------|
| 待发放 → 已发放 | 系统自动 | ✅ 允许 | |
| 待发放 → 停用 | 手动操作 | ✅ 允许 | |
| 已发放 → 任何 | — | ❌ 禁止 | |
| 停用 → 任何 | — | ❌ 禁止 | |

## 5. SQL DDL 参考

```sql
-- 福利表
CREATE TABLE welfare (
    id              BIGINT          PRIMARY KEY AUTO_INCREMENT,
    year            VARCHAR(4)      NOT NULL COMMENT '年度',
    name            VARCHAR(30)     NOT NULL COMMENT '福利名称',
    amount          DECIMAL(10,2)   NOT NULL COMMENT '金额（元）',
    disburse_month  VARCHAR(20)     NOT NULL COMMENT '发放月份',
    status          TINYINT         NOT NULL DEFAULT 0 COMMENT '状态：0待发放/1已发放/2停用',
    remark          VARCHAR(200)    NULL DEFAULT NULL COMMENT '备注',
    created_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at      DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',

    UNIQUE KEY uk_year_name (year, name),
    INDEX idx_year (year),
    INDEX idx_status (status),
    INDEX idx_disburse_month (disburse_month),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='福利表';

-- 操作日志表
CREATE TABLE welfare_log (
    id              BIGINT          PRIMARY KEY AUTO_INCREMENT,
    welfare_id      BIGINT          NOT NULL COMMENT '关联福利ID',
    action          VARCHAR(20)     NOT NULL COMMENT '操作类型：CREATE/UPDATE/STATUS_CHANGE',
    old_status      TINYINT         NULL DEFAULT NULL COMMENT '变更前状态',
    new_status      TINYINT         NULL DEFAULT NULL COMMENT '变更后状态',
    operator        VARCHAR(50)     NOT NULL COMMENT '操作人',
    operated_at     DATETIME        NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '操作时间',
    remark          VARCHAR(200)    NULL DEFAULT NULL COMMENT '操作备注',

    INDEX idx_welfare_id (welfare_id),
    INDEX idx_operated_at (operated_at),
    CONSTRAINT fk_welfare_log_welfare FOREIGN KEY (welfare_id) REFERENCES welfare(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='福利操作日志表';
```

## 6. 设计说明

### 6.1 金额精度
- 使用 `DECIMAL(10,2)` 存储，避免浮点数精度问题
- 前端展示格式：`¥ 1,000.00`（千分位）

### 6.2 同年唯一性
- 通过 `uk_year_name` 唯一索引保证同一年度内福利名称不重复
- 数据库层面强制约束，避免并发写入冲突

### 6.3 软删除策略
- 采用状态字段（status=2 停用）实现逻辑停用
- 不进行物理删除，保留历史数据可追溯

### 6.4 操作日志
- 记录所有关键操作（创建、编辑、状态变更）
- 支持审计追溯，满足合规要求
