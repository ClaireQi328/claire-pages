## 1. 睡眠

> [!tip] 核心结论
> 如果你想获得健康、更好的工作学习状态、提升免疫/新陈代谢/心理状态，**最最重要的前提是拥有良好的睡眠**。

### 1.1 原理

- **生物钟机制**：身体释放皮质醇（cortisol）和肾上腺素（adrenaline）让我们醒来，同时设定松果体释放褪黑素的倒计时钟，十多个小时后让我们再次入睡
- **光照是最大影响因素**：眼睛通过黑视素神经节细胞接收光照信息，设定内在生物钟
  - 通宵后太阳升起会突然精神，就是因为生物钟被重设
- **体温也是控制手段**：体温从深睡眠低状态逐渐升高，到一天后半段下降，再进入睡眠

### 1.2 实践要点

#### 🌅 晨间光照

- 起床后接触阳光 **2-10 分钟**，对血压控制、心理状态、设定睡眠倒计时钟都有好处
- 户外日光效果最好；人造光源中蓝光效果较好，最好是上部（天空位置）光源
- 隔着窗户接收日光强度降低 50% 以上，达到同样效果需要 50-100 倍时间
- 对视障人士也有效（黑视素神经节细胞不用于视觉成像）

#### 🌙 夜间避光

- 晚上尽量减少光源接触，会扰乱生物钟
- **尤其避免晚上 11 点到凌晨 4 点接收光源**，会抑制后续几天的多巴胺释放
- 不可避免时，低位置、暗淡红光、蜡烛相对好些
- 看电脑建议用 blue blockers 眼镜
- 傍晚观察落日有助于入睡，甚至能减轻晚上光照的负面影响

#### 😴 午休与 NSDR

- 人一天精神状态通常在中间有个短暂低谷，午睡对部分人有帮助
- 替代方案：Yoga Nidra、冥想、自我催眠（如 Reveri App）

#### 🌡️ 体温调节

- 早上洗冷水澡 → 快速升温 → 睡眠周期前移（早起）
- 晚上锻炼身体 → 保持高体温 → 周期延后（晚睡）
- 可选购智能床垫自动控制体温提升睡眠质量
- 一般建议锻炼时间：醒来后 30 分钟、3 小时和 11 小时（影响度较小）

#### ☕ 饮食与药物因素

| 因素 | 说明 |
|------|------|
| 咖啡因 | 占据腺苷受体，阻断入睡信号；因人而异，需自己测试 |
| 镁 | 对入睡有帮助 |
| 芹黄素 | 帮助入睡，但注意对雌性激素的影响 |
| 牛磺酸 | 建议不要摄入太多 |
| 褪黑素 | ❌ 不建议使用：规格把控不严格，容易引起抑郁情绪 |
| 酪氨酸食物 | 中午吃（坚果、大豆、蔬菜），提升多巴胺保持清醒 |
| 色氨酸食物 | 晚上吃（淀粉、白肉），转化为血清素，平静助眠 |
| 睡眠时长 | 6-8 小时对绝大多数人比较健康 |

> 各类药物检索参考：[examine.com](https://examine.com)

## 2. 饮食

### 2.1 Fasting（间歇性禁食）

#### 背景：两种身体状态

| 状态 | 血糖 | 身体活动 |
|------|------|----------|
| 吃饱 | 高 | 细胞复制与成长 |
| 禁食 | 低 | 细胞修复与清理（autophagic） |

- 饮食时间的选择实际上是在控制上述两个状态的持续时间和平衡关系
- 世界上很多民族文化和宗教中都有禁食相关的习俗

#### 关键实验（2012）

- 把小白鼠分成两组：一组全天任意吃，另一组只能在固定 8 小时吃
- 结果：**8 小时组即使吃高脂肪食物，健康水平仍然保持甚至提高**，相比不限制组有明显提升

#### 间歇性禁食的好处

促进肝脏健康 · 胆汁酸代谢 · 炎症自愈 · 保持体重 · 提升 brown fat 储备 · 防止非酒精性脂肪肝 · 血糖控制 · 肠道健康 · 养成习惯 60 天以上身体倾向于代谢脂肪供能

> [!important] 核心观点
> **何时进食，与吃什么东西，同等重要。**

#### 实践指南

| 级别 | 规则 | 说明 |
|------|------|------|
| 基础 | 起床后 ≥1 小时不吃，睡前 2-3 小时不吃 | 最简单的执行原则 |
| 高阶 | 8 小时进食窗口（如 10-18 点或 12-20 点） | 研究结果中最理想的窗口 |

- 看起来不吃早饭并不是什么坏事 :)
- 增肌建议把窗口往前移（早上摄入蛋白质对肌肉增长有益）
- **保持窗口时间的稳定性非常重要**，否则跟频繁倒时差差不多
- 建议逐渐切换：每两天缩短 1 小时进食窗口

#### 禁食期间的注意事项

- ❗ 不吃任何东西 ≠ 不能喝水
- ✅ 喝水、茶、咖啡（不加牛奶）不会中断禁食
- ❌ 一勺糖的摄入就会中断
- 晚饭后做轻量运动（散步）加快血糖清理
- 二甲双胍、黄连素（berberine）可直接促进血糖清理
- 肉桂皮、柠檬汁也能轻微降低血糖
- 禁食期间头晕颤抖 → 喝盐水（可加柠檬汁），不必立刻进食

### 2.2 饮食与消化道健康

#### 肠道菌群要点

- 肠道微生物群不仅影响消化系统，对**免疫系统也起关键作用**
- 婴儿成长方式会形成非常不同的肠道菌群生态
- 暴露在微生物环境中有益（养宠物、让孩子自由玩耍），不需要过度清洁消毒
- 菌群多样性越高，一般越健康
- ⚠️ 抗生素会严重破坏肠道菌群生态，需谨慎使用

#### 关键实验：高纤维 vs 发酵类食品

| 对比维度 | 高纤维食物 | 发酵类食品 |
|---------|-----------|-----------|
| 典型食物 | 全谷类、豆类、蔬菜、坚果 | 酸奶、kefir、康普茶、酸菜、泡菜、纳豆 |
| 菌群多样性提升 | 一般（仅对原本多样性高的人有帮助） | ✅ **显著提升** |
| 免疫效果 | 不明显 | ✅ 几十个免疫标志物显著降低 |
| 额外注意 | 工业化饮食结构下改善有限 | 必须是自然发酵、冷藏、非罐装、无添加糖 |

> [!tip] 实践建议
> - **一天两次**摄入天然发酵类食品来改善肠道菌群
> - 日常以植物类食物为主，避免深度加工食品，控制糖摄入
> - 地中海饮食 vs 生酮饮食：效果接近，但地中海更容易坚持，生酮长期有风险 → **推荐地中海饮食**
> - 官方参考：[中国居民膳食指南](http://dg.cnsoc.org/)

## 3. 心态与动力（多巴胺系统）

> 这一集是 Huberman 开播以来播放量最高的一集，对强健心智有非常好的指导作用。

### 3.1 多巴胺原理

多巴胺主要作用于两个神经回路：

| 回路 | 影响 | 相关疾病 |
|------|------|----------|
| 运动回路 | 身体运动 | 帕金森病（多巴胺分泌不足） |
| 动机回路 | 动机、欲望与快乐 | 与几乎所有活动相关 |

#### 多巴胺水平曲线

```
快乐程度
  ↑        ╱╲
  │       ╱  ╲        ← 高峰：达成目标时
  │      ╱    ╲
baseline ──────╲──────  ← 基准线
  │              ╲_____  ← 低谷：高峰之后，低于 baseline
  └──────────────────→ 时间
```

#### 两大核心原理

**① 相对变化量比绝对值更重要**
- 刷抖音：第一个有趣视频 → 快乐，持续刷 → 同样的内容快乐感递减
- 多巴胺已在高位时，难以形成更大的变化量

**② 多巴胺储备是有限的**
- 无论通过学习、工作、娱乐、社交、运动获得快乐，消耗的都是同一种"快乐货币"
- Work hard, play hard → 长期持续会导致 baseline 逐渐下降 → **burn out**
- 游戏上瘾的恶性循环：兴趣范围缩小 → 甚至游戏本身也无法触发多巴胺 → 严重抑郁

#### 多巴胺叠加效应

- 健身时叠加多种快乐因素（好日子 + 能量饮料 + 朋友 + 音乐）→ "前所未有的快乐"
- ⚠️ 高峰越高，低谷越长；长此以往会降低**单纯从运动中获取快乐的能力**
- 同理：边吃饭边玩手机 + 拍照发朋友圈 = 叠加多种快乐因素

### 3.2 影响多巴胺的外界因素

#### 促进多巴胺分泌

| 因素 | 多巴胺提升倍数 | 备注 |
|------|--------------|------|
| 巧克力 | 1.5x | - |
| 性行为 | 2x | - |
| 尼古丁 | 2.5x | - |
| 可卡因 | 2.5x | - |
| 安非他命 | 10x | - |
| 咖啡因 | 少量 | 抑制受体，提升同等多巴胺的感受效果 |
| 马黛茶 | - | 含咖啡因，控制血糖，保护多巴胺神经元 |
| 刺蒺藜豆 | - | 等同 L-DOPA，提升精子数量和质量 |
| 运动 | ≤2x | 喜欢跑步的人效果更明显 |
| 健康社交 | - | - |
| **冷水浴** | **2.5x** | **持续 3 小时；10-14°C；每周 11 分钟足够** |

#### 相关药物（⚠️ 谨慎使用）

- L-Tyrosine（酪氨酸）、PEA（巧克力中也有）、Huperzine A、各类"聪明药"（Adderall, Modafinil, Alpha-GPC, Ginkgo）
- ⚠️ 不推荐持续使用：高峰会带来 baseline 降低
- Huberman 建议：**一周一次**的频率应该是安全的

#### 降低多巴胺的因素

- 褪黑素 → 引起多巴胺减少
- 睡眠时段接触光源 → 接下来几天多巴胺水平下降

### 3.3 维持健康的多巴胺水平

#### 随机奖励机制

- 赌场原理：偶尔赢一次 + 金额浮动 → 吸引持续参与
- 应用到生活中：**随机化叠加因素的多少**
- 健身示例：随机决定今天是否听音乐、是否带手机、是否喝能量饮料
- 单纯健身时多巴胺释放较低 → 模拟有高有低的随机奖励机制

### 3.4 成长型思维

#### 关键实验

- 挑选天生爱画画的小朋友 → 完成画作后给奖励 → 移除奖励后兴趣和动力**大大降低**
- 结论：为活动收到外部奖励（金钱、美食）→ 反而降低活动本身的愉悦程度

#### 正面应用：自我暗示

- 把**努力过程本身当作奖励**："我在努力学习，这个过程本身是有趣的，会让我不断变强"
- 过程中激发多巴胺释放 → 提升情绪和动力 → 困难更容易克服
- 示例：
  - 暗示 fasting 对健康的益处来获取满足感，而非靠 fasting 后的大快朵颐
  - 暗示植物类食物的好处，坚持一段时间 → 觉得花椰菜也挺美味

> [!quote] 底层逻辑
> 这些原理知识能让我们做更好的自我暗示。人类的"硬件系统"都差不多，但知识、思维这些"软件"可以千差万别。

#### "空杯心态"的科学依据

- 接收到支撑已有信念的信息 → 也能激发多巴胺释放 → 改变认知
- 克服方法：调节情绪使自己处于镇静状态（提升血清素水平）→ 更好地倾听不一致的信息

## 4. 学习与专注

### 4.1 学习的原理

- **学习的本质**：神经元的重新连接（rewire）
- 需要大脑处于**神经可塑性（neuroplasticity）**状态
- 两个重要条件：① 足够的专注度 ② "犯错"的信号

#### 犯错信号机制

- 尝试做事情但没达到预期 → 身体发"我犯错了"信号
- 神经系统释放：肾上腺素（alertness）+ 乙酰胆碱（focus）+ 多巴胺（促 rewire）
- **犯错是进入学习状态的重要前提**（跟训练 ML 模型一模一样 :)）

> [!warning] 心流 ≠ 最佳学习状态
> 心流是精神高度集中且接近自动化的状态，是在做**已经知道怎么做的事**，不是在学习新知识技能。

#### 隐藏逻辑

- 遇到挫折 → 大脑进入可塑性状态 → 此时放弃 → 神经元连接到"容易放弃"的行为模式 → **恶性循环**

#### 关键事实

- 学习时乙酰胆碱标记需要改变的神经元，**具体重连接主要在休息和睡眠时发生**
- 25 岁后大脑神经可塑性大大下降

### 4.2 利用神经可塑性

#### ≤ 25 岁

- 神经可塑性仍然很好，可以广泛学习各种知识和技能
- 尽量找到最有兴趣的方向，后续再深入经营

#### > 25 岁：三种方法

| 方法 | 说明 | 示例 |
|------|------|------|
| 增量学习 | 每次学习内容不要太多，多次积累 | 每次视觉偏差只有 7°，不是 180° 大颠倒 |
| 高渴求度 | 达成目标的渴求度越高，可塑性越容易出现 | 为了生存（可操作性不高） |
| **前庭系统扰乱** | 让身体有"新颖的重力体验"，激发犯错信号 | 倒立、瑜伽、体操、滑板 |

- ⚠️ 前庭扰乱体验必须**新颖**，熟练后就不再有效
- 淘宝成立初期的"倒立文化"竟有科学依据

#### Huberman 的核心理念

> **Mood follows action.** 大脑链路：感知 → 认知 → 情感 → 思想 → 行动。与其用精神思想控制自己（"我不能分心"），不如从行动出发，利用神经系统原理反向影响。

### 4.3 学习的理想状态

- 不能太放松（昏昏欲睡），也不能太紧张（无法清晰思考）
- **生理叹息（Physiological Sigh）**：吸两口气 → 出一口长气，1-2 次即可迅速降低压力和警觉水平

#### 学习 Tips

- 学习时听有规律节拍，入睡时播放同样微弱节拍 → 提升记忆效果
- 90 分钟学习后 → 20 分钟 non-sleep deep rest → 加强学习效果
- **Gap Effect**：学习中随机停止 10 秒 → 这些停止会在睡眠中加速"播放"

### 4.4 提升专注

#### 两种网络模式

| 模式 | 激活条件 | 说明 |
|------|----------|------|
| Default Network | 不做任何事情时 | 发散思维 |
| Task Network | 专注于做某些事情时 | 集中注意力 |

- 正常人两者像跷跷板一样协调
- 多动症患者两者无法协调 → 无法专注

#### 安全有效的提升专注方法

| 方法 | 说明 |
|------|------|
| Omega-3 EPA 鱼油 | 神经细胞组成原料，减轻抑郁，帮助治疗 ADHD |
| 身体微运动 | 边运动边工作：半蹲半站更稳定；转笔、指尖陀螺、站立办公同理 |
| 限制视野范围 | 进入"专注模式"，避免消息提示分心 |
| 视线向上 | 显示器至少放在鼻子位置之上，提升警惕性 |
| 减少 context switch | 刷抖音式频繁切换对注意力有伤害 |
| 控制手机时间 | 青少年 < 60 分钟/天，成人 < 120 分钟/天 |
| **17 分钟冥想** | 能对大脑神经元重新连接，**永久改善注意力**，只要做一次 |

> ⚠️ "聪明药"（Adderall, Modafinil 等）能提升多巴胺促进专注，但会带来低谷、上瘾、新陈代谢扰动等负面影响，长期学习记忆效果可能并无提升，应谨慎使用。

## 5. 大脑健康

### 5.1 基础

- ✅ 保证高质量睡眠
- ✅ 每周 150-180 分钟有氧训练（提升心肺功能，支持大脑供能）

### 5.2 关键营养素

| 营养素 | 作用 | 食物来源 | 每日建议量 |
|--------|------|----------|-----------|
| Omega-3 EPA | 大脑组成重要部分 | 鱼、牡蛎、奇亚籽、核桃、大豆 | ≥1.5g，理想 3g+ |
| 磷脂酰丝氨酸 | 认知能力 | 鱼、肉类、卷心菜 | - |
| 乙酰胆碱 | 提升注意力 | **蛋黄**（最佳）、土豆、坚果、水果 | 可用 Alpha-GPC 补充 |
| 肌酸 | 不吃肉者需要补充 | - | 5g |
| 花青素 | 降低 DNA 损伤，缓解认知下降 | 蓝莓、黑莓、葡萄 | 60-120g 蓝莓 |
| 谷氨酰胺 | 缺氧下表现 + 抑制糖需求 | 牛肉、鸡肉、鱼、鸡蛋、大豆 | - |
| 水+电解质 | 神经元信号传递基础 | 钠、钾、镁 | 保证摄入 |

### 5.3 改变食物喜好

三个判断渠道：① 味觉判断 ② 营养成分下意识判断 ③ **多巴胺驱动的喜好形成**

- 不喜欢吃鱼 → 把鱼跟爱吃的食物一起吃 / 心理暗示吃鱼有益 → 大脑释放多巴胺 → 逐渐提升喜好程度

## 6. 长寿

> 来自 Huberman 对哈佛教授 David Sinclair 的访谈。
>
> ⚠️ **更新 2025-06-17**：关于 David Sinclair 教授及其倡导的白藜芦醇、NMN 等抗衰老产品的科学证据仍存在较大争议，请谨慎参考。

### 6.1 衰老的本质

Sinclair 认为：**衰老是一种疾病**，它导致了阿尔兹海默症、癌症等。

衰老 = 基因信息的损失：

| 类型 | 占比 | 说明 |
|------|------|------|
| DNA 本身的信息 | 20% | 辐射等情况下 DNA 结构被破坏 |
| **表观基因组（epigenome）** | **80%** | 控制哪些基因进行表达的信息被破坏 |

#### 衰老时钟

- 人体内有天然"衰老时钟"，**不是匀速的**
- 青春期发育越快 → 时钟走得越快 → 寿命相对短
- 一般比较矮小的人（如侏儒）很少得心脏病/癌症，明显更长寿
- 但基因本身只占 20%，控制基因表达占大多数

### 6.2 Fasting 与长寿

- Sinclair 实验室的老鼠 Yoda 活了 5 年（一般 2 年），主要做法：侏儒基因 + fasting

#### Fasting 提升寿命 30%+ 的机制

| 机制 | 效果 |
|------|------|
| 抑制 mTOR | 低血糖时触发 |
| 激活 sirtuin（去乙酰化酶） | 抵御衰老的重要武器 |
| 清理旧蛋白质 | autophagic 过程 |
| 提高胰岛素敏感度 | 更快吸收血糖 |
| 激活"长寿基因" | 如 SIRT1（胰岛素低时激活） |
| 深层清理机制 | 禁食第 2-3 天启动，可延长寿命 35%（老年老鼠实验） |

> [!important] 核心思想
> 现代长寿研究的核心：不是用抗氧化剂对抗衰老，而是**通过机制手段触发身体自身的衰老抵抗机制**。

### 6.3 抗衰老手段

#### 🥗 饮食

- 参考 Cell 论文：*Nutrition, longevity and disease: From molecular mechanisms to interventions*
- ✅ 多吃：植物蛋白（花生、藜麦、豆类）、脂肪（橄榄油、坚果、牛油果）
- ❌ 减少：精制碳水（白米饭、白面包、蛋糕）、动物脂肪、动物蛋白、糖

#### 🏃 体育锻炼

- 有氧运动：心肺功能、血管健康 → 每周 3 小时
- 力量训练：肌肉、关节、韧带保护 → 每周 2-3 次
- 有氧 + 力量搭配

#### 💊 药物

- 大多数还在人体实验早期
- 参考 Nature 论文：*The quest to slow ageing through drug discovery*
- 包括二甲双胍、NMN 等

#### 🧬 细胞重编程

- **山中因子（Yamanaka Factors）**：通过 Oct4、Sox2、c-Myc、Klf4 四种转录因子，将成体细胞转化为多能干细胞（iPS 细胞）
- iPS 细胞与胚胎干细胞拥有相似再生能力，理论上可分化为成体所有器官组织
- 相关公司：Life Biosciences、Altos Labs

### 6.4 Sinclair 的个人实践

| 项目 | 内容 |
|------|------|
| 饮食 | 不吃早饭，午饭少吃（酸奶/橄榄油），晚饭蔬菜为主+鱼虾；不吃糖、甜品、面包 |
| Fasting | 约 2 小时进食窗口；偶尔整天不吃 |
| 补充剂 | 白藜芦醇 1g + NMN 1g + 二甲双胍；锻炼日可能跳过 |
| 蔬菜为主食 | 富含营养 + 异种激素（Xenohormesis） |
| 运动 | 隔天有氧/力量交替 |
| 药物 | 根据家族病史（如 29 岁开始服用降胆固醇药物） |
| 生理年龄 | 实际 52 岁 → 生理 30 岁左右 |

#### 监控指标

- HbA1c（血糖）· CRP（炎症）· LDL（胆固醇）
- 膳食胆固醇对血液胆固醇几乎没有影响，不需要戒红肉/黄油
- ⚠️ 补充铁元素可能加速衰老
- 医学指标需要个性化

#### 负面因素

- 肥胖症加速衰老 · 吸烟破坏基因表达 · 不必要的 X 光检查

> 现代科学每年让平均寿命延长 1/4 年。如果延长超过 1 年/年 → 实现"永生"。Ray Kurzweil 预测约 2034 年实现。
>
