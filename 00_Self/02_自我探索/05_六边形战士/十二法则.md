> [!summary] 十二法则
> - **核心**：乔丹·彼得森结合认知神经科学、心理学、哲学和神话，提出的12条应对人生混乱与焦虑的法则
> - **出处**：《人生十二法则：解决人生80%的混乱与焦虑》| 浙江科学技术出版社 | 2023
> - **一句话**：哪怕其中一条被践行，生活也将发生神奇的改变

---

## 引言：意义来自痛苦中的成长

> 📌 人生需要更深层的意义，这种意义的本质反复出现在过去的伟大故事当中，而那些故事往往讨论的都是在痛苦中成长，而不是追求快乐。

- 遵循共同的准则可以让人们感到彼此是可预测的，每个人都在按照他人的期待和愿望行事——这样人们就可以合作，甚至和平地竞争
- 人们并不是在为了信仰而战，而是在努力协调信仰、期待和愿望之间的关系，使自己的期待和他人的行动保持一致

---

## 法则一：笔直站立，昂首挺胸
> *我总是失败怎么办？*

**全称**：获胜的龙虾从不低头

| 主题 | 核心 |
|------|------|
| 生物界的领地之争 | 从龙虾的支配等级看人类的竞争本能——大脑回路已进化数亿年 |
| 支配等级金字塔 | 地位低 → 血清素低 → 焦虑、脆弱、消耗更多能量应对压力 |
| 建立自我觉察 | 认识到自己的位置，才能有意识地改变 |
| 走出失败者模式 | 精神上的笔挺站立意味着睁大双眼看清生活的重任 |

> 📌 你需要不停预支为未来储备的能量，将其消耗在当下的高度戒备和慌张行事上

**行动**：先改变姿态和行为，再改变内心感受。

---

## 法则二：待己如助人
> *我总是委屈自己满足别人怎么办？*

**全称**：像照顾生病的宠物一样关心自己

| 主题 | 核心 |
|------|------|
| 混乱和秩序 | 世界的本质是混乱与秩序的平衡，人生就是在两者之间游走 |
| 认识你自己 | 理解自己的需求、边界和价值 |
| 自助者天助 | 先照顾好自己，才有能力帮助他人 |

> 📌 失败和崩溃很容易发生，但受伤的人们总是会坚持下去，这种奇迹般的坚韧值得受到由衷的赞赏。

**行动**：把自己当成一个值得照顾的人，像对待生病的宠物一样温柔而坚定。

---

## 法则三：与真心希望你好的人做朋友
> *我的好朋友堕落了怎么办？*

**全称**：放弃损友

| 主题 | 核心 |
|------|------|
| 荒芜青春 | 年轻人容易被”朋友”拖入深渊 |
| 摆脱”强迫性重复” | 人们会反复选择相似的有害关系模式 |
| 拯救 vs 虚荣 | 拯救他人可能是高尚的，也可能是虚荣的自我满足 |
| 建立互惠关系 | 真正的友谊是双向的、互相提升的 |

> 📌 人们年轻的时候既缺乏独立也缺少认知，因为还没来得及积累阅历与智慧、建立起个人标准，所以只好和他人做比较。

**行动**：选择那些真心希望你变得更好的人，远离消耗你的关系。

---

## 法则四：和昨天的自己比，别和今天的别人比
> *我比别人差怎么办？*

**全称**：战胜内心的批评家

| 主题 | 核心 |
|------|------|
| 与自我博弈 | 对手不是别人，是昨天的自己 |
| 追求什么决定看见什么 | 你的注意力方向决定了你看到的世界 |
| 走出认知困局 | 跳出和他人比较的陷阱 |
| 集中注意力，改善现状 | 关注自己能控制的小事，逐步积累改变 |

**行动**：每天问自己——“今天的我比昨天进步了什么？”

---

## 法则五：管教你家的小怪物
> *我没法对孩子说”不”怎么办？*

**全称**：别让孩子做出令你讨厌他的事

| 主题 | 核心 |
|------|------|
| 提升成本与收益比 | 社会规则的本质——行为有后果 |
| 建立规则与结构意识 | 孩子需要边界才能感到安全 |
| 管教五原则 | 最小必要力量、规则清晰、夫妻一致、社区支持、平衡爱与纪律 |

**行动**：管教不是惩罚，是教孩子学会在社会中生存。规则和边界是爱的另一种形式。

---

## 法则六：批判世界之前先清理你的房间
> *我对任何事都提不起兴趣怎么办？*

**全称**：当痛苦到想诅咒一切

| 主题 | 核心 |
|------|------|
| 存在的价值 | 在你能改变世界之前，先让自己变得有序 |
| 痛苦时如何抉择 | 痛苦不是停止行动的理由，而是开始行动的信号 |
| 清理你的生活 | 从你能控制的最小事情开始——整理房间、规律作息 |

> 📌 不合时宜的质疑不会带来启示，只会制造困惑，阻碍你的行动。

**行动**：先解决眼前可见的问题，再谈大的改变。

---

## 法则七：追求意义，拒绝苟且
> *上班让我不快乐怎么办？*

**全称**：苏格拉底的选择

| 主题 | 核心 |
|------|------|
| 延迟满足的价值 | 当下的快乐不等于长远的幸福 |
| 死亡、劳役与邪恶 | 人生的三大考验——你需要意义来承受 |
| 自由需要建立在约束之上 | 没有纪律的自由是混乱 |
| 超越当下，着眼未来 | 为未来的目标忍受当下的不完美 |

**行动**：选择一条有意义的路并承担后果，比反复分析更有意义。

---

## 法则八：说真话，或者至少别撒谎
> *我对自己的现状不满意怎么办？*

**全称**：不买醉鬼卖的东西

| 主题 | 核心 |
|------|------|
| 逃避还是说出真相 | 撒谎会扭曲你对现实的感知 |
| 拒绝欺骗 | 自我欺骗是最危险的谎言 |
| 选择真相 | 真相虽然痛苦，但它是唯一可靠的基础 |

**行动**：诚实面对自己的处境——不满意就去改变，而不是用谎言麻醉自己。

---

## 法则九：假设你聆听的人知道你不知道的事
> *我觉得周围的人总犯蠢怎么办？*

**全称**：别偷走来访者的问题

| 主题 | 核心 |
|------|------|
| 别给建议，选择聆听 | 倾听比建议更有力量 |
| 表达、思考、聆听自己 | 通过倾听他人来理解自己 |
| 确认对话动机 | 你想帮助对方，还是想证明自己正确？ |
| 共同探索，互惠互利 | 真正的对话是双方共同成长 |

**行动**：下次想说”你怎么这么蠢”时，停下来问：”你知道什么我不知道的？”

---

## 法则十：直面问题，言辞精确
> *我处于人生的至暗时刻怎么办？*

**全称**：不要无视地毯下的龙

| 主题 | 核心 |
|------|------|
| 复杂、多维的世界 | 问题不会因为忽视而消失 |
| 忽视问题是分崩离析的前兆 | 小问题积累成大灾难 |
| 精确分析、创造结构、重建秩序 | 用精确的语言描述问题，是解决它的第一步 |

**行动**：在至暗时刻，把模糊的恐惧转化成具体的问题清单，逐一面对。

---

## 法则十一：承认现实，反对偏见
> *面对他人的偏见怎么办？*

**全称**：不要打扰玩滑板的孩子们

| 主题 | 核心 |
|------|------|
| 被阻止的不只是玩滑板 | 过度保护会扼杀成长 |
| 可怕的反人类精神 | 用善意包装的控制欲 |
| “弱势群体”的陷阱 | 标签化会剥夺人的能动性 |
| 文化源于人类的创造 | 个体的创造力比任何制度都重要 |
| 小心单一因素解释 | 简单归因往往是错的 |
| 同情之罪 | 过度同情是一种伤害 |
| 坚毅而非软弱 | 未来需要的是韧性，不是脆弱 |

**行动**：尊重每个人面对挑战的权利，包括你自己。偏见用行动去打破，不是用语言。

---

## 法则十二：关注存在的善
> *我感到永不满足怎么办？*

**全称**：当你在街上遇到一只猫时，摸摸它

| 主题 | 核心 |
|------|------|
| 存在需要局限性 | 永不满足是人类的常态，但也是诅咒 |
| 用专注替代思考 | 停止无尽的分析，专注于眼前的美好 |
| 发现美好，平衡痛苦 | 在苦难中找到能让你微笑的小事 |

**行动**：在黑暗中看见光——摸摸路边的猫，看看傍晚的云，这些微小的善意是活着的理由。
