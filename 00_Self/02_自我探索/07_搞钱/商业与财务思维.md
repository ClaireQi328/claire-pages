>

# 商业与财务思维

> 供应链做久了，容易陷入"执行思维"——关注降本、交付、库存周转，却忽略背后的**商业逻辑**：钱从哪来、怎么流动、为什么有些生意赚钱有些不赚钱。这份学习路径帮你从"做事的人"升级为"懂生意的人"。

---

## 💡 核心认知

> [!tip]- 先搞清楚三个问题
> 1. **钱的本质**：不是数字，是**购买力的时间价值**。今天的 100 块 ≠ 明天的 100 块。
> 2. **商业的本质**：不是卖东西，是**用更低的成本创造更大的价值，再把差价留住**。
> 3. **财务的本质**：不是记账，是**用数字翻译一家公司的经营质量**。

## 二、阶段详解

### 🟢 阶段 1：建立金钱直觉

**核心问题**：为什么同样月薪 2 万，10 年后有人资产百万有人负债？

| 知识点 | 说明 | 学习方式 |
|--------|------|---------|
| 复利效应 | 72 法则：72÷年化收益=翻倍年数 | 计算练习 |
| 通货膨胀 | 购买力每年缩水 ~3%，现金是"隐形亏损" | 对比 10 年前后物价 |
| 机会成本 | 选择 A = 放弃 B 的收益 | 日常决策练习 |
| 沉没成本 | 已花的钱不影响未来决策 | 反思过去的消费决策 |
| 杠杆 | 借钱投资的放大效应和风险 | 房贷案例分析 |

**推荐资源**：

| 资源 | 类型 | 说明 |
|------|------|------|
| 《富爸爸穷爸爸》 | 书 | 金钱观启蒙，2 天可读完 |
| 《小狗钱钱》 | 书 | 德国人写的理财童话，通俗易懂 |
| 《金钱心理学》 | 书 | 摩根·豪瑟尔，理解人和钱的关系 |
| 《底层逻辑》- 刘润 | 书 | ✅ 已读，可回顾"商业篇"章节 |

---

### 🟢 阶段 2：看懂财报

**核心问题**：打开一份年报，数字在说什么？

**三张表，三个视角**：

| 报表 | 回答的问题 | 关键指标 |
|------|-----------|---------|
| 利润表 | 公司赚不赚钱？ | 营收、毛利率、净利率、费用率 |
| 资产负债表 | 公司家底多厚？ | 资产负债率、流动比率、商誉占比 |
| 现金流量表 | 钱是真的吗？ | 经营现金流 vs 净利润、自由现金流 |

**学习顺序**：

```
1. 先学利润表（最直观：收入-成本=利润）
2. 再学资产负债表（理解"家底"和"负债"）
3. 最后现金流量表（最难但最重要：利润可以造假，现金流很难）
```

**推荐资源**：

| 资源 | 类型 | 说明 |
|------|------|------|
| 《手把手教你读财报》- 唐朝 | 书 | 零基础友好，案例丰富 |
| 《财务报表分析与股票估值》- 郭永清 | 书 | 更系统，适合进阶 |
| 上交所/深交所投资者教育 | 网站 | 免费课程，有互动练习 |
| 巨潮资讯网 | 工具 | 下载上市公司年报实际练习 |

### 🟡 阶段 3：商业模式分析

**核心问题**：这家公司靠什么赚钱？这个模式能持续吗？

**分析框架**：

| 维度 | 问题 | 工具/方法 |
|------|------|---------|
| 价值创造 | 为客户解决了什么问题？ | 客户旅程地图 |
| 价值获取 | 怎么收费？利润率多高？ | 毛利率分析 |
| 护城河 | 别人能不能轻易复制？ | 波特五力、护城河理论 |
| 增长飞轮 | 业务之间有没有正循环？ | 飞轮图 |
| 单元经济 | 每一笔交易赚不赚钱？ | LTV/CAC 分析 |

**推荐资源**：

| 资源 | 类型 | 说明 |
|------|------|------|
| 《商业模式新生代》 | 书 | 商业模式画布，实操工具 |
| 《竞争战略》- 波特 | 书 | 经典，但较重，可先读摘要 |
| 《分析与思考》- 黄奇帆 | 书 | ✅ 已读，回顾产业逻辑部分 |
| 招商证券/中金研报 | 研报 | 免费看行业分析，学分析师怎么思考 |
| 36氪/虎嗅 | 媒体 | 商业案例分析，轻量阅读 |

### 🟡 阶段 4：估值与投资思维

**核心问题**：一家公司值多少钱？现在的价格是贵还是便宜？

| 概念 | 说明 | 直觉理解 |
|------|------|---------|
| PE（市盈率） | 股价÷每股收益 | 多少年回本 |
| PB（市净率） | 股价÷每股净资产 | 溢价多少买 |
| DCF（折现现金流） | 未来现金流折现到今天 | 公司的"内在价值" |
| 安全边际 | 价格 vs 内在价值的差距 | 打几折买才安全 |
| 能力圈 | 只投自己看得懂的 | 不懂的不碰 |

**推荐资源**：

| 资源 | 类型 | 说明 |
|------|------|------|
| 《聪明的投资者》- 格雷厄姆 | 书 | 价值投资圣经，巴菲特推荐 |
| 《巴菲特致股东的信》 | 书 | 用案例讲投资思维 |
| 《估值》- 达摩达兰 | 书 | NYU 教授，系统学估值 |
| 雪球/集思录 | 社区 | 真实投资者讨论，学实战视角 |

### 🔴 阶段 5：拆解真实案例（持续）

**用你最熟悉的公司练手**：

| 公司 | 切入角度 | 思考问题 |
|------|---------|---------|
| 小米 | 硬件低利润 + IoT 生态 + 互联网变现 | 为什么手机不赚钱小米还能活？ |
| 美团 | 本地生活的飞轮效应 | 外卖、到店、酒旅怎么协同？补贴战的终局是什么？ |
| 蔚来 | 换电模式 vs 充电模式 | 重资产投入的换电站，长期能不能跑通？ |
| 拼多多 | 极致低价 + 社交裂变 | 为什么能从淘宝京东嘴里抢肉？ |

**练习方法**：

```
1. 选一家公司，下载最近 3 年年报
2. 用阶段 2 的方法读完三张表
3. 用阶段 3 的框架分析商业模式
4. 用阶段 4 的方法估个值
5. 写成一篇分析笔记，存到对应文件夹
```

### 🔴 阶段 6：个人财务管理（持续）

**从记账到资产配置**：

| 层级 | 内容 | 工具/方法 |
|------|------|---------|
| L1 记账 | 知道钱花哪了 | 随手记 / MoneyForward |
| L2 预算 | 控制支出，提高储蓄率 | 50-30-20 法则 |
| L3 应急金 | 3-6 个月生活费 | 货币基金 / 活期存款 |
| L4 保险 | 转移大风险 | 医疗险 + 重疾险 + 意外险 |
| L5 投资 | 让钱生钱 | 指数基金定投入门 |
| L6 税务 | 合理节税 | 专项附加扣除、公积金最大化 |

> [!tip] 先从 L1 开始
> 你已经有 [[财务|财务与资产]] 的记录基础，现在要做的是**分类更细、定期复盘**。每月花 30 分钟看一次消费结构，比每天记账更重要。

## 五、常见误区

| 误区 | 真相 |
|------|------|
| "我不炒股，不需要学投资" | 投资思维 = 决策思维，适用于职业选择、买房、创业 |
| "财报太难，看不懂" | 三张表的核心指标不超过 10 个，2 周就能入门 |
| "商业模式是大公司的事" | 你的每份工作都是一个"商业模式"：投入时间，换取收入和成长 |
| "理财就是买基金股票" | 理财 = 管理现金流，保险、预算、税务都是理财的一部分 |
| "等有钱了再学" | 越早理解复利，时间越站在你这边 |

- [ ] **练习**：找到小米年报的资产负债表，提取：
  - 总资产、总负债、资产负债率、流动比率、商誉
- [ ] **练习**：找到小米年报的现金流量表，提取：
  - 经营现金流、净利润、两者比值（>1 为健康）
- [ ] **读书**：读完《手把手教你读财报》剩余章节（现金流量表 + 综合分析）
- [ ] **输出**：用下方 [[#模板：公司财报速读]] 模板完成小米年报速读
- [ ] **验收**：能看懂小米年报三张表，说出 5 个关键数字及其含义

### 🟡 阶段 3：商业模式分析（第 7-10 周）

- [ ] **读书**：读完《商业模式新生代》（重点：商业模式画布 9 格）
- [ ] **练习**：用商业模式画布分析你现在的公司（小米），填满 9 格

- [ ] **练习**：回答以下问题并写入笔记：
  - 小米的护城河是什么？是品牌、技术、成本优势还是网络效应？
  - 小米的飞轮怎么转？硬件→用户→IoT→互联网服务→更多用户？
  - 小米的单元经济：每卖一台手机赚多少？互联网服务 ARPU 是多少？
- [ ] **输出**：用下方 [[#模板：商业模式画布]] 完成小米商业模式画布
- [ ] **验收**：能用一页纸讲清楚小米的商业模式，让不懂行业的人也能理解

### 🟡 阶段 4：估值与投资思维（第 11-14 周）

- [ ] **读书**：读完《聪明的投资者》第 8 章（市场先生）和第 20 章（安全边际）
- [ ] **概念练习**：查小米当前股价，计算：
  - PE = 股价 ÷ 每股收益（EPS），和同行业对比
  - PB = 股价 ÷ 每股净资产，和同行业对比
- [ ] **阅读**：在雪球搜索"小米估值"讨论，读 3 篇不同观点的帖子

## 八、练习区

> [!example] 阶段 1 练习：复利 vs 通胀
>
> **题目**：小 A 每月存 2000 元，年化收益 5%，坚持 10 年。小 B 把钱存活期（年化 0.2%），也是每月 2000 元。10 年后两人各有多少？差多少？
>
> **计算过程**：
>
> ```
> 小 A（年化 5%，月复利）：
> 月利率 = 5% / 12 = 0.4167%
> n = 120 个月
> 终值 = 2000 × [(1.004167^120 - 1) / 0.004167]
> = 2000 × [1.6470 - 1] / 0.004167
> = 2000 × 155.28
> = 310,560 元
>
> 小 B（年化 0.2%，月复利）：
> 月利率 = 0.2% / 12 = 0.0167%
> 终值 = 2000 × [(1.000167^120 - 1) / 0.000167]
> ≈ 2000 × 121.10
> = 242,200 元
>
> 差额 = 310,560 - 242,200 = 68,360 元
> ```
>
> **结论**：同样的本金（24 万），5% 和 0.2% 的差距是 **6.8 万**——相当于白干 34 个月。这就是复利的力量，也是通胀的代价。
