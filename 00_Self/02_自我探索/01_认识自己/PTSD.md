# PTSD — 创伤后应激障碍

> **Post-Traumatic Stress Disorder (PTSD)**

> *创伤不是过去的事件——它是储存于神经系统中的、持续影响现在的能量。*
> — Peter Levine

---

## 一、定义与诊断框架

### 1.1 DSM-5 诊断标准

PTSD 是在经历 **实际或威胁的死亡、严重伤害或性暴力** 后出现的一组持续症状，分为 **四大症状簇**：

#### 标准 A：暴露于创伤事件（以下至少一种）

| 类型 | 说明 |
|------|------|
| 直接经历 | 自己亲身经历创伤性事件 |
| 目睹 | 亲眼目睹创伤性事件发生在他人身上 |
| 获悉 | 得知创伤性事件发生在亲密的人身上 |
| 反复暴露 | 反复接触创伤性事件的细节（如急救人员、战争报道记者） |

#### 标准 B：侵入性再体验（≥1 项）

| 症状 | 表现 |
|------|------|
| **侵入性记忆** | 反复出现的、不请自来的创伤记忆——通常以碎片化的感觉（画面、声音、气味）出现 |
| **噩梦** | 反复出现与创伤内容相关的噩梦 |
| **闪回** | 感觉创伤事件正在重新发生——可能伴随解离（失去现实感） |
| **心理痛苦** | 接触与创伤相关的线索时产生强烈的心理痛苦 |
| **生理反应** | 接触与创伤相关的线索时产生明显的身体反应（心跳加速、出汗、颤抖） |

#### 标准 C：回避（≥1 项）

| 类型 | 表现 |
|------|------|
| **回避内在提醒物** | 回避与创伤相关的想法、感受或记忆 |
| **回避外在提醒物** | 回避与创伤相关的人、地点、活动、物品 |

#### 标准 D：认知与情绪的负面改变（≥2 项）

| 症状 | 表现 |
|------|------|
| **无法回忆创伤细节** | 解离性遗忘——不是"忘记"，而是记忆碎片化无法完整提取 |
| **对自己/他人的负面信念** | "我是坏的""没有人可信""世界是危险的" |
| **持续的负面情绪状态** | 恐惧、恐惧、愤怒、内疚、羞耻 |
| **兴趣显著减少** | 对曾经重要的活动失去兴趣 |
| **与他人疏离** | 感觉与他人之间有不可逾越的障碍 |
| **正面情绪减少** | 无法体验快乐、满足、爱的感觉 |

#### 标准 E：警觉与反应性的显著改变（≥2 项）

| 症状 | 表现 |
|------|------|
| **易怒/愤怒爆发** | 对小刺激产生不成比例的愤怒反应 |
| **鲁莽/自毁行为** | 冲动驾驶、物质滥用、不安全性行为 |
| **过度警觉** | 持续扫描环境中的威胁——无法放松 |
| **惊跳反应增强** | 对突然的声音或运动反应过度 |
| **注意力困难** | 无法集中注意力——威胁监测占用认知资源 |
| **睡眠困难** | 入睡困难、频繁醒来、噩梦 |

#### 标准 F：持续时间 ≥ 1 个月

#### 标准 G：造成显著的功能损害

### 1.2 ICD-11 诊断标准

ICD-11 将 PTSD 定义为三个核心维度：

| 维度 | 症状 |
|------|------|
| **再体验** | 创伤记忆的侵入性再体验（闪回、噩梦），通常伴有强烈的恐惧感和躯体反应 |
| **回避** | 主动回避与创伤相关的提醒物 |
| **持续威胁感** | 持续的警觉状态——感到"危险近在咫尺" |

> **ICD-11 的重要变化**：ICD-11 将许多 DSM-5 PTSD 的症状（如情绪麻木、疏离感、负面信念）归入了 **C-PTSD**（复杂性创伤后应激障碍）的"自我组织障碍"维度。

### 1.3 PTSD 亚型

| 亚型 | 特征 | 发生率 |
|------|------|--------|
| **过度唤起型** | 主要表现为高警觉、惊跳反应、愤怒爆发、失眠 | 最常见 |
| **解离型** | 伴随显著的去人格化/去现实化——情感麻木、感觉不真实 | 约 12-30%（Lanius et al., 2010） |
| **延迟发作型** | 创伤后数月甚至数年才出现完整症状 | 约 25% 的 PTSD |
| **急性 PTSD** | 症状持续 1-3 个月 | — |
| **慢性 PTSD** | 症状持续 > 3 个月 | 不治疗则可能持续数十年 |

## 二、症状详细分析

### 2.1 再体验症状的神经机制

再体验是 PTSD 最具特征性的症状——创伤记忆不是被"放在过去"，而是持续侵入当下：

```
创伤事件
    ↓
┌─────────────────────────────────────────┐
│    记忆编码异常                           │
│    • 海马功能被应激激素抑制               │
│    • 情景记忆碎片化（时间/地点/情绪分离） │
│    • 感觉记忆（画面/声音/气味）异常增强   │
│    • 杏仁核过度编码情绪成分               │
└────────────────┬────────────────────────┘
                 ↓
┌─────────────────────────────────────────┐
│    正常人：创伤记忆 → 有时间标记           │
│    "那是过去的事"                          │
│                                            │
│    PTSD：创伤记忆 → 无时间标记             │
│    "感觉正在发生"（因为海马未能标记时间）  │
└────────────────┬────────────────────────┘
                 ↓
           闪回/噩梦/侵入
```

**核心研究**：
- Ehlers & Clark (2000) 的 PTSD 认知模型：创伤记忆的碎片化编码导致侵入性再体验
- Brewin et al. (2010) 的双表征理论：创伤记忆同时以情境化（语言/叙事）和感觉化（碎片/感官）两种方式编码，PTSD 中感觉化编码过度占主导
- Rauch et al. (2006)：PTSD 患者观看创伤线索时杏仁核过度激活、vmPFC 激活减弱

### 2.2 回避症状的功能

```
回避行为的功能循环：

    创伤提醒物（内在/外在）
         ↓
    杏仁核激活 → 恐惧/痛苦
         ↓
    回避 → 短期焦虑减轻（负强化）
         ↓
    杏仁核恐惧记忆未被消退
         ↓
    回避范围扩大 → 功能持续受损
         ↓
    世界越来越小
```

**关键概念**：
- **负强化循环**：回避行为通过减轻焦虑被强化——但同时也阻止了恐惧记忆的自然消退
- **恐惧消退失败**：Milad & Quirk (2012) 的研究表明，PTSD 中前额叶-杏仁核的恐惧消退通路受损——vmPFC 无法有效地"关闭"杏仁核的恐惧反应
- **行为收缩**：回避范围随时间扩大——从回避特定地点到回避所有可能引发回忆的情境

### 2.3 过度警觉的神经基础

| 症状 | 神经基础 | 研究 |
|------|---------|------|
| **持续扫描威胁** | 杏仁核持续激活 + 前额叶调控不足 | Shin et al. (2005) |
| **惊跳反应增强** | 脑桥网状核-杏仁核通路过度敏感 | Grillon & Baas (2003) |
| **睡眠困难** | 蓝斑-去甲肾上腺素系统持续过度活跃 | Germain (2013) |
| **注意力困难** | dlPFC 资源被威胁监测占用 | Aupperle et al. (2012) |
| **愤怒爆发** | 杏仁核对微小挑衅过度反应 + ACC 冲突监测异常 | Coccaro et al. (2017) |

参见 [[前额叶]] 中症状 1（创伤滤镜）、症状 3（杏仁核劫持）、症状 8（耐受窗口）的详细分析。

### 2.4 认知与情绪症状

| 症状 | 认知机制 | 表现 |
|------|---------|------|
| **负面信念** | 创伤改变了基本世界假设（Janoff-Bulman, 1992） | "世界是危险的""我不值得活""没有人可以信任" |
| **解离性遗忘** | 海马功能被应激激素抑制 → 情景记忆碎片化 | 无法按时间顺序叙述创伤经历 |
| **情绪麻木** | 情感性回避——大脑通过"关闭"情感来减少痛苦 | 无法感受爱、快乐、悲伤——"一切都无所谓" |
| **与他人疏离** | "没有人能理解我经历过什么" | 退缩、孤立 |
| **内疚/羞耻** | 生存者内疚；创伤后意义感崩塌 | "为什么活下来的是我？""我做了什么才遭受这些？" |

## 三、成因

### 3.1 为什么有些人发展出 PTSD，有些人不会？

> **关键事实**：暴露于创伤事件的人中，约 **50-90%** 会经历至少一种创伤后症状，但只有约 **6-9%** 最终发展为 PTSD（Kessler et al., 2017）。这意味着存在大量的 **保护因素** 和 **风险因素**。

### 3.2 风险因素

```
                PTSD 的风险-保护因素模型
                         │
          ┌──────────────┼──────────────┐
          ↓              ↓              ↓
    创伤前因素        创伤中因素       创伤后因素
          │              │              │
   ┌──────┴──────┐ ┌─────┴─────┐ ┌─────┴─────┐
   │遗传/气质     │ │创伤严重度  │ │社会支持    │
   │先前创伤史   │ │创伤类型    │ │获得治疗    │
   │精神疾病史   │ │持续时间    │ │安全环境    │
   │性别（女性   │ │是否人际    │ │应对方式    │
   │  风险高2倍）│ │ 暴力      │ │           │
   │年龄（青年   │ │生命威胁感  │ │           │
   │  更脆弱）  │ │           │ │           │
   └─────────────┘ └───────────┘ └───────────┘
```

#### 具体风险因素

| 因素 | 类型 | 风险增加程度 |
|------|------|-------------|
| **既往创伤史** | 创伤前 | 显著增加——"创伤敏感化"效应 |
| **不安全依恋** | 创伤前 | 增加 2-3 倍——见 [[前额叶]] 中依恋创伤的分析 |
| **女性** | 创伤前 | PTSD 发病率是男性的 2 倍（Kessler et al., 1995） |
| **精神疾病家族史** | 创伤前 | 增加——特别是焦虑和抑郁家族史 |
| **人际暴力（vs 意外事故）** | 创伤中 | 增加——人际暴力创伤更可能发展为 PTSD |
| **创伤持续时间** | 创伤中 | 持续越久风险越高 |
| **感知到的死亡威胁** | 创伤中 | 最强的预测因子之一 |
| **创伤后社会支持不足** | 创伤后 | 最强的保护因素缺失——社会支持是最重要的保护因子 |

### 3.3 神经生物学模型

#### 恐惧条件化与消退模型

```
正常恐惧学习：                    PTSD 恐惧学习：
                                 
刺激 → 杏仁核 → 恐惧反应         刺激 → 杏仁核 → 恐惧反应（过度）
         ↓                                ↓
   前额叶抑制（消退）              前额叶抑制失败
         ↓                                ↓
   "这个刺激现在安全了"            "这个刺激永远危险"
         ↓                                ↓
   恐惧记忆被下调                  恐惧记忆持续活跃
```

**关键研究**：
- Milad & Quirk (2012)：vmPFC 的恐惧消退功能在 PTSD 中受损
- Jovanovic et al. (2012)：PTSD 患者的恐惧辨别能力降低——安全信号被错误编码为威胁
- Rauch et al. (2006)：PTSD 的神经环路模型——杏仁核过度激活 + vmPFC 功能减弱 + 海马体积减小

#### HPA 轴失调

| 发现 | 说明 |
|------|------|
| **皮质醇基线偏低** | 与直觉相反——PTSD 患者的基线皮质醇常常偏低（Yehuda et al., 2015） |
| **糖皮质激素受体敏感性增加** | 负反馈增强——HPA 轴对皮质醇更敏感，更早"关闭" |
| **地塞米松抑制增强** | 低剂量地塞米松即可过度抑制皮质醇——HPA 轴过度敏感 |
| **皮质醇治疗窗口** | 部分研究探索在创伤后早期给予皮质醇来预防 PTSD（Zohar et al., 2011） |

#### 神经递质系统

| 系统 | 异常 | 影响 |
|------|------|------|
| **去甲肾上腺素** | 蓝斑系统过度活跃 | 过度警觉、惊跳反应、睡眠困难 |
| **5-羟色胺** | 功能降低 | 情绪调节困难、冲动性增加 |
| **GABA** | 可能减少 | 焦虑增加、前额叶抑制不足 |
| **谷氨酸** | NMDA 受体异常 | 恐惧记忆的异常巩固/消退 |
| **内源性阿片** | 系统异常 | 可能与解离和麻木相关 |

### 3.4 认知模型——Ehlers & Clark (2000)

Ehlers & Clark 的认知模型是理解 PTSD 最有影响力的理论之一：

```
创伤事件
    ↓
记忆编码异常 + 对事件的负性评价
    ↓
┌─────────────────────────────────────┐
│  记忆异常：                          │
│  • 感觉碎片化（无法连贯叙述）         │
│  • 缺少时间标记（感觉"正在发生"）     │
│  • 与原始情绪强度紧密绑定             │
├─────────────────────────────────────┤
│  负性评价：                          │
│  • 对创伤本身的评价（"我彻底毁了"）   │
│  • 对创伤后反应的评价（"我要疯了"）   │
│  • 对世界的评价（"到处是危险"）       │
└────────────────┬────────────────────┘
                 ↓
    ┌────────────┴────────────┐
    ↓                         ↓
再体验/侵入               回避/麻木
（记忆碎片侵入             （回避可能
  当下体验）                触发记忆
    ↓                      的一切）
    ↓                         ↓
    └──── 维持循环 ←──────────┘
         （回避阻止了记忆的
          自然整合和消退）
```

## 四、PTSD 的特殊类型

### 4.1 单次创伤 PTSD vs 复杂创伤 PTSD

| 维度 | 单次创伤 PTSD | 复杂创伤相关 PTSD |
|------|-------------|------------------|
| **创伤类型** | 事故、自然灾害、单一暴力事件 | 反复的、持续的创伤（虐待、战争、家暴） |
| **发病时间** | 任何年龄 | 通常童年期或长期暴露 |
| **核心症状** | 标准 PTSD 四簇症状 | PTSD + 情绪调节困难 + 关系困难 + 身份认同 |
| **治疗反应** | 对标准创伤聚焦治疗反应好 | 可能需要阶段化、长程治疗 |
| **诊断** | DSM-5 PTSD | 部分可能符合 C-PTSD（见 [[CPTSD]]） |

### 4.2 性别差异

| 维度 | 女性 | 男性 |
|------|------|------|
| **发病率** | 10-12% | 5-6% |
| **常见创伤类型** | 性暴力、童年虐待 | 战斗、事故、暴力犯罪 |
| **症状表现** | 更多再体验和回避；更多抑郁共病 | 更多愤怒爆发和物质滥用；更多情感麻木 |
| **求助行为** | 更倾向于求助 | 更倾向于自我药疗（酒精） |

### 4.3 特殊人群

| 人群 | 特殊考虑 |
|------|---------|
| **儿童 PTSD** | 可能表现为游戏中的重复创伤主题；退行性行为；发展倒退 |
| **退伍军人** | 战斗 PTSD + 道德损伤（moral injury）；高自杀风险 |
| **急救人员** | 反复暴露创伤——累积效应；组织文化可能不鼓励求助 |
| **性暴力幸存者** | 羞耻感强烈；身体感觉可能成为创伤触发物 |

## 五、PTSD 的循证治疗

### 5.1 主要心理治疗

| 治疗 | 机制 | 证据 | 适合人群 |
|------|------|------|---------|
| **认知加工治疗（CPT）** | 识别和改变与创伤相关的"卡点"信念（stuck points） | ★★★★★ | 以认知症状为主者 |
| **延长暴露治疗（PE）** | 在安全环境中反复面对创伤记忆和回避的情境——促进恐惧消退 | ★★★★★ | 以回避和恐惧为主者 |
| **EMDR** | 双侧刺激促进创伤记忆的适应性加工——无需详细叙述创伤 | ★★★★★ | 不愿详细叙述创伤者 |
| **叙事暴露治疗（NET）** | 通过讲述人生故事整合创伤记忆——将碎片化记忆放入时间线 | ★★★★☆ | 多重创伤暴露者（如难民） |
| **认知治疗（CT）** | Ehlers & Clark 模型的治疗应用——改变创伤记忆的编码和负性评价 | ★★★★☆ | 以认知偏差为主者 |

### 5.2 暴露治疗的原理

```
恐惧消退学习过程：

暴露前：                      暴露后：
刺激 → 杏仁核 → 恐惧           刺激 → 杏仁核 → 恐惧
                ↓                              ↓
         "没有安全"                  vmPFC 介入 → 消退
                ↓                              ↓
         回避（强化恐惧）             "这个刺激现在安全了"
                                            ↓
                                    新的记忆 → 抑制旧的恐惧记忆
                                    （不是删除，是覆盖）
```

**关键研究**：
- Milad & Quirk (2012)：vmPFC 在恐惧消退中的关键作用
- Foa et al. (2007)：PE 治疗 PTSD 的 RCT 证据
- Shapiro (2014)：EMDR 的神经生物学机制

### 5.3 药物治疗

| 药物 | 作用 | 证据 |
|------|------|------|
| **舍曲林（Sertraline）** | SSRI——增强 5-HT 功能 | FDA 批准用于 PTSD |
| **帕罗西汀（Paroxetine）** | SSRI | FDA 批准用于 PTSD |
| **文拉法辛（Venlafaxine）** | SNRI——同时作用于 5-HT 和 NE | 有效的替代选择 |
| **哌唑嗪（Prazosin）** | α1-肾上腺素受体拮抗剂 | 专门针对 PTSD 噩梦——部分证据 |
| **氯胺酮（Ketamine）** | NMDA 受体拮抗剂 | 新兴研究——快速起效的抗抑郁/抗PTSD效果 |

> ⚠️ **重要提醒**：药物是辅助——心理治疗是 PTSD 的一线治疗。单纯药物治疗的效果不如心理治疗。

### 5.4 新兴治疗

| 治疗 | 机制 | 证据状态 |
|------|------|---------|
| **MDMA 辅助心理治疗** | MDMA 降低杏仁核激活、增强信任和共情——促进治疗中的创伤加工 | Ⅲ期临床试验完成（2023），FDA 审查中——可能是 PTSD 治疗的突破 |
| **迷走神经刺激（VNS）** | 刺激迷走神经 → 增强副交感神经功能 | 早期研究 |
| **经颅磁刺激（TMS）** | 刺激 dlPFC → 增强前额叶调控功能 | 部分证据支持 |
| **裸盖菇素辅助治疗** | 增强神经可塑性、改变默认模式网络 | 早期临床试验 |
| **VR 暴露治疗** | 虚拟现实重建创伤环境——增强暴露的真实性 | 有 RCT 证据，特别适合战斗 PTSD |

## 六、自助与应对策略

### 6.1 日常管理

| 策略 | 操作 | 原理 |
|------|------|------|
| **稳定化技术** | 建立日常规律——固定睡眠/饮食/运动时间 | 可预测性降低 HPA 轴过度激活 |
| **着陆技术** | 5-4-3-2-1 感官着陆（看5样→摸4样→听3声→闻2味→尝1味） | 将注意力从内部创伤拉回当下 |
| **安全基地想象** | 闭眼想象一个让你感到完全安全的地方——详细到每一个感觉 | 激活 vmPFC 的安全感回路 |
| **躯体调节** | 每天30分钟有氧运动 + 10分钟深呼吸/瑜伽 | 增强迷走神经张力、降低基线焦虑水平 |
| **写日记** | 记录情绪和触发——不强求叙述创伤，只是当下觉察 | 外化到纸面降低杏仁核激活 |

### 6.2 闪回/噩梦时的急救

```
┌───────────────────────────────────────┐
│         闪回急救方案                    │
├───────────────────────────────────────┤
│                                        │
│  第1步：识别"这是闪回"                  │
│  → 告诉自己："这不是正在发生的事。       │
│     这是我的大脑在播放旧的录像带。"      │
│                                        │
│  第2步：着陆                            │
│  → 5-4-3-2-1 感官着陆                  │
│  → 双脚踩在地面上                       │
│  → 摸一个粗糙的物体（钥匙/石头）        │
│                                        │
│  第3步：安全化                          │
│  → "我现在是安全的"                     │
│  → 看看周围——这是什么地方？今天几号？   │
│  → 说出5个你现在能看到的东西            │
│                                        │
│  第4步：身体调节                        │
│  → 冷水敷脸（激活潜水反射）             │
│  → 方形呼吸：吸4-屏4-呼4-屏4           │
│  → 或：双手交叉拍膝盖（左右交替）       │
│                                        │
│  第5步：回到当下                        │
│  → 有什么我可以做的小事？               │
│  → 起来走走/喝杯水/和人说说话           │
│                                        │
│  事后：写下来发生了什么                 │
│  → 触发物是什么？→ 闪回持续了多久？     │
│  → 什么帮助了我？→ 下次可以怎么做？     │
│                                        │
└───────────────────────────────────────┘
```

### 6.3 应对回避

| 策略 | 操作 |
|------|------|
| **恐惧阶梯** | 列出所有回避的情境 → 按焦虑程度排序（0-10）→ 从最低的开始逐步面对 |
| **渐进暴露** | 每周面对一个情境——从焦虑 3/10 的开始 |
| **内在暴露练习** | 在安全环境中回忆创伤记忆（从最不痛苦的开始）——促进记忆的重新整合 |
| **安全行为识别** | 识别你在回避情境中使用的"安全行为"（如总坐在门口旁、不停查看手机）→ 逐步减少 |

### 6.4 社会支持

| 策略 | 操作 |
|------|------|
| **选择性分享** | 不需要和所有人分享创伤——选择 1-2 个信任的人 |
| **支持团体** | 与有类似经历的人连接——减少"只有我这样"的孤立感 |
| **伴侣/家人教育** | 让亲近的人了解 PTSD——"我的反应不是针对你的" |
| **边界设定** | "我现在不想谈这个"是完全合理的——选择何时、如何分享 |

## 七、PTSD 的预防

### 7.1 创伤后早期干预

| 干预 | 时机 | 证据 |
|------|------|------|
| **心理急救（PFA）** | 创伤后即刻 | 提供安全感、平静、自我效能、连接、希望——不强制叙述创伤 |
| **单次暴露治疗（SSET）** | 创伤后 2-4 周 | 在急性应激反应中早期暴露可能预防慢性 PTSD |
| **皮质醇** | 创伤后即刻（实验性） | Zohar et al. (2011)：创伤后早期给予皮质醇可能预防 PTSD |
| **睡眠** | 创伤后即刻 | 睡眠促进创伤记忆的正常整合——尽量保证创伤后的睡眠质量 |

### 7.2 不推荐的"干预"

| 不推荐 | 原因 |
|--------|------|
| **强制心理汇报（Critical Incident Stress Debriefing, CISD）** | Cochrane 系统综述发现其无效甚至可能有害——强制叙述可能干扰自然恢复过程 |
| **"你需要马上说出来"** | 不是每个人都需要立即叙述——尊重个体的应对方式 |
| **"时间会治愈一切"** | PTSD 不治疗可能持续数十年——需要主动干预 |

## 十一、关键认知

### ✅ 事实

- PTSD 是 **大脑对创伤的正常反应**——不是"弱点"或"不够坚强"
- PTSD 是可治疗的——多种循证治疗有良好的效果
- 创伤后 **大多数人的症状会自然消退**——只有少数发展为慢性 PTSD
- 社会支持是 **最强的保护因素**——有好的支持系统的创伤暴露者 PTSD 发病率显著降低
- 治疗 **不是删除创伤记忆**——而是帮助大脑以健康的方式整合记忆

### ❌ 误解

- ~~"只有老兵才有 PTSD"~~ → 任何经历创伤的人都可能发展 PTSD
- ~~"坚强的人不会得 PTSD"~~ → PTSD 有神经生物学基础——与"坚强"无关
- ~~"谈论创伤只会更糟"~~ → 在专业指导下聚焦地面对创伤记忆是治疗的核心
- ~~"PTSD 是终身的"~~ → 多数人在治疗后显著改善——完全康复是可能的
