# 物联网技术与发展趋势

Course Info

本课程以介绍各个行业中的物联网建设案例为主轴，讲述实例中所用到的传感器、RFID、

室内/室外定位系统、无线网络、云计算、人机交互、物联网安全、人工智能、区块链等

技术。行业案例将以智慧工地、智慧物流、智慧医疗为主；技术上将讨论基本原理、商

用模块性能、及相关前沿研究。本课程的目标为，在同学们修完课后有能力写一份

"公司物联网建设提案书"，提出一套从物联网架构规划、执行、到维护均有理有据的企划。

专业名词

| 专业名称 |  |
|---|---|
| Shannon capacity | 信息论和通信技术中最核心、最深刻的概念之一。香农容量（Shannon Capacity），通常也叫做信道容量（Channel Capacity），由克劳德·香农在他1948年的开创性论文《通信的数学理论》中提出。它回答了通信领域的一个根本性问题：在给定的有噪声信道中，理论上最高可以达到的无差错传输速率是多少？ |
| polar coding | 突破性进展：上世纪90年代出现了两大接近香农极限的编码方案：Turbo码（1993）：通过并行级联卷积码和迭代解码，性能极度接近香农极限，被采纳为3G和4G移动通信标准。LDPC码（Low-Density Parity-Check code，1960年提出，90年代重新发现）：由香农的同事罗伯特·加拉格（Robert Gallager）提出，但被遗忘多年。后来因其优异的性能和可并行解码的特性，被广泛用于Wi-Fi（802.11n/ac/ax）、5G、光通信等领域。Polar码（极化码，2008）：由埃尔达尔·阿里坎（Erdal Arıkan）提出，是第一种被严格证明可以达到香农容量的编码方案（在特定信道下）。华为是其主要推动者，并被选为5G控制信道的编码方案。 |
| wireless sensing | 无线传感（Wireless Sensing）是一项利用环境中无处不在的无线射频信号（如Wi-Fi、4G/5G、蓝牙、雷达等）来“感知”物理世界、识别目标状态与行为的技术。它使通信基础设施同时成为了感知物理世界的“传感器”，是实现通感一体化（ISAC） 和万物互联智能化的关键支柱。 |
| Mobile computing | 移动计算（Mobile Computing）是指人们在移动中通过便携设备（如智能手机、平板电脑、可穿戴设备等）随时随地访问、处理和交换信息的技术领域。它融合了移动通信、硬件设计、软件开发和云计算，核心目标是实现 “无处不在的计算” （Ubiquitous Computing）。移动计算正经历一场由 人工智能（AI） 和 5G-A 技术驱动的深刻变革，从传统的连接工具向智能化的综合信息服务平台演进 |

应用场景

| 应用场景 |
|---|
| 智慧医疗与健康护理：无线传感在医疗领域的应用包括生命体征监测和智能护理。例如，基于毫米波雷达的生命体征监测系统通过多点反射模型，有效应对了人体轻微运动导致的信号波动问题，实现了长期心率和心率变异性（HRV）的稳健监测。罗彻斯特大学和英特尔公司也开发了智能医疗房间和家庭护理技术，通过嵌入传感器监测居住者的重要征兆和活动状况。 |
| 智能工业与智慧城市：在复杂工业环境（如煤矿井下、地铁隧道）中，无线传感技术用于实现高速可靠通信与精确定位。在智慧城市领域，无线传感器网络应用于环境监测、智能建筑、智能交通等领域，例如监测农作物中的害虫、土壤的酸碱度和施肥状况，或实现智能交通管理。 |
| 军事与安防：无线传感器网络具有密集型、随机分布的特点，使其非常适合应用于恶劣的战场环境中，包括侦察敌情、监控兵力、装备和物资，判断生物化学攻击等多方面用途。美国国防部已投资研发相关的传感器技术。 |
| 低空经济与车联网：通感融合技术被寄望于支持低空无人机监管、车联网协同避障等场景。电信设备商正积极开发相关应用技术。 |

发展挑战

| 发展挑战 |
|---|
| 环境依赖与泛化能力：无线信号特征易受环境的影响，导致感知结果依赖部署环境，泛化能力差、学习训练成本高。 |
| 隐私与安全问题：随着无线传感技术的普及，数据隐私和安全问题日益凸显。需要构建抗攻击通信体系，实现隐私保护与服务质量的协同优化。 |
| 技术标准化与产业化：通感融合技术目前仍处于早期探索阶段，首版6G标准预计2028年底才会出现。产业化方面需要聚焦低成本、高效益的应用场景。 |

发展趋势

| 发展趋势 |
|---|
| 深度融合通信与感知：通感一体化（ISAC）将成为6G网络的核心特征，推动无线网络从“连接”向“连接+感知”转型。 |
| 低功耗与无源传感：无源物联网技术通过采集环境中的能量（如光能、无线电波能量）为传感器供电，有望显著降低部署和维护成本。 |
| 人工智能深度集成：AI将进一步与无线传感融合，实现轻量级、自适应、可解释的感知模型，提升在复杂环境下的感知能力。 |

感-传-算

“感-传-算” 正是物联网（IoT）最核心的技术架构链条，也是理解其演进趋势的关键。这三个字高度概括了物联网如何工作：感知物理世界 -> 传输数据 -> 计算处理并产生价值。

当前，物联网的发展正是围绕这条核心链条，在每一个环节都发生着深刻的变革，并从简单的“串联”走向“协同与融合”。

下面我们分别从这三个环节来看看当前的发展水平和趋势：

![图片展示了物联网核心架构，分为感知层、传输层、计算层。感知层从单一传感（温度、湿度等）到多模态融合（温度、湿度、光感等），再到感算一体（左脑感知、右脑计算），最后是无源物联网（日用电器设备）。传输层有连接技术多、通信一体化（Sensing等）等。计算层有云计算、边缘计算、端侧计算等。该图与上下文紧密相关，直观呈现了物联网感知层的发展趋势。](C7l8bHqthomdv1x8ESmceId6n2c)

感 (感知层/Sensing) - “五官”的进化

这是物联网的起点，负责采集物理世界的各种信息。

传统水平：使用各种传感器（温度、湿度、压力、运动、光感等）和识别技术（RFID、二维码）来获取数据。传感器多为单一功能、被动采集。当前趋势与进化：智能化 (AI at the Edge)：传感器本身变得“聪明”。感算一体（ Sensing and Computing Integration）成为重要方向。在传感器端集成低功耗AI芯片，可以在采集数据的瞬间就进行初步的识别和分析（例如，摄像头直接识别人脸、车辆，而不是仅仅拍下视频流上传），极大减少了数据传输量和延迟。多模态融合：不再是单个传感器独立工作，而是摄像头、雷达、激光雷达（LiDAR）、麦克风阵列等多种传感器协同感知，融合数据，以更全面地理解环境，提高感知的准确性和可靠性。（例如，自动驾驶和机器人就是多模态融合的典型应用）“无源物联网”：这是极具潜力的前沿方向。传感器无需内置电池，而是通过采集环境中的能量（如光能、温差能、振动能、甚至无线电波能量）来工作。这使得未来万物互联的成本、维护难度和环境影响得以大幅降低。

传 (传输层/Transmission) - “神经”的扩展

负责将感知层采集到的数据可靠、高效、低功耗地传输到计算层。

传统水平：网络技术选择有限，存在覆盖、功耗、成本的“不可能三角”。Wi-Fi、蓝牙适用于短距离高速场景，蜂窝网络（2G/3G/4G）覆盖广但功耗高，LPWAN（如LoRa、NB-IoT）解决了低功耗广覆盖问题但速率低。当前趋势与进化：技术多元化与协同：没有一种网络能通吃所有场景，因此多种技术互补共存成为主流。5G（尤其是为物联网设计的RedCap标准）提供了高速率、低延迟的新选择；卫星物联网（如星链）补足了海洋、荒漠等偏远地区的覆盖盲区。通感一体化 (Integrated Sensing and Communication, ISAC)：这是6G的核心愿景之一，也是“传”这一环节的革命性变化。它让通信和感知（雷达等功能）共享同一套硬件和频谱资源。通信信号本身同时用于感知环境，未来基站等通信设备在为你提供网络的同时，也能感知你的手势、姿态、速度，实现无感交互和高精度定位。这模糊了“感”与“传”的边界。

算 (计算层/Computing) - “大脑”的分布

负责处理、分析数据，并最终形成决策或洞见，这是产生价值的核心。

传统水平：计算主要集中在云端（Cloud Computing）。所有数据无论大小，都传回云端的数据中心进行处理。这种方式对带宽压力大，且延迟高。当前趋势与进化：云边端协同 (Cloud-Edge-Device Collaboration)：计算能力正在从集中的云端，下沉到整个“感-传-算”链条的各个位置，形成协同计算的体系。云：依然是大脑中枢，负责海量数据的长期存储、复杂模型训练和大规模全局调度。边（边缘计算/Edge Computing）：在更靠近数据源头的网络边缘侧（如基站、路由器、本地服务器）设立节点，处理实时性要求高的任务（如工业质检），减轻云的压力，降低延迟。端（终端计算）：就是在“感”这一层提到的感算一体，在设备端直接进行处理和初步AI推理，实现极致的实时性和隐私保护。AI赋能：计算的内容不再是简单的数据处理，而是复杂的AI推理和决策。AI模型让物联网系统能够预测性维护、自动优化流程、识别异常模式，真正实现从“连接”到“智能”的飞跃。
