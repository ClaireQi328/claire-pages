代码整体功能

这段代码使用预训练的 ResNet 模型（ONNX格式）对输入图像进行分类，并输出概率最高的5个预测结果。

1. 导入依赖库

import onnxruntime as ort  # ONNX模型推理引擎import numpy as np         # 数值计算import scipy.special       # 特殊数学函数（这里用softmax）from PIL import Image      # 图像处理

2. 图像预处理函数

def preprocess_image(image, resize_size=256, crop_size=224,                     mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]):

这个函数将输入图像转换为模型需要的格式，流程如下：

步骤详解：

image.resize((256, 256)) - 先将图像缩放到256x256image.crop() - 中心裁剪到224x224（标准ImageNet尺寸）np.array(image).astype(np.float32) - 转换为float32格式的numpy数组image / 255.0 - 归一化到[0,1]范围(image - mean) / std - 使用ImageNet数据集的均值和标准差进行标准化np.transpose(image, (2, 0, 1)) - 维度变换，从(H,W,C)变为(C,H,W)reshape((1,) + image.shape) - 添加batch维度，变成(1,3,224,224)

3. 模型加载和配置

session = ort.InferenceSession('resent.onnx')  # 加载ONNX模型# 读取类别标签（1000个ImageNet类别）with open('labels.txt') as f:    labels = [line.strip() for line in f.readlines()]# 获取输入输出名称input_name = session.get_inputs()[0].name    # 通常是"input"等output_name = session.get_outputs()[0].name  # 通常是"output"等

4. 图像处理和推理流程

# 加载并转换图像image = Image.open('img_test.jpg').convert('RGB')# 预处理processed_image = preprocess_image(image)processed_image = processed_image.astype(np.float32) # 确保数据类型# 模型推理output = session.run([output_name], {input_name: processed_image})[0]

这里session.run()执行模型推理，输入是预处理后的图像数据。

5. 后处理和分析结果

# 应用softmax将输出转换为概率分布probabilities = scipy.special.softmax(output, axis=-1)# 获取前5个最可能的类别top5_idx = np.argsort(probabilities[0])[-5:][::-1] # 概率从高到低的索引top5_prob = probabilities[0][top5_idx] # 对应的概率值# 输出结果print("Top 5 predicted classes:")for i in range(5): print(f"{i+1}: {labels[top5_idx[i]]} - Probability: {top5_prob[i]}")

关键技术点说明

1. ONNX Runtime 优势

跨平台: 可以在CPU/GPU上运行，支持多种硬件性能优化: 针对推理场景高度优化模型互通: 支持来自PyTorch、TensorFlow等框架转换的模型

2. 预处理的重要性

# 标准化处理 - 这与模型训练时的预处理必须一致(image - mean) / std

这里的mean和std是ImageNet数据集的统计值，使用不同的值会导致性能下降。

3. 维度变换的意义

# 从 (224, 224, 3) 变为 (3, 224, 224) 再变为 (1, 3, 224, 224)# PIL图像格式 → 通道优先格式 → 批处理格式# [高度,宽度,通道] → [通道,高,宽] → [批次,通道,高,宽]

这段代码展示了一个完整的图像分类pipeline，从图像加载、预处理、模型推理到结果解析，是深度学习模型部署的典型范例。

import onnxruntime as ortimport numpy as npimport scipy.specialfrom PIL import Image# 预处理图像def preprocess_image(image, resize_size=256, crop_size=224, mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]):  image = image.resize((resize_size, resize_size), Image.BILINEAR)  w, h = image.size  left = (w - crop_size) / 2  top = (h - crop_size) / 2  image = image.crop((left, top, left + crop_size, top + crop_size))  image = np.array(image).astype(np.float32)  image = image / 255.0  image = (image - mean) / std  image = np.transpose(image, (2, 0, 1))  image = image.reshape((1,) + image.shape)  return image# 模型加载 2分session = ort.InferenceSession('resnet.onnx')# 加载类别标签labels_path = 'labels.txt'with open(labels_path) as f:  labels = [line.strip() for line in f.readlines()]# 获取模型输入和输出的名称input_name = session.get_inputs()[0].nameoutput_name = session.get_outputs()[0].name# 加载图片 2分image = Image.open('img_test.jpg').convert('RGB')# 预处理图片 2分processed_image = preprocess_image(image)# 确保输入数据是 float32 类型processed_image = processed_image.astype(np.float32)# 进行图片识别 2分output = session.run([output_name], {input_name: processed_image})[0]# 应用 softmax 函数获取概率 2分probabilities = scipy.special.softmax(output, axis=-1)# 获取最高的5个概率和对应的类别索引 3分top5_idx = np.argsort(probabilities[0])[-5:][::-1]top5_prob = probabilities[0][top5_idx]# 打印结果print("Top 5 predicted classes:")for i in range(5):  print(f"{i+1}: {labels[top5_idx[i]]} - Probability: {top5_prob[i]}")
