## 📤 Step 2：Vault 备份到云盘

下载补全完成后，将以下内容上传到交大云盘备份：

### 备份范围

| 内容 | 路径 | 说明 |
|------|------|------|
| 完整课程资料 | `07_SJTU/24秋_*` `25春_*` `25秋_*` | 所有课程文件夹 |
| 精华笔记 | `07_SJTU/*.md` | MOC、课程笔记 |
| 论文资料 | `07_SJTU/14_论文/` | 论文格式、参考 |
| 导师材料 | `07_SJTU/08_导师/` | 导师申请资料 |
| 行业研究 | `07_SJTU/10_行业研究报告/` | 研究报告 |
| 模板资源 | `07_SJTU/09_PPT/` | PPT 模板 |

### 云盘目录结构（建议）

```
交大云盘/Claire/
├── 07_SJTU/                ← 完整课程备份
│   ├── 24秋_*/             ← 按学期归档
│   ├── 25春_*/
│   ├── 25秋_*/
│   └── 资源/               ← PPT模板、论文格式等
├── Vault备份/              ← Obsidian vault 定期快照
│   └── {日期}.zip
└── README.md               ← 备份说明
```

### 备份方式

| 方式 | 操作 | 频率建议 |
|------|------|----------|
| 手动上传 | 交大云盘客户端 → 拖拽文件夹 | 每学期末 |
| 批量压缩 | `7z a 07_SJTU_backup.7z 07_SJTU/` → 上传 | 每月 |
| obsidian-git | vault 已有 Git 备份到 GitHub | 每次编辑 |
