| 关键讨论     | 花姐：当前目标降本增收和NPS提升，极端场景是服务哪一部分呢？物流产能反向影响预测；彤姐：应该归属为NPS提升花姐：极端场景更广义，大促、极端天气、疫情等，如何将极端场景对销量的弹性影响能前置梳理；彤姐：基于一期项目，将物流产能前置how花姐：why层面，到底极端场景有多么重要，在降本增收、稳定性上这俩维度可以做衡量，后续加强跟物流联动花姐：增收方面，供应链与品类联动，比如强哥说的日配、冷链做建设，类似这种是放在品类专项还是怎么样Alex：增收最近有接收到：预售、秒杀的相关项目，在双擎多货有考虑花姐：供应链方案的创新，带来新的售卖模式，推动业务尝试，举例：是否可能有从供应链角度出发的更优方案，一件代发whatever花姐：履约缺货当前放在NPS里，是否可以单拎一个维度「稳定性」来做目标设定花姐：看供应链和物流侧都有品商仓关系，两方是各有侧重点吗？彤姐：业务目标，协同仓渗透率45%，供应链侧重点关注商家履约成本；花姐：更长周期如14天或30天的规划比如物流侧是否开仓，这些跟我们的预测是什么关系？彤姐：物流对仓网开搬阔，是物流规划组的商分在做，没参考销量预测Alex：HM为例，一般都是两三个月周期，从商分对经营进行测算和规划，产出仓容及建设计划，很少跟产研的预测建立联系花姐：刚过去的CNY，节前低估，节中高估彤姐：销量预测能力比商分的效果更优鹏程：商分也在做「目标制定偏离度」，基本都是在自建模型来输出，关键是看谁的模型更优花姐：烽火台跟营销的关系是什么？鹏程：在战区内部by周目标，营销是重要输入信息；预测依赖营销活动的输入，营销依赖预测更早的提供预测数据花姐：区域商分是否可以承接S&OP的相应事务和职责？鹏程：商分是将战区目标拆解为仓维度，再拆解到天，多处于事后分析，缺少前置性的目标设定联动花姐：咱们区域的商分更偏流量侧，但像HM的区总是对商流和物流都很专业的鹏程：战区管理目标线上化，先在一两个战区做试点，让供应链计划业务团队介入，做出样板Alex：产品方面建设目标制定、目标协同能力，让华南区用顺了，让业务感到有收益，再做推广鹏程：by天拆解目标，品类介入比较少，所以很难跟TN排期形成联动花姐：TN排期这块，补GMV，还是补毛利，S&OP里有每天执行完的feedback，可以作为TN排期的输入，第二天的商品规划可以补齐第一天的目标未完成的点花姐：财务FP和商分的by月目标是什么关系？Andy：以商分测算为准，钱方面的财务FP把想法输入给商分，短期内跟销量预测合作，长期跟商分合作花姐：极端场景需要单独拉一个烽火台项目目标，从业务体感和业务运营角度，来制定更标准化的指标：比如Alex提到的异常天数占比花姐：双擎备货看起来是按照预测准确率分层，准确的机器托管，不准确的人工决策，但有何种运营抓手来能确保落地吗？花姐：双擎备货落地的难点是如何让人机真正协同，而不是负向背离，需要有奖惩机制等运营抓手花姐：有两个改善点：生鲜锁库（最大销量设定结合预测给上下限卡控）、PC排产计划升级，引导商家更多使用PC能力，商家的多货问题有改善 |              |                      |            |                                            |
