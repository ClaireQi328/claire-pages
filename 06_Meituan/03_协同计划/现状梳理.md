### 问题一：T日多货（核心指标：多货率）

#### 1.1关键定义

与销售量有关的定义：

| 取值           | 落地系统 | 供应商是否可见 | 仓库是否可见 | 产生者 | 取值定义                                                     |
| -------------- | -------- | -------------- | ------------ | ------ | ------------------------------------------------------------ |
| 最大销售量     | 档期系统 | 否             | 是           | 运营   | 在芥末后台商品系统模块展示，代表着商品在售卖当日的销售上限。 |
| 仓库预估销售量 | -        | 否             | 是           | 仓库   | 仓库在收货环节由仓库人为预估的销售量。                       |
| T-1销量预测    | -        | 否             | 否           | 算法   | 使用算法计算的T-1日预估销售量。                              |
| T日销量预测    | -        | 是             | 否           | 算法   | 使用算法计算的T日预估销售量。                                |

与库存有关的定义：

| 取值         | 落地系统 | 供应商是否可见 | 仓库是否可见 | 产生者 | 取值定义                                                     |
| ------------ | -------- | -------------- | ------------ | ------ | ------------------------------------------------------------ |
| 总库存       | 库存管理 | 否             | 是           | 仓库   | 总库存=可销售库存（含分拣库存、储存库存）+不可销售库存（含原料库存、残次品库存、其他不可销售库存） |
| 系统可用库存 | 库存管理 | 否             | 是           | 仓库   | 系统展示，在芥末后台仓储系统模块展示，代表下个波次开始前可被播种的商品数量。可用库存会随着播种波次而动态变化。可用库存=分拣库存+储存库存 |
| 退货库位库存 | 库存管理 | 否             | 是           | 仓库   | 系统展示，在芥末后台仓储系统模块展示，代表因为超库龄而需要退货给供应商的商品数量。库龄的计算以该商品最早入库时间计算，库龄为三天，超期部分需要退货。如果某个商品T日同时有售卖和退货库存库存，供应商需要在送货时再把退货库位库存二次入仓，让退货库位库位也可以被履约。 |
| 残次品库存   | 库存管理 | 否             | 是           | 仓库   | 在分拣过程中产生的不可用于销售的残次品库存。                 |
| 可销售库存   | -        | 否             | 否           | 采购   | 可销售库存=总库存-残次品库存-退货库位库存                    |
| T日实际库存  | -        | 否             | 否           | 采购   | T日实际库存=T日可销售库存+待收货库存                         |

#### 1.2原因定位

送货量=销售量-库存量。

当销售量预估和实际库存量统计过高或过低时，供应商得到的送货量偏差极大。

核心公式①：送货量=销售量-库存量

在供应商有二配能力的时候，核心是算准销售量、库存量，倒逼送货量，从而避免浪费销售机会。

##### 1.2.1策略型原因

**1）从T-1到T日的多个环节，使用的销售量和库存量在业务上是不同的取值**

下图中蓝色为理想取值，黄色为实际采用值。

**2）用以代表销售量的最大销售量和仓库预估销售量均与实际销售量有较大偏差**

在多货/缺货问题最重要的收货时段和补发时段，销量预测的准确率表现均好于最大销量和库存表现。

![image.png]()

**3）用以代表库存量的T-1实际库存和系统可用库存均与实际销售量有较大偏差**

以系统可用库存为例，T-1日系统可用库存未减去T日退货库位库存，导致系统可用库存偏高。

T日可销售库存未减去待收货库存，导致T日可销售库存偏高。

##### 1.2.2系统型原因

**1）使用的销售量和库存量，需要从多个系统的多个表格中导出人工统计**

销售量和库存量分别在档期系统和仓储管理，需要导出后人为合并计算。

可销售库存和T日实际库存均为采购手动计算，且用于计算的字段来源于系统的不同位置，出错概率高。

可参见https://km.sankuai.com/page/627034759

**2）供应商和仓库均只能看到部分字段**

#### 1.3解决思路

##### 1.3.1策略解决

**1）根据准确率表现，确定各个环节的销售量取值及口径**

①对于生鲜等多货危害>缺货危害的类目，收货/补发环节销售量取预测销量

![image.png]()

②对于标品等缺货危害>多货危害的类目，尝试圈定缺货表现与最大销量相仿的SKU，收货/补发环节销售量取预测销量

![image.png]()

③对于标品等缺货危害>多货危害的类目，收货/补发环节销售量取最大预测量

**2）根据准确率表现，确定各个环节的库存量取值及口径**

##### 1.3.2系统解决

**1）整体梳理供应商/仓库全链条，确定控制发货/收货/补发环节中的取值标准**

**2）在相应场景向供应商/仓库同时展示，确保取值标准一致**

### 问题二：T日缺货（核心指标：缺货率）

![[../assets/images/image-20220511164856713.png]]

#### 2.1关键定义

如1.1。

#### 2.2原因定位

可售卖量=可售卖库存-已售卖量。

当库存-已售卖量<0时，导致超卖。其中已售卖量是准确值。

核心公式②：可售卖量=库存量-已售卖量

在供应室没有二配能力的时候，核心是算准库存量，控制可售卖量，从而避免缺货。

超卖原因一般源于可售卖库存：

**1）以最大销售量作为可售卖库存，一般可售卖库存<最大销售量**

**2）供应商失去二配能力后，仍以最大销售量作为可售卖库存，但供应商已无法补货**

在晚上9点之后，大部分供应商失去二配能力。由于最大销售量大于可售卖库存导致的缺货问题，仍占到所有缺货问题的30%-45%。

![image.png]()

#### 2.3解决思路

**1）供应商失去二配能力后，以可售卖库存截单**

**2）可售卖库存考虑待收货**

### 问题三：T+1日多货（核心指标：库存周转时长&无效仓容占比）

#### 3.1关键定义

库存周转时长 = ∑（sku出仓时间-sku入仓时间）/总sku数

无效仓容占比 = T日无排期sku库存/仓库标准仓容

#### 3.2原因定位

由于货量控制失效导致的库存没有及时排期或取回，导致标准仓容内12%的仓容由无排期商品消耗。
