# 一、季节品销量预测的痛点

1.1 节气类商品缺乏预测感知

1.1.1 速冻面点（冬至）

1.1.2 速冻汤圆（元宵节）

尖峰销量/平时销量约为5。

1.1.3 粽子（端午节）

1.1.4 月饼（中秋节）

1.2 蔬菜水果等季节类商品

1.2.1 麒麟西瓜-夏季

热销季销量/平时销量约为5。

1.2.2 红颜草莓-春季

1.2.3 枣-冬季 

1.2.4 石榴-秋季

1.3 排期提前期不够

典型case是中秋季节性品类规划未拉通全国，导致不同地区目标达成情况差别较大。大部分省区对季节性商品的节奏感把握上不足，从品类规划、供给筹备、排期测品没有全国拉齐。仅部分省区具备判断基本节奏，整体广西、湖北、云南、广东，无论从供给还是排期数上到交易指标表现更为突出。

各网店月饼排期sku数走势

河北、山西、重庆主要定位为运营动作&意识较差，仓均在线商品数低于全国平均水平

供给明显问题：青甘宁-张掖网店、晋蒙-榆林网店、川渝-万州网店等，在节前一周排期数不足10

二、应用场景及方式

2.1 应用场景

根据品类平时销量推测某个品类在热销季的销量范围，热销持续天数。

从基础数据的角度，希望可以获取季节品或者节气商品对应的出入季时间等特征。

2.2 应用方式

将品类热销日期数据通过信息迁移用在后处理策略，对模型预估结果进行调整。

针对季节品以及节气品的出入季期间，可以增加人工预测协同预警机制，根据业务在地域及品类差异化的出入季策略进行计划协同。

2.3 应用问题

因品类太多，干扰数据太多(如下图)，能挖掘出的可迁移知识较少，不适合自动化进行知识迁移，需要人工干预。
