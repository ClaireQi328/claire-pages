## 一、优选OIH项目背景

> 什么是OIH？ Optimal Inventory Health，即库存健康运营管理系统，用于对库存健康的监控、预警和处置，提升库存健康水平的管理系统。

### **1.项目背景**

**业务问题：库存健康缺少定义和运营目标，不健康库库存缺乏预警和标准管控**

**1）库存健康缺少定义和运营目标**

- 库存健康运营仅使用多货相关指标，其他库存健康度指标定义待明确和统一定义；
- 库存健康运营缺乏清晰的运营目标，健康的库存带来的业务价值不明确；

**2）不健康库存缺乏预警和处理**

- **库存监控：**缺乏统一库存健康数据看板，数据分布在芥末系统的库存明细及各类业务自定义的魔数看板，；
- **库存预警：**线上不具备异常库存的预警能力，线下通过wiki的红黑榜在大象群内做每日人工预警通知
- **库存规则：**目前仅有对中心仓多货处理规则，暂无其他库存健康运营管理规则；
- **库存处理：**库存处理以退和报废为主，多货处理的产品能力建设中；

**3）全链路库存缺乏系统化的运营管理**

- 库存管理处于供应链计划末端，强依赖于供应链计划前端备货和商家履约环节，目前各端运营存在脱节；

- 库存健康状态会直接影响仓端产能利用率（成本）和销售机会（收入），需从全链路视角确定合理的运营管理方案；

### 4.项目目标

建设适用于MTYX社区电商的库存健康运营管理（OIH）能力，最大化产能利用率和销售机会，实现业务降本增收。

- **定性目标：**

  - 初步建设优选OIH产品能力，搭建库存管理规划的能力，并实现库存规则管理、库存监控与预警、库存处理与执行线上化，落地动作达成结果；
  - 根据S&OP目标明确不同阶段各仓合理的健康库存结构和水位，最大化中心仓的产能利用率和销售机会；

- **短期定量目标：**

  - 12月底全国中心仓临期/过期库存降低至2Wpcs以内；
  - 12月底全国中心仓多货率降低至30%；

- **长期定量目标：**

  - 中心仓不健康库存比例降低至2%（临期、过期、高库龄）；

  - 全链路库存管理成本降低30%（待商分测算）

    

## 二、OIH产品规划

### 1.OIH产品思路

  **优先建设不健康库存预警和管理，长期建设库存健康最优化的运营能力，最大化产能利用和销售机会**

#### **1）库存健康运营规划**

  | 传统电商                                                     | 社区电商                                                     |
  | ------------------------------------------------------------ | ------------------------------------------------------------ |
  | 低周转，以采定销，侧重以库存管理保销售。供应链计划通过维护库存合理的水位线，来满足后端履约，前端的备货、送货时效要求较低。库存管理侧重库存内的管理，行业会拆分不同商品的标签，设置不同的商品存货水位，以满足前端的销售需求； | 高周转，以（预测）销定采，侧重以商家履约保销售。供应链计划是按“越库”模式设计，通过精准的备货计划和履约送货完成，库存管理是前端执行问题的衍生物。库存管理是反映备货计划、商家履约、大仓作业问题，侧重的是以结果往前看业务问题，追溯问题源头并解决问题；库存内的库存管理相对是较弱的环节； |
  | ![[../assets/images/image-20220511160909378-2256550.png]]*注：以上形状代表供应链履约环节的重要度；* | ![[../assets/images/image-20220511160921977.png]]      |
  | **社区电商区别传统电商：**社区电商的RDC平均周转天数0.4天远低于传统电商，因此不健康库存高库龄、临期/过期商品比例远低于传统电商**，社区电商对“入库后”健康运营管理更轻**；社区电商的履约模式差异，使得库存健康强依赖于供应链计划前端商家备货和履约送货环节，社区电商库存健康运营会**联动对“入库前”和“入库中”的运营管理**；社区电商的供应链计划是朝着越库模式发展，对于库存结构和水位线管理需要能**更加敏捷地支持前端销售**； |                                                              |

  

#### 2）不良库存管理流程

  ![[../assets/images/image-20220511161023121.png]]

  供应链计划可按照PDCA的模式，从事前预测--事中协同&执行--事后预警&处理--复盘优化，四个阶段完成计划的整个闭环。库存预警处理与复盘这两个阶段，是下一轮计划执行的基础。

#### 3）不同仓库不良库存管理

  - 中心仓

    站在平台视角，需要进行强管控，满足业务目标，着重建设多货、临期、过期、售罄、高库龄业务的库存预警、归因分析、库存监控、库存处理的系统运营管理能力。

  - 协同仓、转运仓

    协同仓和转运仓为增值服务，站在平台视角帮助商家进行库存管理，重点建设高周转、临期、过期、高库龄业务的库存诊断、库存打标和库存处理推荐的系统能力。

  - PC仓

  ​     主要是自营PC业务，站在平台视角对原料和成品进行库存管理，重点建设入水口多货和售罄业务的库存监控、库存预警的系统能力。

#### 2）项目整体计划

一期：**对标行业建设不健康库存处理和基础运营能力**

- 接入日常多货库存运营管理，**将多货目标、多货预计和归因分析和多货处置等业务流程线上化，建设针对不健康库存诊断、监控、预警、处理的运营管理能力**；
- 不健康库存中临期/过期库存建设库存标签，作为多货的下钻分类做库存监控和运营管理；
- 其他：如影响库存健康的作业流程预警和管理等

二期：**建设库存健康最优化的运营能力**

- **建设库存结构分析和仿真能力**，指导库存结构运营和水位线管理，最大化产能利用率（成本）和销售机会（收入）；
- **联动“入库前”和“入库中”的运营管理，**与备货计划系统和实时履约产品，将库存健康前置运营；

三期：**建设平台化库存健康运营体系能力**

- 建设全链路库存运营管理能力，以平台视角提供**库存健康度看板**以及**库存健康诊断**，达到库存健康最优化和智能化的运营能力，按照不同的业务指标，构建不同的库存结构和库存水位。

**四期：库存管理运营能力赋能**

- 将库存健康运营能力赋能到商家，站在平台视角帮助商家进行库存管理和库存指导，并提供全链路库存健康分析。构建不同行业的库存管理模型，提供行业横向对比分析。

| 指标分类               | 一级指标                                                     | 二级指标                                                     | 口径                                                         | 备注                              |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | --------------------------------- |
| 库存优化               | 中心仓多货率                                                 |                                                              | 日均累计多货件数/日均当日应收件数（不含缺货）数据来源：多货汇总看板 | 通过OR模型，建议多货/售罄的平衡点 |
| 入水口多货率           | T-1日累计收货中未产生销售的商品件数的占比。计算公式为：【中心仓】T-1累计多货量（销售口径）/T-1销售备货件数。 | 通过入水口增加的多货数据                                     |                                                              |                                   |
| 暂存期多货率           | T-1日中心仓库龄标准内库存件数占【中心仓】期末多货库存量的比例。【中心仓】库龄标准内库存件数/【中心仓】期末全量库存件数 | 出水口的暂存期内的多货占比                                   |                                                              |                                   |
| 库龄标准外多货率       | T日中心仓库龄标准外库存量占【中心仓】期末多货库存量的比例。计算公式为：T日【中心仓】库龄标准外库存量÷T日【中心仓】期末多货库存量。 | 出水口的超过库龄标准外的多货占比                             |                                                              |                                   |
| 中心仓周转天数         | 过去14天平均批次库存量/过去14天平均销售备货件数              |                                                              |                                                              |                                   |
| 中心仓高库龄占比       | 库龄＞7天的库存量占比，高库龄占比=库龄大于7天的库存量/期初批次库存总量 |                                                              |                                                              |                                   |
| 临期库存占比           | 按照商品侧临期库存规则分类，f(x)=临期库存量/期初批次库存总量 |                                                              |                                                              |                                   |
| 过期库存占比           | 商品超过保质期的库存~~量~~件数 占比期末多货库存~~量~~件数 。计算公式：【中心仓】过期库存~~量~~件数 /【中心仓】期末多货库存~~量~~件数 。 |                                                              |                                                              |                                   |
| 建议退货多货占比       | 退货计划建议量/期末多货库存量                                | 评估系统计算的建议退货量占多货件数的占比，考核系统推荐退货的有效性 |                                                              |                                   |
| 退货执行率             | （退货计划建议PCS数-实际执行退货pcs数）/实际执行退货Pcs数    | 评估退货计划到实际出库的执行效果                             |                                                              |                                   |
| 协同仓周转天数         |                                                              | 根据T-1日调出量，有库存的sku中期末库存预计被消耗所需的天数。计算公式为：T日【协同仓】期末库存~~量~~件数 / T-1日调拨出库件数（仅计算有库存的sku的调拨量） |                                                              |                                   |
| 高库龄商品的排期命中率 | 适销性高库龄商品推荐排期系统的商品数量与实际选中商品数量的占比 |                                                              |                                                              |                                   |
| 协同仓库龄             | 商品的批次库存在仓内的存放天数，选取该批次库存入库日期时间T为起始时间进行计算，商品库龄=T-T日8:00:00 |                                                              |                                                              |                                   |
| 临期库存占比           | 按照商品侧临期库存规则分类，f(x)=临期库存量/期初批次库存总量 |                                                              |                                                              |                                   |
| 过期库存占比           | 商品超过保质期的库存~~量~~件数 占比期末多货库存~~量~~件数 。计算公式：【协同仓】过期库存~~量~~件数 /【协同仓】期末多货库存~~量~~件数 。 |                                                              |                                                              |                                   |
