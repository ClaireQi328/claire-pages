偿债风险

核心问题：短期债务能否按时偿还？
评估短期偿债能力。流动比率过低或现金不足以覆盖短期借款时存在风险。
评估指标和计算公式
评估指标
流动比率
⏳
风险触发标准
• 最近一个年度的流动比率 < 1
计算公式
流动比率 = 流动资产 / 流动负债
评估指标
短期偿债能力指标
⏳
风险触发标准
• 最新一个年度的货币资金 < 同期短期借款
计算公式
短期偿债能力指标 = 货币资金 - 短期借款
（单位：亿元）

造血能力风险

核心问题：主营业务能否产生现金？
评估经营性现金流状况。现金流持续为负表明主营业务无法产生足够现金。
评估指标和计算公式
评估指标
经营性现金流净额
⏳
风险触发标准
• 最近一个年度的经营性现金流净额 < 0
计算公式
经营性现金流净额 = 经营活动现金流入 - 经营活动现金流出
（单位：亿元）

评估指标和计算公式
评估指标
现金消耗时间
⏳
风险触发标准
• 现金消耗月份<6个月
计算公式
现金消耗时间 = 期末货币资金 / 月均经营性现金净流出

经营业绩风险

核心问题：经营状况是否健康？
评估盈利能力和经营效率。营收大幅下降或净利润持续为负存在风险。
评估指标和计算公式
评估指标
营业收入同比增速
⏳
风险触发标准
• 最近一个年度的营业收入同比下降 > 30%
计算公式
营业收入同比增速 = (本期营收 - 上期营收) / 上期营收 × 100%
（单位：%）
评估指标
净利润同比增速
⏳
风险触发标准
• 最近一个年度的净利润同比下降或亏损扩大
计算公式
净利润同比增速 = (本期净利润 - 上期净利润) / 上期净利润 × 100%
（单位：%）
