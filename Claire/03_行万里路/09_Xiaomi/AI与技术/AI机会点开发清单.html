实施建议

  • P0 先行（本期 0822-0917）：O1、O4、O5、O11、O12、O15 —— 承接已规划草稿生成与预警能力，覆盖「写合同→核对→催办→沉淀→分析」主链路；其中 O12（历史解析入库）为 O13/O14/O17 等机会的数据底座，建议最先启动数据收集与表结构设计。
  • 架构复用：Agent 部分统一复用样件订单已验证的 L1 总协调 / L2 域 / L3 Skill / L4 CLI 分层架构，沉淀「合同模板库、定点台账、历史合同库」三个数据底座；Skill 与 CLI（ep contract create / 飞书卡片发送等）可在两项目间复用。
  • 人机协同边界：Agent 生成草稿 → 人确认；Agent 识别风险 → 人决定是否阻断；合同签署与价格确认类动作保留人工审批节点。
  • 开发资源预估：P0 六项中，Agent 能力（1-1.5 人）与功能开发（2 后端 + 1 前端）并行推进；O12 涉及 OCR 管道与人工确认台，建议预留测试与数据清洗时间。
