从「流程线上化」到「数据资产化」——业务 B 点、数字化 B 点、耦合机制与分步落地
素材来源：飞书知识库《小米采购数字化 · 现状-B点-差距-路径 战略蓝图》　|　梳理日期：2026-07-31　|　口径：A点=现状，B点=终局目标
🎯 一句话结论：业务 B 点 = 八里程碑上「补数据 / 自动化 / 聚决策」的落点；数字化 B 点 = 四层架构「数据资产化 / 流程自动化 / 决策智能化」的终局；二者通过「三库主数据」枢纽 + 「数据飞轮」耦合；分步策略 = 先夯底座（P0 三库）→ 再装模型（P1 速赢）→ 最后上闭环（P2 决策），双主线并行、FDE 编排、三年分期。

概念先对齐：A 点 → B 点

A 点（现状 · 上半场已走完）
核心采购流程全部线上化，"把事办成"基本达成；但三库缺位、覆盖率仅 5%，治理 / 自动化 / 决策能力近乎空白。
B 点（终局 · 下半场命题）
建成数据资产化、流程全域自动化、决策智能驱动的供应链采购管控体系，平台自运转、自感知、自研判、自优化。采购从"执行部门"升级为"价值中心"。
💡 对"B 点不是什么"的澄清（关键判断①）
B 点不是额外加流程，而是在现有流程节点上——把数据补全、把重复动作自动化、把决策信息聚起来。

业务汽车采购业务流程的 B 点（8 里程碑落点地图）

业务流程横向按整车研发 8 个里程碑展开，纵向分 4 个泳道（项目线 / 车型平台 / 跨部门研发·CE / 采购）。B 点必须落到既有"核心交付物"上，做数据补全、动作自动化、决策增强，而不是另起一套流程。

📌 业务 B 点的节奏判断
① 概念 + 工程决定 70-80% 成本 → SOR 标准化、报价细项结构化、成本库建设的优先级高于量产 VAVE。
② 定点决策是采购价值最高的节点 → B 点价值是"聚合成决策看板"，决策从"拼记忆"变"看数据"，但决策权仍在人。
③ 样件自动下单是下半年试金石 → 跑不通则 RFQ / PO 自动化也难跑通。
④ 供应商库是枢纽 → 全阶段读它写它，不稳则全链路晃。
⑤ 量产数据飞轮是终局 → 燃料来自概念→SOP 每阶段回写，不能等量产再补。

数字化数字化业务的 B 点（四层架构终局）

数字化 B 点 = 平台自下而上四层架构，AI 能力贯穿其中。四层之间是硬约束依赖：主数据底座→可信数据→分析模型→决策闭环，底层没夯实上层都是空中楼阁。

数据采集层
基础底座
全域统一标准化主数据体系，自动采集 / 归集 / 治理，零散数据 → 高质量可复用数据资产。
业务流程层
核心载体
贯通寻源定点→合同→履约→对账→绩效，端到端流程闭环自动化，破除断点。
智能分析层
能力中枢
多维度场景化模型（成本核算、供应商选择、绩效评级、风险预警），自动输出量化结论。
智能决策层
顶层赋能
关键节点（定点评审、风险防控、降本优化）智能推送辅助方案，人机协同决策。
📊 两张验收标尺（北极星指标）
成本：设计期锁定 70-80% 成本结构，Should-cost 标尺驱动，降本成果可量化核算。
效率：机器执行、人管例外，采购员从"操作工"转为"编排者"。

结论一页纸结论（关键判断）

  1. 最大瓶颈是主数据缺失，不是功能不足 —— 所有上层智能都建在流沙上。
  2. 资源优先投回报最大的两件事：主数据底座 + 供应商治理。
  3. 采购杠杆在价值链前移：70-80% 成本在设计期锁定，DFC 评审闸是把采购推回设计期的强制对齐。
  4. B 点不是加流程，而是补数据、自动化重复动作、聚决策信息。
  5. 样件自动下单是下半年试金石：跑不通则 RFQ / PO 自动化也难跑通。
  6. 供应商库是枢纽：全阶段读它写它，不稳则全链路晃。
  7. AI 价值在"越用越准"的数据飞轮，FDE 编排是放大有限研发的关键；终局不是消灭采购员，而是把人从操作工升级为品类策略师。
