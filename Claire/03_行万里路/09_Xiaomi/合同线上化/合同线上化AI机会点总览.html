编号机会点AI 能力说明相对 PRD 的增量优先级
N1 签署版内容语义校验 上传签署版 PDF/Word 后，AI 解析合同文本并与模板、定点数据（金额、币种、期限、签约方）逐项比对，自动标记不一致项 PRD 智能检查为 12 项字段规则级检查；本项是文档内容级语义校验 P0
N2 合同要素智能抽取回填 从签署版 / 历史合同 PDF 自动抽取签约主体、金额、币种、有效期、收付款条款，回填 EP 字段供确认，历史合同批量入库 PRD 无文档解析能力；补齐"数据资产沉淀"短板 P0
N3 供应商签约信息智能补全 输入供应商名称，自动查询签署公司/签署人邮箱（复用合同系统接口），补全证照类型、证照号、经办人信息并校验格式 PRD 仅"联系人/电话自动带出"；本项扩展到证照与海外签署信息 P0
N4 风险条款智能识别 语义识别高风险条款（价格缺失、金额异常、责任条款缺失、期限倒挂），标记并推送法务关注 PRD 检查为必填规则；本项为条款语义级合规前置 P1
N5 签署周期预测与停滞催办 基于历史签署时长预测本次签署周期，识别"待供应商确认/审批中"停滞节点，自动生成催办文案并分级升级 PRD 仅状态展示；本项从"提醒"升级为"预测 + 推动闭环" P1
N6 合同知识问答 自然语言查询合同（"XX 供应商今年签署金额""哪些合同即将到期"），Agent 对话式检索与汇总 PRD 为结构化列表查询；本项为自然语言交互 P1
N7 到期预警与续签建议 基于合同有效期（已支持 hasValidityPeriod 字段）监控到期，生成续签/变更建议，联动定点台账 PRD 无到期维度；合同系统接口已具备有效期字段，数据基础就绪 P1
N8 合同-定点价格一致性 合同金额/价格与定点台账自动比对，总成件/DB 件价格变更时提示合同是否需升版 跨模块联动；PRD 为单模块范围 P2
