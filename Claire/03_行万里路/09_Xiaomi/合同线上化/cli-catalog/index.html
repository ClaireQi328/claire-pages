01 · 查询查询

合同列表查询

$ dx-ep contract info list --user-id <userId> [--contract-status <s1,s2>] [--page <n>] [--page-size <n>]
请求 POST 路径 /api/oa/contract/outer/queryUserContract
按用户与状态分页查询合同列表（状态过滤），支撑 AI 助手合同状态问答与催办对象识别。
输入参数
参数类型必选默认校验说明
--user-idstring是-NotBlank用户 id
--contract-statusstring否全部枚举逗号分隔ContractStatusEnum 多选
--pageint否1≥1当前页数
--page-sizeint否301-30每页大小
返回参数（data）= PageInfo<ContractDto>
totalCount（long 记录总数）· size · currentPage · records（List<ContractDto>，含 id / name / code / type / contractStatus / sealStatus / fileStatus / ourOrganizations / otherOrganizations）
02 · 查询查询

合同详情查询

$ dx-ep contract info detail --contract-id <id> --user-id <userId>
请求 POST 路径 /api/oa/contract/outer/contractDetail
按合同 id 查完整详情（签署方 / 金额 / 期限 / 条款），支撑语义校验与风险识别。
输入参数
参数类型必选默认校验说明
--contract-idint是->0合同 id
--user-idstring是-NotBlank合同创建人或需求发出人
返回参数（data）= ContractDetailDto
id / code / name / type / expenseType / ourOrganizations / otherOrganizations / attachList / signDescAttachList / outerSignatoryList / innerSignatoryList / hasValidityPeriod / validBeginDate / validEndDate / signOnline / sealNum
草稿状态仅名称与 id 必返回，其余字段可能为空。

07 · 查询EVEP 并入

电子签进度查询

$ dx-ep contract esign --scope <vendor|part|project> --id <identifier>
请求 POST 依据 EVEP 代码库 Controller
按供应商 / 零件 / 项目维度查电子签进度，支撑 AI 助手电子签进度问答。接口依据经 evep-master 合同模块核实。
输入参数
参数类型必选默认校验说明
--scopestring是-枚举 vendor/part/project查询维度：供应商 / 零件 / 项目
--idstring是-NotBlank供应商编码 / 零件号 / 项目代号
接口路径与返回参数（按维度）
维度接口路径（EVEP）方法返回
vendor 供应商contractItem/pageContractItempageContractItem(QueryReq)R<PageResult<ContractItemDto>>
vendor 供应商contractSupplier/listContractSupplierlistContractSupplier(IdReq)R<List<ContractSupplierDto>>
part 零件contractItem/listContractItemlistContractItem(IdReq)R<List<ContractItemDto>>
part 零件contractItem/detaildetail(IdReq)R<List<ContractItemSupplierDto>>
project 项目contractApp/pageContractApppageContractApp(QueryReq)R<PageResult<ContractAppDto>>
project 项目contractApp/findByIdfindById(IdReq)R<ContractAppDto>
返回参数（data）关键字段（真实 DTO）
ContractItemDto：id / contractAppId / contractAppCode / name / contractType / contractTypeName / contractCode / hasValidityPeriod / startDate / endDate / fixedAmount / currency / amount / cashPayment / isEle / versionNo / isLatest / sorCode / sorName / suppliers / contractSuppliers / contractUrl / supplierSignInfo / supplierSignDetail / isActive
ContractSupplierDto：id / contractAppId / supplierId / isMain / orderNo / orgName / address / employeeName / employeeMobile
ContractAppDto：id / code / name / projectId / projectName / userId / userName / type / status / statusName / mainName / nomiAppId / nomiAppCode / rfqType / isEle / isMany / isDouble / contractSuppliers / contractItems
通用请求类 QueryReq / IdReq 的字段级定义在代码库中未定位到类源文件（依赖自公共包），CLI 入参以维度标识符为准，接口级入参字段待公共包源码补充。

09 · 写入写入

保存合同

$ dx-ep contract save --save-json <json>
请求 POST 路径 /api/oa/contract/outer/saveContract
新建（id<0）/ 更新（id>0）合同，含幂等，支撑校验后落库。
输入参数
参数类型必选默认校验说明
--save-jsonstring是-JSON 可解析id（int，<0 新建 />0 更新）、name、type（三级逗号分隔）、expenseType、requirementProposer、createUserId、belongingDeptId、sourcePlatform、ourOrganizations、otherOrganizations、signDescAttachList
返回参数（data）= ContractSaveResult
contractId（int）/ code（String），统一返回包装 {state, message, data}。
