⚠️ 异常处理全部分支

🔧 CLI 相关异常

  • 登录超时 → 报错提示重新登录，不自动重试
  • 命令不存在 → 检查安装，提示安装命令
  • 参数错误 → 修正参数后重试，记录原始错误
  • 返回非JSON → 保存原始输出，提示版本问题
  • 调用超时 → 重试1次，仍失败则报错

📋 业务相关异常

  • 校验不通过 → 异常只进报告，不进records
  • 导入失败 → 记录原因，跳过继续，最后汇总
  • 无可下单需求 → 结束批次，报告"无可下单"
  • 一价多供 → 暂停，推送供应商选择
  • 草稿非最低价 → 推送人工核实
  • 订单创建失败 → 记录原因，推送人工处理
  • 到货日期超期 → 自动过滤，记录过滤数量

🖥️ 系统相关异常

  • 多维表格写入失败 → 重试1次，仍失败保存本地
  • 飞书卡片发送失败 → 降级为纯文本，仍失败则Agent输出
  • 配置文件缺失 → 提示检查，使用默认配置继续
  • 分页获取异常 → 已获取数据保留，提示部分数据未获取

👤 人工确认点（共4个）

  • 确认点1：需求导入确认（需求导入人）
  • 确认点2：可下单需求确认（订单管理员）
  • 确认点3：供应商选择（订单管理员）
  • 确认点4：草稿/失败订单处理（订单管理员）
