Agent Space vs Mico · 选型对比速览（2026-09-08）
Agent Space = “Agent 运行/管理工作区”
解决 Agent 在哪跑、谁可用、挂什么 Skill；样件订单 5 个 Skill 已实测落地运行
Mico = “人 + Agent 深度协同平台”
解决人与 Agent 围绕项目上下文交付、沉淀、复用；组织级知识飞轮，多端协同
建议：非二选一
短期 Agent Space 承载确定性订单流程；后续可评估 Mico 作为上层人机协同层
维度 Agent Space（平台实测） Mico（官方介绍）
定位 团队级 Agent 运行平台，工作区隔离权限与数据 AI Native 组织的人机协同编排层（人+Agent）^项目
权限 所有者/管理员/成员分层；Agent 可见性可设工作区或私有 成员同等地位，无法继续分配权限
Skill 本地上传/ GarageHub 引用（须公开）；可按 Agent 分配并选版本 精选 Skill 按角色绑定；支持 Skill/代码仓库/MCP/A2A
Agent 配置 指令/多Skill/知识库(并集)/任务/环境变量/CLI参数/模型/并发(≤50) 智能体+小队（主控拆解子任务并行）；可接入 Claude Code 等 Harness
自动化/工作流 定时自动化运行已有记录；任务队列可见执行结果 定时任务可配；工作流仅 3 个预设不可调，无可用时只能提示词
任务闭环 Issue 状态机（待办→审查中→完成）；WS-1 实际运行至审查中 Issue 承载上下文全链路；人 Review+Approve 闸口
知识库 空间绑定 AgentBrain；Agent 多知识库取并集注入 企业级知识库，自动蒸馏进化；飞书/本地/Git/API 导入
观测/评测 Langfuse 观测 + agentops 独立评测中心（按空间） 全程可追溯、每步日志；数据隔离加密
多端/模型 Web 端；模型可配（Mimo-V2.5-Pro） 桌面/移动/Web 三端；强调不绑定生态
