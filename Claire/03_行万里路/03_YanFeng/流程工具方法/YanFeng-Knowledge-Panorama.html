超市设计公式

超市库存量 = 补货周期需求 + 安全库存
补货周期需求 = 日均消耗 × 补货提前期
安全库存 = Z × √(L×σd² + d²×σL²)
案例: d=500, L=2天, σd=50, σL=0.5, Z=1.65
  SS = 1.65 × √(5000+62500) = 429件
  超市总量 = 1000+429 = 1429件 ≈ 3天

Layer 3 · VSM 价值流图

HOW

核心公式

节拍时间 TT = 每班可用时间 / 每班客户需求量
  示例: 25,200s ÷ 500件 = 50.4s/件

前置时间 LT = WIP × CT（利特尔法则）
  LT = Σ(各工序 C/T × WIP)

增值比 = 增值时间 / 总LeadTime × 100%
  优秀 >25% | 一般 5-25% | 差 <5% | 汽车业典型 <1%

平衡率 = Σ(各工位CT) / (工位数N × 最大CT) × 100%
  示例: (45+42+48+38+40)/(5×48) = 88.75%
  平衡损失 = 11.25% → 年浪费 112.5小时

VA/NVA分类体系

VA (Value Added) 增值
  → 客户愿意付费，改变产品形态/功能
  → 一次做对 (First Time Right)

NVA (Non-Value Added) 非增值
  → 客户不愿付费，但目前必须存在
  → 示例: 检验、搬运、等待、换型
必要NVA (Business Value Added)
  → 法规/安全/质量要求
  → 示例: 最终检验、环保处理、记录

Waste 浪费
  → 完全可以消除的非增值活动
  → 示例: 重复搬运、多余动作、等待

Layer 3 · FMEA 失效模式分析

HOW

核心公式

旧版: RPN = S × O × D（风险优先数）
新版: AP = Action Priority（查AP矩阵表）

S 严重度 1~10（10=安全/法规失效）
O 发生度 1~10（10=极高频率）
D 检测度 1~10（10=几乎无法检测）

AP等级: H(必须采取措施) / M(应该) / L(可以)

Layer 3 · MTM 方法时间测量

HOW

核心公式

标准时间 = 正常时间 × (1 + 宽放率)
正常时间 = Σ(各动作要素时间值) × 评比系数
1 TMU = 0.036 秒
宽放率: 汽车制造业常用 15%

作业时间测定方法:
  秒表法     → ±10-15%  单工位
  工作抽样   → ±3-5%   多人/多机
  MTM-1      → ±5%     单件小批
  MTM-UAS    → ±5-10%  批量生产
  MODAPTS    → ±8-12%  现场快估

MTM家族体系

系统层级适用场景

MTM-2简化层中等精度

MTM各模块详解

MTM-SD (Standard Data)

标准数据基本值(SD-BV)及多用途值的结构原理和应用规则。用于结构/计划/设计工作流程，描述和评估工作内容，改善现有工作系统，创建公司特有过程模块系统。

MTM-UAS

批量生产模式下的过程模块系统。基本操作和标准操作的结构和内容。用于结构、规划和设计工作流程/系统，识别改善潜能。

MTM-Logistics

从MTM-UAS开发。规划、设计和优化物流流程。收集评价AS-IS数据，选择和评估仓储系统。使用传输表和Sankey关系图作为布局优化基础。

MTM-PA (Process Architecture)

面向IE、规划、时间管理和工作组织专业管理人员。定义不同系统间传输数据的应用层级，以产品结构为基础确定过程模块数量，开发公司特有过程模块系统。

MTM-Practitioner

入学要求: 必须通过MTM-1考试 + MTM-HWD/MTM-2/MTM-SD/MTM-UAS/MTM-MEK/EAWS之一 + 实际应用经验。

数字化工具

MOST for Windows / MTM-Link(MTM-1/2/UAS分析平台) / EASEWorks(MTM分析与仿真) / MODAPTSPlus(MODAPTS工时推算)

案例4: 安全库存计算

SS = Z × √(LT × σd² + d̄² × σLT²)

案例参数: d̄=500件, LT=7天, σd=50件, σLT=2天, 服务水平95%→Z=1.65
  SS = 1.65 × √(7×50² + 500²×2²)
     = 1.65 × √(17500 + 1000000)
     = 1.65 × 1008.7
     = 1665件 ≈ 3.3天需求量
