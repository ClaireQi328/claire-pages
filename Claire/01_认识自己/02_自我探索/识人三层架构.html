THREE-LAYER FRAMEWORK · 识人方法论

识人三层架构

把"动机、态度、意愿、影响力、领导力、成就导向、个性品质、内驱力、自我形象"九个散落的词，重新摆回它们各自的水深。看选择不看说法，看极端情境不看日常状态，看时间序列不看单次表现。

总原则：水面之上可学可练，水面之下几乎不可变——但恰恰是水面之下的部分，决定了一个人能走多远、能合作多久。

LAYER 03 · 最外层

输出层 · 个性品质 / 影响力 / 领导力

他怎么和世界打交道？

看什么

  • 和你无关的那30秒——等电梯的表情、和前台的语气、催快递的耐心。他在你面前的礼貌是职业训练，不是人品。
  • 功劳切片能力——讲一件做成的事，他能否准确把功劳切给具体的人（"这个点子是XX提的"）？看不见别人贡献的人，带不了团队。
  • 反对意见时看谁——第一眼神是看向发言者（真在讨论事），还是扫向老板/全场（判断政治风向）？
  • 失败归因的颗粒度——"那次没做好"（粗颗粒，防御）还是"我在X环节判断错了，因为误以为Y"（细颗粒，真反思）？颗粒度即学习上限。
  • 被低估/被高估时的反应差——被低估时是默默做证明给你看，还是立刻跳起来辩解？被高估时是诚实校准，还是顺水推舟？测情绪稳定性和自我认知的一致性。
  • 接手烂摊子的第一反应——前任留下的烂项目/烂团队，他是先骂前任（归因外部），还是先理清楚现状（面对现实）？测尽责性和现实感。

评价标准

  • 大五：尽责性（可靠）/ 情绪稳定性（抗压）/ 宜人性（合作）/ 开放性（学习）/ 外倾性（能量来源）
  • 影响力风格：靠逻辑、关系、权威背书，还是情绪感染？四种路径混用还是有主次？
  • 领导力定义：没人安排、没奖励、要背锅时，他会不会主动站出来
  • 跨情境一致性——顺境/逆境、对内/对外、上级/下属面前，行为模式是不是同一套
  • 学习敏捷度——面对完全陌生的领域，是快速上手拆解，还是立刻退缩到舒适区

常见问题

  • 把"对我好"当"人品好"——他对你好可能因为你有用
  • 把"职业礼貌"当人格底色——面试场合的礼貌是训练
  • 光环效应：业绩好就默认其他维度也好
  • 把"安静"当"稳重"——不说话可能是没想法，也可能是怕说错，不是稳重
  • 把"会社交"当"有影响力"——饭局上热闹不等于能推动事情，场面上活跃和真正让人服气是两回事
结论
这层最容易训练、最容易观察，但受底层限制。 低动机的人，技巧再高也是"精致的平庸"。看他对"暂时没用的人"好不好。

LAYER 02 · 中间层

自我系统 · 自我形象 / 态度 / 意愿

他怎么看自己？愿不愿投入？

看什么

  • 不完美暴露测试——没准备好时，他是"先出一版，烂就烂，迭代"（自我形象稳），还是"必须95分才出手"（自我绑死在完美表现上）？
  • 批评的消化速度——不是看他接不接受，是看他被指出问题后多久能开始谈具体改进。当场问"具体哪里"=不被威胁；几天才能消化=戳中"我不够好"的核心叙事。
  • 没人看时的标准——写一份只有自己看的文档、做一件不会被检查的事，他的标准和有人看时差多少？认真是演给观众的，还是内建的？
  • 利益 vs 和谐的第一动作——自己的观点和"维持关系"冲突时，他先让步哪个？不敢说不=把自我融化进关系；硬顶回去=用防御代替表达。
  • 他如何对待"沉默"——开会时他是害怕沉默所以抢话，还是能忍受沉默思考？独处时是自在还是焦虑？测内在秩序感。
  • "应该"和"想要"的区分度——他做选择时说的是"我应该做这个"（满足他人期待），还是"我想要这个"（跟随真实意愿）？

评价标准

  • 自我效能感：面对挑战是"我能试试"还是"我不行"
  • 态度稳定性：对模糊、失败、权威、冲突的默认反应
  • 意愿与行为的一致性：说的和花时间做的，差多远
  • 内在评价体系的独立度——做判断时是参考自己的标准，还是永远在参照别人怎么看
  • 情绪复原速度——遇到挫折后多久能恢复，恢复后是变得更谨慎还是更开放

常见问题

  • 自我形象外包给权威——自我评价永远等别人打分
  • 把"态度稳定"误判为成熟，其实是长期防御
  • 意愿是个谎，时间账本不会——别信"我很想做"
  • 把"随和"当"自我接纳"——随和可能是不敢表达真实想法，不是真的接纳自己
  • 把"想太多"当"深刻"——反复内耗不等于深度思考，可能是焦虑驱动的反刍
结论
极慢改变，30岁后基本固化。同一台发动机，方向盘不同，终点不同。 自我形象低的人往往不是真不行，而是先假设了不行。
LAYER 01 · 最深层

燃料层 · 动机 / 内驱力 / 成就导向

他为什么跑？能跑多远？

看什么

  • 无奖励时刻的手伸向哪里——自由时间里他刷什么、聊什么、把钱花在什么上。问卷会撒谎，手不会。
  • 真难题前的第一反应——没有现成答案的硬问题，他是先"我来搞清楚"（享受解谜本身），还是先"找谁问/找现成方案/绕开"（只享受解完被夸）？
  • 成就叙事的重音落在哪——讲一件做成的事，重音停在"方案终于跑通了"（事）、"老板当场说我牛"（认可）、还是"团队一起熬那段时间很纯粹"（关系）？
  • 放弃一件事的归因——坚持可以是外驱（怕丢面子、怕失业），放弃才暴露内驱的真实形状。"这方向我判断没意义了" vs "环境不行我没办法"。
  • 他对"平庸"的容忍度——能接受自己做一件"不重要的事"做到60分吗？还是必须每件事都做到100分才有存在感？测成就动机的强度。
  • 他的"野心"长什么样——谈未来时，谈的是"我要达到什么位置"（外部目标），还是"我要成为什么样的人"（内部目标）？前者是地位动机，后者是成长动机。

评价标准

  • 三种动机配比：成就（把事做好）/ 权力（影响他人）/ 亲和（维系关系）
  • 内驱 vs 外驱测试：没人知道、没人评价、没物质回报，还做吗？
  • 成就导向：对卓越的追求强度、对反馈的敏感度
  • 动机的持续性——动力是一阵一阵的（靠兴奋感驱动），还是持续稳定的（靠内在节律驱动）
  • 延迟满足的耐受度——能为远期目标放弃即时快乐吗？还是必须短期就有反馈

常见问题

  • 用高级词汇包装真实动机——"为了成长" often = 想涨钱
  • 外驱包装成内驱：没人盯着就不做
  • 后视镜合理化：事后都能讲成"我当时就是这么想的"
  • 把"努力"当"成就"——过程很辛苦不等于结果有价值，勤奋是美德但不是能力
  • 把"野心"当"内驱"——想往上爬可能是对现状的不满，不一定是对未来的热爱
结论
这是天花板，几乎不可变，是"出厂设置"。配比决定他是做事的人、带队的人还是搞关系的人——决定职业适配，不决定好坏。 看心流日志和极端事件回忆，比任何测评都准。

输出层三维度展开：它们怎么咬合

从左到右层层支撑：个性品质是操作系统，影响力是关系输出，领导力是组织输出。三者不是并列，是底座 → 能力 → 整合。

个性品质

OS · 操作系统
  • 尽责性 — 可靠、自律、条理性
  • 情绪稳定性 — 抗压、情绪调节、韧性
  • 宜人性 — 合作、信任、同理心
  • 开放性 — 好奇心、学习、接纳新事物
  • 外倾性 — 能量来源、社交、表达
它是什么：长期形成的人格底色，最难改变。不直接产出成果，但决定所有行为的默认风格——是后面两个维度的"显卡驱动"。

影响力

OUTPUT · 关系输出
  • 逻辑说服 — 用事实、数据、论证推动他人
  • 关系影响 — 用信任、互惠、人际网络
  • 权威调用 — 用职位、规则、专业背书
  • 情绪感染 — 用热情、共情、情绪调动
它是什么：无职位权力时能否改变别人的决定。可训练，但风格由个性品质决定——高宜人自然偏关系型，高开放偏叙事型，高尽责偏逻辑型。

领导力

RESULT · 组织输出
  • 定方向 — 看清局面、做判断、设目标
  • 带队伍 — 选人、育人、授权、激发
  • 拿结果 — 抓执行、排障碍、担责任
  • 建关系 — 跨部门协作、向上管理、对外链接
它是什么：影响力 + 定方向 + 担责任 + 带队伍的集合。不是单一能力，是在组织场景下把前面所有东西整合后对外输出。
个性品质（底色） → 决定影响力的风格路径 → 支撑领导力的上限
↓ 来自下层的驱动 燃料层（动机配比）决定他天然走哪条路——成就动机 → 拿结果导向；权力动机 → 带队伍导向；亲和动机 → 关系导向。配比没有好坏，但决定他在四个领导力子项里的天赋落点。 自我系统（自我形象稳定性）决定高压下领导力会不会崩——自我形象稳的人，越难越清晰；不稳的人，压力一大就变形，从"定方向"直接退化到"保位置"。

三个贯穿性认知陷阱

不管认识自己还是观察别人，这三个坑最常见、代价最大

01

光环效应

他某个维度强（比如业绩好），你就默认他其他维度也强。人是系统，不是整体优秀或整体糟糕。高成就 + 低宜人性的人很常见，不要因为一项亮眼就给其他维度打高分。

02

投射

你以为"他这么做，动机和我一样"。错——你看到的是你的动机套在他的行为上。先问自己"我做这个行为会是为什么"，再刻意列出另外3种可能。

03

单维过高的阴影

高成就 + 低宜人 = 不惜代价的个人英雄；高权力 + 低成就 = 会搞关系但不拿结果的政客；高亲和 + 低成就 = 不敢冲突的老好人。一个人的"短板"往往不是弱点，是他长板的阴影。

我现在掌握的信息，够不够下结论？

信号状态 特征 应该怎么做
已验证 跨场景一致（对上/下/平级同一套）+ 时间稳定（隔3个月看还是一样） 可以下判断、做决策
待观察 单一场景、单次事件的信号 列入清单，不下结论，继续采样
不可知 水太深（比如动机、自我形象），一小时/几周根本碰不到 不猜、不脑补、不贴标签，等共事出证据
