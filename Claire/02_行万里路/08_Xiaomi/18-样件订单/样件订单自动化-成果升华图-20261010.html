核心变化

同一批事，之前人干、现在 Agent 干，人只拍板
环节之前 · 人工现在 · Agent + 人拍板
需求导入人工
每天翻表核对，逐条确认口径与字段		Agent + 拍板
群推「今日待导入」+ 预览页，含有效/无效统计，一句话确认导入
查询可下单人工
逐个系统查询、手工比对条件		Agent 自动
自动盘库 + 自动分组：一品一点 / 一品多点 / 无供应商，生成确认页
人工确认全人工
逐单核对、电话/邮件反复确认		拍板点

C

价值点

效率、准确、透明——一个数字助理的三重收益
自动化全覆盖
需求导入、可下单查询、自动分组、合并下单、统计日报全链路由 Agent 执行；人工环节 6 步 → 2 个拍板点，人从执行者变成决策者。
下单更准更合规
按订单组合并下单，价格取 CLI 最新最低价；多供应商不静默下单，全部进确认页由人选；结果四分类，草稿/失败绝不误报成功。
透明可追
谁、何时、做了什么、结果如何——全部落执行日志面板；需求申请人打开进度表即知自己的需求到哪一步，下单完成自动收通知。

渐进式落地 · 四层递进

CLI → Skill → Agent → 平台，每层独立验证，样件订单为完整实证
L1
CLI · 原子能力
EP 能力下沉为命令行，先验证「自动能不能做」。
样件订单：dx-ep CLI 1.0.7-beta.4 跑通 query-ready / create-order / submit-list / import-json。
L2
Skill · 场景封装
命令流封装为可复用技能，输入输出标准化，单环节独立可用。
样件订单：demand-import 散件 / demand-check 试制 / demand-query 分组 / demand-order 下单 / daily-report 日报。
L3
Agent · 智能编排
技能串成业务流，对话发起 + 自动执行 + 人工拍板。
样件订单：AgentSpace 对话 + 定时任务；群机器人通知、回 AgentSpace 确认；人只留 2 个拍板点。
L4
平台 · 业务承载
工作台 + 留痕 + 通知 + 多角色，形成运营闭环。
样件订单：执行日志唯一权威 + 需求进度表实时刷新 + 三层留痕 + 群通知分层。
逐层验证：每层先在验证环境跑通再叠加 寄生增强：不替换 EP 系统，风险隔离 人机分工：AI 跑腿、人只拍板
