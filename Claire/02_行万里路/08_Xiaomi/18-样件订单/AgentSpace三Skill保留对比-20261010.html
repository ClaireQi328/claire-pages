上架版相对母版的新增能力 9/24 改造点

母版 9/20 只有基础查询/下单/统计，上架版补齐了分组、分链、结果页、通知与公共模块。

📦 demand · 分组分链

  • 新增 group_demands.py 自动分组
  • 一品一点页 sample-order-one-*
  • 一品多点页 sample-order-multi-*
  • outputs 返回 one_url / multi_url
  • 群通知卡片同时附两个链接

🛒 order · 结果页与编排

  • 新增 run_pipeline.py 一键编排 --auto
  • 下单结果页：统计卡片 + 供应商/采购员汇总 + 明细表
  • notify_order_success 自动附结果页链接
  • 公共模块：logger / notifier / feishu_bot / result_builder 等

📊 report · 日志与去依赖

  • FDS 上传从 galaxy-fds-sdk 改为 requests 直调
  • 新增 whoami.py 自动取操作人
  • 统计报告写入飞书执行日志面板
  • REPORT_WEBHOOK_URL 覆盖群通知

report 无 common/与其他两个 Skill 结构不一致。建议：确认 whoami/config 是否并入公共模块，保持一致性。

结论

三个 Skill 值得保留

  • 职责清晰、数据流闭环：查询分组 → 确认下单 → 统计日报，可独立运行、可上架、可串联成业务流。
  • 上架版 9/24 是当前最新最完整实现；本地 09_Xiaomi 合集与 8 个 zip 均为旧架构，应标记为历史版本。
  • 唯一缺口：上架版源码本地无完整副本，建议立即从 AgentSpace 拉取归档，避免后续只能改旧版导致版本回退。
