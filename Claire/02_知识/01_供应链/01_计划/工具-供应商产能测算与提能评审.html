三条基本定律

跨行业都成立
不因行业而变

这三条不是经验，是数学。它们解释了为什么看起来还有余量的产能，交付会突然崩。

第一定律
瓶颈决定产出，且会漂移
线体 JPH = MIN(各工位 JPH) 解决冲焊(26) 后 → 瓶颈迁到装配(26) → 迁到检验 → 迁到器具/返空 → 迁到排序物流

所以 TOC 五步法的第 5 步是「回到第一步」。不重算全链，等于把堵点往下游推。

第二定律
利用率有 85% 的物理天花板
Kingman：E[等待] ∝ ρ/(1−ρ) ρ 70% 80% 85% 90% 95% 等待 2.3 4.0 5.7 9.0 19.0 (×基准)

产能只多 12%，等待变 3.4 倍。云上是尾延迟，医院是排队，工厂是缺料停线——同一个数学。

第三定律
爬坡靠累计产量，不靠日历
T_n = T_1 × n^b b = ln(学习率) ÷ ln2 26 → 40 JPH（工时降 35%）需累计产量： 90% → 17.0× 85% → 6.3× 80% → 3.8×

26→40 不可能是「熟练」带来的，必须是设备/工装的能力跃迁。任何把提能归因于员工熟练的计划，都该被质疑。

输入

  • 产品规划与平台数量
  • 资本预算与回报门槛
  • 选址候选与公用动力条件

  • 产能蓝图分段（一期/二期/三期）
  • 预留扩产接口清单
  • 实物期权估值
产出
  • 产能路线图（含分期触发条件）
  • CapEx 预算与回收期
  • 总图与接口预留方案

这一阶段的算法

报童临界：F(Q*) = Cu ÷ (Cu + Co) Cu = 产能不足单位损失（丢单毛利 + 罚金 + 信任折价） Co = 产能闲置单位成本（折旧 + 维护 + 机会成本） 回收期 = 投资额 ÷ (增量产能 × 单位利润 × 利用率) // 速查：Cu:Co = 10:1 → 91% 服务水平（宁可多建） // Cu:Co = 5:1 → 83%（建 + 留接口） // Cu:Co = 2:1 → 67%（宁可少建）

这一阶段的死法

✕
总图不留接口。二期无地可用、电力容量不够、物流通道被建筑挡住——再多的钱也买不回时间。
✕
用单点预测做十亿级投资。没有情景规划，等于把公司押在一个数上。
✕
只算进不算退。需求下滑后产能既不能转租也不能转产，变成纯沉没成本。
过门条件 三档情景的 Cu/Co 都算过；扩产接口清单已进设计院图纸；每一期都写明「什么信号触发下一期」。

产能预规划

12–36 月 · 产品规划 + 制造工程

把整车节拍拆成零件 JPH，把 JPH 拆成长周期设备清单。这一步最容易把「年均」当「峰值」。

1

产能预规划

整车要多少节拍？零件要多少 JPH？哪些设备要提前 24 个月订？
时间
12–36 月
决策者
产品规划 / 制造工程
输入
  • 整车节拍目标（takt）
  • 峰值月需求，不是年均
  • BOM 与单车用量
  • 设备 lead time 表
动作
  • 整车 takt → 零件日需求
  • 零件需求 → 资源数量
  • 长周期设备提前锁定
  • 产能假设书评审
产出
  • 产能假设书（含峰值定义）
  • 设备/模具 lead time 清单
  • 供应商产能预留需求

这一阶段的算法

takt = 可用工时 ÷ 整车需求 零件日需求 = 整车日产量 × 单车用量 × (1 + 报废率) 设备台数 N = ⌈ 需求 ÷ (单台JPH × 可用工时 × OEE × Q) ⌉ 工位数 N = ⌈ ΣCT ÷ takt ⌉ // 案例：40 JPH → takt = 90 秒/台 // 869 台/日 × 1 × 1.02 = 886 件/日

这一阶段的死法

✕
用年均当峰值。全年 60% 负荷看起来富余，但 10 月单月 109%——断供就发生在那个月。
✕
用目标 OEE 算产能。拿 95% 目标值算出的产能是愿望；用实测 85% 算出来的才是能力。
✕
漏掉报废率。单件报废 2%，一个月就是 1,700 件的隐性缺口。
过门条件 峰值月的日需求已算出；OEE 与良率用的是同类产线实测值；长周期设备已进入订单。

这一阶段的死法

✕
四项设备全压 3 月底到位。任一延期，4 月仍是 26 JPH；没有缓冲的计划等于没有计划。

✕

过门条件 到货计划已错峰；每台关键设备有独立缓冲；调试人力按周排定；没有「同日到货 3 项以上」的情况。

安装与验证

6–12 月 · SQE + 供应商工艺

这是整条线上唯一能把「承诺」变成「证据」的环节。没有 Run@Rate，所有 JPH 都是口头。

3

安装与验证

能不能在 85% 负荷下，连续 8 小时，用量产人员和工装，跑出合格件？
时间
6–12 月
决策者
SQE / 供应商工艺
输入
  • 设备已安装、已单机验收
  • 量产工装、量产物料
  • 量产人员配置（含新员工）
  • 客户节拍要求
动作
  • 单机 → 联线 → 小批 → 批量
  • Run@Rate：85% 负荷 × 8h
  • PPAP 提交、PSW 签署
  • Cpk / MSA 验证
产出
  • Run@Rate 报告
  • PPAP / PSW
  • 产能验证报告（含瓶颈复测）

Run@Rate 的三重判定

达成率 = 实际合格产出 ÷ (设计JPH × 运行小时 × 85%) 三个条件同时满足才算通过： ① 产出率 ≥ 95% ② FPY ≥ 目标值 ③ Cpk ≥ 1.33 必须四项真实： 量产人员 · 量产工装 · 量产物料 · 跨换型 连续时长：8 小时 或 ≥300 件 // 作弊清单：只跑 2 小时（避换型）、只挑好件（避良率）、 // 用熟手（避学习曲线）、不换色（避换型损失）

这一阶段的死法

✕
只验「能做出来」，不验「能连续做」。单机 45 JPH，联线 26 JPH——瓶颈从来不在单机。
✕
用熟手跑验证。量产后新员工上岗，学习曲线立刻吃掉 15–20%。
✕
PPAP 通过就宣布产能达标。PPAP 验的是质量一致性，不是节拍能力。
过门条件 Run@Rate 报告已签；三个判据全部达标；换型与换色已被纳入测试；瓶颈工位已复测并写入 PPAP。

SOP 爬坡

0–12 月 · 双方项目组

爬坡不是「等它变好」，是每天用数据判断它是否在变好。判据是连续 3 周达成率 ≥95%，不是月底累计。

4

SOP 爬坡

这一周比上一周真的进步了吗？瓶颈迁移到哪了？
时间
0–12 月
决策者
双方项目组
输入
  • Run@Rate 基线
  • 日产出与不良数据
  • 人员到位与培训进度
  • 客户需求版本
动作
  • 日爬坡会（欠产 ≥5% 触发）
  • 用累计产量作横轴看曲线
  • 每周复测瓶颈位置
  • 人员与产能同图对照
产出
  • 爬坡曲线（周度 + 达成率）
  • 瓶颈迁移记录
  • 欠产补回方案

爬坡健康度判据

周达成率 = 实际产出 ÷ 计划产出 稳定判据 = 连续 3 周达成率 ≥ 95% 爬坡斜率 = Δ产出 ÷ Δ周（件/周²） // 用「累计产量」当横轴，不要用「日历周」 // ——否则看不出爬坡是否真的在进步，只看到时间在过

这一阶段的死法

✕
用月末累计掩盖周度欠产。月底冲到 98%，但前三周都在 70%——客户已经停线了。
✕
人员计划与产能计划两张皮。需要 33 人，培训峰值只有 6 人，爬坡曲线必然落空。
✕
不跟踪瓶颈迁移。解决了冲焊，以为万事大吉，结果卡在装配和器具上。
过门条件 连续 3 周达成率 ≥95%；瓶颈位置已复测两次以上；人员到位表与爬坡曲线同图且对齐。

稳态运营

12 月+ · 计划 + 制造

稳态最危险的地方，是所有人都以为它不会变。参数三年不更新，产能就在悄悄流失。

5

稳态运营

OEE 在涨还是跌？换型损失占了多少？器具够不够？
时间
12 月+
决策者
计划 / 制造
输入
  • MES 实时产出与停机
  • 月度需求版本
  • 换型/换色记录
  • 器具周转与返空数据
动作
  • 月度产能评审（负荷 >90% 升级）
  • SMED 持续改善
  • 瓶颈复测（季度）
  • 柔性方案预研
产出
  • 月度产能评审包
  • OEE 趋势与改善清单
  • 扩产预警（负荷连续 2 月 >90%）

稳态的四把尺子

OEE = A × P × Q 健康值 ≥85%（离散） TEEP = OEE × (计划 ÷ 日历) 双班典型 40–60% 平衡率 = ΣCT ÷ (瓶颈CT × 工位数) <75% 先做重排 换型占比 = 尾部SKU换型 ÷ 总换型 >30% 说明真瓶颈是换型 // SMED 通常比买设备便宜一个数量级 // 换型 30min → 10min，等于白得 5–8% 产能

这一阶段的死法

✕
只报 OEE 总分。85% 到底是 A 低还是 Q 低？不拆开就无法定位改善点。
✕
用加班掩盖能力不足。加班能把平均 JPH 拉上去，但掩盖了真实的瓶颈和 OEE 下滑。
✕
器具与返空不算产能。日产量翻倍了，器具没翻倍，有产能也发不出货。
过门条件 OEE 三项分开报且为实测；换型时间已量化；器具数量按「日产量 × 周转天数 ÷ 容量 × (1+返空率)」算过。

尾件备库测算

尾件总量 = 年售后需求 × 供应年限 × (1 + 安全系数) 备库成本 = 尾件总量 × 单价 × (持有成本率 × 年限 + 报废风险) 保留产线成本 = 专用产能年固定成本 × 年限 // 判据：备库成本 < 保留产线成本 → 一次性备库 // 否则 → 保留专线或寻找替代产线

这一阶段的死法

✕
尾件占用主线产能。为 200 台/年的售后件保留一条专用线，等于每年烧掉一条线的固定成本。
✕
共线期没做产能分配。新老产品抢同一条线，两边都不达标。
✕
工装直接报废。没算改制成本 vs 新制成本，也没考虑未来可能的复用。
过门条件 尾件备库 vs 保留产线已做成本对比；共线期产能分配方案已签；工装处置有明确结论和责任人。

三个必算指标

① 尾部集中度 = 前 20% SKU 产量占比 （<70% 说明尾部重） ② 换型时间占比 = 尾部SKU换型 ÷ 总换型时间 （>30% 说明真瓶颈是换型） ③ 服务水平差 = P95 交期 − 平均交期 （>2 倍说明波动主导） // 一句话判断：换型占比 > 30%，真瓶颈不是 JPH，是换型 // 此时买设备是最贵的解法，SMED 才是

五把刀（按优先级）

1 分层
ABC/XYZ 分类。A 类保交付、C 类保成本，别用一套 KPI 管所有 SKU。
2 延迟差异化
把颜色推到最后一刻（后喷、贴膜）。把长尾从产能问题变成库存问题。
3 通用化
10 种颜色 → 3 基色 + 7 后处理，换型损失立刻下降。
4 柔性产能
弹性班次、共享产线、代工池。柔性价值 = 方差 × 单位缺口成本。
5 定价与配额
长尾 SKU 加价或设最小起订，用价格把需求推回头部。

十种死法

每条都在真实报告里见过

这十条不是理论，是从提能报告里逐条抠出来的。能对上几条，就说明这份报告有几处不能信。

#死法表象根因处方
1产能 = 需求量Gap 全 0没做独立测算强制 min(设备,人员,班次×JPH×天数×OEE×Q)
2总量平衡掩盖峰值全年 60% 负荷用年均代替峰值月逐月负荷表 + 峰值月单独审
3「到位」当「达产」3 月底到位 → JPH 40缺 Run@Rate把 Run@Rate 写进付款节点
4瓶颈不重算解决冲焊后仍不达标瓶颈漂移到装配每解一个瓶颈重跑全链
5只用平均 JPH「我们 JPH 40」口径错强制用瓶颈工位 JPH
6良率无措施「预计 95%」空头承诺三条措施 + 责任人 + 周测
7人员与产能脱节需 33 人，培训峰值 6 人两条线各做各的逐周到位表与爬坡曲线同图
8器具/返空不算产能排序物流「无瓶颈」只算节拍不算物流器具 = 日产量×周转÷容量×(1+返空率)
9换型损失不扣多颜色按满产算用能力值不用实际值实测换色时间 × 换色次数
10无退出机制需求下滑后闲置只算进不算退决策时同步定义退出路径
最后一句：产能管理的产出不是一个数字，而是一组契约——在什么条件下、由谁、在多久内、承诺多少。 任何只给一个数字、不说口径的报告，都不该被接受。
