方法论核心：三方法递进式混合研究框架
三种方法均作用于整个韧性S&OP全流程，区别在于分析维度不同：静态结构 → 组态关系 → 动态演化。前一种方法的输出 = 后一种方法的输入，结论三角验证。
三方法递进逻辑链
DEMATEL-ISM
静态结构分析
输出：关键因素
关键因素
→条件变量
→
fsQCA
组态关系分析
输出：组态路径
组态路径
→仿真场景
→
系统动力学SD
动态演化分析
输出：最优策略
三种方法结论互相验证（三角验证）：DEMATEL识别的关键因素应在fsQCA中作为核心条件出现；fsQCA的高韧性路径应在SD仿真中表现出更优的动态效果
方法一：DEMATEL-ISM 静态结构分析 — 回答"影响因素是什么？"
📥 输入
• 18个影响因素（5维度：流程/组织/技术/供应/环境）
• 15-20位行业专家打分（0-3分制影响程度）
• 文献+案例+实践提炼的因素清单
⚙️ 处理步骤
① 构建直接影响矩阵
② 计算综合影响矩阵（归一化+求逆）
③ 绘制因果图（原因型vs结果型）
④ 构建ISM层级模型（可达矩阵+层级划分）
⑤ MICMAC四象限分析（驱动度×依赖度）
📤 输出
• 关键因素清单（原因型核心驱动因素）
• 因素间因果关系图
• ISM层级结构（根源层→中间层→表象层）
• 因素优先级排序（改造杠杆点）
💡 起到效果
识别全流程"哪些因素最关键、因素之间如何相互影响、哪些是根源因素哪些是表象因素"，避免"头痛医头脚痛医脚"
🎯 达成目的
为fsQCA确定条件变量；为流程优化确定杠杆点和改造优先级；回答"影响因素是什么"
方法二：fsQCA（模糊集定性比较分析） 组态关系分析 — 回答"哪些组合能实现高韧性？"
📥 输入
• 7个条件变量（来自DEMATEL关键因素）
• 1个结果变量（S&OP韧性水平）
• 20-25家企业样本（整车厂+Tier1+对比组）
• 数据来源：公开年报+行业白皮书+问卷
⚙️ 处理步骤
① 变量校准（直接校准法：三个锚点）
② 构建真值表（2^k=128种逻辑组合）
③ 必要条件分析（一致性≥0.9）
④ 标准分析（复杂解/简约解/中间解）
⑤ 稳健性检验（调整校准阈值+PRI）
📤 输出
• 3-4条高韧性组态路径（殊途同归）
• 每条路径的核心条件+边缘条件
• 覆盖度（Coverage）和一致性（Consistency）
• 必要条件（单个因素是否必要）
💡 起到效果
识别全流程"哪些因素组合能实现高韧性、有几条等价路径、每条路径的核心条件是什么"，突破传统回归"单一因素净效应"的局限
🎯 达成目的
为SD确定仿真场景；为企业提供路径选择参考（不同条件选不同路径）；回答"哪些组合能实现高韧性"
方法三：系统动力学SD 动态演化分析 — 回答"动态效果如何？最优策略？"
📥 输入
• 6个仿真场景（来自fsQCA组态路径）
• 4个子系统（需求/供应/库存/数字化）
• 4条核心因果回路（正反馈+负反馈）
• 参数来源：文献+案例数据+专家估计（三角验证）
⚙️ 处理步骤
① 构建因果回路图（CLD）
② 转化为存量流量图（SFD）
③ 参数校准（用蔚来ET5案例数据拟合）
④ 模型有效性验证（极端/行为再现/敏感性）
⑤ 6场景仿真对比 + 4参数敏感性分析
📤 输出
• 6场景仿真对比曲线（产量/库存/成本/韧性）
• 最优策略组合（成本-韧性平衡点）
• 中断恢复时间对比
• 4参数敏感性分析结果（哪些参数影响最大）
💡 起到效果
量化全流程"不同策略组合在时间维度上的动态效果、成本-韧性权衡关系、中断恢复速度"，把静态的组态路径放到动态环境中验证
🎯 达成目的
为流程优化提供量化决策支持；验证组态路径的动态有效性；回答"动态效果如何？最优策略？"

实现手段核心：场景规划（思维方式）+ 数字化五层能力（技术底座）
韧性S&OP的落地需要两个支柱：①场景规划作为思维方式贯穿全流程，确保每个环节都在"多场景假设"下做决策；②数字化五层能力作为技术底座，提供实时数据、智能算法、协同共享和智能决策的技术支撑。
数字化五层能力框架（自下而上，支撑韧性S&OP全流程）
L5
智能决策层
AI辅助决策引擎 + 场景仿真平台 + 智能预警系统
支撑韧性能力：学习（战略复盘）+ 恢复（快速决策）
具体应用：中断时AI推荐最优恢复方案；高管会议实时仿真不同策略效果
L4
协同共享层
跨企业信息共享平台 + 供应商协同系统 + 需求信号共享
支撑韧性能力：吸收（供应商协同）+ 恢复（跨企业协同）
具体应用：供应商库存实时可见；需求变化实时同步给上游供应商
L3
智能算法层
ML需求预测 + 优化排产算法 + 库存优化模型 + 风险预警算法
支撑韧性能力：适应（动态预测）+ 准备（风险预警）
具体应用：ML多场景需求预测；供应风险自动识别和分级预警
L2
数据治理层
主数据管理 + 数据质量监控 + 数据标准 + 数据安全
支撑韧性能力：准备（数据基础）
具体应用：物料/供应商/产品主数据统一管理；数据质量自动监控和告警
L1
基础设施层
IoT传感器 + 云平台 + 数字孪生 + 边缘计算
支撑韧性能力：准备（实时感知）
具体应用：工厂/仓库IoT实时数据采集；供应链数字孪生镜像
自下而上：L1提供数据感知 → L2保证数据质量 → L3提供智能分析 → L4实现跨企业协同 → L5支撑智能决策
🔀 场景规划：韧性S&OP的思维方式核心（贯穿全流程）
1️⃣ 多场景假设
每个计划环节都同时考虑乐观/基准/悲观/极端四种场景，不再只做单点预测
2️⃣ What-if 仿真
基于数字孪生和SD模型，实时模拟"如果某供应商断供/需求暴增/物流中断"的效果
3️⃣ 应急预案预演
中断发生前就备好各场景的恢复预案，定期演练，确保中断时能快速启动
4️⃣ 动态触发切换
设定关键指标阈值（库存/交付/风险评分），指标超阈值时自动从"正常模式"切换到"中断模式"

• 数据质量监控

韧性目标：可预测（能预判问题）

特征：跨企业协同、智能计划
重点：L4建设

• 需求信号实时共享
• 多场景滚动计划
韧性目标：可协同（能联合应对）
→
阶段四：引领期
特征：自主决策、生态协同
重点：L5建设
• AI辅助决策引擎
• 供应链数字孪生
• 场景仿真平台
韧性目标：可自愈（能自动恢复）
