📋 Agent 管理工作区平台核心

Agent 不是虾：独立配置指令（System Prompt）、模型（Mimo-V2.5-Pro）、知识库（AgentBrain）、并发上限；不依赖虾运行时

▼ 驱动
⏰ 自动化 / 任务队列确定性
定时自动化触发 Agent；任务队列可见执行结果；Issue 状态机（待办→审查中→完成），人机闸口清晰
▼ 调用
⌨️ CLI / 工具
Agent 通过 Skill 调用 dx-ep sapo order 等 CLI，完成样件订单导入/检查/查询/下单等业务操作
⚠️ 关键差异：Agent 执行体是否为「虾」
Mico → 依赖虾
Mico 的 Agent 执行体是「虾」，平台层（协同/工作流/Skill）围绕虾构建；虾承担提示词驱动与工具调用，脱离虾 Mico 无法独立运行 Agent。
Agent Space → Agent 非虾
Agent Space 的 Agent 是独立配置的执行体（指令 + 模型 + 知识库 + Skill），不依赖虾运行时；平台直接管理 Agent 生命周期与自动化触发，Agent 可脱离虾独立运行。
