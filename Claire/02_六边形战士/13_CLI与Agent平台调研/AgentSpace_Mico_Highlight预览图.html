Agent Space vs Mico · Highlight 总结
2026-09-08 ｜ 来源：Agent Space 平台实测 + MiCo 官方介绍 + 原选型对比文档
Agent Space
Agent 运行与管理工作区
解决 Agent 在哪跑、谁可用、挂什么 Skill · 偏确定性任务执行
Mico
人 + Agent 深度协同平台
解决人与 Agent 围绕项目上下文协作交付、沉淀复用 · 偏组织级协同
组合建议
非二选一
短期 Agent Space 跑确定性流程；后续评估 Mico 作上层协同层
⚡ 主要差异
维度Agent SpaceMico
权限分层：所有者/管理员/成员；可见性可设工作区或私有成员同等地位，无法继续分配权限
Skill工作区共享、本地上传；可按 Agent 分配并选版本精选 Skill 按角色绑定；Skill/代码仓库/MCP/A2A 多接入
工作流定时自动化 + 任务队列可见执行结果仅 3 个预设不可调，无可用时只能提示词驱动
任务闭环Issue 状态机（待办→审查中→完成），人机闸口清晰Issue 全链路上下文，人 Review+Approve 决策
知识库空间绑定 AgentBrain，多知识库并集注入企业级知识库，自动蒸馏持续进化，多源导入
观测/评测Langfuse 观测 + agentops 独立评测中心全程可追溯、每步日志，数据隔离加密
多端/模型Web 端；模型可配（Mimo-V2.5-Pro）桌面/移动/Web 三端；不绑定生态、可接 Harness
🧭 适用场景
✅ Agent Space 适合
确定性业务链路自动化（如样件订单五环流程）
团队权限隔离与分层管控
Skill 版本化管理（本地→测试→上传→共享）
定时任务驱动 · 可观测可评测
✅ Mico 适合
研发协作（多角色 Agent 小队、15 节点流水线）
人机混合团队交付（主控拆解子任务并行）
组织级知识沉淀与复用
跨角色场景（Bug 修复/巡检/运维/测试/PPT）
样件订单现状：Agent Space 已挂 5 个 Skill，WS-1 执行至「审查中」；下一步卡点＝查询可下单 CLI（dx-ep sapo order query-ready）待开发。Mico 工作流模式无可选预设。
