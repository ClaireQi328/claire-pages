底座补齐路线与数字化部门生态位
采购数字化 · 26Y 四层架构 × 五层 AI 能力体系 ｜ 2026-09-08
六个底座：现状 → 动作 → 目标
① 数据底座（数据采集层）
现状：268 问卷 100% 回收 · 7954 零件定价 · 3534 零件 BOM 拆解
动作：MVPS 品类主数据 → 供应商 360° 画像 → 成本数据库 → 数据治理目录
② 能力底座（L5 CLI）
现状：19 个查询型 CLI
动作：WAVE2/3 写入（订单/合同/变更）· 契约化（入参出参/版本/错误码）· 可观测看板
③ 技能底座（L4 Skill）
现状：编排规则散在 Agent 层
动作：规则分级 → Skill 封装 → 领域服务 → 规则引擎下沉 · 配套测评 Agent
④ 智能底座（L2/L3）
现状：流程执行自动化先行
动作：L3 提效（样件 26.5→2、合同 14.5→1 人时/天）→ 数据齐备后上线 L2 辅助决策 · 人机协同
⑤ 治理底座（贯穿层）
现状：开放数据与写操作，缺治理即失控
动作：权限分级（只读/可写/审批）· 写操作审计 · Agent 调用治理（配额/熔断/版本）· 敏感字段脱敏
⑥ 组织底座（FDE 体系）
现状：产品开发、数据分析岗位有"做空"风险
动作：研发做 CLI · FDE 编排场景 · 业务定目标；产品岗→场景编排者，分析岗→数据质量+评测+研判
数字化部门生态位：平台方 + 赋能方 + 治理方
数据资产方
主数据 · 画像 · 成本库 · 治理
不可替代性：数据口径解释权
能力平台方
CLI / Skill 原子能力
不可替代性：研发一次、FDE 复用多次的杠杆
场景赋能方
Agent 场景编排 · FDE 协同
不可替代性：业务目标→技术方案的翻译能力
规则守护方
权限 · 审计 · 评测 · 风控
不可替代性：开放与安全的平衡
能力抓手（可量化）
能力资产（CLI/Skill 数、复用次数）· 提效成果（人时/FTE/周期）· 数据资产（主数据覆盖率、质量分）· 治理水平（审计覆盖、事故数趋零、评测通过率）
价值公式：沉淀可复用能力 × 治理数据资产 × 放大业务决策质量
AI 提效已验证数据（人时/天）
