EP 产品功能 · 设计说明（v0.8）

模块定位：「成本库与交叉比价中心」挂载在 EP「报价管理」下，定位大型成本数据库。所有报价按 final 模板结构化入库，按 零件 / 供应商 / 工艺 / 场地 / VPPS / 品类 / 状态 / 报价包 任意组合检索。

v0.17 高级质感 · 三大能力升级：整体视觉升级（深色渐变主视觉 / 卡片层次 / KPI 渐变数字 / 表头深色 / 图表悬浮）。① 基准价格维护：维护 Tab 新增「基准价格总览」——每条已维护基准自动汇总 命中报价数 · 实际均价 · 偏差%（超基准红 / 低于绿）。② 报价数据对比：对比 Tab 沉淀表（报价包/供应商/工厂/轮次/零件/报价详情全字段列配置）。③ 关键要素对比：新增独立卡片——11 项要素（人工费/工时/费率/设备/场地/能耗/模具/开发/物流/管理/样件）可拆选，逐报价逐项对比 + 均值行 + 偏离计数（超均值 ±15% 自动标色）。④ 图表丰富：新增 基准偏差（出厂价 vs 均值 红绿标色+均值线）/ 供应商六要素雷达画像 / 价格×制造费气泡（气泡=模具费），共 8 图勾选组合。

v0.16 维护基准 / 对比双 Tab：页面拆为「维护基准」与「对比」两个 Tab：维护基准集中 采购员基准维护（分组基准价/上下限）+ 费率维护（24 项费率表格内直接编辑、偏离参考实时算）+ 费率参考库；对比 Tab 为完整报价沉淀与交叉比价（检索/KPI/费率库表格/沉淀表/图表）。沉淀表新增 报价包名称、报价详情（材料/制造/模具/开发/物流/管理 六类构成，悬浮显示全量）等字段，默认列扩至 23 列。

v0.15 关键要素费率库表格化：关键要素费率库由分组卡片改为表格（类别 / 费率项 / 单位 / 参考值 / 库内维护值 / 偏离参考 / 来源），支持按类别筛选，维护值与参考值同列对比并自动计算偏离百分比（超参考标红、低标绿），库内实测沉淀（直接人工费/年工时/设备投资/OEE/模具单件/样件倍数）保留在表下方随报价入库自动重算。

v0.14 关键报价要素明细列：中粗项粒度新增「人工明细」（直接/间接人数、直接工时、人工费率）与「设备与场地」（设备投入总额、折旧费、OEE、场地费分摊）两组要素列，管理费用组补 DB/利管费率（=金额÷出厂价），关键要素列（设备/人工/报废/能耗/耗材/场地/工时/费率/管理费）默认展示，一行一报价横向对比，支持列配置勾选、费率维护、基准行与异常识别。

v0.13 中粗项 + 细项沉淀：沉淀表新增「粒度」切换（中粗项 / 材料细项 / 制造细项），行源、列配置、口径、分组、图表随粒度联动并分别持久化。中粗项列对齐《报价细项列表导出》（48 列：材料费 自制/外购/客户指定/委外、制造费 设备/报废/耗材/能耗/人员、模具/开发 分摊汇总·量·单价、物流 包装/运输/排序/中转、管理 DB/利管/其他、样件 手工/软模/硬模倍数与价格）；材料细项沉淀 BOM 子件（层级/来源/数量/材料/单价/回收单价/原材料/外购件/材料费）；制造细项沉淀工段/线体（CT/OEE/LCR/占地/折旧/能耗/报废/耗材/人员/制造费小计），随真实报价数据入库自动增长。

v0.12 精简文字 · 字段对齐《报价细项 PRD》：删除顶部价值卡/维度条/大段定位说明，页面直入 检索 → KPI → 沉淀表 → 图表 → 费率库。沉淀表列定义按 PRD 报价细项 8 模块重写：材料费用（材料费=原材料价格+外购件价格）、制造费用（设备/人员/报废/能耗/耗材中粗项）、人工明细（直接/间接/工时/费率）、设备成本、模具费用（总额/数量/单价）、开发费用、物流费用（运输/包装/中转/排序）、管理费用（DB/利管/其他+费率）、样件费用（倍数+计算）、汇总（出厂价=材料+制造+管理；到厂价=出厂价+模具+开发+物流）。列配置默认展示到厂价。

v0.11 沉淀成本数据库（视觉重构）：整体改为专业 BI 看板风（浅灰底 / 白卡 / KPI 大数字 / 表格 hover / 胶囊选项）。顶部沉淀均值 KPI：沉淀报价 / 报价包·零件 / 平均出厂价 / 平均材料 / 平均制造 / 平均人工 / 平均管理 / 平均模具单件（元/件口径，随报价入库自动重算）；报价沉淀表：行分组 报价包 / 供应商 / 零件 / 工厂，列＝报价细项（38 字段列配置勾选展示/对比，口径原值/均值/vs均值，异常识别，基准行）；图表组合展示：成本构成堆叠 / 供应商对比 / 地域均值 / 制造要素占比 / 轮次趋势，勾选组合、随检索与口径联动（ECharts）。费率库保留默认可见。

v0.10 供应商报价数据源：参考 CE 核价数据源（est/proc/equip 三层 + 主数据）建立「供应商报价数据源」——报价 Excel 导入即结构化入库，数据模型 6 层（报价头 / 成本构成 / 制造要素 / 工艺卡 / 模具设备 / 费率库），字段逐项对齐 CE 核价输入（quote_id→id、material→mat、mfg→mfg、admin→ga、logistics→logi、tool→tool、quote→quote…），可直接作为 CE 核价的上游数据源；页面新增 Schema 表 + 字段映射矩阵 + 样例数据（RFW-D01 完整结构）。

v0.9 关键要素费率库：在对比表上方新增「关键要素费率库」面板，默认展开、无需任何选择即可查看——沉淀 24 项参考费率（人工 / 场地 / 能源 / 折旧 / 比率 / 产能 / 包装），按分组卡片展示当前值与来源；顶部统计条展示库内沉淀现状（报价 / 供应商 / 城市 / 参考费率 / 采购员维护数）；「库内实测沉淀」随报价入库自动聚合（直接人工费、年工时、设备投资、OEE、模具单件、样件倍数）。采购员在「列配置 → 费率维护」中改值后，面板与对比表费率列实时联动（带「维护」徽标）；折叠状态本地记忆。

v0.8 简化收敛：不再拆「选件列表 + 分析 Tab」多模块——所有需要对比的信息统一通过 列配置（勾选对比字段：价格 / 材料分项 / 制造要素 / 人工·工时 / 设备 / 模具 / 开发 / 物流 / 管理 / 样件 / 维度列）和 选项（行分组：不分组 / 按零件 / 按供应商 / 按地域；口径：原值 / 均值 / vs均值；异常识别开关；基准行）在单张对比表内实现。列头点击排序，空值标"—"。

口径保护：元/件与元/KWh 不混算（均值 / 基准 / 异常仅按元/件口径统计，元/KWh 行单独标注）；演示零件族与演示供应商标注「演示」；VPPS / 品类为示例标注。采购员基准与费率维护存于本机（localStorage），正式版同步 EP 主数据与费率库。
