03 / Decision Matrix

精简决策：必要 × 喜欢 四象限

对每件物品问两个问题："我需要它吗？"（功能必要性）和"我喜欢它吗？"（情感/审美价值）。落入哪个象限，就按对应策略处理。

✓ 必要 + 喜欢 → 留

这是你衣橱的核心。穿着频率高、穿上自信、功能不可替代。好好保养，坏了就换同款或升级。

典型：白色运动鞋、裸色高跟鞋、白T、牛仔裤。

⚡ 必要 + 不喜欢 → 换更好的

功能需要但穿着体验差（磨脚、扎皮肤、不合身）。不要凑合，淘汰后买一件真正喜欢的替代品。

典型：不合身的运动内衣、磨脚的靴子。

◆ 不必要 + 喜欢 → 限量保留

不是生活必需，但带来快乐和自我表达。设定物理边界和数量上限，在边界内尽情保留。

典型：Salomon 潮鞋、特殊颜色单品、爱好相关物品。

✗ 不必要 + 不喜欢 → 出

既不需要也不喜欢，留着纯粹是因为"扔了可惜"或"万一以后用"。果断出，空间比物品值钱。

典型：一年没穿的衣服、重复款、赠品。

04 / Redesign Guide

已有物品重新设计：五步法

极简不是剥夺，是精选。目标是让每一件留下的物品都有明确的位置、用途和情感价值，同时为"乐趣"留出专门的空间。

1

全量盘点：看见你拥有的一切

把所有物品从柜子里拿出来，按空间分区进行（先衣橱、再鞋柜、再抽屉、再其他）。不要边整理边放回去，全部摊开才知道总量。

  • 建立物品清单：用本页的鞋子/衣服表格模板，逐件记录名称、类别、购入时间
  • 拍正面照：每件物品拍一张白底正面照，存入手机"我的物品"相册
  • 识别沉默成本：标记"过去一年没穿过/没用过"的物品，这些是重点淘汰对象
2

三层筛选：功能 → 频率 → 情感

对每件物品依次过三层筛选，任何一层不通过就进入"出"的堆。拿不准的放"待定"，最后统一再审。

  • 功能层：还能用吗？有替代品吗？功能是否和其他物品重叠？
  • 频率层：过去 3 个月用过吗？过去 1 年呢？（季节款按对应季节算）
  • 情感层：看到它开心吗？穿上/用上自信吗？有不可替代的纪念意义吗？
  • 待定堆处理：如果超过总量的 10%，说明标准太松，重新过一遍；真的拿不准的，装一个箱子写上日期，3 个月没打开就原封不动捐掉
3

乐趣边界：为喜欢但非必需的东西设限

这是"简单"和"无趣"的分界线。你不需要放弃喜欢的东西，但要给它们设定物理边界和数量上限，在边界内自由保留。

  • 设定物理容器：乐趣物品只允许放在一个抽屉/一个架子/一个箱子里，满了就必须淘汰旧的才能进新的
  • 设定数量上限：例如"运动鞋不超过 3 双""帽子不超过 2 顶""包不超过 3 个"，数字由你定，但定了就要守
  • 一进一出：买一件新的乐趣物品，必须淘汰一件旧的同类物品
  • 数字化替代：书可以用电子书、纪念品可以拍照存档、CD 可以转数字文件，把物理占有变成数字收藏
4

重新设计收纳：一物一位、一目了然

留下的物品按"使用频率"和"使用场景"重新分配位置。高频物品放视线平齐处，低频放高处或底层。

  • 按频率分区：每天用的放最顺手的位置，每周用的放次层，每月/每季用的收起来
  • 按场景分区：出门穿戴（外套+鞋+包+钥匙）集中在玄关，居家物品集中在卧室
  • 可视化原则：能挂就不叠，能竖叠就不横叠，能看到全貌就不收进暗处
  • 一物一位：每件物品有固定位置，用完归位，不允许"暂时放一下"
5

建立维护机制：从"一次整理"到"持续精简"

整理不是一次性事件，是日常习惯。用最小的维护成本防止反弹，同时让精简成为持续的生活方式。

  • 每日 1 分钟：睡前把当天用过的物品归位，衣服挂回或放洗衣篮
  • 每周 10 分钟：周日花 10 分钟检查各区域是否整洁，预排下周穿搭
  • 每季 1 小时：换季时盘点当季物品，标记一次没穿的，做小淘汰
  • 每年 1 次大清理：年底全量盘点一次，更新物品清单，淘汰率目标 10-20%
  • 购物前 30 天等待清单：想买的非必需品先记进清单，30 天后还想买再买，大部分冲动消费会自然消失
05 / Multi-Device Access

多设备查看方案

MD、Word、HTML 文档如何在电脑和手机之间便捷查看？以下三种方案对比，以及推荐组合。

飞书在线文档

把 MD/Word 内容转成飞书文档，手机和电脑都有原生 APP，阅读体验最好，支持搜索、目录、评论。

✓ 手机电脑原生体验 ✓ 自动同步 ✓ 可搜索可评论

✗ HTML 可视化效果会丢失 ✗ 需要手动转换

飞书云空间

把 MD/Word/HTML 原文件上传到飞书云盘文件夹，手机飞书 APP 可直接预览 Word/MD，HTML 可下载后浏览器打开。

✓ 保留原文件格式 ✓ 统一入口 ✓ 支持搜索

✗ HTML 手机预览需下载 ✗ 大文件加载慢

静态托管链接

把 HTML 部署到静态托管（如 GitHub Pages、Vercel），生成永久链接，手机电脑浏览器直接打开，体验最佳。

✓ HTML 完整体验 ✓ 链接随时分享 ✓ 不占本地空间

✗ 需要部署操作 ✗ MD/Word 不适用

推荐组合方案

  1. 日常工作文档（MD/Word）：转成飞书在线文档，存入飞书知识库的"我的工作台"空间，手机电脑随时看
  2. 可视化报告（HTML）：原文件上传飞书云空间保留，同时我可以帮你把核心内容同步成飞书文档摘要
  3. 物品清单（本页）：建议转成飞书多维表格——每双鞋/每件衣服一行，可加图片、状态、穿着频率字段，手机端可随时编辑和勾选
  4. 统一入口：在飞书文档里建一个"我的工作台"首页，把所有文档链接、云盘文件夹、HTML 链接汇总在一起，收藏到手机桌面
06 / Action Plan

30 天执行计划

不要想着一天搞定。按周推进，每天 15-30 分钟，一个月后你的物品系统会完全不同。

第1周
盘点 + 拍照建档

每天处理一个区域：周一衣橱上装、周二衣橱下装+裙装、周三鞋子、周四包袋配饰、周五其他物品。逐件拍正面照，填入清单表格。

第2周
三层筛选 + 分流

用"功能→频率→情感"三层筛选逐件决策。准备三个袋子：留 / 出（捐/卖/送）/ 待定（装盒写日期，3个月后处理）。目标淘汰率 30-40%。

第3周
收纳系统重建

采购统一衣架、抽屉分隔盒、鞋盒标签。按"频率+场景"重新归位。鞋子按类别分区，当季常穿放鞋柜外层，不常穿收抽屉或鞋盒。完成后拍"整理后"全景照。

第4周
习惯养成 + 数字化

开始每日 1 分钟归位、每周日穿搭预排。把物品清单转成飞书多维表格，手机端随时更新穿着记录。建立"30 天购物等待清单"。

每月
回看 + 微调

月底回看 OOTD 相册和物品清单，标记一次没穿的物品。季度末做小淘汰，年底做大清理。精简是持续过程，不是终点。

简单不是拥有得少，是每一件都值得。

整理完成后，把"整理后"照片和更新后的清单发我，帮你做搭配建议和二次优化。
