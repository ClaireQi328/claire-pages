# 🖥️ IHSC 与芯片供应链

> 硬件与芯片供应链 — 字节 Data 事业部的核心战场，GPU 是「硬通货」。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **覆盖品类**：服务器整机、交换机、网络设备、IDC 部件（GPU/CPU/DRAM/光模块）、基础设施（液冷/机柜）、Foundry/OSAT
> - **核心矛盾**：GPU 产能受限（美国出口管制）vs AI 算力需求爆发
> - **采购模式**：ODM/JDM 定制为主，Buy&Sell 采销联动
> - **流程特点**：高价值、长交期、序列号管理、全球寻源

---

## 一、品类全景

| 二级品类 | 核心标的 | 供应商 | 采购特点 |
|----------|---------|--------|---------|
| **服务器整机** | 标准型、定制型 | 浪潮、超聚变、联想、富士康 | ODM/JDM，高价值，序列号管理 |
| **交换机整机** | 白盒交换机、品牌交换机 | Arista、H3C、锐捷 | 含 CPO（共封装光学） |
| **网络设备** | 光模块、AOC、DAC、综合布线 | 中际旭创、新易盛、康普 | 400G/800G 迭代快 |
| **GPU** | H100/H800/H20/自研 | NVIDIA、AMD、自研 | 最紧缺，交期 6-12 个月 |
| **CPU** | Xeon/EPYC/鲲鹏 | Intel、AMD、华为 | 主流 x86 + ARM 信创 |
| **DRAM** | DDR5 ECC | Samsung、SK Hynix、Micron | 价格波动大（2025 涨 171%） |
| **SSD** | NVMe Enterprise | Samsung、Solidigm、WD | IOPS 密集型 |
| **Foundry** | Wafer、Mask | 台积电、中芯国际 | 自研芯片流片 |
| **OSAT** | Bump、CP Test、封装 | 日月光、长电科技 | 封装测试 |
| **基础设施** | Tank、氟化液、rPDU、机柜、CDU | 维谛、英维克、申菱 | 液冷部署趋势 |

## 二、流程特点

### 2.1 寻源特点

| 特点 | 说明 |
|------|------|
| 全球寻源 | GPU/光模块需全球比价，涉及出口管制 |
| 长交期 | GPU 交期 6-12 个月，需提前 1-2 年规划 |
| 战略囤货 | 核心芯片需提前锁定产能、签订长期协议 |
| 替代方案 | 受限后需评估国产替代（华为昇腾、寒武纪） |

### 2.2 订单特点

| 特点 | 说明 |
|------|------|
| 高价值 | 单台 AI 服务器 50-200 万元 |
| 序列号管理 | 每台服务器有唯一 SN，全生命周期追溯 |
| 配置非标 | 按周变更配置（CPU 换代、SSD 换家） |
| Buy&Sell 联动 | 采购订单自动关联销售订单 |

### 2.3 收货特点

| 特点 | 说明 |
|------|------|
| 通电测试 | 服务器到货后需开箱通电验证 |
| 序列号逐一核对 | SN 与订单/ASN 逐一比对 |
| 批次追溯 | 部件需追溯到批次号（芯片批次） |
| 高密度验收 | GPU 集群需整组验收 |

### 2.4 结算特点

| 特点 | 说明 |
|------|------|
| AVAP 模式 | 采购价与销售价联动 |
| Rebate 核算 | 阶梯返利，年度核算 |
| 月度对账 | 大额采购，月度三单匹配 |
| 预付款 | GPU 等稀缺资源可能需预付 |

---

## 三、Buy&Sell 模式（ODM 业务）

> IHSC 供应链的核心采销模式。

```
BDSG 采购部件 → 供应商供货 → ODM 组装（浪潮/超聚变） → SG 销售成品 → 交付签收 → 结算
```

**关键设计要点**：
- AVAP 价格联动：采购价 → 销售价 → Rebate 价
- 库存双向可见：采购侧和销售侧同步
- 三单匹配：PO-ASN-发票

详见 [[Buy_Sell模式]] 和 [[08_ByteDance/01_产品介绍/SCM 产品介绍]]

## 五、风险管理

| 风险 | 影响 | 应对 |
|------|------|------|
| GPU 出口管制 | 供货中断 | 囤货、国产替代、自研芯片 |
| DRAM 价格暴涨 | 成本失控 | 长期协议、多供应商 |
| 交期延误 | 项目延期 | 安全库存、备选供应商 |
| 质量问题 | 上架失败 | IQC 严格检验、供应商绩效 |
