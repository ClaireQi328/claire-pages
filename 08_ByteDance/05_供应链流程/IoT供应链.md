# 📱 IoT 供应链

> IoT 硬件供应链 — 从电子元器件到整机成品的全链路管理，核心是「齐套」。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **覆盖品类**：IoT 整机、XR 整机、电子件（被动元件/芯片/传感器）、电子结构件、包材
> - **核心挑战**：BOM 齐套管理 — 一台设备几十上百种物料，缺一个都装不了
> - **采购模式**：多品类组合采购，JIT 配送，库存周转要求高
> - **流程特点**：品类多、批量大、交期紧、质量要求高（3C/RoHS）

---

## 一、品类全景

| 二级品类 | 核心标的 | 供应商特点 | 采购特点 |
|----------|---------|-----------|---------|
| **IoT 整机** | 火山、飞书等硬件整机 | ODM/OEM 代工 | 整机 BOM 管理 |
| **XR 整机** | VR 整机、AR 整机 | 专业 XR 代工厂 | 新品类，供应商少 |
| **芯片** | CPU、存储芯片、MCU | 高通、联发科、兆易创新 | 战略品类，交期长 |
| **传感器** | 影像、气压、陀螺仪 | Sony、博世、TDK | 技术壁垒高 |
| **被动元件** | 电阻、电容、电感、磁珠 | 村田、三星电机、TDK | 标准化，量大价低 |
| **连接件** | BTB 连接器、射频座 | 安费诺、莫仕、JAE | 多规格，需齐套 |
| **模组类** | 显示模组、芯片模组、通信模组 | 京东方、移远 | 集成度高 |
| **光学结构** | 镜头、滤光片 | 大立光、舜宇 | 精度要求高 |
| **结构件** | 金属件、注塑件、数据线 | 富士康、比亚迪电子 | 模具投入大 |
| **包材** | 包装件、铭牌、标签 | 包装供应商 | 低价值，量大 |

## 二、流程特点

### 2.1 齐套管理

> [!warning] PM 核心挑战
> IoT 的核心不是「买不买得到」，而是「能不能齐套」。一台设备可能需要 50+ 种物料，缺任何一个都无法组装。

```
BOM 分解 → 各品类分别下单 → 交期对齐 → 齐套检查 → 齐套放行 → 投产
```

**齐套管理要点**：

| 要点 | 说明 |
|------|------|
| BOM 分解 | 整机 BOM 拆解为各品类采购需求 |
| 交期对齐 | 所有品类交期必须对齐到同一窗口 |
| 齐套检查 | 系统自动检查各品类到货状态 |
| 缺料预警 | 任一品类延迟，立即预警 |
| 替代方案 | 关键物料准备替代供应商 |

### 2.2 寻源特点

| 特点 | 说明 |
|------|------|
| 多品类并行 | 50+ 品类同时寻源 |
| 模具投资 | 结构件需开模，供应商切换成本高 |
| 认证要求 | 3C、RoHS、REACH 等合规认证 |
| 小批量验证 | 新供应商需小批量试产验证 |

### 2.3 订单特点

| 特点 | 说明 |
|------|------|
| 多品类组合 | 一台设备涉及多个采购订单 |
| 批量大 | 消费级产品，单批次量大 |
| 交期紧 | 产品上市时间窗口有限 |
| 变更频繁 | BOM 变更、替代料切换 |

### 2.4 收货特点

| 特点 | 说明 |
|------|------|
| IQC 抽检 | 按 AQL 标准抽检 |
| RoHS 合保 | 有害物质检测 |
| 批次管理 | 电子件需批次追溯 |
| 可焊性测试 | PCB 焊接物料需测试 |
| 齐套确认 | 所有物料到齐才能放行投产 |

## 三、齐套管理详解

### 3.1 齐套流程

```
BOM 版本确认 → 物料需求分解 → 各品类下单 → 交期跟踪 → 齐套检查 → 放行投产
      ↑                                                          |
      └──────────── BOM 变更触发重新齐套 ←────────────────────────┘
```

### 3.2 齐套指标

| 指标 | 说明 | 目标值 |
|------|------|--------|
| 齐套率 | 按时齐套的订单比例 | ≥95% |
| 齐套周期 | 从下单到齐套的平均天数 | 按品类设定 |
| 缺料率 | 因缺料导致的停工比例 | ≤2% |
| 替代率 | 使用替代料的比例 | 尽量低 |

## 五、风险管理

| 风险 | 影响 | 应对 |
|------|------|------|
| 芯片缺货 | 整机停产 | 安全库存、替代方案 |
| 齐套延迟 | 上市延期 | 提前下单、交期预警 |
| 模具损坏 | 产能中断 | 备用模具、应急维修 |
| 合规不达标 | 产品下架 | 前置认证、定期抽检 |
| BOM 变更 | 库存呆滞 | 变更管理、呆滞料处理 |
