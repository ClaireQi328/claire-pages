# 🌐 服务供应链

> 服务供应链 — 非实物交付的供应链管理，核心是「里程碑验收」和「SLA 达标」。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **覆盖品类**：CDN 综合服务、专业服务（外包/物流/设计/EDA/IP）、设备运维、安装维修、处置回收
> - **核心差异**：无实物物流，以「交付物验收」和「里程碑付款」为核心
> - **流程特点**：服务合同 + SLA 条款 + 里程碑验收 + 满意度评估
> - **管理挑战**：服务质量难以量化、验收标准主观性强

---

## 一、品类全景

| 二级品类 | 核心标的 | 供应商特点 | 采购特点 |
|----------|---------|-----------|---------|
| **非中 CDN 综合服务** | 租赁、布线、集成安装 | CDN 服务商、ISP | 长期合同、SLA 保障 |
| **外包服务** | 技术人力外包、流程外包、代采外包 | 人力资源公司、外包公司 | 按人天/人月计费 |
| **物流仓储服务** | 进出口、仓储、配送 | 顺丰、京东物流、DHL | 按件/按重计费 |
| **设计服务** | ID 设计、委托开发 | 设计公司、ODM | 项目制、里程碑验收 |
| **EDA&IP** | EDA 工具、IP 授权 | Synopsys、Cadence、ARM | 年度授权费 |
| **生产加工服务** | SMT 贴片 | EMS 厂商 | 按件计费 |
| **质量与咨询服务** | 测试服务、行业报告 | 第三方检测机构 | 按项目计费 |
| **安装与维修服务** | 设备安装、维保 | 设备厂商、第三方 | 按次/按年 |
| **处置回收服务** | 设备报废、回收 | 环保公司 | 按批计费 |
| **其他专业服务** | 商标注册、法律咨询 | 专业机构 | 按项目计费 |

## 二、流程特点

### 2.1 合同特点

| 特点 | 说明 |
|------|------|
| 服务合同 | 区别于采购订单，以「服务合同」为主 |
| SLA 条款 | 明确服务水平承诺（可用性、响应时间） |
| 里程碑定义 | 明确交付节点和验收标准 |
| 计费方式 | 人天/人月/项目/按量 |
| 保密协议 | 涉及技术外包需签 NDA |

### 2.2 寻源特点

| 特点 | 说明 |
|------|------|
| 资质优先 | 服务能力、行业经验、资质认证 |
| 方案评估 | 技术方案和报价同等重要 |
| 参考案例 | 要求供应商提供成功案例 |
| 试用评估 | 小范围试用后再大规模合作 |

### 2.3 交付特点

> [!info] PM 视角
> 服务供应链没有「物流发货」环节，取而代之的是「交付物提交」和「里程碑验收」。

| 特点 | 说明 |
|------|------|
| 无实物物流 | 通过系统/文档/人员交付 |
| 交付物验收 | 代码、报告、设计方案等 |
| 里程碑付款 | 按里程碑节点付款 |
| 满意度评估 | 服务质量主观评价 |

### 2.4 结算特点

| 特点 | 说明 |
|------|------|
| 按里程碑对账 | 里程碑验收后触发对账 |
| 人天核算 | 外包服务按实际工时核算 |
| SLA 扣款 | 未达标按合同扣款 |
| 发票类型 | 增值税专用发票/服务发票 |

## 三、CDN 综合服务详解

> 非中地区 CDN 服务的供应链管理（参考 [[08_ByteDance/03_CDN/CDN定价分析]]）。

### 3.1 服务内容

| 服务项 | 说明 |
|--------|------|
| 机柜租赁 | 数据中心机柜空间租赁 |
| 带宽采购 | 公网带宽、BGP 多线 |
| IP 地址 | 静态 IP、IP 段 |
| 专线 | 跨境专线、MPLS |
| CDN 节点 | 边缘节点部署 |

### 3.2 采购流程差异

| 环节 | CDN 服务 | 硬件采购 |
|------|---------|---------|
| 寻源 | 运营商/IDC 服务商评估 | 供应商招采 |
| 合同 | 服务合同+SLA | 采购合同 |
| 交付 | 开通服务、配置上线 | 物流发货、到货验收 |
| 验收 | 连通性测试、性能基准 | 外观+功能检查 |
| 结算 | 按月/按量计费 | 按订单对账 |
| 付费 | 月度账单自动扣费 | 月度对账+付款 |

### 3.3 定价模式（中国 vs 非中国）

| 维度 | 中国区 | 非中地区 |
|------|--------|---------|
| 定价方式 | 标准化商品，统一价格 | 组件拆分，灵活组合 |
| 计费模式 | 按流量/带宽阶梯计费 | 机柜/带宽/IP 分开计费 |
| 价格水平 | 较低（竞争激烈） | 较高（跨境成本） |
| 合规要求 | 强合规，全链路整合 | 宽松，聚焦数据隐私 |

详见 [[08_ByteDance/03_CDN/CDN定价分析]]

## 四、外包服务管理

### 4.1 外包类型

| 类型 | 说明 | 计费 |
|------|------|------|
| 人力外包 | 按人天/人月提供技术人员 | 人天单价 × 工时 |
| 流程外包 | 整体流程外包（如客服） | 按量/按月 |
| 项目外包 | 整个项目外包（如开发） | 固定总价/里程碑 |

### 4.2 管理要点

| 要点 | 说明 |
|------|------|
| 人员准入 | 外包人员需通过安全审查 |
| 工时管理 | 每日工时填报、审批 |
| 质量验收 | 代码 Review、交付物验收 |
| SLA 考核 | 响应时间、交付及时率 |
| 知识产权 | 明确代码/方案归属 |

---

## 五、风险管理

| 风险 | 影响 | 应对 |
|------|------|------|
| 服务质量不达标 | 业务受损 | SLA 条款+验收标准 |
| 人员流失 | 项目延期 | 备选人员、知识沉淀 |
| 知识产权泄露 | 竞争劣势 | NDA + 访问控制 |
| 供应商倒闭 | 服务中断 | 备选供应商、数据备份 |
| 成本失控 | 预算超支 | 人天核算+预算告警 |
