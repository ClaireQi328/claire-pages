# ⛓️ 云服务供应链

> 云服务供应链 = 从「芯片」到「云服务」的价值转化链。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **云服务供应链 vs 传统供应链**：从「离散制造」变为「算力基建」
> - **六大环节**：芯片/硬件 → 服务器整机 → IDC 建设 → 网络/带宽 → 软件平台 → 云服务交付
> - **核心矛盾**：GPU 产能受限 vs AI 算力需求爆发
> - **字节实践**：ODM/JDM 定制 + Buy&Sell 模式 + 全球 IDC 布局

---

## 一、云服务供应链全景

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 芯片/元器件 │ → │ 服务器整机 │ → │ IDC 建设  │ → │ 网络/带宽 │ → │ 软件平台 │ → │ 云服务   │
│  GPU/CPU  │    │ ODM/JDM │    │ 机房/液冷 │    │ CDN/ISP │    │ 虚拟化   │    │ 交付     │
│  内存/SSD │    │ 组装测试 │    │ 配电/制冷 │    │ 专线/BGP │    │ 编排     │    │ 计费     │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

## 二、环节一：芯片与元器件采购

### 2.1 GPU（最紧缺资源）

| 维度 | 说明 |
|------|------|
| 主要供应商 | NVIDIA（H100/H800/H20）、AMD（MI300X）、自研 ASIC |
| 采购挑战 | 美国出口管制、产能不足、交期 6-12 个月 |
| 战略应对 | 囤货、替代方案（国产 GPU）、自研芯片 |
| 字节实践 | 内部自研芯片团队（上海/杭州），配合台积电流片 |

### 2.2 CPU

| 供应商 | 产品线 | 特点 |
|--------|--------|------|
| Intel | Xeon Sapphire Rapids / Emerald Rapids | 市场份额最大 |
| AMD | EPYC Genoa / Bergamo | 性价比高，核心数多 |
| 华为海思 | 鲲鹏 920 | 信创市场，ARM 架构 |

### 2.3 存储与内存

| 品类 | 供应商 | 说明 |
|------|--------|------|
| DRAM | Samsung、SK Hynix、Micron | 价格波动大（2025 涨 171%） |
| SSD | Samsung、Intel/Solidigm、WD | NVMe 成主流 |
| HDD | Seagate、WD | 冷存储场景 |

### 2.4 网络芯片与光模块

| 品类 | 供应商 | 说明 |
|------|--------|------|
| 交换芯片 | Broadcom（Memory）、Memory | 数据中心核心 |
| 光模块 | 中际旭创、新易盛、Lumentum | 400G/800G 迭代 |
| SmartNIC | NVIDIA（BlueField）、Intel | 智能网卡，卸载 CPU |

## 三、环节二：服务器整机

### 3.1 制造模式

| 模式 | 说明 | 典型供应商 | 字节采用 |
|------|------|-----------|---------|
| OEM | 品牌整机（Dell、HPE） | Dell、HPE、联想 | ✅ 通用场景 |
| ODM | 定制设计制造 | 浪潮、超聚变、富士康 | ✅ 大规模采购 |
| JDM | 联合设计制造 | 浪潮、超聚变 | ✅ AI 集群 |
| 自研 | 自己设计 + 代工 | Google、Meta | 字节探索中 |

### 3.2 服务器类型

| 类型 | 用途 | 配置特点 |
|------|------|---------|
| 通用计算型 | Web、微服务 | CPU 为主，中等内存 |
| 内存型 | 缓存、数据库 | 大内存，高内存带宽 |
| GPU 训练型 | AI 模型训练 | 8×GPU，高速互联（NVLink/NVSwitch） |
| GPU 推理型 | AI 推理服务 | 1-4×GPU，高吞吐 |
| 存储型 | 对象存储、大数据 | 大容量 HDD/SSD |
| 高密度型 | 边缘计算 | 紧凑设计，低功耗 |

### 3.3 服务器 BOM 结构（参考 [[08_ByteDance/02_行业研究/服务器产业链研究]]）

```
服务器 BOM
├── 计算模块
│   ├── CPU（Intel/AMD）         ~30-40%
│   ├── GPU（NVIDIA）            ~40-60%（AI 服务器）
│   └── 内存（DRAM）             ~15-20%
├── 存储模块
│   ├── SSD（NVMe）              ~5-10%
│   └── HDD                      ~2-5%
├── 网络模块
│   ├── 网卡（SmartNIC）         ~2-3%
│   └── 光模块                   ~1-2%
├── 机箱与散热
│   ├── 机箱/导轨                ~1-2%
│   └── 散热（风冷/液冷）        ~2-5%
└── 主板与电源
    ├── 主板                     ~3-5%
    └── 电源                     ~2-3%
```

## 四、环节三：IDC 建设

### 4.1 数据中心等级

| 等级 | 可用性 | 冗余设计 | 适用 |
|------|--------|---------|------|
| Tier I | 99.671% | 无冗余 | 非关键业务 |
| Tier II | 99.741% | 部分冗余 | 一般业务 |
| Tier III | 99.982% | N+1 冗余 | 大多数企业 |
| Tier IV | 99.995% | 2N 冗余 | 金融、关键业务 |

### 4.2 建设内容

| 系统 | 内容 | 关键供应商 |
|------|------|-----------|
| 供配电 | UPS、PDU、柴油发电机 | 施耐德、ABB、华为 |
| 制冷 | 精密空调、液冷系统 | 维谛、依米康、绿色云图 |
| 消防 | 气体灭火、烟感 | 海湾、利达 |
| 网络 | 综合布线、光纤主干 | 康普、劳兰 |
| 安防 | 门禁、监控、巡检 | 海康、大华 |
| 液冷 | 冷板、CDU、冷却液 | 英维克、申菱 |

### 4.3 液冷数据中心（AI 时代新趋势）

| 液冷方式 | 原理 | 适用 | PUE |
|----------|------|------|-----|
| 冷板式 | 冷却液通过冷板接触芯片 | GPU 高密度场景 | 1.1-1.2 |
| 浸没式 | 设备完全浸入冷却液 | 极高密度场景 | 1.05-1.1 |
| 喷淋式 | 冷却液喷淋到芯片表面 | 实验阶段 | 1.1-1.15 |

**字节实践**：字节正在大规模部署液冷数据中心，以支撑 AI 训练集群的散热需求。

|------|------|---------|

## 七、环节六：云服务交付

### 7.1 交付模式

| 模式 | 说明 | 用户感知 |
|------|------|---------|
| 公有云 | 多租户共享资源 | 按需开通，弹性伸缩 |
| 私有云 | 独占资源 | 专属环境，安全可控 |
| 混合云 | 公有云 + 私有云 | 灵活部署，统一管理 |
| 边缘云 | 就近部署 | 低延迟，本地处理 |

### 7.2 交付 SLA

| 指标 | 标准 | 说明 |
|------|------|------|
| 资源开通 | < 5 分钟 | 自动化开通 |
| 可用性 | 99.95%-99.995% | 按等级承诺 |
| 数据持久性 | 99.9999999% | 9 个 9 |
| 故障恢复 | < 4 小时 | RTO |

## 八、云服务供应链 vs 传统供应链

| 维度 | 传统供应链（汽车） | 云服务供应链 |
|------|-----------------|-------------|
| 产品形态 | 离散制造，标准化 BOM | 算力服务，非标配置 |
| 交付方式 | 物流发货，一次性交付 | API 开通，持续服务 |
| 库存管理 | 物理库存，周转天数 | 资源池化，按需分配 |
| 生命周期 | 采购→使用→报废 | 采购→上架→运维→迭代 |
| 计费模式 | 一次性采购 | 按量付费 |
| 供应链核心 | 零部件齐套 | 算力供给保障 |

> [!info] PM 视角
> 云服务供应链的核心挑战不是「齐套」（传统供应链的核心），而是**算力供给的及时性和成本控制**。GPU 到了仓库马上就要上架跑模型，系统要解决的是「资产全生命周期管理」。
