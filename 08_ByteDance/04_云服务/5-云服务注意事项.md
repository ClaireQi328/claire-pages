# ⚠️ 云服务注意事项

> 上云不是终点，而是新的起点——合规、成本、安全、锁定，每一个都是坑。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **四大风险域**：技术风险、安全合规、商业风险、运营风险
> - **成本失控**是云服务最大的隐性风险——FinOps 是必修课
> - **供应商锁定**：迁移成本可能高达数百万，必须提前规划
> - **合规要求**：金融/医疗/政务行业有严格的等保和数据主权要求

---

## 一、技术风险

### 1.1 供应商锁定

| 锁定类型 | 表现 | 迁移成本 | 应对策略 |
|----------|------|---------|---------|
| API 锁定 | 使用私有 API | 高（需重写代码） | 使用标准 API、开源中间件 |
| 数据锁定 | 数据格式不兼容 | 高（需数据迁移） | 使用开放格式、定期导出 |
| 架构锁定 | 依赖特定架构 | 中（需重构） | 云原生、容器化 |
| 服务锁定 | 依赖特有服务 | 中（需替换） | 多云策略、抽象层 |

> [!warning] PM 视角
> 供应商锁定的最大成本不是技术迁移，而是**业务中断风险**。建议在架构设计阶段就考虑「可迁移性」。

### 1.2 服务可用性

| 风险 | 影响 | 应对 |
|------|------|------|
| 单可用区故障 | 业务中断 | 多可用区部署 |
| 区域级故障 | 大面积中断 | 多地域容灾 |
| 网络中断 | 无法访问 | 多线接入、CDN |
| 存储故障 | 数据丢失 | 多副本、跨区域备份 |

### 1.3 性能风险

| 风险 | 表现 | 应对 |
|------|------|------|
| 超卖 | 共享资源性能波动 | 选择独享型实例 |
| 网络延迟 | 跨地域访问慢 | 就近部署、全球加速 |
| 存储 IOPS | 数据库性能瓶颈 | 使用 SSD、预配置 IOPS |
| 带宽限速 | 突发流量被限 | 预留带宽、弹性伸缩 |

## 二、安全合规

### 2.1 数据安全

| 风险 | 说明 | 应对措施 |
|------|------|---------|
| 数据泄露 | 多租户环境隔离不严 | 加密存储、严格访问控制 |
| 数据丢失 | 硬件故障、人为误删 | 多副本、跨区域备份、回收站 |
| 数据篡改 | 未授权修改 | 完整性校验、审计日志 |
| 数据主权 | 数据跨境传输 | 数据本地化、合规评估 |

### 2.2 合规要求

| 行业 | 合规标准 | 关键要求 |
|------|---------|---------|
| 金融 | 等保三级+、PCI DSS | 两地三中心、加密传输、审计可回溯 |
| 医疗 | HIPAA、等保三级 | PHI 保护、审计日志保留 6 年 |
| 政务 | 等保三级+、国产化 | 信创要求、数据不出境 |
| 通用 | 个人信息保护法 | 用户授权、数据最小化 |

### 2.3 安全防护

| 威胁 | 防护措施 | 产品 |
|------|---------|------|
| DDoS 攻击 | 流量清洗、弹性防护 | DDoS 高防（详见 [[08_ByteDance/02_行业研究/IT基础设施采购指南]]） |
| Web 攻击 | WAF、CC 防护 | Web 应用防火墙 |
| 数据泄露 | 加密、访问控制 | 密钥管理、RAM |
| 内部威胁 | 最小权限、审计 | IAM、操作审计 |

## 三、商业风险

### 3.1 成本失控

云服务最大的隐性风险——**账单永远比预期高**。

| 成本陷阱 | 表现 | 应对 |
|----------|------|------|
| 闲置资源 | 开了不用的实例 | 定期清理、自动关机 |
| 过度配置 | 买了用不完的规格 | 右 sizing、监控利用率 |
| 流量费用 | 出站流量费超预期 | CDN 缓存、内网通信 |
| 存储膨胀 | 冷数据占高价存储 | 生命周期策略、存储分层 |
| API 调用费 | 高频调用累积 | 缓存、批量调用 |

**FinOps 实践框架**：

```
通知(Inform) → 优化(Optimize) → 运营(Operate)
     ↓              ↓              ↓
  账单可视化     资源右 sizing    持续治理
  预算告警       竞价实例         自动化策略
  成本分摊       预留实例         KPI 考核
```

### 3.2 供应商风险

| 风险 | 说明 | 应对 |
|------|------|------|
| 服务商退出 | 小厂商可能倒闭 | 选择大厂、多云策略 |
| 服务变更 | API 变更、功能下线 | 关注公告、版本管理 |
| 价格上涨 | 垄断后涨价 | 长期合同、多供应商 |
| 技术路线变更 | 产品方向调整 | 评估影响、迁移准备 |

### 3.3 合同风险

| 风险 | 说明 | 应对 |
|------|------|------|
| SLA 不达标 | 赔偿远低于损失 | 明确 SLA、评估赔偿合理性 |
| 隐藏费用 | 费用条款不透明 | 详细审查合同、测试账单 |
| 数据归属 | 数据所有权不明确 | 明确数据所有权和使用权 |
| 退出条款 | 迁移支持不明确 | 约定退出支持、数据导出 |

## 四、运营风险

### 4.1 运维能力不足

| 风险 | 表现 | 应对 |
|------|------|------|
| 技能缺口 | 团队不熟悉云原生 | 培训、引入人才 |
| 运维工具缺失 | 没有监控/告警 | 建设可观测性平台 |
| 流程不成熟 | 变更管理混乱 | ITIL、DevOps 实践 |
| 应急响应慢 | 故障处理不及时 | 应急预案、演练 |

### 4.2 容量规划不足

| 风险 | 表现 | 应对 |
|------|------|------|
| 资源不足 | 业务高峰期扩容不及时 | 自动伸缩、预留缓冲 |
| 资源浪费 | 低谷期大量闲置 | 弹性伸缩、竞价实例 |
| 预算超支 | 增长超预期 | 预算告警、成本分摊 |

## 五、注意事项 Checklist

| 类别 | 检查项 | 优先级 |
|------|--------|--------|
| 安全 | 数据加密（传输 + 存储） | 🔴 高 |
| 安全 | 访问控制（最小权限） | 🔴 高 |
| 安全 | 审计日志（操作可追溯） | 🔴 高 |
| 合规 | 等保评估（按行业要求） | 🔴 高 |
| 合规 | 数据驻留（数据不出境） | 🟡 中 |
| 成本 | 账单监控（预算告警） | 🔴 高 |
| 成本 | 资源清理（闲置回收） | 🟡 中 |
| 成本 | FinOps 实践（持续优化） | 🟡 中 |
| 架构 | 多可用区部署 | 🔴 高 |
| 架构 | 容灾备份方案 | 🔴 高 |
| 架构 | 避免供应商锁定 | 🟡 中 |
| 运维 | 监控告警体系 | 🔴 高 |
| 运维 | 应急预案和演练 | 🟡 中 |
| 合同 | SLA 条款审查 | 🔴 高 |
| 合同 | 数据所有权确认 | 🔴 高 |
