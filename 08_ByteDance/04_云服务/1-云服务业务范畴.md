# ☁️ 云服务业务范畴

> 云服务的本质是将 IT 基础设施从「买资产」变为「买服务」，按需付费、弹性伸缩。

---

## 💡 Highlights

> [!tip]- 核心要点
> - **三层模型**：IaaS（基础设施）→ PaaS（平台）→ SaaS（软件）
> - **字节火山引擎**聚焦 AI + 视频 + 数据，阿里云生态最全，华为云主打政企混合云
> - 云服务业务范畴 = 计算 + 存储 + 网络 + 数据库 + 安全 + AI + 大数据 + 边缘

---

## 一、云服务三层模型

### 1.1 IaaS（基础设施即服务）

最底层，提供「裸金属」级别的资源。用户自行安装 OS、中间件、应用。

| 资源类型 | 典型产品 | 说明 |
|----------|---------|------|
| 计算 | ECS / 轻量应用服务器 / GPU 实例 | 虚拟机、容器宿主机、AI 训练卡 |
| 存储 | 块存储 / 对象存储 / 文件存储 | ESSD、OSS、NAS |
| 网络 | VPC / 负载均衡 / 弹性公网 IP | 私有网络、流量分发、公网接入 |
| CDN | 内容分发网络 | 边缘节点加速（详见 [[08_ByteDance/03_CDN/CDN介绍]]） |
| 数据中心 | 机柜 / 带宽 / IP | IDC 基础设施（详见 [[08_ByteDance/01_产品介绍/Infrastructure]]） |

**字节视角**：IaaS 层是字节 Data 事业部的核心战场——GPU 采购、服务器 ODM、液冷数据中心建设，都属于 IaaS 层的供应链管理。

### 1.2 PaaS（平台即服务）

中间层，提供「开箱即用」的平台能力。用户无需管理底层 OS，专注业务逻辑。

| 平台类型 | 典型产品 | 说明 |
|----------|---------|------|
| 数据库 | RDS / PolarDB / MongoDB / Redis | 关系型、文档型、缓存 |
| 大数据 | MaxCompute / DataWorks / EMR | 数据仓库、ETL、Hadoop 生态 |
| AI 平台 | PAI / ModelScope / 百炼 | 模型训练、推理部署、MLOps |
| 中间件 | 消息队列 / API 网关 / 微服务引擎 | 异步通信、流量管理、服务治理 |
| 容器服务 | ACK / ACI / Serverless K8s | 容器编排、弹性伸缩 |
| 视频服务 | 视频点播 / 直播 / 实时音视频 | 编解码、转码、分发 |

**字节视角**：火山引擎的 PaaS 层是核心差异化——飞书文档引擎、推荐算法平台、视频处理流水线，都是字节内部技术的外溢。

### 1.3 SaaS（软件即服务）

最上层，提供「即开即用」的软件应用。用户直接使用，无需开发。

| 应用类型 | 典型产品 | 说明 |
|----------|---------|------|
| 协同办公 | 飞书 / 钉钉 / 企业微信 | IM、文档、会议、审批 |
| CRM | 纷享销客 / Salesforce | 客户关系管理 |
| ERP | 用友 / 金蝶 | 企业资源计划 |
| 安全 | 态势感知 / WAF / DDoS 防护 | 安全防护（详见 [[5-云服务注意事项]]） |
| 运维 | 云监控 / 日志服务 / APM | 可观测性 |

## 二、业务范畴全景

```
┌─────────────────────────────────────────────────────┐
│                    SaaS 层                           │
│  协同办公 │ CRM │ ERP │ 安全 │ 运维 │ 行业解决方案   │
├─────────────────────────────────────────────────────┤
│                    PaaS 层                           │
│  数据库 │ 大数据 │ AI平台 │ 中间件 │ 容器 │ 视频服务  │
├─────────────────────────────────────────────────────┤
│                    IaaS 层                           │
│  计算(ECS/GPU) │ 存储(块/对象/文件) │ 网络(VPC/ELB) │
│  CDN │ IDC(机柜/带宽/IP) │ 安全(DDoS/WAF)           │
├─────────────────────────────────────────────────────┤
│                 基础设施层                            │
│  数据中心 │ 服务器 │ GPU/CPU │ 网络设备 │ 存储设备    │
└─────────────────────────────────────────────────────┘
```

## 三、三大云厂商业务范畴对比

### 3.1 阿里云 — 生态最全的「全家桶」

| 层级 | 核心产品 | 特色 |
|------|---------|------|
| IaaS | ECS、ESSD、VPC、CDN | 全球 30+ 地域，89 可用区 |
| PaaS | PolarDB、MaxCompute、PAI、ACK | 数据库市场份额第一 |
| SaaS | 钉钉、宜搭、通义千问 | 办公 + AI 双轮驱动 |
| 安全 | 云盾、WAF、DDoS 高防 | 安全产品线最完整 |
| 行业 | 金融云、政务云、医疗云 | 行业解决方案覆盖 100+ |

**核心优势**：产品线最全（200+ 产品），生态最成熟，开发者社区最大。

### 3.2 火山引擎 — AI + 视频的「技术外溢」

| 层级 | 核心产品 | 特色 |
|------|---------|------|
| IaaS | ECS、GPU 实例、对象存储 | 字节内部验证过的基础设施 |
| PaaS | 豆包大模型、视频云、推荐平台 | AI 大模型 + 视频处理核心能力 |
| SaaS | 飞书、飞书多维表格 | 协同办公 + 低代码 |
| 特色 | A/B 测试、增长分析、CDN | 字节增长方法论的工具化 |

**核心优势**：AI 大模型（豆包）+ 视频处理 + 增长方法论，技术从抖音/TikTok 实战中来。

### 3.3 华为云 — 政企市场的「国家队」

| 层级 | 核心产品 | 特色 |
|------|---------|------|
| IaaS | ECS、OBS、VPC、CDN | 鲲鹏 + 昇腾自研芯片生态 |
| PaaS | GaussDB、ModelArts、IoT 平台 | 国产数据库 + AI 开发平台 |
| SaaS | WeLink、云会议 | 企业协同 |
| 特色 | 混合云 Stack、政企专区 | 满足数据主权和合规要求 |

**核心优势**：自研芯片（鲲鹏/昇腾）+ 混合云方案 + 政企关系，满足信创和国产化要求。

## 四、字节内部的云服务业务定位

根据 [[08_ByteDance/01_产品介绍/Landing Info]]，Data 事业部的 **ICS（Infrastructure, Cloud Service and SRE）** 负责：

| 职能 | 说明 |
|------|------|
| 自建机房运维 | 数据中心日常运维、容量管理 |
| 云主机资源采购 | 内部云服务的资源采购和分配 |
| SRE | 服务可靠性工程，保障 SLA |

ICS 的云服务采购已有系统支持，机房类需求由 DCD/IE 承接。
