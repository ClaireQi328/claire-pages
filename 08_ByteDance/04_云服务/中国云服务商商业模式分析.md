# 中国主要云服务商商业模式分析 (2025-2026)

> 调研日期: 2026-07-09
> 覆盖厂商: 阿里云 / 火山引擎 / 华为云

---

## 一、市场格局总览

中国公有云 IaaS+PaaS 市场呈现"一超多强"格局:

| 排名 | 厂商 | IaaS 大致份额 | 核心标签 |
|------|------|-------------|---------|
| 1 | **阿里云** | ~26-28% | 全栈能力 + 生态 |
| 2 | **华为云** | ~12-14% | 自主可控 + 政企 |
| 3 | 天翼云(电信) | ~10-12% | 运营商云 |
| 4 | 腾讯云 | ~10-12% | 游戏/音视频 |
| 5 | **火山引擎** | ~4-6%(高增长) | AI + 互联网基因 |

## 二、阿里云 (Alibaba Cloud)

### 2.1 定位与战略

- **定位**: 全栈云服务提供商, "AI + 云" 一体化
- **2025 战略**: AI 驱动 + 公共云优先 + 被集成策略
- **基础设施**: 29 个公共云区域, 94 个可用区, 3200+ 边缘节点, 180+ Tbps 网络带宽

### 2.2 核心产品矩阵

#### IaaS 层 (基础设施)

| 领域 | 核心产品 |
|------|---------|
| **计算** | ECS 云服务器 / GPU 云服务器 / 智能计算灵骏 / 弹性裸金属服务器 / E-HPC 高性能计算 / 边缘节点服务 ENS |
| **存储** | OSS 对象存储 / EBS 块存储 / NAS 文件存储 / CPFS 并行文件系统 / Tablestore 表格存储 |
| **网络** | VPC 专有网络 / EIP 弹性公网IP / SLB 负载均衡 / NAT 网关 / VPN 网关 / 高速通道 Express Connect / CEN 云企业网 / 全球加速 GA |
| **CDN** | CDN / 边缘安全加速 ESA |

#### PaaS 层 (平台服务)

| 领域 | 核心产品 |
|------|---------|
| **数据库** | PolarDB 云原生数据库 / RDS / Tair(Redis) / Lindorm 多模数据库 / MongoDB / AnalyticDB 数据仓库 / ClickHouse / SelectDB |
| **大数据** | MaxCompute / E-MapReduce / Hologres 实时数仓 / Flink 实时计算 / Elasticsearch / DataWorks 数据治理 / Data Lake Formation |
| **AI/ML** | PAI 人工智能平台 / 百炼大模型服务平台 / DashVector 向量检索 / PAI-EAS 模型在线服务 / PAI-灵骏智算 |
| **容器** | ACK 容器服务 / ACS 容器计算 / ACR 容器镜像 / ASM 服务网格 / ACK One 分布式云容器 |
| **中间件** | MSE 微服务引擎 / EDAS 分布式应用 / RocketMQ / Kafka / RabbitMQ / API 网关 / EventBridge |
| **Serverless** | 函数计算 FC / SAE Serverless 应用引擎 / CloudFlow 工作流 |

#### SaaS 层 (应用服务)

| 领域 | 核心产品 |
|------|---------|
| **AI 应用** | 通义千问大模型 / OCR 文字识别 / 视觉智能 / NLP / 机器翻译 / 智能推荐 AIRec / OpenSearch / 语音识别/合成 / 虚拟数字人 / AgentOne 企业Agent平台 |
| **协作办公** | 钉钉 / Teambition / 阿里邮箱 / 宜搭低代码 |
| **云电脑** | 无影云电脑(企业版/个人版) / 无影云手机 / 无影云应用 |
| **开发工具** | 云效 DevOps / Qoder AI 编程 / 魔笔低代码 / BizWorks |
| **安全** | DDoS 防护 / WAF / 云安全中心 / SASE / 数据安全中心 / AI 安全护栏 |
| **云通信** | 短信 / 语音 / 号码隐私保护 / Chat App 消息服务 |
| **商业分析** | Quick BI / DataV 数据可视化 / Quick Audience |

### 2.3 供应链结构

```
芯片层: 平头哥自研(倚天710 CPU / 含光800 AI芯片)
   ↓
硬件层: 自研服务器 + 与浪潮/新华三等OEM合作
   ↓
虚拟化层: 飞天操作系统 (Apsara) — 阿里自研分布式云操作系统
   ↓
平台层: 统一资源调度 → 各PaaS产品
   ↓
应用层: 钉钉 + 通义系列 + 行业解决方案
```

### 2.4 定价模型

| 模式 | 说明 |
|------|------|
| **按量付费** | 按小时/秒/流量计费, 灵活但单价较高 |
| **包年包月** | 预付折扣, 1-3年承诺, 折扣20-60% |
| **抢占式实例** | 空闲算力低价出售, 适合批处理 |
| **资源包/预留实例** | 存储容量包SCU、计算预留实例等 |
| **免费层** | 部分产品提供免费额度(如函数计算、百炼平台) |
| **AI 模型定价** | 按 token 计费, 百炼平台提供多种模型选择 |

**定价策略**: 2024-2025年多次主动降价(核心产品降价40-55%), 以价格换市场份额, 同时通过AI增值服务提升ARPU。

### 2.5 Go-to-Market 策略

1. **被集成**: 让合作伙伴基于阿里云构建行业解决方案, 而非自己做项目交付
2. **开源生态**: 通义系列模型开源(ModelScope), 吸引开发者
3. **国际化**: 东南亚、中东持续布局, 服务出海企业
4. **行业深耕**: 金融、政务、制造、零售四大行业重点突破

## 三、火山引擎 (Volcano Engine — 字节跳动)

- **定位**: 企业级智能增长云, "AI 时代的云"
- **核心理念**: 将字节跳动在抖音/今日头条等产品中积累的技术能力对外输出
- **2025 战略**: AI 原生 + 低价抢量 + 增长飞轮

### 3.3 供应链结构

```
芯片层: 依赖第三方(GPU采购NVIDIA, 部分国产芯片)
   ↓
基础设施层: 自建数据中心 + 租用IDC(抖音海量算力溢出)
   ↓
平台层: 字节内部技术平台改造对外(推荐/音视频/数据)
   ↓
模型层: 豆包自研大模型(Seed系列) — 核心差异化
   ↓
应用层: 扣子/AgentKit/TRAE 等 AI 应用层
```

### 3.4 定价模型

| 模式 | 说明 |
|------|------|
| **按量付费** | 基础云服务标准按量计费 |
| **模型 token 计费** | 豆包大模型 API 按 token 收费, 2024年大幅降价(降幅达90%+), 极具价格竞争力 |
| **免费层** | Coze/方舟平台提供免费额度, 吸引开发者 |
| **企业定制** | 大客户提供定制化部署方案 |

**定价策略**: 极度激进的价格战 — 豆包大模型 API 价格远低于行业平均, 以"AI 民主化"为口号抢占市场, 短期亏损换长期用户规模。

### 3.5 Go-to-Market 策略

1. **字节内部技术溢出**: 核心卖点是"抖音同款技术", 以字节系产品成功案例背书
2. **AI 优先**: 不卖传统云, 直接卖 AI 能力, 定位"AI 时代的云"
3. **开发者生态**: TRAE/Coze/Marscode 等工具降低 AI 开发门槛
4. **行业聚焦**: 互联网、汽车、金融、消费四大行业
5. **增长飞轮**: 将云服务与企业增长方法论结合(推荐/A/B测试/增长分析)

### 3.6 产品设计哲学

- **内部验证优先**: 所有产品先在字节内部大规模使用(抖音/头条/飞书), 验证后再对外
- **AI 原生**: 不是在传统云上叠加AI, 而是以 AI 为核心重构产品
- **极简上手**: 扣子(Coze)等产品强调零代码/低代码, 降低使用门槛
- **规模化效应**: 字节的海量业务规模带来成本优势, 转化为价格优势

## 四、华为云 (Huawei Cloud)

### 4.1 定位与战略

- **定位**: 政企数字化首选云, "AI for Industries"
- **核心理念**: 全栈自主可控, 云网边端协同
- **2025 战略**: AI 原生云 + 行业深耕 + 国产化替代

### 4.2 核心产品矩阵

#### IaaS 层 (基础设施)

| 领域 | 核心产品 |
|------|---------|
| **计算** | ECS 弹性云服务器 / CCE 云容器引擎 / FunctionGraph 函数计算 / 鲲鹏+昇腾架构 |
| **存储** | OBS 对象存储 / EVS 云硬盘 / SFS 弹性文件服务 |
| **网络** | VPC / ELB 弹性负载均衡 / CDN |
| **AI 算力** | 昇腾 AI 云服务(基于自研昇腾 NPU) / Atlas 系列 AI 硬件 |

#### PaaS 层 (平台服务)

| 领域 | 核心产品 |
|------|---------|
| **数据库** | GaussDB(自研) / RDS / DDS 文档数据库 |
| **AI/ML** | 盘古大模型 / ModelArts AI 开发平台 / EI 企业智能 |
| **大数据** | MRS MapReduce / DLI 数据湖探索 / DataArts Studio |
| **容器/云原生** | CCE 容器引擎 / Serverless / 微服务治理 |
| **IoT** | IoT 平台 / IoT Edge |
| **视频云** | VOD 视频点播 / 实时视频 / 媒体处理 MPC |
| **数字孪生** | 数字孪生平台(智慧城市/智能制造) |
| **数字内容** | MetaStudio 数字内容生产 |

#### SaaS 层 (应用服务)

| 领域 | 核心产品 |
|------|---------|
| **安全** | 云安全中心 / WAF / DDoS 防护 / 密钥管理 KMS / SecMaster |
| **混合云** | 华为云 Stack(本地化部署) |
| **行业大模型** | 政务/金融/矿山/气象/药物研发等行业专用模型 |
| **云市场** | SaaS 星光计划 / ISV 合作伙伴生态 |

### 4.3 自研技术栈 (核心差异化)

```
芯片层: 鲲鹏(Kunpeng) CPU + 昇腾(Ascend) NPU — 全自研
   ↓
操作系统: openEuler(开源) / EulerOS
   ↓
AI框架: MindSpore(自研AI计算框架) + CANN(异构计算架构)
   ↓
数据库: GaussDB(自研分布式数据库)
   ↓
云平台: 华为云 Stack / EI 企业智能
   ↓
应用层: 盘古大模型 + 行业解决方案
```

**这是华为云最核心的差异化** — 从芯片到应用的全栈自研, 在信创/国产化场景中具有不可替代性。

### 4.4 供应链结构

```
芯片: 鲲鹏/昇腾自研(华为海思设计) → 受美国制裁影响产能
   ↓
硬件: TaiShan 服务器(自研) + 合作OEM
   ↓
基础设施: 全球数据中心(亚太/欧洲/中东非洲/拉美)
   ↓
平台: 统一云操作系统 + AI 框架(MindSpore)
   ↓
行业: 与行业ISV伙伴共建"行业一朵云"
```

### 4.5 定价模型

| 模式 | 说明 |
|------|------|
| **按量付费** | 标准按需计费 |
| **包年包月** | 预付折扣 |
| **华为云 Stack** | 按节点/容量授权, 面向大型政企 |
| **昇腾算力即服务** | AI 算力按需使用, 降低 AI 门槛 |
| **行业定制** | 大型政企项目制定价, 含长期服务合同 |

**定价策略**: 偏向高端定位, 以"全栈自主可控"溢价支撑价格, 在政企市场通过长期合同锁定客户, 在公有云市场价格与阿里云基本持平。

### 4.6 Go-to-Market 策略

1. **政企深耕**: 政务云/央企/国企市场为核心, 通过关系型销售 + 行业解决方案切入
2. **国产替代**: 信创场景的首选, 鲲鹏+昇腾满足合规要求
3. **行业伙伴**: "共建行业一朵云"模式, 与ISV深度合作
4. **全球化**: 覆盖亚太/欧洲/中东非洲/拉美, 服务出海企业
5. **开发者生态**: 鲲鹏社区/昇腾社区, 推动开发者迁移

### 4.7 产品设计哲学

- **全栈自主可控**: 从芯片到应用不依赖任何外国技术, 满足安全合规需求
- **行业纵深**: 不做通用型云, 而是针对政务/金融/制造/医疗等行业做深度定制
- **硬件协同**: 软硬件深度优化(昇腾+MindSpore), 在AI场景下性能优势明显
- **混合云优先**: 华为云 Stack 满足政企数据不出门的需求

## 六、2025-2026 关键趋势

### 6.1 AI 大模型成为核心战场

- 从"卖算力"转向"卖智能", MaaS(模型即服务)成为新增长极
- 阿里云: 通义千问系列 + 百炼平台(模型市场)

### 6.2 AI Agent 生态爆发

- 阿里云: AgentOne 企业Agent平台 + Qoder
- 火山引擎: Coze + AgentKit + HiAgent + ArkClaw(最激进)
- 华为云: 盘古Agent + 行业智能体

### 6.3 价格战持续

- 火山引擎率先大幅降价, 引发行业跟进
- 云计算基础服务价格持续下降, 利润空间受挤压
- AI 模型 API 价格进入"毛利时代"

### 6.5 运营商云崛起

### 6.6 出海竞争

- 阿里云全球化布局最成熟
- 华为云在中东/非洲/东南亚有独特优势
- 火山引擎跟随字节全球化(TikTok生态)拓展

## 七、总结

| 厂商 | 一句话定位 | 核心优势 | 主要挑战 |
|------|----------|---------|---------|
| **阿里云** | 中国云计算的"基础设施" | 产品线最全、生态最大、全球化最成熟 | 增速放缓、份额被蚕食 |
| **火山引擎** | AI时代的"破局者" | AI原生、极致性价比、互联网基因 | 政企积累不足、盈利压力、品牌认知 |
| **华为云** | 政企数字化的"国产首选" | 全栈自主可控、政企深耕、硬件协同 | 公有云份额追赶、生态相对封闭 |

三家厂商分别代表了中国云服务的三种典型路径:
- **阿里云**: 电商平台 → 全栈云 → AI增强
- **火山引擎**: 互联网流量 → 技术溢出 → AI原生云
- **华为云**: 通信硬件 → 全栈自主 → 行业AI

在 AI 大模型时代, 竞争格局正在重塑, 未来2-3年将是关键窗口期。
