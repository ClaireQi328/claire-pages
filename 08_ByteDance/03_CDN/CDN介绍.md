# CDN 定价与行业

本文整合字节跳动 CDN 定价结构、行业计费逻辑、竞品对标及 CDN 管理全流程。

---

## 一、为什么要做 CDN 自建/采购分析

> [!note]- 背景
> CDN（内容分发网络）是字节跳动（火山引擎）**用量最大、成本最高**的云服务品类之一。抖音/TikTok 的视频分发、直播、广告素材等高度依赖 CDN。理解 CDN 的定价逻辑、成本结构和行业对标，是做好云服务供应链管理的基础。

---

## 二、全球 CDN 定价逻辑

### 2.1 计费维度

| 计费项 | 说明 | 适用场景 |
|--------|------|----------|
| **按带宽峰值** | 取月度/日峰值带宽计费 | 流量稳定的大客户 |
| **按流量** | 实际消耗流量阶梯计费 | 流量波动大的中小客户 |
| **请求数** | HTTP/HTTPS 请求数计费 | 高并发小文件场景（API、图片） |
| **增值服务** | WAF、DDoS 防护、视频转码、HTTPS 请求数 | 按需叠加 |

### 2.2 阶梯定价的核心逻辑

定价：**阶梯折扣 × 区域系数 × 计费方式**

阶梯折扣：用量越大，单价越低，鼓励客户"将流量集中到单一供应商"。

### 2.3 中国 vs 非中国定价差异

| 维度 | 中国区自建 CDN | 非中地区 CDN |
|------|---------------|-------------|
| **定价模式** | 专门商品 + 统一价格 | 机柜/带宽/IP 拆分 + 专线叠加 |
| **政策逻辑** | 强合规管控，全链路整合 | 宽松监管，聚焦数据隐私 |
| **市场成熟度** | 大厂主导，标准化运营 | 市场分散，需灵活组合 |
| **成本结构** | 境内资源成本低，整合后摊薄 | 跨境带宽贵，区域套利控本 |
| **用户需求** | 中小客户为主，即开即用 | 大企业/跨国客户，定制化架构 |

> [!tip]- 核心洞察
> 中国区 CDN 是"政策驱动下的标准化商品"，非中地区是"需求驱动下的组件化服务"。详见 [[CDN定价分析]]。

## 三、主流 CDN 供应商定价概览

### 3.1 中国市场

| 厂商 | 计费模式 | 特点 |
|------|----------|------|
| **阿里云** | 流量/带宽阶梯 + 区域加权 | 最大份额，定价标杆 |
| **腾讯云** | 流量/带宽阶梯 + 请求次数 | 游戏行业强势 |
| **华为云** | 流量/带宽阶梯 + 区域加权 | 政企市场，鲲鹏生态 |
| **火山引擎** | 流量/带宽阶梯 | 字节自用，快速扩张 |
| **网宿科技** | 带宽/流量 | 传统 CDN 厂商 |

### 3.2 海外市场

| 厂商 | 计费模式 | 特点 |
|------|----------|------|
| **Akamai** | 带宽承诺 + 超额阶梯 | 全球最大传统 CDN |
| **Cloudflare** | 按请求/按功能订阅 | 安全+性能一体化，增长最快 |
| **AWS CloudFront** | 流量阶梯 + 请求次数 | AWS 生态深度绑定 |
| **Fastly** | 流量 + 请求次数 | 边缘计算方向 |
| **Google Cloud CDN** | 流量阶梯 + 缓存填充 | GCP 生态 |

## 四、CDN 管理全流程（行业最佳实践）

```
需求分析 → 供应商评估 → 方案设计 → 价格谈判 → 合同签订 → 上线部署
    ↓                                                         ↓
  用量预测                                              监控运维
  性能指标                                              定期优化
  预算约束                                              成本分析
```

### 4.1 关键管理维度

| 维度 | 要点 |
|------|------|
| **供应商评估** | 节点覆盖、性能指标、价格水平、服务水平、合规资质 |
| **合同管理** | 承诺量、阶梯折扣、SLA 条款、违约责任、合同期限 |
| **成本监控** | 带宽峰值、流量消耗、缓存命中率、回源率 |
| **性能优化** | 缓存策略、协议优化（HTTP/3、QUIC）、边缘计算 |

## 五、CDN 行业竞品对标

### 5.1 性能对标

| 指标 | 说明 | 行业基准 |
|------|------|----------|
| **首次字节时间（TTFB）** | 从请求到收到第一个字节 | < 50ms（国内） |
| **缓存命中率** | 请求在边缘节点命中的比例 | > 95% |
| **可用性** | CDN 服务可用时间 | > 99.95% |
| **下载速度** | 大文件下载速度 | > 50Mbps（国内） |

### 5.2 服务对标

| 能力 | 云厂商 CDN | 专业 CDN 厂商 |
|------|-----------|--------------|
| 基础加速 | ✅ 完善 | ✅ 完善 |
| 安全防护 | ✅ WAF/DDoS 集成 | ✅ 深度安全能力 |
| 视频处理 | ✅ 转码/DRM 集成 | ⚠️ 需第三方 |
| 边缘计算 | ✅ Serverless 函数 | ✅ Compute@Edge |
| API 网关 | ✅ 集成 | ⚠️ 需额外产品 |
| 混合云支持 | ⚠️ 有限 | ✅ 更灵活 |
