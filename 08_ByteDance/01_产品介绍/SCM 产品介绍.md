# SCM 产品介绍

> 字节跳动采购履约平台 — 从需求到付款的全链路供应链管理系统

---

## 💡 Highlights

> [!tip]- 核心要点
> - **SCM 是字节 Data 事业部的核心采购履约系统**，覆盖寻源、采购、发货、结算全流程
> - **系统演进**：2012 OA 时代 → 2018 采购中心（Ariba 海外）→ 2020 SCM 系统（支持 Buy&Sell）
> - **四大业务类型**：IDC 资产设备、采销进销存、ODM Buy&Sell、综合寻源采购
> - **服务对象**：DATA 供应链、采购部、教育线、懂车帝等自营产品团队
> - **核心模块**：基础数据 → 采购价格 → 需求&订单 → 发货执行 → 结算管理 → 销售管理
> - **供应商管理已迁移至集团平台**（准入/准出/绩效），SCM 保留品类和单据协同

## 1. 系统建设背景

| 阶段 | 时间 | 说明 |
|------|------|------|
| OA 时代 | 2012 | 邮件/OA 管理需求和费用报销，财务手工记账 |
| 采购中心 | 2018 | 采购部集中受理全国需求，线上化管理需求→订单→交付→付款，海外用 Ariba |
| SCM 系统 | 2020 | 支持 IDC Buy&Sell、智能硬件，建立供给计划和连续性采购流程 |

数字化采购的范畴已扩展为：供给端（寻源、匹配、采购管理）+ 需求端（需求统计、上报、采购、分发）的全链条泛采购。

## 2. 服务业务方

- **DATA 供应链团队**：服务器及智能硬件的供应链业务
- **采购供应链团队**：间接采购的供应链
- **各业务线**：自营产品线等各自有供应链业务的团队

## 3. 主业务流程

| 业务类型 | 模式 | 典型品类 |
|----------|------|---------|
| IDC 资产设备 | 采销 | 服务器、网络设备、自维保 |
| 采销类业务 | 进销存全流程 | IOT 整机、集采自营业务线 |
| ODM 模式 | Buy&Sell 全流程 | 智能硬件、服务器部件 |
| 寻源采购 | 综合性采购 | DATA 所有业务线 |
| 销售报价 | 报价测算 | 服务器 |

## 4. 主要功能模块

### 4.1 基础数据管理

管理 SCM 基础物料分类、物料编码等数据的创建与维护：

- 物料新增、查询
- 物料关系管理

### 4.2 采购价格管理

管理采购执行过程中的价格和份额：

- 采购价格新增、变更、失效
- 份额新增、变更、失效
- 价格/份额查询列表

### 4.3 采购需求 & 订单

需求到订单的履约流程：

- 整机需求提报、变更、关闭、套餐拆分
- 采购需求提报、变更、关闭、复核
- 订单下达、发布、确认
- 订单门户协同
- 到货计划填写、更新

### 4.4 发货执行

订单发布后的供应商发货履约：

- 供应商协同发货、取消、释放
- GIT 上传、报盘上传
- 收货单创建、查询
- 退货申请、退货单创建

### 4.5 结算管理

验收/退换货完成后的采购结算付款：

- 对账单创建、发布、确认
- 对账单门户协同
- 预/后付款发起、提交
- 一件代发对账付款

### 4.6 销售需求 & 订单（ODM）

ODM 采购需求转销售订单：

- ODM 需求创建、确认、取消
- 采购需求创建销售订单
- 销售订单提交、变更、取消
- 到货需求创建、确认、关闭、变更

### 4.7 销售执行

B&S 发货、交货、签收、结算：

- 销售交货单创建、取消
- 销售签收创建、附件上传、自动签收
- 销售发票创建、合并开票、取消、金税发票

### 4.8 销售价格 & 报价中心

B&S 销售价格和服务器内部报价测算：

- 销售价格查询、新增、变更、失效
- 销售报价费用项配置
- 销售报价单管理
- 销售报价测算

## 5. 供应商管理

> [!warning] 供应商管理核心功能已迁移至集团平台，SCM 保留品类管理和单据协同

> [!info] PM 视角
> 供应商管理迁移至集团平台是正确方向——统一主数据、统一流程、统一评估标准。SCM 侧需做好数据同步和业务协同，避免信息孤岛。

### 5.1 准入管理

**准入方式**：

- **常规准入**：标准流程，需评估供应商身份（原厂/代理/贸易商）
- **限制准入**：需预估合作金额，有生效时长限制

**准入状态**：草稿 → 审批中 → 已完成 / 审批拒绝 / 过期失败 / 已关闭 / 变更中

### 5.2 绩效评估

**评估模板**：

- 模板名称、团队、BU、品类
- 公开/私有/受限三种可见性
- 一级指标 + 权重，支持加分项/扣分项
- 等级明细（最小值/最大值/等级说明）

**评估周期**：月度 / 季度 / 半年度 / 年度

## 6. 寻源管理

> [!info] PM 视角
> 寻源是采购的「入口」，决定了后续所有环节的质量。AVAP 模式（批准供应商批准价格）是 B&S 业务的关键创新，实现了采购价与销售价的自动联动。

### 6.1 寻源策略

**采购方式**：

- 竞争性采购：竞争性招采、竞争性评估、两阶段评估
- 非竞争性采购：唯一来源、单一来源、指定供应商、无授权采购、小金额采购

**策略类型**：

- **招采启动**：年度框或项目型报备，用于采购方式和 AVL
- **招采策略**：单个寻源事项的策略，侧重供应商选择规则和中选规则

### 6.2 寻源事项

**RFx 类型**：RFQ（报价）、RFP（提案）、RFI（信息征集）

**寻源状态**：草稿 → 报价中 → 已截止 → 比价中 → 已完成 / 再次寻源中 / 已作废 / 开标中

**报价方式**：

- 以不含税单价报价 → 系统自动计算含税单价和交易币种价格
- 以含税单价报价 → 系统自动反算不含税单价

### 6.3 寻源结果（PVF）

**价格评估方式**：成本分析、报价比较、行业分析、报价均价、综合评估

**AVAP（Approved Vendor Approved Price）**：批准供应商批准价格，仅针对 B&S 业务，选中后自动同步销售价格库和 Rebate 价格库

**成本节约分析**：对比历史价格 / 成本基线 / 最终价格 / 预算价格 / 方案优化节约

### 6.4 Sourcing 模板

- 模板编码、名称、适用 BU、授权人管理
- 物料颗粒度策略：寻源物料、报价物料、份额物料的颗粒度控制
- CBOM 报价模板：适用品类、模板编码、默认规则

## 7. 采购执行

### 7.1 采购申请（PR）

**需求提报**：申请类型、公司主体、BU、申请人、立项名称、服务器业务类型

**需求受理**：增加寻源经理、财务 BP、是否指定供应商等字段

**行信息**：物料编码、含税单价、税率、采购数量、要求交货日期、预算科目、收货地址等

### 7.2 采购订单（PO）

**创建订单**：关联 PR 行，填写供应商、采购订单类型、币种、贸易条款、合同等

**付款条款**：

- 支付节点：预付款 / 后付款
- 结算方式：月结 / 非月结
- 日期类型：工作日 / 非工作日

### 7.3 送货通知（ASN）

ASN（Advance Shipment Note）是供应商发货后发送给买方的通知：

- 发货地点、数量、送货时间、订单号
- 应用：仓储安排、物流跟踪、库存管理、跨境报关

### 7.4 收货单

- 收货单编号、发货单编号、采购订单、供应商、物料、状态
- 详情：公司主体、实际验收日期、行信息（物料、数量、机房、仓库等）
- 配送信息：物流公司、运输方式、物流单号
