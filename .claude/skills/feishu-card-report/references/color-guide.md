# 飞书卡片视觉风格参考

## 颜色主题

| 主题 | header.template | 适用场景 |
|------|----------------|---------|
| 蓝色 | `blue` | 数据报告、技术文档 |
| 绿色 | `green` | 进度报告、成功案例 |
| 红色 | `red` | 风险告警、紧急通知 |
| 黄色 | `yellow` | 提醒、建议、中等风险 |
| 紫色 | `purple` | 时间线、创意内容 |
| 青色 | `turquoise` | 画像、人物介绍 |
| 靛蓝 | `indigo` | 对比分析、深度报告 |
| 灰色 | `grey` | 归档、历史数据 |

## 状态图标

| 状态 | 图标 |
|------|------|
| 正常/完成 | ✅ |
| 进行中 | 🔵 |
| 待处理 | ⚪ |
| 警告 | ⚠️ |
| 危险/失败 | ❌ |
| 趋势上升 | 📈 |
| 趋势下降 | 📉 |

## 数据格式化

| 类型 | 格式 | 示例 |
|------|------|------|
| 金额 | ¥X万 / ¥X亿 | ¥123万 |
| 百分比 | X.X% | 95.5% |
| 日期 | YYYY-MM-DD | 2026-05-12 |
| 趋势 | ↑X% / ↓X% / →持平 | ↑12.5% |

## 尺寸限制

- 最大元素数：20
- 最大文本长度：3000字
- 最大按钮数：5
- 最大列数：4
