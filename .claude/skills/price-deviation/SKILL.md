# 框架价格偏离对比器

## 核心定位

对比不同框架（Framework）或系统间的价格数据，检测价格偏离异常，分析偏离原因，生成结构化的对比分析报告。适用于供应链成本对比、供应商报价分析、竞品价格对标、预算执行监控等场景。

## 输入格式

### 1. 价格数据表

支持以下格式：
- **CSV/Excel**: 包含框架名称、商品/服务名称、单价、数量、总价等字段
- **Markdown 表格**: 直接粘贴对比表格
- **JSON**: 结构化价格数据
- **自然语言描述**: 口述价格对比需求

### 2. 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `偏离阈值` | 价格偏离超过此百分比视为异常 | 10% |
| `对比维度` | 按商品/供应商/框架/时间对比 | 按商品 |
| `输出格式` | 报告格式：Markdown/HTML/PPT | Markdown |
| `基准选择` | 偏离计算基准：最低价/平均价/目标价 | 最低价 |

## 工作流程

### Step 1: 数据解析

1. 识别输入数据格式和结构
2. 提取框架名称、商品/服务、价格字段
3. 标准化数据格式（统一货币、单位、精度）
4. 识别缺失值和异常值

### Step 2: 偏离计算

```
偏离率 = (对比价格 - 基准价格) / 基准价格 × 100%
```

计算类型：
- **绝对偏离**: 价格差值
- **相对偏离**: 偏离百分比
- **排名偏离**: 价格排名变化

### Step 3: 异常检测

基于配置的阈值检测异常：
- ⚠️ **轻微偏离**: 偏离率 ≤ 10%
- 🟡 **中度偏离**: 10% < 偏离率 ≤ 25%
- 🔴 **严重偏离**: 偏离率 > 25%
- 🚨 **极端偏离**: 偏离率 > 50%

### Step 4: 原因分析

自动分析可能的偏离原因：
- 采购量差异
- 供应商等级差异
- 地区价格差异
- 时间点差异
- 规格/配置差异
- 付款条件差异

### Step 5: 报告生成

输出结构化报告，包含：
- 📊 价格对比总览表
- 📈 偏离分布图（按框架/商品）
- 🚨 异常价格清单
- 💡 优化建议
- 📋 详细数据附录

## 使用示例

### 示例 1: 供应商报价对比

```
Use framework-price-deviation-comparator 对比以下三家供应商的报价：

商品：XX零件
供应商A: ¥120/件
供应商B: ¥135/件
供应商C: ¥118/件

偏离阈值设为15%，以最低价为基准。
```

### 示例 2: 多框架成本对比

```
Use framework-price-deviation-comparator 对比以下框架的成本：

| 商品 | 框架1 | 框架2 | 框架3 |
|------|-------|-------|-------|
| 芯片 | ¥500 | ¥480 | ¥520 |
| 模组 | ¥200 | ¥210 | ¥195 |
| 组装 | ¥100 | ¥105 | ¥98 |

输出HTML格式报告，偏离阈值10%。
```

### 示例 3: 竞品价格对标

```
Use framework-price-deviation-comparator 对比我方与竞品的价格体系：

我方产品A: ¥2999
竞品X产品A: ¥2799
竞品Y产品A: ¥3199

分析价格偏离原因，给出定价建议。
```

## 注意事项

- ⚠️ 价格数据敏感，注意脱敏处理
- ⚠️ 偏离阈值需根据业务场景调整
- ⚠️ 原因分析为辅助建议，需人工确认
- ⚠️ 大量数据时建议分批处理
- ✅ 支持增量对比（新数据与历史数据对比）
- ✅ 支持趋势分析（价格变化趋势）
