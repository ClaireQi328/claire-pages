## 实施方案

### 新建 1 个核心参考文件

**`03_YanFeng/02_流程工具方法/工业工程方法论.md`**（~800 行）

按 5 大领域组织，每个方法论包含完整的 5 个维度：

| 领域 | 方法论 |
|------|--------|
| **工时测定** | MTM 体系、秒表时间研究、工作抽样、MODAPTS、PTS 法 |
| **质量工具** | FMEA、SPC、MSA、QFD、APQP/PPAP |
| **流程分析** | VSM、SIPOC、线平衡、约束理论 TOC |
| **精益生产** | Lean 五大原则、八大浪费(DOWNTIME)、拉动/Kanban、Kaizen、TPM |
| **物流与数字化** | PFEP、安全库存、Andon、AMS、MES、e-Kanban、数字仿真 |

每个方法论的 5 个维度：
1. **原理与核心概念** — 起源、定义、适用场景
2. **公式与计算** — 核心公式（含变量定义和示例）
3. **工具与操作步骤** — 具体步骤/表格/模板
4. **数字化工具映射** — 软件/平台/系统
5. **原型与案例** — 延锋/Bosch 场景下的应用实例

## 核心公式预览

| 方法论 | 核心公式 |
|--------|---------|
| VSM | TT = 可用时间 / 客户需求量；LT = Σ(C/T × WIP) |
| 线平衡 | 平衡率 = ΣCT / (N × Max CT) × 100% |
| 安全库存 | SS = Z × σ_LTD = Z × √(L × σ_d² + d² × σ_L²) |
| FMEA | AP = O × S（新版用 AP 矩阵替代 RPN） |
| SPC | UCL/LCL = X̄ ± A₂R̄；Cpk = min[(USL-μ)/3σ, (μ-LSL)/3σ] |
| MTM | 标准时间 = 正常时间 × (1 + 宽放率) |
| OEE | OEE = 可用率 × 性能率 × 良品率 |
