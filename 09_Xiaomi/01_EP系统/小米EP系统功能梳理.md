# 小米 EP 系统功能梳理

> 小米生产采购系统（EP）的功能架构与演进规划

---

## 💡 Highlights

> [!tip]- 核心要点
> - **EP 系统覆盖 13 大功能模块**：供应商门户、供应链控制塔、采购项目管理、零部件寻源定点、变更/变价、价格中心、履约管理、供应商管理、基础信息管理
> - **未来演进重点**：供应商全生命周期管理、准入评估体系、绩效联动配额/招标、风险管理看板
> - **可立项方向**：效率提升（框架合同、样件、上会自动化）、合规管理（品类管理、采购主数据）、透明度（成本下探、报价比价）、成本降低（大宗）、上下游协同（预算、风险、配额服务化）

## 2. 未来演进方向

| 一级功能模块 | 二级功能模块 | 主要功能 | 成熟度评分 | 可优化方向 |
|-------------|-------------|---------|-----------|-----------|
| **供应商管理** | 供应商清单 | 邀请供应商注册、重新邀请、查看供应商信息（基本信息、财务、联系人、主要产品、生产过程、商务数据、研发能力、关键二级供应商、协议、账期、变更记录等） | 7.5/10 | 升级供应商状态机，扩展为"潜在→准入→评估→合格→淘汰"完整生命周期 |
| | 供应商信息变更 | 供应商发起信息变更申请，采购方/管理员审核 | 8/10 | 变更字段高亮标记、变更摘要卡片、支持历史版本对比 |
| | 供应商邮件通知 | 向所有/正式/预选/特定供应商发送邮件通知 | 9/10 | 探索支持更多角色（如工程联系人） |
| | 供应商公告 | 新建、发布公告 | 9/10 | 支持弹窗（强制阅读）和浮动窗口（非干扰型）两种形式 |
| **供应商准入** | 准入发起/评估/模板配置 | 标准化、可量化、全视角的供应商评估体系，覆盖商务、质量、技术、物流、财务等维度 | 0 | 评估模板配置、多维度评估任务分发与协同、准入决策与状态流转 |
| **供应商退出** | 退出发起/规则配置 | 质量红线、出口管制、财务风险、供应短缺等触发的供应商退出，支持暂停新业务、全量退出 | 0 | 分阶段退出工作流、人工发起时自动弹窗提示关联业务、退出规则与系统打通、退出原因结构化标签 |
| **供应商绩效管理** | 发起绩效评估/评估/模板配置 | 定期评估供应商整体情况，输出绩效评估报告，制定改进措施 | 0 | 滚动评估机制（月度汇总、季度报告）、与配额/招标联动（A 级价格系数、D 级暂停新业务）、绩效分析报告含趋势线和对标图、扣分明细溯源 |
| **供应商风险管理** | 供应商风险看板/地图 | 实时监控供应商风险 | 0 | 合规风险、财务风险、供应风险、质量风险四大维度 |
| **账期管理** | 通用/非标/模具/研发账期、应付账款 | 标准账期、非标账期、模具&研发账期一处管理，统计应付账款 | 5 | 供应商维度应用账期、非标账期申请、一次性/分期费用、在执行合同应付账款 |
| **采购项目管理** | 采购项目列表/新建项目 | 基础车型、SOR、外购件、平台、量纲、产销规划 | 5 | 与 BOM 联动、采购项目任务进度统计、成本分析、量纲调整同步、自动分配任务 |
