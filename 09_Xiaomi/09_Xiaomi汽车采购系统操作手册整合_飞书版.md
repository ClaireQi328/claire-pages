# 二、系统权限申请

## 2.1 采购员常用系统清单

- **EP系统**：小米汽车直接采购系统
- **SP门户**：供应商邀请注册、供应商账号管理
- **MIBOM / Miracle**：企业级 BOM 管理系统
- **合同系统**：合同签署申请、合同查询

## 2.2 EP、SP、MIBOM 权限申请

**路径：** 小米办公 → 工作台 → 小米审批 → 发起流程 → 汽车部-应用系统账号功能权限申请

**操作步骤：**

1. 进入审批流程后，勾选对应系统（EP / TAKO / MIBOM）
2. 选择申请类别：**申请职能角色权限**
3. 选择职能角色：**采购工程师**
4. 确认已完成清河大学课程学习 → 提交审批

<callout emoji="bulb" background-color="light-blue">
**TAKO 门户权限**：在申请页面选择"汽车门户"模块，填写申请人所属业务领域（采购）和常用应用系统（EP），系统自动关联权限。
</callout>

## 2.3 Miracle 权限申请

- **方式1**：直接访问 [Miracle权限申请入口](https://bpm.infra.mioffice.cn/approval/formDetail?modelCode=bpmn_895697923745374208&formOld=0)
- **方式2**：Miracle 系统右上角 → 权限申请按钮

填写申请模块（总基线）、申请原因，提交审批即可。

## 2.4 合同系统账号申请

合同系统权限需单独申请，详见《合同提交权限》和《汽车部新合同系统操作手册》文档。

# 三、EP 系统操作手册（采购端）

<callout emoji="wrench" background-color="light-green">
**内网地址：** https://ep.ev.mioffice.cn
EP（Electronic Procurement System）是小米汽车生产采购系统，支撑从定点到量产阶段的全部生产采购业务。
</callout>

## 3.1 系统角色与职责

| 角色 | 核心职责 |
|------|---------|
| **采购项目经理** | 维护采购项目、分发任务、审批价格 |
| **采购工程师** | 执行寻源、询报价、定点等具体操作 |
| **研发工程师** | SOR0/SOR1 发布、长清单/BDL 审核、TR 评审 |
| **物流工程师** | SOR 包物流要求填写、RFQ 物流价格确认 |
| **SQE 工程师** | 质量目标协议上传、长清单/BDL 审核、PSA/QTR 评审 |
| **财务 CE** | 填写财务目标价 |

<callout emoji="fire" background-color="light-red">
**铁律：信息 100% 准确 + 处理 100% 及时。** 采购项目信息直接影响后续所有流程。
</callout>

## 3.2 采购项目管理（三大核心操作）

### 维护采购项目信息

采购项目是采购业务流程的**第一步**。

- 维护节点计划、产销规划
- **重点关注**：基础车型、项目量纲（影响 RFQ 采购量和报价分析公式）
- 可在"项目基础信息变更日志"中查询历史版本

### 分发任务

- **SOR 任务**：SOR 审批结束后自动分发到采购项目经理 → 填写定点要求完成时间 → 选择采购工程师 → 下发
- **EWO 任务**：一个工程变更可能导致多个对手件变化 → 一个 EWO 可能分发给多个采购工程师

### 审批价格

定点、定价、变价的最终审批单需采购项目经理审核。

## 3.3 供应商管理

<callout emoji="bulb" background-color="light-blue">
EP 系统**没有**邀请供应商的模块。EP 是商务端企业信息数据库。邀请供应商和 P 账号管理在 **TAKO/SP 门户系统**操作。
</callout>

### 供应商分类与编码

| 阶段 | 编码 | 说明 |
|------|------|------|
| 未注册 | - | 尚未在系统中创建信息 |
| 已注册未签署 NDA | - | 企业信息已录入，保密协议待签 |
| **预选供应商** | **SUPTxxx** | 双签 NDA 后获取，可参与询报价 |
| **正式已定点供应商** | 正式编码 | 定点审批完成后，供应商完善信息获取 |

<callout emoji="memo" background-color="pale-gray">
新定点供应商在定点申请单审批完成后，会收到邮件提醒完善企业信息，完成后获取正式编码，才能进行订单交互。
</callout>

### 供应商信息变更

- 供应商端主动发起变更 → 采购工程师收到待办 → 审核
- 信息变更单会**标红显示修改点**，重点查看修改项
- **银行信息变更**：审批通过时手动增加财务共享中心审批
- **更换社会信用代码**：使用"供应商主体变更"功能

## 3.4 寻源与前期开发

### 寻源 SOR0 任务 & 长清单评审

**寻源 SOR0**：根据产品选型方案，制作零部件初版需求文档，确定初选供应商范围。

**流程：**

1. **发起**：研发工程师发起 → 采购项目经理下发给采购工程师
2. **接收**：采购工程师点击接收 → 创建长清单
3. **长清单范围选择**：按线下铁三角会议结论选择供应商 → 发起审批
4. **长清单供应评审**：SQE 和研发工程师填写意见 & 上传附件

**长清单审批流：** 采购工程师 → 研发工程师 → SQE 工程师 → 研发主管 → SQE 主管 → 采购主管

> 该审批流已切到 BPM，审批节点无需手动选择，系统自动带出。

### 早期开发 ESI 任务

**ESI 定点**：项目早期需要供应商参与设计开发的定点需求，仅少量零件需要。

**流程：**

1. 研发工程师发起 → 采购项目经理下发 → 采购工程师接收 → 创建 RFQ
2. 填写 RFQ 基本信息 → 选择预选供应商 → 发起审批
3. ESI 预选供应商审批：采购工程师 → SQE 主管 → 采购主管
4. 审批通过后 → 研发填写供应商评审意见
5. 发出询价 → 供应商报价 → 采购工程师可提前结束轮次或修改截止日期

> RFQ 支持开多轮次。供应商须在报价截止时间之前提交报价。

## 3.5 量产定点

### SOR 包任务发布与接收

**SOR 包内容：** 基础车型下零件号对应的单车用量及装配比例、物流要求、财务 CE 目标价、技术文件、数模图纸、质量目标协议等附件。

**流程：**

1. 研发工程师创建 SOR 包 → 审批流转到采购项目经理 → 下发给采购工程师
2. 采购工程师接收 → 立即创建 RFQ

**结算模式：**

| 供货方式 | 结算模式 |
|---------|---------|
| 软件 | 下线结算 |
| PUS | 入库结算 |
| JIT | 入库结算 |
| JIS | 下线结算 |
| Tier2 | 入库结算 |

### RFQ 基本信息维护

- 维护报价货币
- RFQ 预计采购量由系统自动计算（支持人工修改）
- 物流要求：供货方式为软件/Tier2 时可修改，其他 3 种不允许

# 四、EP 系统操作手册（供应商端）

<callout emoji="pushpin" background-color="light-blue">
**供应商门户：** sp.ev.mi.com
**采购端：** ep.ev.mi.com
EP 系统是小米采购与供应商进行商务交流的业务系统。
</callout>

## 4.1 供应商信息变更

### 创建变更

进入"供应商变更申请"页面 → 创建申请变更 → 切换页签维护信息。

| 页签 | 内容 |
|------|------|
| 公司基本信息 | 供应商名称、注册资本、服务类型等 |
| 财务信息 | 银行信息、商务前提（账期、承兑等） |
| 联系人信息 | 联系人姓名、电话、邮箱 |

### 变更银行信息

<callout emoji="x" background-color="light-red">
**首次定点银行信息必填。** 维护完成后无法清除，只能修改。
</callout>

- **仅现金** → 电汇结算银行信息必填
- **仅承兑** → 承兑结算银行信息必填
- **现金+承兑** → 两者都需填写
- 变更完成后 → 保存 → 启动审批

## 4.2 询报价

### RFQ 类型速查

| 前缀 | 含义 |
|------|------|
| RFQ- | 标准 SOR 询报价 |
| EWO- | 设变询报价 |
| CWO- | 颜色询报价 |
| LPC- | 物流价格变更询报价 |
| RFQ-AS | 售后 SOR 询报价 |
| RFQ-SWO | 售后设计变更询报价 |
| Q-RFQ | 快速定点询报价 |

### 报价操作步骤

1. **确认参与报价 & 报价前提** — 首页待办 → 报价管理 → 参与报价
2. **确认商务条件** — 已定点供应商无需填写
3. **出厂价报价** — 材料费 + 制造费
4. **分摊费用报价** — 模具分摊 + 开发分摊
5. **物流费报价** — 按供货方式填写
6. **样件费 & 管理费** — 支持倍数/价格两种方式
7. **一次性费用** — 不分摊在零件单价上
8. **上传附件** — 物流信息表 + 其他附件
9. **提交报价** — 系统校验必填项后提交

### 报价填写方式

<callout emoji="bulb" background-color="light-green">
**支持 4 种填写方式：**
1. **页面直接填写** — 逐步录入
2. **导出 Excel → 线下填写 → 导入解析** — 批量处理推荐
3. **工厂引用** — 同一零件不同工厂，只填一次，其他引用
4. **上轮报价带出** — 默认引用上一轮报价数据
</callout>

### 出厂价报价明细

**材料费** = 原材料价格 + 外购件价格

> 汇总逻辑：零件层级 > 1 时，汇总下级 1.1 级零件的细项费用；未拆结构时，取小米采买级零件费用。

**制造费** = 设备费 + 人工费 + 报废费用 + 能耗费 + 耗材费

### 分摊费用报价

- **模具分摊**：填写模具费分摊支付明细 + 模具清单（无费用则填 0）
- **开发分摊**：填写分摊金额、数量，费用拆分到人员/试验/标定（无费用则填 0）

### 样件费 & 管理费

- **样件费**：倍数模式（推荐）或价格模式
  - 样件价格 =（出厂价 + 物流费）× 倍数
  - 倍数模式优势：后续调价时倍数可自动跟随调整
- **管理费** = DB 管理员 + 利管费 + 其他管理费（必填，无费用则填 0）

# 五、EP 系统操作手册（研发端）

<callout emoji="wrench" background-color="light-green">
**系统地址：** https://ep.ev.mioffice.cn
**账号申请：** 小米审批 → 发起流程 → 汽车部-应用系统账号功能权限申请-研发工程师
</callout>

## 5.1 关键规则

<callout emoji="warning" background-color="light-yellow">
- **"取消"**：创建了长清单后，取消按钮置灰不可取消
- **"删除"**：只有草稿状态的单据可以删除
- **"转派"**：离职交接或工作变动可转派给其他研发工程师
- **上传附件大小 ≤ 20M**
</callout>

## 5.2 寻源需求创建

1. 主菜单 → SOR 管理 → 寻源需求管理 → 新建
2. 填写寻源需求名称、项目编码、寻源需求描述 → 保存
3. 上传支持材料 → 点击发布
4. 发布后采购项目经理收到任务并分配给采购员

## 5.3 SOR1 创建与升版

### 创建 SOR1

1. 点击创建 → 填写 SOR 名称 → 选择功能分组及项目编码
2. 选择零件（支持**批量导入**：下载模板 → 填写 → 导入）
3. 添加 SOR 附件 → 启动审批流程

### SOR 升版

- 只能对**已发布/退回**的 SOR 升版
- 版本号自动 +0.1（如 1.0 → 1.1）
- 可删除/新增零件，修改单车用量/装配比例，但**不能修改项目**
- 置灰数据不可修改

## 5.4 ESI 创建与升版

### ESI 创建

1. SOR 管理 → ESI 管理 → 新建
2. 维护带星号的基本信息 → 下一步
3. 维护 ESI 服务描述 → 上传附件 → 启动审批

### ESI 升版

- 只能对**已发布**状态的 ESI 升版
- 版本号自动 +0.1
- 审批人自动集成，支持手动编辑

## 5.5 预选供应商审批 & 评审

**审批流程：** 采购工程师 → SQE/研发工程师 → 研发工程师 → SQE/研发主管 → 采购主管 → 车型平台负责人

**评审操作：**
1. 收到待办（PC 端或飞书端）
2. 填写研发意见 → 上传附件 → 启动审批
3. 审批通过后飞书收到提醒

## 5.6 长清单管理

### 长清单审批

- 首页待办或小米审批收到审批单据
- 操作：**通过** 审批 / **否决** 驳回 / **转派** 转给他人
- 通过时**必填**审批意见及附件

### 长清单评审

- 首页待办收到评审任务
- 填写研发意见/原因（必填）→ 附件（选填）→ 启动审批
- 审批人由组织架构自动确定

# 六、TAKO 供应商门户操作手册（业务端）

<callout emoji="pushpin" background-color="light-green">
**内部登录地址：** https://tako.ev.mioffice.cn/
集成 EP（商务）、SCM（物流计划）、SQMS（质量）、SRM（对账结算）四大系统，统一入口跳转。
</callout>

## 6.1 新供应商注册（场景1：无 P 账号）

<callout emoji="clipboard" background-color="light-blue">
**完整流程 4 步：** 采购邀请 → 采购审核企业信息 → 领导审核账号 → 供应商签署 NDA
</callout>

### 第一步：采购发起邀请

登录 https://tako.ev.mioffice.cn/ → 供应商及人员 → 邀请供应商 → 填写信息 → 提交

**必填字段：**

| 字段 | 说明 |
|------|------|
| 供应商名称 | 全称，系统校验真实性 |
| 注册地区 | 中国大陆 / 港澳台或境外 |
| 统一社会信用代码 | 系统校验真实性 |
| 手机号 | 纯数字，唯一，接收通知 |
| 邮箱 | 唯一，不能用 xiaomi.com |
| 姓名 | 须与身份证一致（激活时校验） |
| 姓氏拼音 / 名字拼音 | 字母 |

提交成功后，系统发邮件提醒供应商注册企业信息。

### 第二步：采购审核企业信息

登录 EP 系统 → 首页待办 → 审核企业注册信息 → 检查无误 → 注册通过

### 第三步：领导审核账号 → 供应商激活 P 账号

- 采购领导在小米审批中收到审核申请 → 审核通过
- 供应商收到激活邮件/短信 → 点击"验证身份"完成认证
- **重置密码**：https://account.mioffice.cn/forget/index

### 第四步：签署 NDA 协议

- 供应商登录 https://ep.ev.mi.com → 签署 NDA → 上传签署文件
- 采购在 EP 系统审核 NDA → 完成

## 6.2 新供应商注册（场景2：已有 P 账号）

只需完成 **注册企业信息 + 签署 NDA** 两步（无需账号申请和激活）。

4. 收到 NDA 签署邮件 → 登录 ep.ev.mi.com 签署 → 等待采购审核

### 场景2：已有 P 账号

1. 收到采购邀请邮件 → 注册企业信息
2. 收到 NDA 签署邮件 → 登录签署 → 等待采购审核

**必填字段：** 手机号、邮箱、姓名、姓/名字拼音、人员类型（自有/VMI）、配置权限
