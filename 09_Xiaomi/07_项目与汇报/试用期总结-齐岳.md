## 成果2：CLI 基础建设，和 FDE&Agent 模式初步探索

- **目标：**以采购业务为试验田，探索"数据基座 → 业务封装 → 智能应用"的三层实现路径。先在寻源定点域落地 CLI + Skill，验证方法论可行性；再将同一思路延伸至订单域，以FDE模式探索自动下单 Agent 。
- **职责：**梳理采购域CLI，建设
- **CLI & Skill 层方案：**

  - **场景：**零件定点全流程涉及 SOR、预选、询报价、物流确认、定点签约等多个分散节点，链条冗长、状态难追踪；采购、DRE、SQE、物流等岗位需求各异，缺乏统一查询入口。单条 CLI 只能完成原子查询，实际业务场景往往需要跨域组合（如某供应商是否可以创建定点申请单需串联多条指令）。

  - 定义 17 个 CLI 指令，覆盖供应商、SOR、RFQ、定点申请单四大业务域。采用原子化设计，统一入参规范、标准化出参结构、模块间独立解耦，为上层 Skill 和后续跨域复用提供标准化数据调用基座。
  - 基于 CLI 组合封装业务 Skill，将多步查询编排为端到端的业务流程。既可独立供业务人员使用，也为后续跨域复用积累可移植的封装模式。

# 思考与总结

### 对采购业务的思考

- 采购业务正进行端到端流程梳理框架，形成从上往下驱动的业务管理理念
- 流程性业务（如定点周期、框架合同签署等）已初步落地，但在全局成本管控、TCO 全生命周期分析、变更精细化管理、品类战略管理等纵深维度仍有提升空间
- 未来可围绕"成本可见性"和"供应商和品类策略"两个方向深耕，推动采购从流程驱动向价值驱动转型

### EP发展规划

- 经过前序建设，EP 已具备流程级可用性及可见性，有了良好的基础——定点、框架协议、价格等核心流程均可在线承载并实现状态追踪。报价细项项目将寻源定点的成本穿透能力从出厂价下探至材料费与制造费层级；框架协议升级则强化了价格模块的结构化管理能力
- 现有能力偏重采购流程流转，在供应商深度管理、品类差异化运营、全生命周期成本管理等纵深维度仍有短板
- 从四层架构看，数据采集层与数据汇聚层已相对成熟，但分析模型层（成本模型、价格指数、Should-cost）与复盘决策层（根因分析、自动纠偏、基线回写）相对欠缺，制约了从"数据可见"到"数据驱动决策"的跃迁
- 从全链路成本可见性的视角，当前成本可见性集中在定点环节的报价拆解，但成本的全生命周期——从设计阶段的 Should-cost 预估、定点阶段的竞价博弈、量产阶段的价格波动与变更影响、到回收阶段的残值核算——尚未形成端到端的贯通。以报价细项为切入点持续充实成本数据采集，为分析模型层的成本模型与 Should-cost 因子库积累数据基础；以 CLI + Skill + Agent 的技术路径为样板，探索四层架构在采购域的轻量化落地模式；同时从系统层面，思考如何在流程层已有模块的基础上，抽象全链路成本管理能力
- 下一阶段以 AI 为核心驱动力，同时实现提效与赋能：借助 AI 实现高频操作的流程自动化，减少人工介入；同时将 AI 嵌入分析模型层与复盘决策层，让采购团队具备自助成本拆解、业务判断与异常预警能力，在提升效率的同时增强业务洞察深度

# 价值观陈述

### 工程师思维

以报价细项项目为例，明细报价是业内普遍想推进但难以真正落地的场景。面对这一挑战，从三个维度持续攻坚：

1. **打磨业务方案**：深入调研采购、SIE、CE 等多角色需求，反复迭代报价模板，使其适配大部分场景
2. **攻克技术难题**：在 SVC 排期受限、无法提供接口的情况下，主动梳理数据入湖方案与数据库结构，聚合跨系统数据
3. **敢想敢干**：各方团队协同钻研，最终将一个"业内难落地"的场景变为现实

### 共创共识

作为新人，共创共识是试用期中感受最深的一项价值观。通过参与 4 月共创会与 7 月立项会，切身体会到这一理念的价值：

1. **充分论证后再实施**：关键决策经过多轮共创与评审，方案成熟度更高，上线后返工率显著降低
2. **基于长期规划推进**：不局限于当下需求，而是站在 B 点目标倒推当下的建设优先级，避免"做一步看一步"
3. **共识降低协作成本**：决策过程让相关团队充分参与并理解"为什么这样做"，后续执行阶段的沟通成本大幅降低，团队可以聚焦于创新而非反复对齐
