### 25Y总结：实现直采价格要素100%线上化

- 核心定位：直采业务相关价格数据 “**线上化**”  “**合规化**”

- 关键能力：通过**“EP 价格体系补齐“**（银行承兑、返利补差、大宗原材料补差、台账失效、供应商主体切换业务核心数据），构建价格相关信息全流程合规管控体系，为供应链管理价格合规/透明/分析做基础支撑

### 26Y规划：构建数字化供应链管控体系

**业务共创：**

- **管理层共创**：[【现场会】供应链\&体系联合共创会 2025/12/6](https://mi.feishu.cn/docx/JD5PdwV1oo1MMPxhUgGcVPGVnth)

- **业务目标共识**：

    - **成本压力增加，需要挖掘更多的成本优化机会点：**如VAVE，效率提升，基础材料改进等等

    - **交付变数大，需要对供应商产能做精细化管理：**26年PSI的不确定性，可能造成一边呆滞，一边提能的情况。当前每次提能和保供都是线下多人次与供应商沟通，未形成有效数据库，需要对供应商产能做精细化管理

    - **出口合规：**汽车供应链ESG合规体系基本空白，出海面临的供应链碳管理，供应商美国来源、出口管制调查等，都需要从0搭建

    - **完善****的****供应商资源池管理：**供应商数量与复杂度激增，线下管理效率低下、风险难控，需

        - **建立准入供应商资源池取代过往的长清单**

        - **建立供应商综合绩效的评价标准**和**奖惩机制**，**规范并提升供应商表现**

        - **供应商标签在线化**，包含财务信息，全球工厂布局、客户情况等

    - **精细化管理提效：**避免随着工厂/车型/零件增加，造成的财务成本核算偏差问题\(A\+B价格，分摊剥离/多代工厂物流费补差/跨工厂暂作价偏差\)

- **数字化建设策略：26年保持现有资源投入，支持业务大需求\+小迭代需求\+运维**

    - **系统定位**：间采保持易购、供应商管理系统SMS（天星）范围暂时不拓展、其他直采相关的均在EP建设（包括品类资源池、标签管理等）

    - **需求资源共识**：直采数字化不增加HC，保持现有10人投入规模不变

    - **需求优先级共识**：优先做合规\&成本价格相关需求，供应商管理线下试运行后推动线上化，最后考虑体验类提升\-任务中台

    - **核心构建产品能力模块：**

        - **报价细项：**增强询报价模块，将价格模型拆分原子级，规范填写格式，建设标准化的价格管理模型

        - **价格联动模块**：构建价格联动模块，将零件价格成本从“事后核算”转变为"事中控制"

        - **出海供应链合规**：构建进出口调研模块，提升供应链出口合规能力

        - **任务管理工作台**：重构任务管理模块，打通上下游业务数据，将任务整体进度“一览无余”，高效管理

        - **合同管理模块**：通过复用整合集团合同系统的能力，统一合同签署入口，形成供应商合同数据库，解决“合同多，查找难”的问题

        - **供应商管理**：构建供应商管理模块\(供应商绩效，标签管理，风险筛查，品类管理\)，实现供应商分层分级、绩效及风险的全面管理

    - **立项策略：分阶段立项验收**

        - **第一阶段（26年1月\-5月）交付内容**

            - 售后价格有效期管理

            - 出海供应链调研线上化

            - 报价细项线上化

            - 框架协议优化

        - **第一阶段****建设方案**

            - 建设进出口调研模块，增强采购任务管理/询报价管理/台账管理/框架协议等模块支撑业务核心诉求

### 业务数字化建设思考

供应链0\-1阶段，为确保采购敏感数据合规，EP始终着力在业务线上化的布局上。截止目前基本实现已有场景下的业务全面线上化。



为应对2026年供应链业务的不确定性，通过本次供应链流程地图的初步梳理，识别到**新增需要流程线上化场景**：

1. 报价细项线上化（成本管理）

2. 定点产能管理线上化（交付管理）

3. 供应商绩效、品类资源池管理（品类管理、供应商管理）

4. 出口管制调研（合规管理）

5. 合同管理线上化（项目交付物管理）



同时，在流程线上化的基础上，更应致力于构建**智能**、**有机、协同**的运营体系，**EP内部\+外部的数据互联互通**是进一步提升效率管控风险的必经之路。

1. EP报价细项 x 财务成本系统（成本管理）

2. EP x MVPS x BOM（成本管理、项目管理）

3. EP x SMS（供应商绩效、风险、品类资源池）

4. EP台账\&框架原子级管理 x SAP（成本管理、框架管理）

5. EP任务中台（不同角色的任务管理）

## 26Y建设规划

### 建设目标

**提高“风险管控”能力：**

- **出海供应链合规在线化**：应对汽车出海，提升出海供应链管理能力（ESG等）的在线化管理与预警能力。

- **数据驱动价格成本管控**：通过数据驱动，实现零件价格成本从“事后核算”转变为"事中控制"。



**提升“精细化运营”能力：**

- **报价细项管理**：实现价格原子级拆分\(原材料/制造/设备等费用\)，提高采购议价能力。

- **任务管理精准把控：**通过任务整合、优先级管理与智能提示，实现对定点、设变、变价等任务整体进度，关键节点清晰把控，及时发现问题并解决。

- **合同管理：**并全面推进直采合同的线上化管理，解决“合同多，查找难”的问题。

- **供应商管理在线化**：实现以品类维度的供应商分层分级，供应商绩效及风险的生命周期动态管理。

### 建设策略

- **核心构建产品能力模块：**

    - **报价细项：**增强询报价模块，将价格模型拆分原子级，规范填写格式，建设标准化的价格管理模型。

    - **价格联动模块**：构建价格联动模块，将零件价格成本从“事后核算”转变为"事中控制"。

    - **出海供应链合规**：构建进出口调研模块，提升供应链出口合规能力。

    - **任务管理工作台**：重构任务管理模块，打通上下游业务数据，将任务整体进度“一览无余”，高效管理。

    - **合同管理****模块**：通过复用整合集团合同系统的能力，统一合同签署入口，形成合同数据库，解决“合同多，查找难”的问题。

    - **供应商管理**：构建供应商管理模块\(供应商绩效，标签管理，风险筛查，品类管理\)，实现供应商分层分级、绩效及风险的全面管理。

### 26Y里程碑计划

### 立项策略

**分阶段立项验收，分为四个阶段立项**

**第一阶段**：完成出海供应链管理 与 价格精细化管理\(报价细项线上化 \& 框架协议优化 \& 售后价格有效期管理\)

**第二阶段**：特殊场景下的MVPS**与**EP管理试点打通 \(A\+B价格联动 \& 分摊剥离预警 \& 多代工厂物流费管理/补差\)

**第三阶段**：任务中台\(任务管理中台及任务看板 \& 合同管理线上化\)

**第四阶段**：供应商管理线上化\(品类资源池管理 \& 供应商绩效 \& 标签\)
