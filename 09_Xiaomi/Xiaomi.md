# 📱 Xiaomi · EP 采购系统

> [!summary] 小米生产采购系统（EP）的产品建设与 AI 探索
> - **角色**：EP 采购系统产品经理（当前活跃），负责询报价·比价·核价·供应商管理全链路
> - **核心系统**：EP 采购系统 · CE 核价 · 比价系统 · 价格中心 · EP Agent（AI 辅助采购）
> - **10 大领域**：EP 系统 → 询报价 → 合作伙伴 → 品类管理 → 数据分析 → AI 技术 → 项目汇报 → 生产计划 → 质量管理 → 出海

> [!tip] 这段经历的核心收获
> 1. **采购系统的核心复杂度在于「规则引擎」**——CE 核价、比价逻辑、供应商评分，每个都是多层嵌套的业务规则
> 2. **AI Agent 是采购系统的下一个形态**——从「人操作系统」到「人监督 Agent」，EP Agent 是这个方向的探索
> 3. **品类管理 = 数据 × 策略 × 执行**——PRD 写得再好，没有数据支撑的品类策略就是空中楼阁
> 4. **小米的速度文化**——「天下武功，唯快不破」在 B 端也适用：先上线 MVP，再迭代优化
