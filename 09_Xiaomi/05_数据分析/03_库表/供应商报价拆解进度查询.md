> [!summary] 供应商报价拆解进度查询 SQL（v6）
> - **核心**：查询供应商报价拆解进度的完整 SQL，关联 RFQ、供应商、采购员等多表，输出拆解层级（L1未拆解~L4 BOM+VSM）
> - **要点**：基于 dwd_rfq_quotes_base_info 宽表做去重（取最新轮次）；关联 dim_md_supplier 获取供应商信息；关联 dim_ts_acct_user 获取采购员名称（注意用 id 字段关联）；按提交日期过滤
> - **关联**：[[dwd_rfq_quotes_base_info 报价基础信息宽表]] · [[dim_md_supplier 供应商主数据维度表]] · [[dim_ts_acct_user 用户账户维度表]]

# 供应商报价拆解进度查询 SQL（v6）

> **修正**: dim_ts_acct_user 关联 id 字段（非 user_id）

```sql
WITH rfq_round_agg AS (
    SELECT
        pp_rfq_id,
        COUNT(DISTINCT round_no)   AS total_rounds,
        MAX(CAST(round_no AS INT)) AS max_round_no
    FROM iceberg_nc4cloudprc_hadoop.ep.dwd_rfq_quotes_base_info
    GROUP BY pp_rfq_id
),
dedup AS (
    SELECT
        pp_rfq_id, pp_rfq_item_id, md_supplier_id,
        rfq_code, rfq_name, rfq_status, round_no,
        supplier_submit_date, qi_status,
        svc_bom_status, svc_vsm_status, bom_self_decomposed,
        ROW_NUMBER() OVER (
            PARTITION BY md_supplier_id, pp_rfq_id, round_no
            ORDER BY supplier_submit_date DESC
        ) AS rn
    FROM iceberg_nc4cloudprc_hadoop.ep.dwd_rfq_quotes_base_info
    WHERE rfq_type = 'RFQ_TYPE_FIXED_PLANT'
)
SELECT
    t.rfq_code AS `rfq编码`,
    t.rfq_name AS `rfq名称`,
    CASE t.rfq_status WHEN 'NOMINATED' THEN '已完成' WHEN 'END_ENQUIRING' THEN '询价中' ELSE t.rfq_status END AS `rfq状态`,
    s.org_name AS `供应商名称`,
    CASE s.supplier_type WHEN 'OFFICIAL' THEN '正式供应商' WHEN 'POTENTIAL' THEN '预选供应商' ELSE s.supplier_type END AS `供应商属性`,
    t.round_no AS `当前轮次`,
    rra.total_rounds AS `总轮次`,
    DATE_FORMAT(t.supplier_submit_date, 'yyyy-MM-dd HH:mm:ss') AS `最新提交时间`,
    CASE WHEN t.supplier_submit_date IS NOT NULL THEN '已提交' ELSE '未提交/流标' END AS `提交状态`,
    CASE WHEN t.svc_bom_status = 'OK' AND t.svc_vsm_status = 'OK' THEN 'L4-BOM+VSM' WHEN t.svc_bom_status = 'OK' THEN 'L3-BOM结构' WHEN t.svc_bom_status = 'NOK' AND t.bom_self_decomposed = 'OK' THEN 'L2-自行拆解' ELSE 'L1-未拆解' END AS `拆解层级`,
    COALESCE(rfq.buyer_id, rfq.pre_buyer_id) AS `采购员ID`,
    COALESCE(u_buyer.user_name, u_pre.user_name) AS `采购员名称`
FROM dedup t
    LEFT JOIN iceberg_nc4cloudprc_hadoop.ep.ods_pp_rfq rfq ON rfq.pp_rfq_id = t.pp_rfq_id
    LEFT JOIN iceberg_nc4cloudprc_hadoop.ep.dim_md_supplier s ON s.md_supplier_id = t.md_supplier_id AND s.is_deleted = '0'
    LEFT JOIN iceberg_nc4cloudprc_hadoop.ep.dim_ts_acct_user u_buyer ON u_buyer.id = rfq.buyer_id AND u_buyer.is_deleted = '0'
    LEFT JOIN iceberg_nc4cloudprc_hadoop.ep.dim_ts_acct_user u_pre ON u_pre.id = rfq.pre_buyer_id AND u_pre.is_deleted = '0'
    LEFT JOIN rfq_round_agg rra ON rra.pp_rfq_id = t.pp_rfq_id
WHERE t.rn = 1
  AND COALESCE(t.supplier_submit_date, rfq.create_date) >= '2026-05-11'
ORDER BY t.rfq_code DESC, t.round_no DESC;
```
