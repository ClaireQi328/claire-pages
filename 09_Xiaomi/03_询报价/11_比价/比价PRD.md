# RFQ 比价 PRD

---

## 1. 概述

### 1.1 背景
比价功能用于在 RFQ 询报价流程中，对多家供应商报价及 CE 核价进行横向对比分析，为定点决策提供数据支撑。

### 1.2 核心定位
- **汇总比价页面**：从 RFQ 维度总览报价情况
  - 多家供应商及 CE 核价的横向对比
  - 多家供应商中粗项成本结构占比
  - 关键报价要素（上会材料快速引用）

### 1.3 变更说明（0519 变更点）
- 原方案公式补充（详见 Excel）
- CE 核价新增字段：模具总费用、开发总费用

---

## 2. 比价轮次设计

### 2.1 设计原则
从实用性（轮次报价后才比价）和资源节省（无需每次点击均重算）角度，将比价功能改造为**按轮次比价**：
- 默认呈现报价包最新轮次
- 支持用户手动选择比价轮次
- 完整呈现全部比价轮次（比价留痕）

### 2.2 比价维度

| 层级 | 说明 |
|------|------|
| RFQ（询价单） | 比价的顶层容器，包含多个「报价轮次」 |
| 报价轮次（Round） | 每一轮 RFQ 发起 → 形成一个轮次，每轮包含多家供应商报价 + CE 核价结果，轮次是比价的最小分析单元 |

### 2.3 轮次状态设计
- 只有「已截止」轮次进入比价集合

### 2.4 数据更新与冻结逻辑

| 轮次类型 | 定义 | 数据策略 | 用途 |
|---------|------|---------|------|
| 最新轮次 | 当前最新的"未废弃轮次" | **动态更新**：供应商补报/修改→轮次截止更新；CE 核价调整→实时更新 | 默认比价展示 |
| 历史轮次 | 所有已截止且非当前轮次 | **快照冻结（Snapshot）**：在「轮次截止」时生成快照，后续不再随供应商或 CE 变更而变化 | 历史比价留痕 |

## 3. 比价前提

查看汇总比价前，充分查看比价前提，比价前提按照轮次代入。

- **样式**：模块可折叠，默认展开
- **提示**："请关注当前比价前提，如车型项目信息或量纲有误，请更新基础数据后重发报价"

### 3.1 零件-车型-单车用量-装配比例

按「项目分组」，项目内再按「车型展开」，不做跨项目合并。此部分只有零件信息，无工厂。

#### 3.1.1 RFQ 零件信息
| 字段 | 说明 |
|------|------|
| 零件号 + 零件名称 | 如 P001 进气管总成 |
| 采购零件号 + 采购零件名称 | 同 RFQ 中的采购零件号 |
| 展示顺序 | 与 RFQ 相同 |

#### 3.1.2 项目信息
| 字段 | 说明 |
|------|------|
| 项目编号 | 同 RFQ-首页基础信息中选择的项目编号，如 Mann(8042) |

#### 3.1.3 量纲
- 同步展示项目编号的整体量纲，取值自采购项目管理，车型总量纲
- **关注点**：不同轮次之间量纲可能有更新，每次比价获取最新的量纲信息

#### 3.1.4 基础车型
- 展示全部基础车型编码，过滤【已冻结】状态基础车型
- **关注点**：不同轮次之间基础车型可能有更新，每次比价获取最新的基础车型信息

#### 3.1.5 基础车型销售比例
- 基础车型编码的建议销售比例
- **关注点**：不同轮次之间销售比例可能有更新，每次比价获取最新信息
- 建议销售比例为空的基础车型需要展示

#### 3.1.6 单车用量
- 同 RFQ 基础信息的零件单车用量

#### 3.1.7 装配比例
- 同 RFQ 基础信息的零件装配比例

### 3.2 零件-年份-量纲（RFQ）

取值自 RFQ 首页-预计采购量中的零件-工厂-量纲。
- **关注点**：不同轮次之间预计采购量可能有更新，每次比价获取最新的预计采购量信息

| 字段 | 说明 |
|------|------|
| 零件号 + 零件名称 | 同 RFQ 中的采购零件号 |
| 工厂信息 | 同 RFQ 中小米工厂 |
| 展示设计 | 可与 RFQ 完全一致，可拆分字段 |

## 4. 汇总比价

### 4.1 CE 比价触发节点
- **报价比价**：轮次快照
- **CE 核价**：因可能发生在定点上会前的任意节点，故与报价的轮次快照不同，有 CE 核价更新即需更新

### 4.2 RFQ 汇总比价及备注说明

| 字段 | 来源 | 示例 |
|------|------|------|
| RFQ 编号 | RFQ 编号 | RFQ-20260303-001 |
| RFQ 名称 | RFQ 名称 | MX11 上车体 |
| 采购工程师 | RFQ 中的采购工程师 | 路梦瑶 |
| CE 工程师 | CE 核价任务中的采购工程师 | XXX |
| 轮次 | 当前轮次 | 第 x 轮 \| 共 x 轮

### 4.3 供应商 + CE 对比卡片

- 所选轮次参与报价的供应商 + CE 生成对应比价卡片
- CE 核价未提供 → 该模块也展示，金额全部 `--`
- 某家供应商流标 → 该模块也展示，金额全部 `--`

#### 4.3.1 卡片字段定义

| 字段 | 类型 | 说明 |
|------|------|------|
| 供应商/CE 核价 | 标识 | 供应商：供应商编码 \| 供应商名称；CE 核价：固定展示为"CE 核价"
| 出厂价 | 汇总值 | 见公式 |
| 含分摊到厂价 | 汇总值 | 见公式 |
| 材料费 | 汇总值 | 见公式（0519 新增） |
| 制造费 | 汇总值 | 见公式（0519 新增） |
| 管理费 | 汇总值 | 见公式（0519 新增） |
| 模具分摊单价 | 汇总值 | 见公式 |
| 开发分摊单价 | 汇总值 | 见公式 |
| 物流费 | 汇总值 | 见公式 |
| 模具分摊总额 | 汇总值 | 见公式 |
| 开发分摊总额 | 汇总值 | 见公式 |
| 一次性模具费 | 汇总值 | 见公式 |
| 一次性开发费 | 汇总值 | 见公式 |
| 一次性软模费 | 汇总值 | 见公式 |
| 模具费总额 | 计算值 | 一次性模具费 + 模具分摊总额 |
| 开发费总额 | 计算值 | 一次性开发费 + 开发分摊总额 |
| 全生命周期总金额 | 计算值 | 见公式 |
| 差异百分比 | 计算值 | 见公式 |

### 4.4 计算公式

#### 通用加权公式（出厂价/含分摊到厂价/材料费/制造费/管理费/模具分摊单价/开发分摊单价/物流费）

$$
\text{指标汇总} = \sum_{k=1}^{n} \left( \text{单零件-单工厂指标值} \times \text{单车用量} \times \text{装配比例} \times \text{销售比例} \times \frac{\text{所属车型量纲}_k}{\sum \text{全部车型量纲}_k} \right)
$$

#### 模具分摊总额 / 开发分摊总额

$$
\text{分摊费总额} = \sum_{k=1}^{n} \left( \text{单零件-单工厂分摊总金额}_k \right)
$$

#### 一次性费用（模具费/开发费/软模费）

$$
\text{一次性费用} = \sum_{k=1}^{n} \left( \text{单零件-一次性费用}_k \right)
$$

#### 模具费总额

$$
\text{模具费总额} = \text{一次性模具费} + \text{模具分摊总额}
$$

#### 开发费总额

$$
\text{开发费总额} = \text{一次性开发费} + \text{开发分摊总额}
$$

#### 全生命周期总金额

$$
\text{全生命周期总金额} = \sum_{\text{所有零件}} \left[ (\text{出厂价} + \text{物流费}) \times \text{对应 RFQ 零件量纲} \right] + \text{模具费总额} + \text{开发费总额}
$$

#### 差异百分比

$$
\text{差异百分比} = \frac{\text{其他供应商的（出厂价 + 物流费）}}{\text{该零件所有供应商中最低价的（出厂价 + 物流费）}}
$$

## 5. 成本结构饼图

- 与卡片布局一致，随轮次变更
- 包含维度：材料费、制造费、管理费
- 出厂价 = 材料费 + 制造费 + 管理费

---

## 6. 关键报价要素

### 6.1 定位
与上会材料关键字段保持一致，报价过程中可获取的数据自动带入关键报价要素表，支持用户直接上会使用，减少手动编辑，提效 + 合规。

### 6.2 关键字段

| 字段 | 公式 |
|------|------|
| 含分摊到厂价 | 出厂价 + 物流费 + 模具分摊单价 + 开发分摊单价 |
| 差异百分比 | 其他每一家的（供应商的出厂价 + 物流费单价）/ 该零件所有供应商中最低价的（出厂价 + 物流费单价） |

### 6.3 导出
- 关键报价要素支持导出
- 导出文件名格式：`RFQ-YYYYMMDD-NNN-比价.xlsx`（如 `RFQ-20260101-001-比价.xlsx`）

---

## 7. 状态与样式说明

### 7.1 流标
- **标签**：该轮次供应商未参与报价 → 打标【流标】
- **填充**：流标卡片填充灰色以示区别

### 7.2 CE 核价
- **标签**：绿色标签【CE 核价】
- **边框**：CE 核价边框绿色
- 无 CE 核价数据 → 卡片填充灰色以示区别

### 7.3 异常情况
| 场景 | 处理 |
|------|------|
| CE 核价未完成 | 金额显示 `--` |
| 供应商流标 | 金额显示 `--` |

---

## 8. 计算逻辑验证要点

| 校验点 | 说明 |
|--------|------|
| 校验点 1 | 比价的公式逻辑正确 |
| 校验点 2 | 不同轮次更新了车型项目及其销售比例，验证历史轮次数据可以正常带出 |
| 校验点 3 | CE 核价转单后，CE 核价人员不区分轮次做更新 |
| 校验点 4 | 导出功能正常 |
| 校验点 5 | 定点单通过后，不可编辑核价；定点单作废后，可以核价 |
