# 调研背景和目标

- **调研背景**

    - 调研SQMS的实际运行情况，收集一线用户对支持业务能力的核心痛点及系统体验，识别用户在产品使用过程中的实际困难与盲区。

- **调研目标**

    - 判断 SQMS 建设的需求优先级与价值回报

# SQMS系统运行现状

当前SQMS系统已初步实现了APQP/PPAP、0km索赔/二次索赔等核心业务流程的线上化管理，但功能仍处于基础阶段，各模块相对独立，端到端流程与数据尚未完全打通。

# SQMS用户访谈反馈（VOC）

根据对SQMS系统各核心模块（APQP、PPAP、二次索赔、0公里索赔）的访谈反馈，当前系统痛点可归纳为以下四个结构性层面：

- **系统性能与基础体验存在严重瓶颈**

    - **性能问题突出**：在高并发或复杂操作场景下（如页面加载、批量处理），系统响应缓慢，甚至出现卡顿、崩溃，直接影响业务处理时效。

        - 二次索赔业务量增加（月均1w单），列表页加载时间过长、甚至卡顿崩溃

        - 0km索赔单列表页加载时间过长、甚至卡顿崩溃

    - **交互不流畅**：关键筛选条件缺失、数据下载不稳定等问题频发，用户在完成基础操作时成本较高，使用阻力明显。

        - 无法按照筛选项（如项目、车型）等过滤用户所需数据

- **新业务及复杂场景支撑及适配不足**

    - **新数据同步节点设计与实际业务节奏不匹配**

        - 当前系统仅在**框架协议签署后**才同步 SQMS 零件主数据，但在实际业务中，**APQP 任务往往在框架协议签署前已启动**，导致 APQP / PPAP 任务因“零件主数据不完整”无法正常流转。为规避流程阻塞，业务侧被迫采用**手工导入零件数据**的方式，进一步引发数据重复、口径不一致与主数据混乱等问题。

    - **多供应商场景未支持**

        - 系统未能有效支持实际业务逻辑（如“一品多点”的供应商模式），导致异常单据持续积压。

    - **多工厂场景未支持**

        - EP等系统管理颗粒度精细到工厂，但PPAP任务按照零件提交，导致出现多工厂的重复数据，且无法进行合并或删除，任务数量不断累积无法关闭，系统内存在大量冗余信息。

- **端到端流程可见性和跨系统协同效率待提升**

    - **系统间流程割裂**：

        - 与 SRM、SAP、SQIR 等系统之间存在明显的数据与流程断点，业务状态（如扣款结果）无法在系统内追踪。

    - **逆向流程复杂：**

        - 信息需多次手工录入，撤销、回退等逆向流程依赖复杂的线下审批与人工对接。

    - **无APQP任务的全局视图：**

        - 用户需每天人工导出清单进行核对，系统当前无法提供稳定、可订阅的任务状态视图

    - **人员变更依赖后台改数：**

        - 针对组织调整的情况，未与HR人员管理系统打通，依赖大量的人工运维调整

- **产品与运营支撑缺失**

    - **需求流转不顺**：

        - 无专职人员负责需求梳理与推进，历史优化需求（如去年提出的功能改进）长期搁置，且因对接人员频繁变更而无人跟进。

    - **迭代资源不足**：

        - SQMS无独立迭代资源，需与整体QMS系统共同排期，在双周迭代机制下实际可投入资源有限

        - 需求实现依赖上游数据与多系统配合，进一步放大排期不确定性



当前SQMS系统面临从**基础性能、新场景适配、流程闭环到持续运营**的全链条挑战。

优化路径必须遵循**先保稳定可用，再通流程断点，后完善功能体验”**的优先级，并亟需建立固定的**产品支持机制**以保障持续迭代。

# 优化路线\&资源支持

基于当前需求梳理，SQMS 的优化路径建议遵循 **“夯实可用性、适配业务变化和复杂度、端到端链路可视性及提升易用性”** 的分阶段演进思路，逐步从问题修复型建设，过渡到具备全链路问题解决能力的质量管理平台。

同时亟需一套**稳定、可执行的需求治理与发布机制，**支撑业务的可持续发展。

**第一阶段：夯实基础功能可用性**

实现基础性能的优化，保障现有功能主链路的通顺，为后续功能深化奠定稳定底座。

**第二阶段：适配业务变化和业务复杂度**

调研并适配多工厂、多供方的新业务场景，支撑业务高速发展

拉通数据同步节点、统一跨系统数据的颗粒度，保证数据一致性及精简性

**第三阶段：端到端链路可视化、提升易用性**

与 SRM、SAP、SQIR 等核心系统的数据与流程打通，实现供应上质量管理端到端的可视化

支撑人员变更、逆向流程等任务的自动化处理效率

支持合并单据提交封功能，提升业务效率
