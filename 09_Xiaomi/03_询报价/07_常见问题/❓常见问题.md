# 飞书文档自动同步工具

## 功能说明

自动将本地 Markdown 文档同步到飞书文档，支持：
- 创建新文档
- 更新现有文档
- 批量同步内容
- 保持文档结构

## 前置准备

### 1. 创建飞书应用

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 获取 **App ID** 和 **App Secret**

### 2. 配置应用权限

在飞书开放平台为应用添加以下权限：

| 权限 | 说明 |
|------|------|
| `docx:document` | 读写文档 |
| `drive:drive` | 访问云空间 |
| `drive:file` | 读写文件 |

### 3. 安装依赖

```bash
pip install requests
```

## 配置说明

编辑 `config.json` 文件：

```json
{
  "feishu": {
    "app_id": "cli_xxxxxxxxxx",      // 飞书应用 App ID
    "app_secret": "xxxxxxxxxx",       // 飞书应用 App Secret
    "folder_token": "fldcnXXXXXX"     // 目标文件夹 token（可选）
  },
  "sync": {
    "markdown_file": "报价细项常见线上问题.md",  // 要同步的 Markdown 文件
    "document_id": "",                          // 已有文档 ID（留空则创建新文档）
    "auto_sync": false,                         // 是否自动同步
    "sync_interval": 300                        // 自动同步间隔（秒）
  }
}
```

### 获取文件夹 token

1. 打开飞书云文档
2. 进入目标文件夹
3. URL 中的 `fldcnXXXXXX` 就是文件夹 token

### 获取文档 ID

1. 打开飞书文档
2. URL 中的 `doccnXXXXXX` 就是文档 ID

## 使用方法

### 方法一：直接运行脚本

```bash
# 设置环境变量
export FEISHU_APP_ID="cli_xxxxxxxxxx"
export FEISHU_APP_SECRET="xxxxxxxxxx"

# 运行同步
python sync_to_feishu.py
```

### 方法二：使用配置文件

```bash
python sync_to_feishu.py --config config.json
```

### 方法三：同步到指定文档

```bash
python sync_to_feishu.py --document-id doccnXXXXXX
```

## 高级功能

### 1. 文件监控自动同步

创建 `watch_and_sync.py`：

```python
import time
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler
from sync_to_feishu import FeishuDocSync

class MarkdownHandler(FileSystemEventHandler):
    def __init__(self, syncer, document_id):
        self.syncer = syncer
        self.document_id = document_id

    def on_modified(self, event):
        if event.src_path.endswith('.md'):
            print(f"检测到文件变化: {event.src_path}")
            self.syncer.sync_markdown_to_doc(event.src_path, self.document_id)

def main():
    # 配置
    APP_ID = "your_app_id"
    APP_SECRET = "your_app_secret"
    DOCUMENT_ID = "doccnXXXXXX"

    syncer = FeishuDocSync(APP_ID, APP_SECRET)
    handler = MarkdownHandler(syncer, DOCUMENT_ID)
    observer = Observer()
    observer.schedule(handler, path='.', recursive=False)
    observer.start()

    print("开始监控文件变化...")
    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
    observer.join()

if __name__ == "__main__":
    main()
```

### 2. 批量同步多个文档

创建 `batch_sync.py`：

```python
import os
from sync_to_feishu import FeishuDocSync

def batch_sync():
    APP_ID = "your_app_id"
    APP_SECRET = "your_app_secret"
    FOLDER_TOKEN = "fldcnXXXXXX"

    syncer = FeishuDocSync(APP_ID, APP_SECRET)

    # 要同步的文件列表
    files = [
        "报价细项常见线上问题.md",
        "其他文档.md"
    ]

    for file in files:
        if os.path.exists(file):
            try:
                doc_id = syncer.sync_markdown_to_doc(file, folder_token=FOLDER_TOKEN)
                print(f"✅ {file} -> {doc_id}")
            except Exception as e:
                print(f"❌ {file} 同步失败: {e}")

if __name__ == "__main__":
    batch_sync()
```

## 常见问题

### Q1: 同步失败，提示权限不足

**解决**：检查飞书应用权限是否配置正确，需要 `docx:document` 权限。

### Q2: 图片无法同步

**说明**：当前版本暂不支持自动同步本地图片，需要手动上传或使用图床。

### Q3: 文档格式丢失

**说明**：Markdown 到飞书文档的转换会保留基本格式（标题、列表、文本），复杂格式可能需要手动调整。

### Q4: 如何更新已有文档？

**解决**：在配置文件中填写 `document_id`，脚本会自动更新该文档。
